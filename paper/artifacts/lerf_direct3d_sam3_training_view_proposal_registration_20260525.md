# SAM3 Training-View Proposal Registration

This audit tests a label-free object-aware direct-3D score fusion branch. The
branch uses official SAM3 masks cached on training views only. It does not call
official SAM3 on query/evaluation RGB images, and it does not use LERF GT masks
when building proposal memory.

## Protocol

- Base evaluator: `radio_gs/scripts/eval_lerf_direct_3d_selection.py`
- Cache root: `output/radio_gs/foundation_cache_sam3_modelscope_mapped_trainviews`
- Fusion point: primitive text scores are fused before threshold selection.
- Main tested setting: `alpha=0.8`, `gate=all`, `min_probability=0.55`.
- Query-conditioned setting: uses `mask_query_indices` from the SAM3 cache and
  only fuses a query score with masks generated by the same text query.

## Result

| Variant | Figurines | Ramen | Teatime | Waldo | Macro |
|---|---:|---:|---:|---:|---:|
| Direct field baseline, best threshold | 0.4261 | 0.5711 | 0.5226 | 0.2757 | 0.4489 |
| SAM3 proposal registration, best threshold | 0.4434 | 0.5100 | 0.4819 | 0.2883 | 0.4309 |
| Delta | +0.0173 | -0.0611 | -0.0407 | +0.0126 | -0.0180 |

Fixed `thr0p25` macro mIoU also drops from `0.4380` to `0.4135`.

The query-conditioned variant is not better: it reaches `0.3985` on Figurines
and `0.4587` on Teatime, below the matched baselines.

## Conclusion

Do not promote this branch. SAM3 training-view proposals give useful evidence
for object-aware registration on Figurines and Waldo, but the same global rule
damages Ramen and Teatime. The failure mode is consistent with proposal
coverage/association noise: object proposals are not stable enough to replace
the compact direct primitive scores across scenes.

The paper should keep the current compact direct field / VPR-trained primitive
readout as the main direct-3D path and mention SAM3 proposal registration only
as an implemented negative diagnostic or future object-memory direction.
