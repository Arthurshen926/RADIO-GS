# TPAMI Reproducibility Package

Date: 2026-06-01

This note is the reproducibility entry point for the TPAMI-format GaussFM
submission package. It separates three levels of evidence:

1. Paper-package checks that can be run without datasets.
2. Canonical result registries and source artifacts used by the manuscript.
3. Data-dependent rerun commands for the three benchmark tracks.

The paper-facing method name is **GaussFM**. The repository and implementation
name remain **RADIO-GS**.

Large checkpoints, datasets, rendered masks, and feature caches are indexed in
`paper/artifacts/tpami_large_asset_release_manifest_20260601.md`; they are not
duplicated in the small paper-artifact snapshot.


Expected state for the current package:

- The main TPAMI draft compiles to `paper/radio_gs_tpami.pdf`.
- The supplementary material compiles to
  `paper/radio_gs_tpami_supplement.pdf`.
- The three log-grep commands print no matches.
- `validate_paper_claims.py` prints `paper claims ok`.
- `sha256sum -c paper/artifacts/checksums.txt` reports `OK` for all tracked
  artifacts.

## 2. Canonical Paper Results

The canonical result registry is:

```text
paper/artifacts/final_rows.yaml
```

The registry is intentionally stricter than the manuscript tables. It records
the exact promoted row, protocol boundary, caveat, and whether a row is locally
reproduced.

| Track | Canonical row | Source artifact | Main metrics |
| --- | --- | --- | --- |
| T1 LERF rendered-view OVS | `ctfgs_rendered` | `paper/artifacts/final_rows.yaml`; `paper/lerf_ovs_main_table.tex` | 64.98 mIoU / 82.68 Acc |
| T2 LERF direct 3D selection | `ctfgs_compact_prompt_ensemble_score_component_guard_thr0p55` | `paper/artifacts/final_rows.yaml`; `paper/lerf_ovs_main_table.tex` | 54.36 mIoU / 80.84 Acc@0.25 |
| T3 VALA-aligned ScanNet-8 point query | `radio_gs_dino_cv_contextual_knn_scene_mean_support` | `paper/artifacts/final_rows.yaml`; `paper/scannet_published_context_table.tex` | 36.55 / 42.78 / 57.85 mIoU on split 19/15/10 |

Important scope boundaries:

- The main LERF and ScanNet tables use the reproduced protocols reported in the
  manuscript. Historical compatibility/source-context notes remain in separate
  audit files only for traceability.
- The direct-3D compact row does not read a multiview-registration feature cache
  and does not call an official RGB SAM decoder at inference. It does use a
  GT-free RGB/color-edge score-component support calibration; the strict no-RGB
  one-map ablation is reported separately in
  `lerf_direct3d_compact_readout_ablation_20260528.{md,json}`.
- The ScanNet row is a VALA-aligned direct point-query feature probe, not a
  full ScanNet semantic segmentation leaderboard.

## 4. Data-Dependent Evaluation Templates

The following templates document the promoted protocol knobs. Scene-specific
config and checkpoint paths must point to the trained GaussFM checkpoints used
for each scene.

### T1: LERF Rendered-View OVS

```bash
/root/miniconda3/envs/cybersim_agent/bin/python \
  radio_gs/scripts/eval_lerf_grounding.py \
  --scene all \
  --config "radio_gs/configs/<lerf_scene_config_with_{scene}>.yaml" \
  --checkpoint "output/radio_gs/<lerf_scene_run_with_{scene}>/checkpoints/best.pth" \
  --label_dir /mnt/pool/sqy/3d_understanding/lerf_ovs/label \
  --output_dir output/radio_gs/freeze_eval \
  --threshold_mode fixed \
  --iou_threshold 0.60 \
  --scoring softmax_scene \
  --mask_refinement sam3_prompt_mask_head \
  --sam3_prompt_mask_head_initial_refinement peak_component \
  --sam3_prompt_mask_head_require_peak_in_refined \
  --sam3_prompt_mask_head_apply_to rendered
```

The paper row is sourced from
`paper/artifacts/lerf_rendered_grounding_feature_sam3_boundary_20260525.json`.
The boundary head is feature-only; it does not invoke an official RGB SAM
decoder at evaluation time.

### T2: LERF Direct 3D Object Selection

Run once per LERF scene:

```bash
/root/miniconda3/envs/cybersim_agent/bin/python \
  radio_gs/scripts/eval_lerf_direct_3d_selection.py \
  --scene <figurines|ramen|teatime|waldo_kitchen> \
  --config "radio_gs/configs/<lerf_scene_config>.yaml" \
  --checkpoint "output/radio_gs/<lerf_scene_run>/checkpoints/best.pth" \
  --label_dir /mnt/pool/sqy/3d_understanding/lerf_ovs/label \
  --output_dir output/radio_gs/lerf_direct3d_score_component_guard_20260528 \
  --score_source direct \
  --selection_mode score_threshold \
  --score_threshold 0.55 \
  --selection_min_ratio 0.005 \
  --selection_max_ratio 0.05 \
  --scoring softmax_scene \
  --prompt_templates "{query}|a photo of {query}|a photo of a {query}|the {query}|a {query} object" \
  --use_point_summary_adapter \
  --point_summary_adapter_valid_mask_mode opacity \
  --direct_primitive_confidence_mode opacity \
  --direct_primitive_confidence_blend 1.0 \
  --mask_refinement rgb_grabcut_score_component_guard \
  --score_component_guard_min_mass_fraction 0.50 \
  --score_component_guard_max_components 2 \
  --component_guard_min_total_pixels_for_multicomponent 6000 \
  --silhouette_threshold 0.70 \
  --save_masks
```

The exact promoted metrics are recorded in
`paper/artifacts/lerf_direct3d_score_component_guard_20260528.{md,json}` and
mirrored in `final_rows.yaml`.

### T3: VALA-Aligned ScanNet-8 Direct Point Query

The promoted ScanNet protocol follows the VALA-aligned eight-scene subset:

```bash
/root/miniconda3/envs/cybersim_agent/bin/python \
  radio_gs/scripts/eval_scannet_pointcloud_radio_gs.py \
  --scene_list scene0000_00,scene0062_00,scene0070_00,scene0097_00,scene0140_00,scene0347_00,scene0400_00,scene0590_00 \
  --prepared_root dataset/scannet_og \
  --config "radio_gs/configs/generated/scannet_dino_cv/scannet_og_hybrid_v67_dino_cv001_b2_s32768_ft20_{scene}.yaml" \
  --checkpoint "output/radio_gs/scannet_og_{scene}_v67_dino_cv001_b2_s32768_ft20/checkpoints/best.pth" \
  --output_dir output/scannet_pointcloud_eval/vala8_dino_cv_knn16_cand80_scene_mean_a045_smoothk12a1_20260524 \
  --class_splits 19,15,10 \
  --query_mode knn \
  --k 16 \
  --candidate_k 80 \
  --chunk_size 8192 \
  --opacity_filter_mode auto \
  --logit_calibration scene_mean \
  --logit_calibration_alpha 0.45 \
  --logit_smoothing spatial_knn \
  --logit_smoothing_k 12 \
  --logit_smoothing_alpha 1.0 \
  --logit_smoothing_iterations 1 \
  --prompt_templates "{query}" \
  --text_embedding_cache checkpoints/siglip2_scannet_text_embeddings_v67_knn.pt \
  --device cuda
```

The registry validator checks that the ScanNet source JSON still contains these
protocol arguments before the row can be treated as paper-facing.

## 5. Required Provenance Guards

Before using any regenerated paper numbers, run:

```bash
/root/miniconda3/envs/cybersim_agent/bin/python \
  radio_gs/scripts/validate_final_rows_registry.py

/root/miniconda3/envs/cybersim_agent/bin/python \
  radio_gs/scripts/validate_paper_claims.py --root /root/RADIO-GS

bash radio_gs/scripts/run_repo_python.sh \
  radio_gs/scripts/verify_submission_provenance.py \
  output/radio_gs/reports/submission_freeze_manifest.json \
  --check_paths --root /root/RADIO-GS
```

`validate_paper_claims.py` protects against common paper drift:

- promoting mean+std Direct3D threshold sweeps instead of the fixed compact
  score-component row,
- describing ScanNet as a full semantic segmentation leaderboard,
- adding unpublished or unavailable comparison rows to the current comparison,
- mixing historical source-context rows into the paper-facing reproduced
  benchmark tables.
