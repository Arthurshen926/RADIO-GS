# GaussFM / RADIO-GS LaTeX Draft

Active TPAMI manuscript entry points:

```bash
cd paper
latexmk -pdf -interaction=nonstopmode -halt-on-error radio_gs_tpami.tex
latexmk -pdf -interaction=nonstopmode -halt-on-error radio_gs_tpami_supplement.tex
```

The paper-facing TPAMI draft follows the June 15 storyline:

- Main concept: compact reconstructive RADIO Gaussian feature memory.
- Main tables: LERF-OVS 2D/3D and VALA-aligned ScanNet-8 same-protocol reproduced
  comparisons.
- Provenance: `paper/artifacts/final_rows.yaml`,
  `paper/artifacts/reproduced_benchmark_update_20260615.md`, and the optional
  audit table `paper/benchmark_provenance_table.tex` retained outside the main
  manuscript.
- Figure generation: `paper/scripts/draw_method_figures.py` writes
  `paper/figures/figure1_overall_framework.*` and
  `paper/figures/figure2_method_details.*`.
- The framework-figure prompt is stored in
  `paper/figure_prompts/radio_gs_framework_prompt.md`.
- Storage and failure-analysis tables are generated by
  `radio_gs/scripts/build_storage_footprint_report.py` and
  `radio_gs/scripts/build_lerf_failure_analysis.py`.

`archive/radio_gs_draft_legacy_cvpr.tex` is a legacy working draft retained only
for traceability. It is not an active submission entry point and should not be
included in a TPAMI upload package.
