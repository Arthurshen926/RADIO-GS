同一个 RGB-assisted Registered-2D compiler，能否把两种 reference prompt 变成一个可信的 Gaussian posterior？

本原型只回答 Choose the shared RGB-assisted reference-prompt query mechanism for NVOS and SPIn-NeRF： 在两个 LUDVIG-online Evaluation Contract 已授权全部注册 captured RGB、但仍禁止 Gaussian-rendered RGB 的前提下，冻结哪一个 Query-Time Vision Model、prompt sanitizer、多视角证据构造、候选边缘化、校准、Query Workspace 生命周期与最小 pilot，才能让 NVOS positive scribble 和 SPIn-NeRF complete mask 共用一个 task-agnostic compiler。

原型假设与边界 这是状态模型，不读取图片、不调用 SAM3、不运行 benchmark、不制造分数。它默认使用已选 sidecar-free D512/L512 Single Compact Feature Field 和 Boundary-Calibrated Field Region Hierarchy；本 ticket 只决定 Query 机制。模型质量只能由后续 sealed exact-contract pilot 证明。

可点击的全视角证据与 Gaussian posterior 示意

e[k,g] = robust_sum_v Wᵥᵀ mask(v,k) / Wᵥᵀ1
α[k] ∝ exp(prompt-consistency(k) + source-frozen-quality(k) + field-support(k)); preserve all legal k
p[g] = sigmoid(global-affine(anchor[g], Σₖ α[k]e[k,g], field-hierarchy-marginal[g])), binary p≥0.5
对象区域：蓝边表示最终 Gaussian Query Posterior ≥ 0.5。
干扰区域：顺序相关 self-training 或 winner-take-all 容易放大一次错误。
背景/遮挡：positive scribble 未标注区保持 unknown；complete-mask complement 才是 negative。
SAM3 只消费已授权 captured RGB；投影提示来自 posterior/geometry，不是 Gaussian-rendered RGB。
紫色诊断层永远在 evaluator 后面 Vision candidate、registration、field representability ceilings 只能在所有候选 posterior、predictions 与 Query Abstentions 封存后计算。它们只归因，不能选 mask、候选、阈值、field checkpoint 或 retry。
