同一个 RGB-free reference-prompt completion，能同时服务 NVOS 与 SPIn-NeRF 吗？

本原型只回答 Choose RGB-free reference-prompt completion for NVOS and SPIn-NeRF： 在 sidecar-free D512/L512 Single Compact Feature Field 上，如何把 NVOS 正负 scribble 与 SPIn-NeRF 完整 reference mask 编译成同语义的注册证据，如何只用冻结字段补全到一个 Gaussian Query Posterior，以及怎样用最小 exact-contract pilot 把字段不可表示与 prompt completion 失败分开。

原型假设与边界 这是逻辑原型，不读取数据、不运行 benchmark、不制造分数。它假设已冻结的 Boundary-Calibrated Field Region Hierarchy 可从合法冷状态重建；本 ticket 决定的只是 reference-prompt compiler、INSTANCE posterior update、协议分区与归因证据。
