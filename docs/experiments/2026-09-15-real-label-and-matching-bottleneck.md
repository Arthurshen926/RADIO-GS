# 真实标注与匹配瓶颈：执行结果（2026-09-15）

完成两个场景 16 次新训练、真实 LERF 多边形文本评估、三类 query 伪标签复核、第二个初始化种子、去 RADIO、模板控制、阈值无关排序指标及几何分阶段诊断。没有候选通过全面替代默认配置的质量门槛。历史性能基线继续保留。

## 已落实的实现

- 训练新增可选 latent dimension、初始化 seed、双向原生 query-region 关系监督、训练输入 SVD 固定投影基、仅软文本监督对照。默认仍为 64 维、seed42，新增监督和投影选项全部关闭。
- 双向关系同时约束每个区域的 query 排序与每个 query 的区域排序；作用于实际单位元素方向的贡献均值，教师头不能独立吸收这项损失。词表和图像 query bank 仅来自训练资产，轮转合法训练视角。
- 固定投影基是训练词表与训练图像编码的非中心化 SVD，不读取验证 query；不是居中 PCA，不引入推理偏置。
- 软文本控制同时关闭硬文本 2D/3D membership 和硬文本 membership 边界；保留原生软匹配关系以及图像、提示主监督。报告中的文本 membership 仍是诊断监控，明确不作为该候选的训练损失。
- 新真实标注评估器使用在线原生文本编码、冻结全场景渲染、已有 COLMAP 相机；禁止教师特征、episodes、queries 缓存访问。没有目标 RGB 编码、负词校准或阈值搜索。
- 评估增加正确处理并列分数的 AP/AUROC，避免仅用一个阈值的 IoU 判断能力改善。保存首个标注帧、按类别顺序选前三个存在目标的 GT/响应/预测图，不按好坏挑样例。

## 评估合约与范围

真实标注来自本地 LERF-OVS 多边形。figurines 4 帧、21 类、56 个类别-视角任务；ramen 7 帧、14 类、71 个任务。标注帧均不属于当前语义训练帧。它们可能在历史项目开发中使用过，所以属于真实 GT 的开发评估，不是新的最终盲测。几何先验的可见性范围另行记录，不能声称几何也完全未见。

固定宽度 480，按标注比例取高；类别字符串原样编码。完整冻结场景先遮挡，再用有效元素贡献归一化；有效贡献比例 >0.5 且 alpha>1e-8 才预测，未覆盖正样本计漏检。报告观察任务宏平均及类别宏平均。该合约不同于历史 selected-only、generic-negative relevancy 等协议，历史约0.475的结果不能直接相减。

## 因果证据和未通过的方向

1. 步数翻倍能把 figurines 训练图像/提示 IoU 提至接近0.998，但真实文本 IoU仍约0.056；128维也未明显改善真实标签。不能继续把核心问题归因于步数不足或64维太小。
2. 原生到学习后文本两两相似关系的 Pearson 为 figurines 0.032、ramen 0.199；其余原生图像关系也明显失真。独立教师重建头的低损失不保证最终 query 空间保持能力。双向匹配关系改善了图像关系，却没有修复文本关系失真。
3. 双向关系在两个初始化种子上改善真实文本固定阈值 IoU，去 RADIO也能运行并有类似趋势；但是两个场景 AP均下降，figurines提示也下降。因此保留为实验，不推广为整体改善。
4. 源输入 SVD固定基没有解决问题：真实 IoU约0.020/0.006，图像伪标签也退化。保留原生 query关系本身不足以保证学出的地图与之匹配。
5. 硬文本监督只有5/6类。figurines为 camera/remote/toy/wall/water；ramen为 banana/blanket/floor/paper/rock/wall。它们是固定词表 top1+微小margin筛选，未核验语义正确性。不能据高训练 IoU声称开放词汇能力已重建。词表字符串含 a photo of a 前缀，原始字符串零交集不能直接当作概念零交集；另存归一化词表审计。
6. 同样使用源训练的 a photo of a 模板后，基线真实 IoU约0.021/0.040，未解释低分。该结果是明确输入模板控制，不用来挑模板汇报最优。
7. 去掉硬文本只保留软关系也未成为可用修复。相对关系不标定绝对membership；尤其ramen文本后验不能通过既有0.5阈值。仍需要可靠的实际召回/存在性监督，不能用软教师关系完全替代它。

## 几何细节：已定位的限制

在 figurines固定前三个已接受mapping帧3/6/8上，增加双轴有符号深度边缘诊断，并分开原始点、固定足迹、像素足迹和单视角1cm体素化。没有读取留出预测数组或语义标签。

同视角原始点使用固定7.5mm切向sigma时，水平边缘幅度中位数仅参考的0.0068–0.0102；改成0.35像素足迹后达到0.703–0.726且覆盖100%。但1cm体素化后再使用像素足迹，覆盖降至36.7%–56.7%，说明不能仅缩小现有高斯：采样密度和足迹必须一起处理。当前融合载体的水平边缘比约0.066–0.072。

这些是依赖同视角参考的分阶段控制，不是可部署重建结果；并未隔离所有多视角筛选误差。当前几何文件和所有特征分配保持原哈希，没有将这个自参照结果用来推广新几何。

## 验证与下一步

- 相关12个测试文件65项通过；包含原生投影基的余弦原点保持、软匹配教师梯度隔离、单区域多query约束、排序并列分数处理。
- 两场景实际GPU比较稀疏贡献与直接渲染的元素后验，最大误差分别5.96e-7/4.77e-7；不是新评估渲染器换算错误导致约0.05的低分。
- 16次训练均完成全部任务预算、可见元素梯度覆盖、文件哈希与冷加载响应一致性核验。去RADIO候选的原生三类query另做新进程缓存禁读验证，单独冷报告记录结果。
- 下一步必须建立源侧可靠的文本—区域与跨视角身份/存在性监督，并同时约束匹配空间和绝对响应；不能继续把有限词表伪分类当作任务真值。几何改进需要源侧自适应采样与足迹联合设计，重新构造后必须重建全部特征分配。
- 未完成：正式同合约历史主线比较、独立3D真值、图像/提示真实任务GT适配、更多场景与最终盲测。这些没有被本轮文本GT评估替代。
