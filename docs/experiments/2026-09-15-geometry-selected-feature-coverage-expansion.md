# 按几何选择视角并扩充四教师特征覆盖

本轮实际完成新增六个训练视角的精确投影、四教师特征、三类 query 监督、原生 query 输入，以及原覆盖/扩充覆盖两组同为 408 步的训练。几何始终冻结，验证帧仍为 31、35，没有加入训练。

## 选择与覆盖

新增可复用 `radio_gs/geometry/coverage_selection.py` 与 `scripts/audits/select_geometry_coverage_views.py`。在几何 mapping 帧与现有原生 SAM 帧索引的交集内选择，但选择评分只读取几何贡献，不读取 SAM 内容或语义特征。排除验证帧后，以新增可见元素数贪心选择六帧；并列按帧号处理。原六个训练帧保持。

新增顺序：109、76、131、101、105、90。训练几何可见元素从 92956 增至 255984（总数 362198，25.66%→70.67%）。验证可见但训练不可见元素从 13306 降至 4346。全图可见性不等价于所有特征均已充分训练。

四个原验证区域的训练覆盖比例分别从 1.96%、97.17%、0%、82.67% 变为 69.34%、97.70%、66.40%、99.14%。新资产区域编号变化，但已逐元素验证四个区域的 2D mask 与 3D region probability 完全一致。query encoder identity 也一致。

新资产目录：`/mnt/pool/sqy/results/RADIO-GS/output/three_query_coverage_expansion_20260915/ramen`。四教师全部提取，200 个 SAM 区域；训练文本/图像/提示任务为 50/136/136，验证仍各 4 个任务。没有将观测 mask 强制置真。原始资产保留。

## 同预算训练和共同标签域评估

训练前记录 408 步协议，两组共享 SigLIP adapter，四教师及其权重不变，覆盖全部任务。每步数量相同，训练任务构成和每任务重复数不同；这不是完全相同的每样本训练预算。

扩充支持后，可评估像素也增加，直接比较各自报告不公平。因此评估工具新增 `--field-root` 和 `--reference-run`：模型加载仍核对几何及编码器身份；预测使用模型完整支撑，标签有效范围限制为与参考模型的共同观测支撑。这里两组都使用原始 query/标签资产，且检查每个任务的已知正负样本数和已知比例完全相同。

下表为全部任务分母、未定义 IoU 计零的共同已知支撑伪标签 IoU：

| 同为 408 步 | 文本 | 图像 | 原始提示 |
|---|---:|---:|---:|
| 原六帧训练 | 0.906995 | 0.612707 | 0.498963 |
| 新十二帧训练 | 0.924427 | 0.499576 | 0.557508 |

文本与提示改善，但图像下降，不能推广为全面优于旧版。新覆盖区域自身也应评估：扩充版在自身可评估范围为 0.578421/0.524857/0.611059；文本和图像/提示的已知像素比例分别约 10.64%/9.42%，仍远非全图标注。全部结果都是开发伪标签诊断，不是历史主线同口径 benchmark。

两次实际训练均完成所需监督梯度和保存/冷加载一致性检查；新增选择器验证排除验证帧、确定性并列和输入不变。相关测试 23 项通过；代码差异空白检查通过。

下一步重点是扩充后图像 query 的监督构成及身份一致性：先比较原有任务与新加入任务的冲突/覆盖，再检验保持原有任务训练频次的调度。不要因覆盖增加就假定图像身份表征改善，也不要用验证标签挑选新增训练视角。本轮未推广性能主线。
