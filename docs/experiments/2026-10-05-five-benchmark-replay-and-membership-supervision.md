## 共同机制不能只做“扩大范围”

对本轮已经落盘的最终输出，按原评价真值补充纯度 TP/预测、覆盖 TP/真值。
LERF/NVOS 为各自二维输出，ScanNet 为类别点集合，UQIS 为实例顶点集合；这些不是同一标签域，
不能把数字差额当成模块损失比例。它们可以检验各任务是否在漏目标或收进太多背景。

|实际输出|纯度|覆盖|
|---|---:|---:|
|LERF 实际选取投影|75.286|82.173|
|NVOS 目标视图响应|95.698|90.100|
|ScanNet 19 类，沿用出现类的场景宏平均|76.186|73.761|
|UQIS text|30.463|20.380|
|UQIS image|59.999|42.893|
|UQIS point_2d|80.057|48.520|
|UQIS point_3d|80.352|47.733|

**第一，缺少的是可靠归属，而非统一向外扩张。** UQIS 点查询多数选对身份却只覆盖约一半目标；
LERF 已有相当多范围外误检。典型 LERF 例子是 ketchup：覆盖约 99.93%，纯度约 24.89%；
corn：覆盖约 82.82%，纯度约 29.58%。继续扩张不会解决这些查询。
已有整图范围先验在 UQIS 增加覆盖、却大幅降低纯度的结果，正是同一类成员误归属的另一表现。

**第二，原生语义排序与集合决策仍需分别解决。** `ottolenghi` 的二维 AP 约 97.24%，
固定语义读出 IoU 约 0.23%；`onion segments` 则 AP 约 1.31%、IoU 为 0。
前者不能主要解释成“不认识目标”，后者也不能靠改范围阈值补救。
这些是全量评分后的诊断，不据此为查询调阈值、切分支或继承旧答案。

**第三，UQIS 文本有额外的实例身份问题。** 最终选集中目标为唯一主导实例的数量仍为
text 23/67、image 45/67、2D 点 57/67、3D 点 58/67。
只统计身份正确的对应子集，四类覆盖仍约 52.18 / 54.87 / 51.36 / 49.94%。
这是条件子集的 query 宏平均，不能当主成绩；它说明认对后也没有完成范围恢复。

**第四，统一架构应保留有效的合法证据。** ScanNet 同次输出的原生地图 19 类 mIoU 为 50.147691%，
当前完整源辅助融合为 61.011491%。这两个阶段的证据预算不同，差额不是新机制的公平消融，
但足以说明不能为形式统一而去掉现有有效源证据。NVOS 的合法参考图也应保留；
UQIS 仍只能读取地图及该 query 允许的输入。

## 已落实：为真实实例归属监督准备不重叠的数据

旧可靠性实验的九个训练房间与当前 ScanNet 十景有重叠。它们不是当前 v8 启用的训练头，
不因此宣布当前结果泄漏；但下一阶段不能直接复用这个划分来宣称未见场景收益。

本地可读的 `/mnt/pool/sqy/3d_understanding/agile3d_data/ScanNet/scans/` 包含实例标注点云。
以官方训练名单为范围，排除当前 ScanNet/UQIS 所有 19 个房间前缀及其重扫描，
剩余 1,181 个扫描、556 个房间。固定房间哈希划分先保存，再读取标签建立完整索引：

|用途|房间|扫描|逐扫描实例标注条目|点数|
|---|---:|---:|---:|---:|
|拟合|445|945|30,295|138,260,911|
|机制验证|111|236|7,315|33,535,376|

同一房间的不同扫描不会跨拟合/验证，也不会与当前五项评价房间重叠。未标注点保留 unknown，
不能归入负例。实例数包含重扫描中的标注条目，不冒充互不重复的物理对象数。
该划分是新机制的训练/验证准备，不声称项目历史上从未接触这些官方训练场景。

**目前完成的是完整数据索引和监督条件，尚未训练或部署新模型。**
这些资产提供完整实例归属，但没有部件层级、每个实例的语义类别映射，以及兼容当前 VFM
观测场的训练观测。不能说它已补齐所有 query 的语义监督，更不能用完整实例标签强迫部件 query 扩张。
附加 3D 标注属于新的监督条件，必须与当前不使用目标标注拟合的 v8 分列。

## 下一步收敛为一个方法问题

保留冻结几何和原生教师身份空间，训练“在给定身份/锚点和请求范围时，哪些实际元素属于目标”的读出。
监督同时惩罚错收成员与漏掉成员，直接检验最终选集；源掩码未覆盖仍不能自动等于真负例。
单实例、同类全部实例和部件保留明确类型：别的同类实例对单实例可能为负，对类别集合必须为正。

先补齐与该读出相容的独立训练观测，或显式声明仅使用三维几何/RGB 的结构先验条件，
再在预留房间上验证真实归属收益。未通过这个条件，不继续扫并集/图连接/通用 object 提示参数。
有可迁移净收益的候选必须再次跑完整五项共同配方，不能仅以 UQIS 提升升级主线。
本文的数据准备不是这个方法问题已经解决的证明。
