# 图像查询自视角监督的单变量检查

本轮仅检验一个假设：源自视角图像 membership 使用与教师相同的编码，是否导致校准和召回过拟合。

源同区域编码余弦为 1.0。既有跨视角正对应在 figurines 的 min/P10/P50/P90/max 为 0.716/0.773/0.868/0.958/0.977；ramen 为 0.768/0.845/0.919/0.958/0.981。该分布差异支持开展控制，不能独立证明因果。跨视角对应仍是源伪对应，不是实例真值。

新增实验选项 `--cross-view-image-only`：只删除 query 与 target 属于同一视角的图像成员任务，保留文本任务、提示任务、所有源区域教师覆盖及原有跨视角任务；如果删除后没有图像任务则拒绝训练。禁止同时启用会重新加入自视角图像监督的 `--source-membership`。

两场景各做两组同预算候选：

- `cross_image_native` 对照 `decoder_coupled`，教师权重 0.1，无额外原生响应损失；
- `cross_image_response` 对照 `decoder_response_retention`，教师权重 1.0，原生响应权重 10。

figurines 删除 223 个自视角图像任务，保留 128 个跨视角图像任务；ramen 删除 218 个，保留 322 个。总训练预算仍分别为 2,106 / 3,240 步，图像步数相同，保留的跨视角任务重复次数增加。因此这是固定预算下改变任务分布，不是固定每任务曝光次数的比较。源区域教师调度独立于被删除的图像任务，保持不变。

不增加教师、维度、训练步数或真实标注监督。所有结果仍属真实标注开发评估，不是独立最终 test。协议：`paper/artifacts/cross_view_image_protocol_20260916.json`。

## 同口径结果

以下均为 %，全文本与参考图像使用各自固定队列。

| 场景 / 模型 | 文本 IoU | 文本 AP | 图像 IoU | 图像 AP | 直接提示 IoU |
| --- | ---: | ---: | ---: | ---: | ---: |
| figurines / decoder_coupled2106 | 28.23 | 43.73 | 32.03 | 50.44 | 26.81 |
| figurines / cross_image_native_2106 | 24.05 | 37.78 | 25.16 | 41.46 | 25.85 |
| figurines / decoder_response_retention_2106 | 21.39 | 35.73 | 0.15 | 38.89 | 22.61 |
| figurines / cross_image_response_2106 | 21.69 | 36.08 | 19.62 | 35.71 | 23.22 |
| ramen / decoder_coupled3240 | 15.50 | 20.17 | 18.39 | 28.51 | 19.76 |
| ramen / cross_image_native_3240 | 12.25 | 19.36 | 13.75 | 22.69 | 21.39 |
| ramen / decoder_response_retention_3240 | 10.78 | 23.00 | 7.00 | 24.40 | 22.82 |
| ramen / cross_image_response_3240 | 10.31 | 21.83 | 5.15 | 22.89 | 21.42 |

结论：不推广删除自视角任务。强教师约束下 figurines 的图像 IoU 恢复，但 AP 仍下降；原一致解码下反而退化，ramen 也没有稳定改善。这一干预影响校准，但不是低召回的统一解决方案。

图像余弦判正门槛：原一致解码 figurines 0.0983→0.1021，ramen 0.0954→0.0749；强教师响应约束 figurines 0.8516→0.6921，ramen 0.8871→0.6337。阈值下降不保证排序改善或对象范围正确。四项新训练均完整覆盖原有 223 / 218 个源教师区域，明确保留了教师覆盖。

## 用实际源教师重新隔离压缩损失

关闭 sigmoid 和可学习校准，统一使用逐元素 `(cosine+1)/2` 再做完整场贡献聚合，未知像素为 0。两条路径使用完全相同的几何、查询和可观察性；对照分别为：

- 当前实际源区域 SigLIP 描述子，以源 region_probability 加权融合到元素，不压缩；
- 当前已训练场的实际解码元素。

这次使用当前源区域教师，不是早期固定裁剪网格的另一个教师。融合是明确的构造性对照，不是几何真值或可达到精度上界。两边使用原学习场已观察元素与源融合有支持元素的交集，figurines 为 71,763 个，ramen 为 168,961 个；小于原场全部有效元素数。因此只能在本次同口径内比较，不直接与之前生产 sigmoid 读出的 AP 相减归因。

| 同口径文本 AP / % | figurines | ramen |
| --- | ---: | ---: |
| 原生源区域教师融合 | 56.66 | 22.15 |
| 实际学习场解码 | 50.10 | 20.40 |

逐类 miffy 为 61.07→2.54，jake 为84.12→74.29，old camera 则69.34→77.64；ramen 的 egg 为23.31→4.08，chopsticks 为7.15→1.60，wavy noodles 为9.03→7.35。平均分掩盖了严重的逐类遗忘，原模型并非每一类都退化。

结论：miffy 已有源教师与当前几何融合的可用能力，却没有保留在学习场中，是明确的能力写入损失案例；chopsticks 的当前源教师融合本身也很弱，不能期待仅修紧凑空间就解决。弱融合表现不能进一步分解为教师、源范围或融合各自责任，仍需逐层检查。

最后增加源教师 SVD64 控制：基仅用训练源区域描述子拟合，查询仍保留原生空间；压缩融合元素后解码回原生空间，用相同的 sigmoid 前渲染排序。未使用目标图像、目标特征或评估查询来拟合基。

| 同口径 AP / % | 未压缩源融合 | 源 SVD64 融合 | 实际学习场 |
| --- | ---: | ---: | ---: |
| figurines 全查询 | 56.66 | 56.02 | 50.10 |
| figurines / miffy | 61.07 | 60.85 | 2.54 |
| ramen 全查询 | 22.15 | 22.54 | 20.40 |
| ramen / egg | 23.31 | 27.52 | 4.08 |
| ramen / chopsticks | 7.15 | 4.45 | 1.60 |

这次是实际三维元素经冻结几何渲染的结果，不再只是 GT 裁剪识别。64 维构造保留了 miffy 的原生源融合能力，因此该类的严重退化不是不可避免的维度不足。投影可改变排序，所以局部高于未压缩融合不应称为更高的能力上界。

当前下一项修复应从这个已验证的源构造出发，核对它与历史失败的固定基方法在融合顺序、查询归一化和训练更新上的差别，再检验训练如何改变其逐类排序。不能直接把新基矩阵替换进旧 latent，也不能把只验证文本排序的构造宣传成完整三查询部署方法。

四个新训练均未通过共同质量门槛，旧场与默认任务分布保留。26 项相关测试通过，脚本编译与 diff 检查通过。本轮未修改几何或其他 benchmark 管线。原生融合与 SVD 融合阶段的公共两条路径复现相同指标，结果绑定各自实现哈希。
