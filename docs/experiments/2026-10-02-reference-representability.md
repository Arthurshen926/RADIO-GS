# 固定载体的单视角表达与多视角共同拟合

完成八查询、302个合法源视图的完整对照：两个标签域，每个视角单独拟合，以及所有视角共同拟合；均记录120步和继续至480步的结果。共604个单视角拟合轨迹、16个共同拟合轨迹；另完成八次完整掩码共同字段的目标评价。所有作业结束，默认方法不变。

## 实验合约

固定地图、相机、源跟踪缓存、192×256光栅。已知区域域采用当前腐蚀正例/膨胀外负例；完整域使用全部有几何投影的源像素。两个域都拟合原教师连续概率，以当前Huber求解器与相同初始化计算。单视角模型每视角拥有独立元素响应，是更宽松的诊断条件，不可作为统一三维地图部署。

所有单视角/共同拟合比较在同一源像素域上进行。源指标先在场景内平均，再对八查询平均。GT和目标RGB不进入重建；目标标签仅在字段冻结后由既有评估器读取。边界未知元素在源诊断中保持共同初始化，故全域诊断不能直接等同部署字段外部的弃权行为。未证明全局最优或不可表示性下界。

固定载体在单视角平均可拟合99.24%的源范围，当前已知区域共同拟合也到99.87%。因此先前看到单Gaussian的标签混合，不能推出整个Gaussian组合无法表达范围；多Gaussian共同渲染能解释大量混合。应纠正“混合占比高就必须先拆分载体”的推断。

trex完整域单视角99.14%、共同91.13%，明确显示加入共同三维约束后误差大幅增加；这可能来自对应/几何、遮挡或教师范围不一致。不能单凭本轮把责任全部归给跟踪。其他场景共同拟合更高，但源标签本身仍可能错误。

120→480步的变化很小，继续增加迭代不具备已验证收益。这是实际可行解的诊断，不是数学全局收敛证明。

## 阶段结论

本阶段排除了两种过早判断：不是看到单Gaussian混合就应普遍拆分载体，也不是把当前未知边界全部补成监督就会解决准确率。当前求解器对已提供监督已经拟合充分；完整源范围共同拟合仍存在场景相关冲突，而且源监督正确性/完整性尚未由独立真值保证。

下一阶段必须把源证据质量和正确三维对应作为核心对象：先定位trex那些单视角可拟合、共同拟合失败的对应区域，区分教师范围变化与真实遮挡/错位；对orchids检查漏掉范围是否从未被正确跟踪。只有固定几何与来源后仍有确定的空间表达缺口，才进入载体变化。不能继续以源拟合提高或局部方差下降冒充目标泛化。

当前没有新默认、集合头提升、LERF/ScanNet结果、四query验收或SOTA结论；UQIS保持暂停。
