## ScanNet 几何核心定位

同一 scene0000_00、全部 32 源相机、宽 320 栅格，以提供的无标签三角网格渲染为参考；包括 MoGe 校准曾拒绝的相机，不缩小分母。

|载体|元素数|覆盖|深度一致覆盖|平均相对深度误差|
|---|---:|---:|---:|---:|
|当前网格校准 MoGe 融合|39,476|28.64%|24.19%|11.46%|
|输入网格顶点，固定 7.5mm 切向 sigma|81,369|57.75%|40.20%|9.23%|
|相同顶点，按代表表面积确定 sigma|81,369|100.00%|91.20%|1.70%|

固定高斯尺度与室内网格采样间距不匹配，和 MoGe 融合丢失表面同时存在。仅增加教师或优化查询头不能修复这些几何缺口。
面积规则为 `sqrt(顶点重心分配面积/pi)`，限于 3–50mm，法向 sigma 固定 1mm，opacity 0.8；不读取标签，不按查询/召回指标调参。

**这是共享输入网格的自一致性，不是独立传感真值精度，也不是最终召回提升。** 尚需原分辨率及深度边界检查，不能将 100% 覆盖等同于边界准确。
宽 640 重复对照：MoGe 覆盖27.84%/深度一致覆盖23.67%，固定网格宽度48.51%/32.97%，面积宽度100%/91.06%。结论在更高分辨率保留，固定宽度受低分辨率栅格足迹影响更明显；640 仍不一定是所有源图的原分辨率。
八场候选载体均已生成，训练标签、语言特征和实例注释的读取被禁止。五项面积、身份、刚性变换与退化输入测试通过。
证据：`output/scannet_mesh_carrier_control_20260918/scene0000_00/report.json`、`output/scannet_provided_mesh_track_20260918/manifest.json`。

输入轨道必须如实标为 provided-unlabelled-mesh；当前已用网格校准的 MoGe 也不能标成纯 RGB。OpenGaussian 官方 reader 使用 `points3d.ply`，逐帧 depth 为 None，说明“不用逐帧深度”不等于“没有外部几何输入”。

## NVOS 正涂鸦八任务结果

重新生成参考 SAM mask/crop，只读取官方正涂鸦；系统读取钩子禁止负涂鸦与目标 RGB/GT。没有复用先前正负涂鸦生成的 crop。统一使用先前封存的 `image_supervised_native_residual_measured_support512` 图像分支；两项 horns 共用同一地图，不逐场选最优分支。
公开 all-view 任务允许更多 RGB 访问，本次没有使用目标 RGB。按该任务连续概率双线性缩放后固定0.5阈值评分；先落盘预测、再读取目标GT。LUDVIG自身的SAM采样/分数归一化不是本方法读出。

已有证据进一步限定下一个方法问题：flower 的 AP89.18% 但 IoU25.76%，其参考正涂鸦仅48.58%得到最终场响应；fortress 的 AP99.13% 但参考正涂鸦响应56.63%。当前正提示经过 SAM crop 转成图像 embedding 后，没有显式强制最终地图满足给定正位置。另一方面，leaves 已满足100%参考正涂鸦，目标 IoU仍23.74%。因此既要保留正提示的空间约束，也要验证完整范围，不能把“满足正点击”或“原生正响应”当作正确对象范围证明。后续控制应固定同一地图、同一正输入，分别报告参考约束、目标概率图和真实元素选择；不能读取负涂鸦补分或把未覆盖区域统一标负。

## ScanNet 源监督与类别任务适配

在读取 ScanNet 语义真值前固定：主结果以冻结原生教师空间余弦进行 split 类别 argmax，所有已观测元素均可属于该类别；原单对象范围读出作为同步对照保存。类别分割要求同类的所有实例，不能直接把单对象范围当作类别范围。两份预测都先落盘，随后调用原 VALA Gaussian-domain evaluator；不根据真值决定选哪条读出。

原按帧位置选出的两张源验证图在 scene0000_00/scene0062_00 没有三类 query 的有效跨视角监督。适配器保留冻结 episode compiler 的非空断言，先用源几何/外观对应检查划分：原划分有效则保留；否则按帧号选第一对同时保证训练、验证三类监督非空的源视角。原始教师张量及哈希不变，原划分、失败日志和诊断均保留。这只是源监督可用性划分，不是独立 benchmark 测试集，也不证明对象身份无误。

实际落盘网格载体已在全部32源相机、宽640再次渲染验证。CPU/GPU法向与四元数有微小浮点差异，未宣称逐位相同；实际渲染覆盖与深度一致覆盖保持不变，平均相对误差差异约2.9e-11。证据为 `paper/artifacts/registered_mesh_actual_render_validation_20260918.json`。几何、相机、来源绑定和原 ScanNet 指标共22项相关测试通过。
