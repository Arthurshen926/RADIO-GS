# 功能迁移阶段结论：成员求解可恢复，但完整范围与响应功能仍未闭环

本轮完成四组顺序研发实验，每组覆盖完整四场 LERF、68 文本，使用同一批
72 源视图、5137 区域和固定教师接受；每组全部预测封存后才评分。最后一组冻结
4b74134。后续设计参考了前组结果，因此不是独立确认性测试。

**48.0850% 是源教师辅助、逐查询临时拟合的能力参考，不是单场标准部署成绩。**
场参数与几何不变；不能将这些评测查询的拟合答案写回场或训练部署解码器。
此次没有新的统一五任务评估，不能宣称已经恢复 v10 或完成论文贡献闭环。

## 四组实验分别排除了什么

1. 精确先并集再提升：用查询无关的重叠原子保存同源部分标签的联合结构，
   全部单区域P/N列误差最大1.1921e-6，满足冻结2e-6门限。主组实际37.2457%，
   比边际并集37.3503%低0.1046pp，四场均降。新增840,140,994字节没有收益，
   不提升为默认场状态。v1元数据错误在评分前终止，原始失败保留。
2. 去掉已知位置的有限先验、改用P/(P+N)：主组降至23.7258%，四场退化。
   弱部分证据被当成确定成员的做法失败，不代表v10完整成员函数失败。
3. 从该退化初始化补回真实成员opacity轮廓求解：无footprint为26.4769%，
   有footprint为36.6399%。说明轮廓与支撑代价有效，但仍受初始状态影响。
4. 固定目标及footprint测度后只换初始化：达到48.0850%。因此不能用第三组
   的不足否定联合解码，更不能把增加监督或训练收敛当成功能恢复。

## 高已知像素拟合掩盖了什么

对同样453个有正证据的查询/源视图对，重新渲染实际二值成员，固定alpha阈值
10.5/255。按场内查询/视图平均后取四场宏平均。未知像素只在已知指标中排除；
完整掩码协议比较使用全部栅格。

| 源侧诊断 % | finite_parts | 联合/source初始化 | 联合/finite初始化 |
|---|---:|---:|---:|
| 已知正负像素 IoU | 65.7156 | 75.1596 | **92.3145** |
| 完整栅格与已接受候选并集 IoU | 38.2197 | 38.4941 | **55.5858** |
| 完整栅格与RAW源教师 IoU | 35.1743 | 35.3478 | **51.9250** |
| 预测像素落在未知区域的比例 | 62.3781 | 67.0882 | **60.5616** |
| 预测像素在候选并集之外的比例 | 61.5532 | 61.2479 | **42.5202** |

候选并集与RAW源教师自身的一致性86.0662%。这些是条件源协议诊断；源教师、候选
均不是真值，未知区域与候选外像素不能直接称为误报。此处也不是留出视图评估。

代码中的 partial_mask_target 只把尺寸比[0.5,2]内的互不重叠候选内部作为负；
其他背景、嵌套和缺失候选区域保持未知。多部分组合还对负取交。因此当前目标
约束了局部正负，却没有表达完整对象范围。92.31%已知拟合不能证明成员功能已
迁移；其余差距也不能全归到跨视图泛化。原生条件接受、源覆盖、教师错误、有限
求解及响应读出仍有影响，不能归结为唯一原因。

## 收敛后的方法职责与下一门槛

保留单Gaussian场、SigLIP语义/DINO外观/SAM分组、类型化查询以及同一实际集合
贯通2D/3D。允许区域坐标保留原生查询函数，成员解码允许联合约束；不再把逐点
有限P/N公式固定成最终架构。职责分为：条件身份接受、可靠排除与范围完整性、
实际成员解码、与该集合一致的响应读出。四者都要功能验收。

下一优先级是**条件排除/范围完整性**，与响应功能并列作为通过门槛；先保持
来源、接受、初始化和优化测度固定，验证可信排除能否在不丢真成员的前提下改善
完整范围。未知不能全改负；空教师不能作为不存在证明；不做阈值扫描或盲目扩并集。
如果源侧完整功能参考通过，才用独立于评测查询的构建条件迁移到场内函数，考核
冷启动与禁止源访问后的相同集合和响应，再运行同一配置五任务。逐查询拟合仅是
研究参考，不成为部署路径。暂不继续花成本增加原子容量或仅增加语义训练损失。
