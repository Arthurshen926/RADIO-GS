# 局部几何校准：重建后的留出改善与原生语义传递对照

本轮继续执行 G1/G2，并完成一项 G3 范围内的诊断重建。首次得到较明显的 ramen 几何改善，但没有将候选晋升为完整主线：figurines 仍有覆盖损失和原生召回回退，两场景完整结构/范围头尚未重训。

## 1. 从“没有正确表面”与“可见表面错误”分开定位

对上一轮每个源轨迹参考 XYZ 查询冻结地图最近的 Gaussian 中心。这只是诊断：最近元素可能属于邻近的另一表面，不能当作正确可见性的证明。

在 ramen 几何留出视角、原语义覆盖区域，2987 次深度相对误差超过 5% 的观测中，2023 次在参考点 1 cm 内有元素（67.73%）。figurines 对应为 13/111。ramen 的一部分问题是近参考表面存在，但完整场渲染没有由它主导；figurines 更多涉及局部支持缺失/错位。不能给两场景套同一个全局阈值解释。

附加复核了实际 COLMAP 相机：两场景均为 PINHOLE。逐观测原图重投影误差中位约 0.46 px，P90 为 1.54/1.34 px；高深度误差子集也没有表现为普遍的大像素错配。该复核未发现镜头畸变模型错用或显著坐标错配，不代表相机模型已无误差。

## 2. 实际构建并拒绝的三类几何候选

全部使用既有 mapping 视角，留出视角不参与候选构建。过滤/重建不使用语义特征或 benchmark 标签；当前 observed 元素仅用于固定评估分层。

1. **收紧源深度一致性后硬筛选**：容差由 `sqrt(3)*voxel + .01*depth` 改为 `.5*voxel + .005*depth`，要求至少两次同意且同意多于自由空间冲突。
2. **同一证据软调整 opacity**：按同意/(同意+冲突) 调整原几何 opacity，未知证据保留原值。用于检验硬删除是否是唯一问题，不把可靠性权重声称为物理 opacity 真值。
3. **只用原校准直接通过的视角重新融合**：去掉通过邻近视角恢复尺度的来源；保留其他融合参数。

| 全部几何留出轨迹，覆盖率 / 中位 AbsRel / P90 (%) | figurines | ramen |
|---|---:|---:|
| 原几何 | 89.29 / 4.40 / 47.14 | 99.84 / 5.72 / 10.44 |
| 硬一致性筛选 | 72.62 / 29.68 / 139.22 | 96.95 / 4.25 / 25.91 |
| 软 opacity 调整 | 87.20 / 6.34 / 65.90 | 99.82 / 4.87 / 12.91 |
| 仅原校准通过来源重建 | 88.10 / 5.61 / 63.14 | 98.38 / 5.48 / 9.63 |

共同支持域与缺失惩罚也已记录。三类候选均不采用。恢复视角不能一律删除，收紧阈值也不能替代正确校准。

## 3. 有效方向：稀疏源轨迹约束的局部乘法深度校准

新增 `radio_gs/geometry/local_depth_calibration.py`。它属于几何预处理，不是语义 hash 分支，也不使用 VFM 语义特征：

- 校准样本来自源 COLMAP 轨迹，使用参考深度/预测深度的 log 比值。
- 所有新拟合统一排除 `point_id % 5 == 0`，避免同一留出点在另一视角进入校准。
- 邻域同时限制归一化图像距离与 log-depth 距离，避免前后景直接混合。
- 最多 16 个邻居、至少 4 个有效邻居，使用加权中位数；局部尺度限制在全局拟合尺度的 1/1.2 到 1.2 倍。
- 无局部支持时使用全局尺度；全局样本不足或拟合检查失败的视角，在完整重建中保留原校准/恢复结果。
- 局部变形后，法线按 `X'=s(u,v)X` 的逆转置 Jacobian 同步变换；不能移动表面后继续假定旧法线方向正确。

单视角深度向另一视角传递的先导实验，ramen 同一批 384 个留出观测对：

| 方法，128 宽网格误差 | 中位 px | P90 px | 均值 px |
|---|---:|---:|---:|
| 全局深度比中位数尺度 | 1.28 | 12.73 | 4.98 |
| 全局重投影尺度 | 0.91 | 9.09 | 3.34 |
| 局部深度校准 | **0.51** | **1.86** | **0.94** |

这支持误差具有空间变化，而非单一视角尺度即可充分修复。但局部拟合仍受稀疏轨迹分布影响，不能视作无纹理区域的精度保证。figurines 在此小源视角交集协议仅一个共享留出点，不能用两条观测宣称泛化成功。

## 4. 完整重建，而非仅在轨迹上替换数值

按相同 mapping 集合实际物化 480 宽局部尺度图，更新深度与法线后重新融合。ramen 102/107 个 mapping 视角通过新全局拟合检查，figurines 15/81；其中只有邻域证据足够的位置使用局部修正。新几何分别为 376323/277527 个元素，与旧元素行不兼容。

重点检查既未参与新校准的点，又处于未参与表面融合的视角：

| 双重留出稀疏观测 | figurines 原→新 | ramen 原→新 |
|---|---:|---:|
| 候选观测数 | 65 | 1001 |
| 覆盖率 | 86.15→84.62% | **99.90→99.90%** |
| 已覆盖观测中位 AbsRel | 5.99→4.52% | **5.82→3.12%** |
| 已覆盖观测 P90 | 35.08→34.18% | **10.91→6.15%** |
| 深度误差≤5%的总观测覆盖率 | 38.46→46.15% | **37.16→84.62%** |
| 缺失计1、误差截断到1的均值 | 27.05→27.08% | **7.43→4.18%** |

ramen 共同支持恰好为同一 1000 条观测，改善不是删除困难点换来的。figurines 少覆盖一条，包含缺失惩罚后没有整体改善，不能联合晋升。

**独立性边界：** 点 ID 从每一次新校准中排除，但旧几何、旧全局尺度和现有相机/稀疏重建可能用过这些观测。因此“双重留出”特指本轮新增校准和表面融合，不是完全未使用过参考的最终 test，也不是稠密手工几何真值。

## 5. 把改善放回系统检查：重新提升原生教师，评估真实文本查询

为两份新几何重建了独立像素贡献 authority。只复用不依赖元素行号的源 2D mask 和 SigLIP 描述；重新计算每个区域的元素 membership、observed 支持和 64D 原生语义融合。没有复用旧场的元素特征、结构32、范围头或 prompt 种子。

使用同一源 SVD basis、query encoder、原有 source query 标定和相同 480 宽标签评估。新几何没有重新拟合标定，因此 AP 是更主要的诊断。这是纯原生路径对照，不是当前完整主线成绩。

| 原生语义场，IoU / AP (%) | figurines | ramen |
|---|---:|---:|
| 原几何、原生读出 | 33.60 / 58.48 | 8.20 / 30.97 |
| 新几何、重新提升教师后 | 31.45 / 56.89 | **11.76 / 31.82** |

ramen 部分类改善明显：chopsticks IoU 0→22.6%、AP 40.2→49.8%；spoon IoU 0→27.9%、AP 16.9→40.7%；wavy noodles AP 10.4→18.3%。但 egg AP 41.6→11.9%、onion segments 13.0→2.2%，说明不能只展示改善的类。

几何改善传递到了一部分召回，但平均 AP 增益有限且有显著类间回退。这提示需要继续处理源区域范围、粒度和聚合，不能据此把剩余全部误差归于某一个教师。完整保留主线的文本 IoU 仍为 43.52/28.42%，**不能拿本表的原生基线增益宣称完整方法已经提升**。
