# TMM 论文的科学问题、核心机制与证据组织

日期：2026-10-18。当前分支：`codex/tmm-query-response`。
对应 [ADR0041](../adr/0041-scientific-question-and-evidence-led-paper.md)。
本轮整理已有实现与证据，不产生新的 benchmark 分数。

## 1. 一句话定位

**研究如何把局部、不完整、带查询条件的教师证据，变成身份正确、范围完整、读出一致的三维响应。**

建议题目：**From Partial Evidence to Complete 3D Responses: Query-Conditioned Evidence Fusion**。
“Complete”指面向完整成员范围的输出能力，不表示预测总是完美。
研究对象是查询响应形成；不重新发明教师特征、统一特征场或压缩系统。

科学问题不是“怎样继续提高一个分数”，而是：
**一条局部观察在什么条件下有权支持或排除某个空间位置？这些证据怎样形成用户真正要求的完整答案？**

三个容易混淆的事实必须拆开：

1. 匹配到正确对象，不代表已经看到它的全部范围。
2. 精确传播一个不完整掩码，可以精确地传播遗漏；更低的拟合损失不等于正确答案。
3. 连续语义分数与实际选出的三维集合不是同一种输出，遮挡和渲染会进一步放大区别。

## 2. 一个核心机制，而不是三套松散模块

**先估计证据的身份适用性与空间作用范围，再进行与输出一致的融合。**

`原生教师/查询 → 身份适用性 → 支持、排除、未知的范围 → 几何响应或完整成员 → 类型对应的输出`

- **身份适用性**：观察是否指向用户要找的对象。文字候选用查询内原生分数准入，图像用局部对应，真实点提供空间条件。
- **空间作用范围**：匹配成功之后，哪些位置有支持证据，哪些有排除证据，哪些仍未知。未知不能仅因“不匹配”就变成负标签。当前实现仍有预测掩码补集等不完备估计，论文必须承认。
- **响应形成**：在正确几何与任务读出下使用这些证据。语义融合、独立轮廓选集和条件完整成员是不同类型的实现，不能画成一个实际上不存在的通用网络。

NVOS 的具体机制最清晰：
**正负参考提示与原生相似性 → 补全参考候选 → 参考端整响应准入 → 跨视图传播 → 原生射线拟合 → 实际重渲染。**
把范围修复放在传播之前，是它与“传播旧掩码后加大优化力度”的实质区别。
SAM3、DINOv2 都是有明确归属的外部能力；新增负提示和目标 RGB 必须披露。

v10 的身份准入、证据实际使用、局部匹配、完整成员都属于本文方法。
L11 整响应替换只作为独立扩展，不承担主论文的统一机制主张。

## 3. 理论应该解释什么

正文新增 [问题定义与理论分析](../../paper/tmm_response/sections/problem_analysis.tex)，给出两个命题和一个构造反例。

| 结论 | 严格条件 | 解释的设计必要性 | 不能声称 |
|---|---|---|---|
| 不完整范围的不可辨识性 | 只有正集合 P、负集合 N，未知区域没有额外区分信息 | 局部正证据的补集不能自动作为负证据；需要额外范围信息 | RGB 也无法辨识，或我们的补全必然正确 |
| 错误负证据的衰减 | 固定原有权重、先验和几何，直接加权共识 | 错误排除会污染归一化；更好几何不能自动消除此错误 | 同一精确公式适用于 Huber、分类树或所有任务 |
| 选择与语义渲染不等价 | 一条含前景遮挡的透明度合成射线 | 继承功能必须同时保留优化目标与读出 | 某个读出总是更优，或这是实测精度提升 |

第二项给出精确关系：原响应 r=S/D，加入错误零响应质量 u 后，
r'=S/(D+u)，损失为 r·u/(D+u)。原本 r≥τ 时，翻转条件是 u>D(r/τ−1)。
这是有边界的解释性分析，不包装成新的优化理论或精度保证。

反例中前方未选高斯透明度 0.9、后方已选透明度 0.2：
整场归一化成员响应约 0.0217，而单独选集透明度为 0.2。
因此“保存特征/成员分数”并不等于“保存实际选集功能”。

## 4. 三条论文贡献

1. **问题与分析**：把查询身份、证据范围和响应输出的区别形式化，解释局部证据形成完整响应的必要条件和失效方式。
2. **方法机制**：查询条件的证据准入与范围处理，尤其是“参考补全及整响应准入先于传播”，结合既有有效的几何融合和完整成员能力。
3. **实证闭环**：五项输出覆盖、历史配对组件干预、参考补全的匹配对照与评估协议审计，区分机制增益、教师/输入能力和评分口径。

不把加权平均、冻结教师、训练收敛本身列成独立创新点。
相关工作已明确承认 VALA 的可见性聚合、LUDVIG 的特征提升与扩散，以及 EviSplat 的查询相关证据选择；差异落在本文具体的范围/排除语义和完整输出机制上。
原论文来源分别见 [VALA](https://arxiv.org/abs/2509.05515v1)、[LUDVIG](https://arxiv.org/abs/2410.14462v5)、[EviSplat](https://arxiv.org/abs/2609.34853v1)。

## 5. 结果怎样与机制对应

| 论文问题 | 对照证据 | 支持的结论与限制 |
|---|---|---|
| 身份是否需要先解决？ | LERF 准入 64.12→66.66；UQIS 局部对应 30.74→34.88 | 固定对应控制项，身份处理有效；不是所有教师的统一规则证明 |
| 有了证据是否就足够？ | LERF 实际使用已准入响应 50.59→70.38 | 功能进入最终响应很重要；不是新平均公式独占 19.79 点 |
| 完整范围是否必须恢复？ | UQIS 同身份下完整成员 34.88→39.90 | 条件完整成员有实测收益；必须披露 22 训练房间和 3 校准房间 |
| 先补全再传播是否有用？ | N12 同传播/拟合：原参考 88.20→约束补全 91.48 | 下游保持一致，范围机制有效；其中负提示、DINO、SAM 尚未完全单独拆开 |
| 收益是否只靠目标 RGB？ | N15 相同 318 源视图、无目标图像证据：88.01→92.75；AP 98.26→98.81 | 补全收益可进入源视图融合，5 项提升、3 项回退；不等于未见场景验证 |
| 是否只是拟合不够？ | E04 全部 22 源任务损失下降，ScanNet 61.01→60.28；LERF AP 87.62→87.00 | 更低源损失不充分，不能继续用训练收敛代替功能迁移 |
| 再解码是否全面更好？ | N16 IoU 93.28，但 AP 98.47；N14 为 93.17/98.95 | 保留更高 IoU 但暴露代价，不用单指标覆盖机制结论 |
| 是否评分 bug？ | LERF/ScanNet 独立评分，NVOS 两种 GT、A24 排序精度审计 | 已检查的评分/数值路径不足以解释大增益；不宣称排除了所有可能 bug |

不同队列、不同阶段的增益不能相加。历史配对实验不能冒充最终系统的完整 leave-one-module-out 消融。

NVOS 正文同时保留：
- 原 v10：86.51 IoU；
- N14 预声明主策略（参考可行性）：92.94 IoU / 98.86 AP；
- N14 固定次策略（参考质量）：93.17 / 98.95，当前较均衡；
- N16 局部再解码：93.28 / 98.47，当前最高 IoU，但有明确 AP 代价。

直接图像的 93.50 不能当作三维重渲染的 93.17；
新增输入后的结果不能写成与 v10 输入完全相同的 +6.66。
N15、N16 已停止的路线继续停止，不意味着证明了 NVOS 全局上限。

## 7. 当前闭环与下一步

**可以闭环的是：科学问题 → 有条件的失效分析 → 实际机制 → 局部配对证据 → 五项任务结果与边界。**
可以按这个组织完成一篇机制导向的 TMM 稿件，而不是把所有历史工程堆成贡献。

仍不能写成已完成的结论：同一准入算法跨所有教师/查询稳定获益、未见场景泛化、
完全相同输入下的外部 SOTA、参考补全各新增能力已做最终系统完整因子消融。

下一步优先级：
1. 冻结上述主线，补主文的失败案例与范围/身份错误可视化，保留完整队列选择规则。
2. 在匹配输入下明确负提示、范围补全、参考准入各自的作用；已有配对证据先用足，不重跑无关系统消融。
3. 选未用于设计的场景/适配教师做冻结规则验证，封存后统一评分。
4. 最后处理 TMM 模板、语言、篇幅与参考文献格式，不再用当前八任务的参数搜索取代科学闭环。
