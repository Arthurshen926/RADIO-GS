## 3. MoGe 中间特征：可提取，不等于可匹配

锁定官方 `Ruicheng/moge-3-vitl` revision `a96e58bad16a94c9a3c193a5d4cd75b4b6906c94`，实际提取 encoder 1024 通道、refiner 最后输出投影前 32 通道。refiner 稀疏坐标与像素的完整一一映射已检查，不能按扁平顺序直接 reshape。原始 refiner 网格为 832×1120，区域对照使用 96×128；没有声称已证明像素级对应不变性。

在已有可靠性筛选的源区域对上，refiner 原始正负余弦都约 0.98–0.99，不能把绝对余弦当可靠性。训练源视角中心化后部分区分能力恢复；encoder 的区域对应区分通常更好。验证对仅 8/4 对，且准入曾使用 DINO，DINO 对比有选择偏差，不是独立模型排名。

见 `paper/artifacts/{scene}_moge_region_correspondence_20260917.json`；原始提取与模型/图片身份在 `moge_feature_teacher_20260917/{scene}/manifest.json`。本轮 refiner 辅助未通过增益验收；encoder 目前仅完成可用性诊断，不宣称已完成其重建训练消融。

## 4. 功能替换实际跑通，但不等于更强

新增能力声明与同空间身份检查。OpenCLIP ViT-B-16 LAION2B 的本地权重、预处理、文本/图像编码器、512 维教师目标、64 维源基底、监督和场全部重新构建。旧 `siglip` 槽位明确声明为“文本—图像对齐能力”，不是偷偷使用 SigLIP。独立安装 OpenCLIP 2.32，未修改主环境依赖。

| 场景 | text IoU/AP | image IoU/AP | prompt IoU/AP |

| figurines | 26.29 / 42.96 | 22.63 / 48.74 | 32.03 / 52.11 |

这是同阶段基础场三类查询，不是带全部范围头的最终替代主线。替代裁剪由存储的低分辨率 mask 回采样，原 SigLIP 使用原生 mask；因此证明功能替换可运行，不是纯 backbone 优劣对照。无稳定优势，不晋升。

还修复了一个流程约束：没有合格的旧式文本验证伪标签时，可显式声明该监控项缺失，记录 `None` 和零样本，不能降低标签门槛或拿零分代替缺失。训练证据不足仍然报错。fig 的 OpenCLIP 验证文本配对数为 0，不能宣称源侧三类伪标签验证齐全。

## 5. 有界统一范围读取：作为默认方案拒绝

为 text/image 提供同一原生 logit 上的有界范围修正，强度预先固定为 0 和之前图像源验证选择的 2，不用本次 GT 调强度。全部元素/头张量保持不变；有界差值保护足够大的原生 margin，并非保护所有排序。

注册坐标亲和读取现在可以显式跳过未被使用的 DINO 前缀。只允许经过架构检查的坐标读取，学习型 prompt adapter 和 query refinement 不允许这样处理。重新评估保留主线 prompt 仍为 40.71/24.77%，这是计算路径清理，不是精度提升。

## 6. 几何：正确性修复和效果判断分开

发现并修复带非零 offset 的仿射深度 `d'=a*d+b` 未同步变换法线的问题。校正后的点是 `X'=(a+b/Z)X`，法线必须用其 Jacobian 的逆转置变换；纯尺度不改变方向，非零 offset 一般会改变切平面。已通过斜平面数值差分、单位不变性和真实 loader 集成测试。两个场景真实重建完成；载体数不变，整体深度变化很小，不将其包装为低分主因。旧冻结资产不原地修改。

全部融合留出视角稠密评估显示，局部尺度修正仍未解决深度边界。它在稀疏 SfM 参考上可显著改善，却未同步改善 MoGe 稠密参考的所有尾部和边界。因此不能单看稀疏平均值晋升。MoGe 稠密参考也不是几何 GT。

把体素直接改为 5 mm 的两场景重建均失败：覆盖下降，尾部和边界没有共同改善。这个对照同时改变了体素相关一致性容差，不是纯 footprint 干预。

按 ADR 0008 的显式实验例外，完成固定源 DINO、双向重投影循环、深度/法线门控后的联合尺度试验；与同采样、同循环门控、同求解器的纯几何对照比较。映射源图特征不等同于语义训练视角特征；几何留出图像不提取描述符，benchmark query/GT 不参与。

宽度 480 的共同稀疏参考队列中，固定特征方案在 figurines 的预留点上提高覆盖并改善误差，但 ramen 预留点 P90 由 10.84% 变为 11.71%，准确到 5% 的覆盖从 39.06% 降至 32.87%；拒绝跨场景统一采用。源对应拟合残差降低不代表留出几何改善。

证据在 `paper/artifacts/{scene}_geometry_candidate_tracks_20260917.json`、`{scene}_local_geometry_dense_edges_20260917.json` 和外部 `feature_assisted_geometry_20260917/{scene}/report.json`。预留 point ID 只从新局部拟合排除，旧校准可能使用过；全队列与语义支持子集、128/480 分辨率指标不得混用。
