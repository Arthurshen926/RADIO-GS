# 当前载体、源预算与同实例 mask 分辨率审计

本轮只读核验了 LERF4 与 ScanNet8 的当前载体、源预算以及 **20,707 个原生 SAM 源实例**，没有训练、目标真值、GPU 或新 benchmark 评估。主要结论是：**源边界确有损失，细小区域也被提前筛掉；但当前网格并不比所核验历史路径更粗，不能用“高分辨率/更多元素”单独解释或修复历史差距。**

## 载体和预算

所有当前 exact-responsibility 写入网格均为 **96×128**。历史 LERF exact-MPR 为46×62，waldo为45×62；历史 ScanNet MPR 为60×81。这些是对应聚合算子的网格，不能当作所有教师的原生分辨率或最终评估分辨率。当前 SigLIP 区域裁剪来自原生 SAM mask，DINO 独立提取46×62，之后才在96×128参与聚合。

当前 observed 指 next30 中保持原64维坐标的原生地图支持，不是所有可选教师的联合支持率，也不是目标正样本覆盖率。历史 ScanNet 的RADIO valid_count与之定义不同，JSON保留但不据此评优。

历史 LERF 的32个 query-free proposal 源视角与120个 exact-MPR兼容视角是不同预算，不能相加或混称120个proposal视角。当前LERF几何mapping视角为81/107/96/93，语义训练为20/25/23/22；“完成所选源视角的完整场重建”不等于所有mapping RGB均用于语义重建。

当前 LERF 是冻结MoGe表面载体；ScanNet是提供的无标签三角网格派生Gaussian。旧几何为历史RGB-3DGS。ScanNet新旧元素数相同，但位置/尺度/opacity和由此派生的评分测度并不能据数量认定相同。本轮没有测量点位置对独立几何真值的误差。**几何覆盖、点位置准确、投影轮廓准确、相邻语义可分离，是四个不同问题。** 增加背景或重叠载体也可以提高覆盖，而不改善小物体边界。

## 同一个源实例，细节损失发生在哪里

逐帧使用原始打包SAM mask、原`native_proposal_indices`和当前parent前缀，验证同一实例对应；little-bit解包、实际nearest-exact下采样及面积筛选均逐项重放完全一致。追加grounded区域共3,963个，没有对应原生SAM实例，明确排除这项配对统计。

固定操作是原生mask→实际96×128 mask→原始网格nearest-exact，完全不经过教师识别、跨视角传递或学习头。薄结构子集使用事先固定的几何proxy `2×面积/周长 ≤ 2` 个源网格像素；它不是语义“部件”标签。

1. **进入地图前的区域缺失。** [prepare_four_teacher_retrieval.py](../../radio_gs/scripts/prepare_four_teacher_retrieval.py)在SigLIP裁剪编码之前只保留coarse面积占比0.2%–60%的区域。原生SAM生成门槛允许更小区域，最终2,014个proposal因下限被删除，占全部9.73%；另外49个因上限删除。这些区域没有各自的原生裁剪描述子写入普通区域证据。它们可能仍被整体mask覆盖，追加grounded区域也可能补回部分能力，因此不能把2,014直接叫做丢失对象数。
2. **已经保留区域的轮廓损失。** 18,644个对应实例的场景平均回放IoU为87.5%–89.8%，薄结构子集为77.0%–81.0%。这证明写入mask的细节损失存在，尤其集中于薄/小区域，但它不是全部低召回的充分解释。
3. **不是大量mask完全消失或相等碰撞。** 所有20,707个原生mask下采样后仍非空。被保留且原生不同、coarse完全相同的集合仅ScanNet0140出现1组，其余11场为0。大部分损失表现为边界形变和混合，而非两个完整实例变成逐像素完全相同。因此再次优先做exact-dedup没有依据。

这些IoU只衡量源伪mask的固定采样损失，不是物体真值IoU，也不是任何学习系统的绝对上限。多个视角、更准确的几何或更高分辨率特征可能恢复细节；本轮没有证明它们会提高最终指标。

## 对后续方法的约束

本轮最具体的改进动机是：在不更换原生语义空间的前提下，验证被面积阈值排除的**已存在、非空源小区域**是否补足细粒度证据，并在未参与写入的源视角同时检查小区域、整体区域、文本与图像响应。保留父区域不能自动替代部件描述；反过来小区域也不能只因尺寸小就获得无限票数。仍须遵守同像素质量分摊和可靠跨视角对应，避免增加proposal后重新引入重叠票放大。

对于保留mask边界，任何更高分辨率写入实验都应复用同一原生实例、教师描述子和几何，再单独判断新责任算子与实际元素选择，而不能只把96×128 mask插值放大并称为恢复原生细节。

已匹配的next31梯度诊断仍表明区域重叠混合与跨视角写入是核心待解决环节；本轮否定的是“当前比历史更低分辨率/更少元素，所以必然差”的简单归因，并没有宣布几何已正确或语义写入已解决。
