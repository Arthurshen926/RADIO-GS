# NVOS fern：实际新场、2D signed query 与支持域审计

这是 **fern 单场景开发诊断**，不是 NVOS 八场景平均，也不是与完整 LERF caption/范围头相同的方法身份。它已经实际构建新教师、训练新场并预测未见目标，不能再与仅编译 query 的早期工作混为一谈；但仍不满足 E2 的联合 benchmark 主项。

## 构建与输入权限

- 冻结 MoGe 几何 140,051 个元素；14个合法语义源视角，其中12个训练、2个验证。目标 `IMG_4027` 不进入几何/特征训练，参考提示来自 `IMG_4038`。
- 从原生源 RGB 生成 query-free SAM 掩码，232个有效区域；原生 SigLIP、DINO 教师重新计算，不使用 RADIO。修复教师准备和冷启动输入准备对 LERF 历史 SAM bundle 的硬编码依赖，显式支持带 RGB/模型/生成配置身份的 SAM manifest。
- 编译配对 train text/image/prompt 为824/910/910，validation为14/14/14。训练文本用实际 SAM3 源文本定位替换旧裁剪类别伪标签，得到6类、56个正负可验证任务；这不等于原来的824个伪任务都有真值。
- 按源区域完整覆盖构建实际训练任务56/1106/1106，训练6,636步，再做源侧 image balanced 校准。原生64冻结、结构32学习，源融合、教师、监督、编码器和几何身份绑定齐全。
- 三类原生 query 冷启动通过；在线/缓存编码余弦 text/image/prompt 为0.9999994/0.9999842/1.0。图像最大后验差约0.0101，不能称为逐位相同。

2D路径是“官方正负scribble → 参考图SAM掩码 → 原生图像query → 固定地图”。评估拒绝打开目标RGB，先保存预测再允许读目标GT。推理网格1008×756；官方目标GT为3985×2988，按manifest指定nearest插值连续响应，再以 `>=0.5` 判定。响应含义是membership probability，**不是历史 foreground/background cosine margin，也不声称与已发表SAGA配置完全相同**。早期首次评估因网格不同明确失败，未生成分数；随后显式加入此适配。

## 实际目标成绩与交互约束

| 模型 / 查询路径 | IoU | AP | pixel accuracy |
|---|---:|---:|---:|
| 原生基础场，SAM图像query | 67.67 | 83.78 | 88.74 |
| 图像残差，同样query | 66.55 | 84.55 | 89.24 |
| 基础场 + 完整signed参考图约束 | 68.40 | 82.93 | 89.09 |
| 图像残差 + 完整signed参考图约束 | 68.46 | 85.28 | 89.40 |

图像残差在这里没有单独提高IoU，不能以LERF两场景的收益直接晋升跨benchmark方案。最后两行差距很小，不当作可靠胜出。

新增的signed步骤只拟合当前查询的97维临时系数，在冻结字段上给图像logit施加有界修正，并通过真实参考视角渲染拟合完整正负scribble；不更新地图、encoder或几何，不读取目标GT。默认预算120步，按参考图的支持域内正负平衡错误率选系数，其次BCE。它改善了提示遵从，但两组都**没有满足全部支持域内约束**，应记录失败，不声称严格满足交互输入。

基础场的完整正/负提示符合率从90.49/97.93%变为91.54/99.61%；残差场从84.06/99.99%变为87.45/99.88%。平衡错误率改善不意味着每种约束单独单调改善。

## 更关键的支持域问题

`train_three_query_field.py` 为保护native64，将整个 field.observed 设为源区域native锚的有效域，同时结构训练与全部查询共用该域。这是原保护实验的明确限制，**不能当作几何可见域本身**。

支持分解实测：

| 正像素队列 | 几何覆盖（部署alpha门槛） | alpha > 0.1覆盖 | 最终语义支持 |
|---|---:|---:|---:|
| 参考图正scribble | 100.00% | 99.95% | 93.46% |
| 未见目标前景GT | 98.00% | 96.26% | 90.96% |

参考图1,486个正提示像素有几何，却被语义支持域排除；目标前景241,709个像素属于同类问题，另有68,759个几何缺失像素。不能把约9%的无有效响应统一归因于MoGe几何，也不能仅放开mask让随机或未监督特征参与召回。

已完成的支持扩展控制仅对原先缺失的载体采集固定源RGB局部tile的真实原生特征，要求至少两个训练源视角贡献，旧支持行不改；文本/点提示仍保留旧域，新图像行不外推未经训练的结构/残差头。扩展必须同时更新image响应的分子与raster归一化分母；仅改变输出有效位会造成新的实现错位。该控制结果如下；保留原始对照，不覆盖历史字段。

证据：

- `nvos_frozen_authority_20260916/fern/field_execution_20260917.json` 及各阶段报告。
- `nvos_fern_image_route_20260917/report.json`、`nvos_fern_signed_image_route_20260917/report.json`。
- `paper/artifacts/nvos_fern_cold_queries_20260917.json`。
- `paper/artifacts/nvos_fern_geometry_semantic_support_20260917.json`。

NVOS其余场景、ScanNet OVS同完整方法、物理实例/absent query以及跨场景稳定性均未验收；没有新的独立最终test。

## 源贡献分辨率定位及实测修复

相同几何、相同训练视角，在96×128源网格上只有98,938个载体有贡献（至少两视角94,279）；384×512增加到135,262（至少两视角134,887）。这不是新增几何，而是源特征采样遗漏。固定4×4原生RGB局部tile编码，仍在96×128贡献网格补特征，只补4,161行，目标支持90.96→91.23%，基础场IoU67.67→67.45%，不采用为独立改进。

384×512重建贡献后，实际给41,854个原先缺失载体采集至少两个源训练视角的特征，总image有效行135,258。原来93,404个有效行、所有原参数及几何保持不变。新增行只填写native前缀，结构后缀为零，不调用原残差头；text/prompt保留原有效域。目标正像素支持达到97.9982%，与当前几何覆盖一致。

| 相同目标/评分协议 | IoU | AP | accuracy |
|---|---:|---:|---:|
| 基础场 + 高分辨率实测支持 | 70.58 | 87.85 | 89.66 |
| 图像残差 + 高分辨率实测支持 | 69.88 | 88.29 | 90.26 |
| 基础场 + 高分辨率实测支持 + signed | 71.78 | 86.09 | 89.94 |
| 图像残差 + 高分辨率实测支持 + signed | 71.94 | 89.19 | 90.31 |

主要可归因收益来自补全实际源特征支持域。基础场同协议IoU增加2.91点；同signed协议增加3.38点。最后一行相对最初基础场增加4.27点，但同时改变支持域、残差和交互推断，不把全部收益归因于单一模块。残差在signed条件下仅增加0.16点，尚不足以认为可靠胜出。signed后仍存在未满足提示，不能声称硬性满足所有输入。

保留性核验（冷启动query加每模态4个固定随机query）：text/prompt全行响应差为0，image原93,404行差为0。有限query测试不能替代无限query数学证明；代码通过模态有效域隔离和旧行不变保护路径。渲染必须各用对应模态的支持质量作分母，不能共用扩大后的image分母稀释text/prompt。

新增证据：`nvos_fern_measured_support512_20260917/report.json`、`nvos_fern_signed_measured_support512_20260917/report.json`，以及仓库 `paper/artifacts/nvos_fern_support512_retention_20260917.json`。这些仍是fern开发结果，不是八场景/联合benchmark验收。


## LERF推广对照：覆盖增加但召回基本不变

沿用同一384×512贡献、4×4原生RGB tile、至少两源视角的预定规则，figurines/ramen分别新增10,944/37,280行。对照是已有image-only残差候选，原模型在修改后的评估器上重跑逐观测完全一致。

| 场景 | image IoU：扩展前→后 | image AP：扩展前→后 |
|---|---:|---:|
| figurines | 39.4111→39.4083 | 57.6561→57.6806 |
| ramen | 19.9111→19.9131 | 47.6766→47.7027 |

所有参考text/prompt逐观测不变。冷启动固定query加随机query验证原支持行响应相同，注册prompt核验显式绑定原几何。结论：支持缺失在fern是实质瓶颈，在这两个LERF场景并非主要召回误差；不以载体覆盖增加宣传跨场景精度改善。证据及实现快照封存在 `paper/artifacts/measured_support_seal_20260917.json`，原模型和失败/中性对照均保留。
