# 从裁剪规则转向受过区域语义监督的读出

2026-10-03。本轮改变源侧语义表征，不再扫描置信度、温度和融合强度。
默认系统仍为v5。全部120项新预测与冻结点评价已经完成；没有新增单元测试框架或参数扫描。

## 研究问题与参照

此前完整对照已经显示：真实范围上的原生教师类别排序可能错误；不能默认教师正确，
只把损失归因于三维场或紧凑化。本轮分离两个因素：自然上下文是否缺失，以及读出是否
受过区域识别训练。几何和评价协议均保持冻结。

[Mask-Adapter原论文](https://arxiv.org/abs/2412.04533)与
[作者代码](https://github.com/hustvl/MaskAdapter)直接讨论正确掩码下裁剪/池化识别仍会失败，
使用训练得到的语义激活图汇聚区域及上下文特征。我们复用其公开预训练能力作为外部教师，
不把该模块或训练思想声称为RADIO-GS的新贡献。也没有将它的权重移植到不兼容的SigLIP空间。

## 1. 仅保留上下文，不足以解决身份识别

同一SigLIP、同一1.5倍范围窗口、384分辨率、全部1,158源图及5,392个非空类别集合：
自然图像经过一次编码，同时输出原始全局描述子与只在最终注意力汇聚时限制掩码的描述子。
后者允许Transformer读取上下文，但未训练新的区域识别能力。

|区域表征|直接类别回读19/15/10，%|只参与冲突消解19/15/10，%|
|---|---:|---:|
|前轮灰背景集合裁剪|51.666103 /53.687556 /62.382611|60.064263 /61.447709 /71.558695|
|自然上下文，全局汇聚|31.022522 /33.330232 /42.482079|60.363293 /61.770702 /71.738755|
|自然上下文，最终汇聚限于范围|41.132035 /43.555672 /54.259521|60.293159 /61.675780 /71.632086|

v5完整结果59.592965 /60.869057 /71.430577%。两个新冲突分支19类均8景提高、2景不变，
但增益仅约0.7个百分点。两个直接分类分支均10景下降。40项评价均完成，原生先验指标差为0。
**仅恢复背景或只限制最后的汇聚位置，不能替代区域语义学习。** 不据此开展窗口/温度扫描。

## 2. 同骨干检验学习区域读出

新增可选教师：作者FC-CLIP + Mask-Adapter checkpoint；使用其中冻结ConvNeXt-L CLIP和区域读出头，
不调用其分割预测器。仍使用原有源检测范围，类别集合和几何传递保持相同。

同一完整源图短边800、长边上限1333，归一化后补齐32倍数。每张源图只做一次骨干编码，
同时得到普通二值掩码池化、学习语义激活图池化；二者使用相同原生CLIP文本坐标及完整19类名称。
未增加同义词、类别专用规则、参数搜索或源图上限。学习头的16个语义激活图按作者实现读出。
原始SigLIP地图保持不变。

|同骨干、同掩码读出|直接类别回读19/15/10，%|只参与冲突消解19/15/10，%|
|---|---:|---:|
|普通掩码池化|53.140041 /55.043842 /64.877690|59.969888 /61.303591 /71.528704|
|公开预训练Mask-Adapter|58.844875 /59.908476 /69.573109|60.192913 /61.578239 /71.822583|

直接类别回读净增5.704834个百分点，支持“区域语义读出方式有重要影响”。
但58.84仍略低于v5，冲突模式也只比v5提高0.599948个百分点，不能把5.70记为相对主线的收益。
源侧检测名直接作类别的同读出对照为58.386028%；新识别头尚未形成明显优于该简单对照的完整结果。
学习冲突分支19类8景提高、2景不变；累计纠正6,699个、破坏2,711个原本正确的评价点。
这是点数汇总，不是场景宏平均IoU。

40项评价完成。新增1,158次完整源图骨干编码，5,392个范围各产生两种描述子；无新SAM调用。
两分支缓存共71.79 MiB，公开完整checkpoint约1.55 GiB；原有模型、图像、地图和源缓存额外计算。
构建耗时记录为各进程合计208.73秒，包含各场景模型加载；不等于单GPU延迟或端到端查询时间。
相对SigLIP对照还改变了外部预训练及图像分辨率，不能把跨骨干差异归于我们的算法。

## 3. 查询无关地图中的独立验证

已完成原有全部73,905个自动区域、1,158源图的同骨干两分支建图及20项评价。
只替换区域字典中的描述子，保留原有稀疏W、几何及完整源视图顺序；构建不读取类别查询或query条件检测。
文本编码随字典切换至同一CLIP坐标，避免异构空间直接匹配。结果均为固定10景宏平均。

|地图表征|map-only 19/15/10，%|保留v5源融合后19/15/10，%|
|---|---:|---:|
|v5 SigLIP区域字典|50.147691 /51.846346 /61.127582|59.592965 /60.869057 /71.430577|
|ConvNeXt普通掩码池化|49.601052 /50.640539 /62.541344|58.300036 /59.339037 /70.788887|
|ConvNeXt + 预训练区域读出|57.737935 /58.547684 /70.270321|60.273548 /61.830371 /72.138956|

**地图本身相对v5提高7.590244个百分点19类；同骨干的学习读出相对普通池化提高8.136883个百分点。**
前者9景提高、1景下降（scene0347下降6.188个百分点）。说明改善不只是局部案例，
也不是单纯换一个普通骨干即可获得。两个同骨干分支拥有相同输入及骨干编码次数，
学习头仍有额外推理开销与外部预训练知识，不能称为严格等总算力或我们的新机制贡献。

完整源融合只相对v5提高0.680583 /0.961314 /0.708378个百分点，19类8景提高、2景下降：
scene0062下降5.586，scene0140下降2.032。**不把离线地图的7.59个百分点算成完整系统的收益。**
逐景结果和配对评价点见`output/adapter_observation_control/comparison.json`。

新地图对、旧系统最终错的59,032个有效评价点中，后续融合保留27,320个，仍丢失31,712个。
另一方面源融合也纠正新地图的42,168个错误点，同时破坏39,677个正确点。
这说明源范围证据既有补充作用也有破坏作用，不等于应该取消源辅助。
这些均是生成预测后的真值诊断，未反馈为类别专用规则；点数不等于宏平均IoU。

每种新地图语义部署文件合计约1.1043 GiB，模型、几何与源辅助资源另计。
地图构建共新增1,158次骨干前向，两种描述子共用该前向；所有区域均进入构建，未设小区域或源图数限额。
各场景构建进程合计557.90秒，不含随后查询与评价，不能用作端到端单GPU延迟。
当前是768维原生教师字典，不是已经验证的紧凑多教师学生。

## 4. 更好的地图能否靠范围外直接弃权获得完整收益？

再完成20项严格固定对照：旧/新地图分别将未检测到的范围外像素从负证据改成未知。
只在既有visibility vote中取消这些负项，保留正证据、原有正置信度、可见性和0.1先验强度。
没有同时改成另一套分类解码，没有重新缩放正置信度来抵消负证据的删除。

|固定地图|原源融合19/15/10，%|范围外未知19/15/10，%|
|---|---:|---:|
|v5 SigLIP|59.592965 /60.869057 /71.430577|56.688070 /57.699894 /67.809623|
|预训练区域读出地图|60.273548 /61.830371 /72.138956|59.602818 /60.429842 /71.628947|

直接取消负项，两张地图均未提高完整结果。未知规则语义上避免把漏检当成负例，
但它本身不能抑制错误正范围；当前二值正范围和独立类别投票仍会把误检传播出去。
这一对照不能证明所有原负证据正确，也不能证明每一个退化点都是误检导致。
**下一步需要可独立验证的身份与范围证据决定覆盖关系，而不是再扫描先验强度或全局弃权系数。**

## 系统决策

本轮确认了可复现的上游能力改善，并完成从源表征到查询无关地图、再到源融合的分责。
现有骨架保持：冻结几何、原生匹配坐标、显式区域到元素传递和类型明确的读出。
但外部教师改进尚未转成稳定的大幅完整收益，故v5继续作为唯一默认，新读出为明确的研究候选。
没有逐场拼接最佳结果，也没有把此闭集类别算子应用到LERF整体/部件或NVOS参考实例。

下一阶段只聚焦一个方法问题：源范围可能不完整或认错时，如何在独立身份依据下决定
哪些正/负观察能够覆盖地图；用同一固定新地图和相同源证据比较最小机制与现有vote。
不能把外部Mask-Adapter成果包装成我们的论文贡献。独立新场景与四query真值仍是未完成项。

## 实现与复现

- `radio_gs/models/context_region_encoder.py`：未训练的自然上下文/范围汇聚对照。
- `radio_gs/models/pretrained_mask_adapter.py`：公开预训练头的推理移植与同骨干普通池化。
- `radio_gs/pipeline/category_union_adapter.py`：查询条件源侧集合编码，不能当作离线地图。
- `radio_gs/pipeline/adapter_observation_field.py`：查询无关自动区域字典构建，W不变。
- `scripts/research/run_source_identity_control.py`：共用完整对照入口，避免再复制每轮读出实现。
- `scripts/research/run_adapter_observation_cohort.py`：完整10景双地图构建及独立生成后评价。

```bash

PYTHONPATH=. /root/miniconda3/envs/cybersim_agent/bin/python scripts/research/run_source_identity_control.py

PYTHONPATH=. /root/miniconda3/envs/cybersim_agent/bin/python scripts/research/run_adapter_observation_cohort.py
PYTHONPATH=. /root/miniconda3/envs/cybersim_agent/bin/python scripts/research/run_region_negative_control.py
```

完整输出`output/union_context_control/summary.json`、`output/union_adapter_control/summary.json`；
新增地图结果`output/adapter_observation_control/summary.json`，范围外未知对照`output/region_negative_control/summary.json`。
配对诊断见各目录`comparison.json`。遵守各分支的源照片权限，GT只在生成预测后的评价中读取。
这些是同一开发队列上的机制对照，不是独立新场景、公开SOTA或我们的新颖性证明。
LERF/NVOS未在这些ScanNet类别实验中修改；四query的精度、独立3D提取及紧凑学生仍待完成。
