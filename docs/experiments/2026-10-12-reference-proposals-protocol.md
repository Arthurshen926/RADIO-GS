# 将候选范围保留到成员提案：固定完整对照

上一轮edit实际86.8689%、旧响应83.8238%。trex退化主要表现为错误扩张。

假设：前端提供的候选范围应在后端保留为提案许可，而不是只用于初值后被
完全丢弃。候选许可不是成员真值，不要求同组同步，不锁定任何正成员。
候选外未知不生成新的背景监督；其能否正确补全需要另有身份准入证据。
本实验先检验这个最小函数接口，不声称范围限制或坐标下降本身新颖。

固定原八请求/七场/120源观察、完整当前SAM参考mask/camera、同一场、原组合
初值、等权A_obs/R_set数据项、.1有限改动足迹和四遍预算。无训练、新场状态、
历史源RGB/mask/camera访问、查询答案存储、连续参数拟合或参数扫描。
完整参考mask生成成本继承，不替代raw笔画。

全八例四条件，主候选预定为scope：

- free：上一轮edit完整公共路径复现，全部可用成员可提案。
- scope：提案域为前端选中区域的正关联并集、与原可用成员域取交；初值
  必须是其子集，任何初始成员仍可删除。范围内独立Gaussian也可增添。
- matched：固定seed20261012，仅在非初始、可用成员中随机重排范围许可。
  以当前A_obs的未观测、前景多数、背景多数、精确平票四类分层，保持每层
  可新增候选数和初始成员不变。未另匹配空间局部性、足迹幅值或身份真值。
- prioronly：提案域仅为初始集合，结果只能是其子集，仍可删除任意初始成员。
  它用于检验scope收益是否仅来自不再扩张，不是预定部署方法。

先封存全部32预测，再评分。free必须与上一轮edit选集逐位一致，响应最大
误差<=1e-6；各条件的初值、物理成本、范围输入和完整可用域完全一致。
物理算子不截断，所有条件的最终集合仍在原完整几何中评价；提案域只是
坐标更新许可，不是重新归一观测或删去场景几何。

独立审计重建区域并集、观测分层和随机控制，检查最终可行域、全部初末
物理函数及目标指标；用独立枚举验证受限逐提案轨迹和所有正成员可删除。
