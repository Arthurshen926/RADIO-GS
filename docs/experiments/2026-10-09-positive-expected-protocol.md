# 正部分并集中的射线不确定性：四条件完整八例

前项positive_union_v1完整结果：置信并集响应69.59→80.37%，实际79.46→77.44%，
精确率91.69→81.69%且八例均降，故不晋升。当前射线内部归一化混合原型，
丢掉特征一致性强弱与几何方差，可能放大混合射线。此为待验证原因，不是结论。

固定同场/旧120来源/查询/负分支/尺度/阈值/来源refine，无训练或新场状态。
四条件全部32预测封存再统一八例评分：

1. positive_ray_local：此前log-mean-exp原型能量混合基线，重新预测。
2. positive_ray_confidence_union：上轮失败的置信并集，重新预测。
3. positive_ray_coherent_union：保持并集和像素质量，只保留射线内特征均值的
   原始模长，不重新归一化；空间仍只用均值中心，不引入方差。
4. 主方案positive_ray_expected_union：在3基础上加入同一成员空间能量的射线
   方差项。由原始支持的期望成员能量精确计算，不选择单一深度。

3→4单独测几何方差；2→3测组特征/若启用原生局部特征的一致性模长。本队列
是否有原生局部项由场配置报告，不用这些控制单独解释所有误选来源。内部射线
的概率权重与外部明确正部分的并集是不同职责。保留c_r∈[0,1]，不归一化掉弱
像素质量；仍max_r[c_r sigmoid(E[e|ray])],不是E[校准前景概率]。

已有expected-energy历史失败不能因改名忽略：本次只在每条射线内部积分，
跨明确正部分用并集，区别于把所有正支持平均成一个全局期望。直接对每个
Gaussian算原成员能量再加权积分的独立单测必须一致；单深度退化到原并集。
