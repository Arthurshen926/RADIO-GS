# 源范围审阅、三段定位与 v2 完整依赖重建

本轮按用户“你来审阅”的授权，由助手实际查看源 RGB 与 mask 图。审阅不属于独立人工 GT；没有把审阅结果写入训练。专家 P0–P5 清单仍未全部完成，尤其 P3 的可泛化查询条件范围训练、P4 父模型也未见的家族验证和 P5 同完整方法跨 benchmark 仍有缺口。

## 1. 11 组审阅：不能把所有碰撞都归结为同一种错误

审阅记录：`docs/reviews/2026-09-18-source-scope-review.json`。

- 袋子/塑料容器：可辨认的不同物体范围，不能共享同一答案。
- 两种“许多塑料玩具”描述：近义集合查询，教师却一边只标单个蓝色玩具，另一边标多个玩具；属于集合完整性问题，不能据此声明两个查询必须对应不同实例。
- 山/天空、建筑/城市：局部、集合或上下文范围不同，远景几何仍不确定。
- 绿色球/气球、粉色闪光/道路等：指代或教师范围不可靠；不能用未经确认的标签给读出判错。
- 木椅/木桌：木桌清楚，椅子标注仅覆盖窄背景木边，不能认证完整椅子。
- 两组碰撞的完整读出均为空，不应归因于“共同对象头返回同一物体”。

记录保留语义、粒度、身份未知和边界未认证状态。没有将不确定案例自动转成正负真值。

## 2. 一个明确失效链：原生分支找到袋子，范围读出换成其他物体

额外检查 11、21、31、174 帧袋子相关候选图，确认 11/21/174 中同一个直立彩色零食包装袋。31 帧没有选出可靠候选，不当作目标不存在。固定审阅范围见 `docs/reviews/2026-09-18-bag-scope-track.json`。

源教师分别描述为 `bag of candy`、`candy box`、`plastic bag`。按完全相同短语收集证据时，`plastic bag` 只有 174 帧，因此未进入需要至少两视图的概念组。这个事实在 v2 全量缓存中仍成立。

| 同一目标的源诊断 | 三视角平均 IoU |
|---|---:|
| 同视角范围投影回环 | 95.35% |
| 审阅确认对应，其他两视角范围经冻结几何传递 | 67.66% |
| 自动同短语证据，相同留出视角传递 | 39.68% |
| 当前原生文本分支 | **70.50%** |
| 当前完整文本读出 | **0.058%** |
| 其他两视角审阅裁剪形成图像 query | 57.26% |
| v2 完整重建后的完整文本读出 | **0.029%** |

几何、目标、query 文本均固定。后两种文本分支间的巨大差异直接证明这个案例存在有害范围接管；不能归咎于原生教师不认识目标或 64 维压缩。图像参考提供了额外身份信息，不能视作等信息的文本基线。

这些是选定源对象、教师像素边界和助手确认身份下的开发诊断。原模型看过源图，目标视角仅从各自传递/参考池排除；不是独立 benchmark，也不能相减分配可加的因果责任比例。

## 3. 自动对应的有界修复控制：没有共同收益，不启用

实现不依赖短语相等的源区域双向几何对应。要求双向深度一致 IoU、覆盖、precision/recall、原生描述符相似度和视图对内互选；保留候选关系，不能宣称物理身份已验证。

新模块 `linked_scope_evidence.py` 仅做一次关联：

- 推断前移除所有涉及留出视角的边；
- 只从原始检测出发，不沿新关联递归传播；
- 已有同短语检测的视角不被静默覆盖或扩大；
- 缺失检测保持未知；同视角范围先做像素并集，再投影。

得到 figurines/ramen 255/512 条候选对应。完整符合条件源短语的留出视角比较：

| 源 mask 传递 | Figurines | Ramen |
|---|---:|---:|
| 同短语原始证据 | 41.004% | 52.195% |
| 单跳关联补充证据 | 40.902% | 52.514% |
| 有新增证据的观测 | 605 | 265 |
| IoU 改善 / 退化观测 | 248 / 278 | 116 / 113 |

不推广为共同改进。它也没连接到袋子背面：174 帧袋子的最高双向几何 IoU 候选为 38 帧的 `camera` 区域（IoU 0.568、描述符余弦 0.595），被外观条件拒绝。仅凭几何重叠放宽关联并不可靠；不能为修袋子而调低阈值。

## 4. 家族验证审计：旧短语留出远远不够

按同视角显著重叠或整体/部件包含建立保守污染家族，连接的短语必须同折。它表示潜在信息重叠，不认证物理实例。

- Figurines：251 个短语，6 个家族，大小 `[246,1,1,1,1,1]`；旧验证 49 条中 48 条与训练侧有重叠边。
- Ramen：100 个短语，5 个家族，大小 `[61,21,9,8,1]`；旧验证 19 条全部与训练侧相连。

两个划分都因巨大家族支配而标为不可用。不能切断包含关系制造均衡折，也不能把少数小孤立家族当作充分验证。家族生成器同时检查生成器输入、多级关系、端点合法性和过度集中的划分。

P4 尚未通过：本轮没有重训父场和范围头来消除这些家族曝光。后续应先用审阅明确范围家族/排除不适合作目标家族的模糊上下文，或采用完整场景隔离；候选生成和收益验证必须真正分离。

## 5. v2：完整重建所有受影响资产，不覆盖旧结果

执行入口：`scripts/audits/run_v2_scope_rebuild.py`。两场景重新执行全量源短语 SAM grounding、原生 mask 去重、描述符、区域提升、概念组、独立范围、渲染范围、候选、路由、校准、图像残差、收益准入与完整在线/记录编码重放。

复用的只有与 caption 无依赖的冻结几何、基础 SAM episodes、四教师、原生像素融合及结构场等资产，全部复制并验证哈希。Caption grounding 位于这些基础资产之后；本轮并非从原始 RGB 全部重训。训练均通过 source guard，旧结果完整保留。

本次还使用已有“同视图先并集再投影”的范围提升修复，因此不是只有 v2 去重一个变量的消融。新缓存区域数明显变化，任何新分数只能绑定新模型。

完整数值和在线/重放、原生场、几何、prompt 不变量检查由 `scripts/audits/verify_v2_scope_rebuild.py` 写入 `paper/artifacts/v2_scope_rebuild_20260918.json`。不能把混合收益称为共同性能晋升。


完整开发评估（每格为 IoU / AP，百分比）：

| 场景/任务 | v1控制 | v2重建 |
|---|---:|---:|
| figurines / text | 46.20 / 66.80 | 43.81 / 60.08 |
| figurines / image | 49.95 / 66.84 | 46.16 / 64.08 |
| figurines / prompt | 46.56 / 64.39 | 46.56 / 64.39 |
| ramen / text | 32.97 / 49.75 | 33.47 / 50.87 |
| ramen / image | 29.77 / 56.69 | 32.06 / 54.61 |
| ramen / prompt | 32.94 / 49.20 | 32.94 / 49.20 |

两场完整在线与记录编码重放的逐观测指标、逐query分数哈希均一致。原生latent/decoder、支持域和几何保持精确一致；prompt逐观测精确不变。Caption依赖的文本范围、图像残差重拟合，因此图像结果允许变化。新模型没有达到共同性能晋升要求；未按场景拼接新旧最优。

相关15项测试通过，新增脚本语法检查和 `git diff --check` 通过。

## 6. 后续验收边界

已完成审阅授权、一个可信对象的分段定位、自动关联有界控制和验证污染审计。它们没有解决全部核心问题。下一项实现应直接针对实际 query 条件下的范围学习及原生正确响应被破坏的风险，先用审阅诊断验证机制，再看完整分母；不能再用更高源拟合率替代这个检查。

同版本 benchmark 缺口登记在 `paper/artifacts/current_benchmark_gap_matrix_20260918.json`。旧 NVOS 图像分支结果不能填入完整 caption 方法，历史 ScanNet 或 LERF3D 不能填入当前 96D 方法；P5 不能标已完成。
