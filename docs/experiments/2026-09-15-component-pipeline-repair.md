# 源区域、元素教师与三类召回流程修复

本轮以 pipeline 正确性为先。保留上一轮的几何冻结、源/验证分离、监督绑定、冲突弃权和覆盖检查；在此基础上重建源区域和三类 query 输入，并逐项做对照。统一源区域的开发候选改善了图像和注册点提示召回，但没有达到所有指标共同提升，更不是历史主线性能已恢复。

## 确认的问题与处理

### 独立单位区域目标可能根本不可同时满足

旧 `native_region_alignment` 要求区域内单位元素向量的加权均值等于单位教师向量。由三角不等式取等条件，区域里每个正权重元素都必须指向同一目标。两个相交区域的目标不同，两个约束就无法同时精确成立。旧源区域审计中，figurines 有155对显著相交区域，其中101对目标余弦低于0.95；ramen为793对、649对。相交门槛为至少20个共同高置信元素，且覆盖较小区域至少10%。这不是调大训练权重能解决的优化问题。

训练入口现在拒绝普通 `--native-space-alignment`；只有明确添加 `--allow-legacy-region-alignment` 才能运行历史控制。旧函数保留用于复现和不可满足性测试，不作为推荐方法。

新增 consistent native element teacher：先把源区域描述混合到源像素，再通过冻结几何的真实合成贡献融合到元素，最后每个元素只归一化一次。一个元素只有一个方向目标，因此这项特征监督自身有可实现解。它不是所有区域召回标签、其他教师目标也相容的证明。训练产物绑定 episode、教师清单、几何、SVD基和源视角；只用于训练，不是推理时额外查询的场。

### 局部区域教师遗漏了大量可见元素

原区域教师只覆盖 figurines 的55,900/92,249个可见元素（60.6%），ramen为166,544/255,984（65.1%）。新增固定6×8源图裁剪网格、两种裁剪尺度，只补没有区域mask覆盖的像素，使用同一冻结贡献融合。两场景教师覆盖均达到100%，独立多视角证据元素分别为51,978和181,032。

覆盖率是证据可达性，不是语义正确率；融合向量的长度也不能当作校准后的置信度。没有使用目标RGB或目标GT补洞。

### 三类 query 的输入粒度没有同步更新

只升级语言定位，却保留旧图像碎片和点提示对应，会让三类输入学习不同粒度的区域。新流程从相同源SAM3定位结果产生连通外观区域，分别重新计算原生SigLIP裁剪、区域DINO、注册正负点和跨视角任务。语言仍监督类别并集，图像/点提示使用连通外观支持；不把连通分量冒充物理实例身份。

figurines 源区域92→223，图像/提示任务各32→128；ramen 源区域174→218，图像/提示任务各136→322。源grounded文本仍为63/99条任务，固定79词定位词表不按评估类别扩充。原验证区域、几何及训练/验证视角划分保持一致。新资产全部写入独立 `component_retrieval_pipeline_20260915` 目录并重新编译、绑定，历史文件不覆盖。

新区域会暴露更多伪对应矛盾：figurines排除7,930个query-element相反标签对、1条与输入点冲突的目标任务；ramen分别53,522对、5条。保护措施保留，输入点监督保留。扩大区域不等于对应真值更准确。

### 教师“保持住了”不能作为任务验收

仅用软元素对齐，初始化教师方向仍会明显漂移；新增可选余弦锥约束可量化保持程度，并在训练结束检查最小余弦。另提供 element-only SigLIP 路径，让真实元素目标承担SigLIP监督，不再用独立SigLIP解码头吸收误差。RADIO、DINO、SAM辅助监督仍可独立选择。

但强保持原生方向的完整三query实验失败：figurines图像AP约0.55，IoU却为0；该模型图像读出scale约6.39、bias约−6.25，正概率阈值对应余弦约0.979，实际源图像拟合IoU也仅0.028。这是读出和受限特征训练未收敛到可用决策的直接证据，不能用较好的排序能力掩盖。ramen的文本和提示也退化。余弦约束、固定SVD、可学习标定均不提升为默认。

进一步以逐像素归一化的逆mask面积替代等权区域混合，不改变几何/像素观测总权重。源图像正负平均余弦间隔仅从0.1900→0.1925、0.11758→0.11773；ramen仍有2条源任务平均间隔非正。它没有解决主要退化，保留为失败对照，不包装成有效修复。

## 复现入口

新根目录为 `/mnt/pool/sqy/results/RADIO-GS/output/component_retrieval_pipeline_20260915/{scene}`。源流程依次使用：

1. `build_grounded_native_region_inventory.py --split-components`：源定位连通区域和原生描述。
2. `prepare_component_source_root.py`：隔离的新源教师/query输入和原验证资产。
3. `compile_three_query_episodes.py`：三类输入、几何对应、注册提示和训练任务。
4. 在新根目录重新运行源SAM3定位及grounded监督编译，核验完整新资产绑定。
5. 可选 `build_consistent_native_element_teacher.py --dense-fallback`：独立实验所需的元素教师。

推荐训练形态如下；figurines用768步、ramen用1932步。它保留共享可学习文本/图像适配器和固定读出，没有强制原生方向约束。

```bash
python radio_gs/scripts/train_three_query_field.py \
  --root ROOT --geometry GEOMETRY --name NEW_RUN \
  --steps STEPS --share-siglip-adapter \
  --grounded-text-supervision ROOT/grounded_text_supervision.pt
```

移除RADIO使用 `--teachers dino,sam,siglip`。训练禁读RADIO缓存，不是把权重置零但仍依赖缓存。所有推理继续使用同一元素场，不读取训练teacher、episode或元素教师。

## 验收范围与尚未解决的问题

本轮几何未改变；训练及冷加载核对完整绑定，不能由这些检查反推“几何精度已优于历史版本”。没有新增独立3D真值实验。

相关单元回归分两组85+16=101项通过；包含不相容区域目标、可实现元素目标、梯度分离、余弦投影、教师绑定、连通区域、归一化聚合、冲突/提示保护和共享查询加载。语法检查与diff空白检查通过。早期隔离目录使用软链接被不可变资产检查拒绝，已改成独立复制并重建；失败日志保留，没有用放宽哈希规则绕过。

仍需解决的实际问题是：源伪对应/类别并集不等于完整对象或实例身份；紧凑空间的开放词汇泛化仍不充分；受限原生空间和概率读出存在收敛/校准风险；ramen文本排序退化尚未消除。训练源拟合很高不构成测试能力的保证。后续应首先提高跨视角对应的可验证性和正负任务可靠性，在独立源验证上约束读出，再做冻结协议下的历史回归。

本轮所有训练、失败控制、指标和文件哈希由 `paper/artifacts/component_pipeline_iteration_20260915.json` 汇总，不删除失败实验，不把重复使用的开发数据改称盲测。
