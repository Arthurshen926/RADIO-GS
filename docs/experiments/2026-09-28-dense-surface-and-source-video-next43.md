# Next43：稠密语义载体与合法源视角视频传播（2026-09-28）

## 结论与执行边界

本轮完成两条方法实现及固定配方对照：NVOS 8 项视频证据融合，以及 figurines、ramen、ScanNet scene0000 的两种稠密教师 × 四种承载方式。NVOS 有实测增益；稠密文本替换没有成功，不替换保留主线。没有增加防御性测试或协议审计。结果是开发评估，不是独立最终测试或公开 SOTA 对比。

## NVOS：独立时序对应 + 有符号证据融合

原方法主要把一个参考范围写入地图；本轮让参考目标在允许的源视角中连续追踪，再通过冻结几何反投影到同一元素集合。使用已有正提示参考掩码，不新增提示，不读取目标 RGB，不读取目标 GT 来生成预测。SAM3 正反向传播仅访问合法的稀疏源帧；目标缺失视角弃权，掩码边界带弃权。负证据来自对象存在时的掩码外区域，仍是伪负例。固定 60 步融合，原场先验权重 0.1；所有场景使用同一参数。

## 文本：稠密教师与承载方式的受控替换

两种教师：C-RADIO 的 SigLIP 空间特征接原生 SigLIP 局部池化头；直接使用原生 SigLIP 视觉编码器接同一局部池化头。后者无需 RADIO。原始空间 token 与 pooled language embedding 并不等价，先前直接使用 token 的失败结果只作错误接口诊断。3×3 局部池化是实验性用法，不代表已经获得经过训练的高质量稠密语言教师，也不是 LESV 复现。

固定几何下四种方式：全部高斯贡献、仅较强可见贡献、位置与法线分桶的表面索引、表面索引加跨视角鲁棒聚合。完整存储 1536 维原生特征，避免把失败归因于 64 维压缩。表面索引仍建立在现有高斯中心上，并映射回原渲染器；尚不是独立深度一致的 surfel 重建。无新特征元素回退旧场。校准与部署均使用同一回退规则；源侧固定 100 步校准，不使用目标标签选阈值。

## 本轮修正与仍待解决的核心问题

- 修正稠密校准与部署对无新特征元素回退旧场的不一致，最终使用 matched 目录重跑全部 24 个评估。早期未匹配版本不参与结论。
- 视频融合使用与最终读出一致的 image_observed 支持域与证据质量归一化，leaves/orchids 已据此重跑。
- 文本仍缺少经过原生查询验证的稠密定位教师。下一步应先构造/学习保留对象语义的局部特征并在二维源视角验证，再写入地图；单独换载体不能解决这个缺口。
- NVOS 仍缺乏对追踪完整性和跨视角冲突的判断；对象存在不代表掩码完整。后续应以独立视角一致性区分可用负例与未知区，不能靠目标 GT 挑场景或调阈值。
- 附件的多原型载体、完整 identity/extent typed decoder、独立重建/渲染表面载体没有在本轮全部实现；不应宣称整套建议已完成。稠密前置能力失败后不继续堆下游模块。
- 本轮未全量重跑 LERF4、全量 ScanNet8、图像 query 或 UQIS。保留主线的这些结果不变，不能宣称四个 benchmark 都提升。
