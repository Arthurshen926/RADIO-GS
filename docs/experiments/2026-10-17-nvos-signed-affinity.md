# NVOS：范围恢复与实例身份的冲突（N09–N10）

日期：2026-10-17；工作树 `/root/RADIO-GS-query-field`；分支 `codex/tmm-query-response`。

## 当前结论

本轮完成两项方法实验，而非调阈值或单任务修补。**尚未提高最佳完整八任务
成绩，也未达到 SOTA**。最佳观察图像条件三维对照仍是 N08 静态分支：
IoU **88.8424**。N09 完整复跑补测其 AP 为 **96.5817**，低于 v10 的
98.0222；两种 GT 下全部逐任务混淆计数与 N08 相同，但连续三维响应非逐位相同。

新证据的确能够补全 flower 和 orchids，失败原因并不是“所有缺失范围均不可恢复”。
问题是**跨视角的语义相似性没有保住查询所指实例**：horns-center 混入另一个
horn，leaves 混入其他叶片。更高源端拟合质量、增加合法负提示、再经过 SAM，
均不能自动解决这一冲突。直接去掉 SAM 也没有超过原静态方案。

## 固定设计与合法输入

- N09：`nvos_signed_affinity_v1`，ADR0032；九组、八任务，72 张响应全部封存后评分。
- N10：`nvos_direct_affinity_v2`，ADR0033；六组、八任务，48 张响应全部封存后评分。
  它在 N09 评分前登记。四组对照使用 N09 完全相同的连续数组和评分。
- 全部使用固定 0.5 读出、逐任务宏平均、原几何／相机／观察域和 120 步求解；
  分别报告 `GT > 127` 与 LUDVIG `GT / max` 二值边界定义。
- 新分支使用原始参考 RGB、目标 RGB、官方正／负参考涂画、冻结 DINOv2 ViT-B/14
  和冻结 SAM3。**DINOv2、官方负涂画、目标 RGB 是明确的输入扩展**；静态与 v10
  比较不是输入完全相同的模块消融。新 signed/pseudo 两组才具有相同输入和教师。
- 没有修改特征场、训练新教师、增加人工标注、读取目标 GT 决策、调整逐任务参数，
  也没有把不同任务的最高分拼成结果。其他四个 benchmark 的 23 个 job 仅核验
  既有哈希，不能称为重新推理或证明本轮机制已跨任务泛化。

N09 在 54×72 DINO patch 网格上构造正／负／未知授权。仅涂画分支让未标注
区域保持未知；pseudo 对照额外把原参考 SAM 掩码／补集赋予正负标签，再以
同一官方涂画覆盖。正负涂画同时覆盖的 patch 保持未知。

对归一化描述子，用最大正相似度减最大负相似度得到 margin。温度由参考端
signed leave-one-out margin 的中位数除以 log(9) 确定；支持不足或中位数非正时
返回中性证据并禁用更新。温度未使用目标标签。随后通过相同 SAM 解码和原生
射线三维写回。N10 对完全相同的亲和概率直接写回，以隔离二次分割的作用。

## 归因：哪个环节失效

1. **扩大范围与保住身份是两个能力。** 相对静态三维，signed + SAM 在 flower
   新恢复 287,419 个前景像素，损失 397 个；orchids 新恢复 320,701 个，损失 1,435 个。
   但 horns-center 新增 704,841 个误报像素，leaves 新增 779,547 个。
   八任务图显示这些误报主要包含其他实例，不能统一归为边界粗糙。
2. **参考端可分不等于跨视角身份可分。** signed 的参考留一准确率为
   99.8024%–100%，包括严重失败的 leaves、horns-center。它只能检查参考描述子
   对已给正负证据的分离，不能校准目标视角的实例选择，更不能用作整体正确率。
3. **把未知改回全负也不是通用解法。** pseudo 三维比 signed 平均高 4.5009 pp，
   但仍比静态低 2.7613 pp，且失去大部分 orchids 的范围收益。当前标注授权选择
   是范围与干扰抑制之间的冲突，尚未得到可靠统一解。
4. **SAM 不是唯一瓶颈。** 在相同 signed 亲和图上，SAM 使图像 IoU 提高
   4.1607 pp，AP 却下降 8.6843 pp。直接三维写回比 SAM 三维多 7.3633 AP 点，
   IoU 少 3.8496 点。它对边界和完整区域有价值，也会把错误身份解释成自信分割。
   “删掉 SAM 即可恢复完整性能”不受本次实验证据支持。
5. **本轮主要损失在写回之前。** signed/pseudo 从 SAM 图像到三维分别仅下降
   0.0975/0.1526 IoU 点；原始亲和图直接写回反而小幅增加 0.2136/0.1086 点。
   继续优化同一写回分辨率或增加迭代，不对准数个至数十点的身份／范围错误。

![完整八任务：绿为 TP，红为 FP，蓝为 FN](../../output/tmm_response_20261016/study/nvos_signed_affinity_v1/errors.png)

全部新写回相对 v10 的源教师残差均升高；这些输出仍是视角条件响应，
没有证明为查询全局一致的三维场。源教师掩码本身也可能缺范围，因此残差升高
是需要报告的冲突，不能直接当作目标 GT 质量判决。

## 方法收敛与下一步的可证伪设计

已验证的实现仍是 **v10 原生查询身份与证据融合 → 有明确输入条件的响应修正 →
原生射线三维求解和实际重渲染**。N09 提供范围提议的局部成功证据，不成为替代
身份模块的新默认。当前论文不能把未验证的通用授权器写成已闭环贡献。

下一项方法实验应隔离**实例约束能否保留范围收益**：以原始正／负参考涂画
通过已有相机与几何传递得到的可见性证据，约束候选区域的查询身份，再让冻结
教师恢复区域范围。需要把“没有实例证据”保留为未知，不能把旧响应所有低分
像素直接定成背景，也不能只用语义相似或 SAM 质量分数证明身份。

建议同一完整八任务比较无身份约束、v10 响应锚点、原始涂画几何证据三组，
匹配候选、教师、提示和写回。测量 IoU/AP 与误报／漏报的变化，并同时检查源视角
冲突。所有参数、失败回退和主要候选须先固定，再开始预测。这是下一项待实现／
验证的设计，不是本轮已取得的效果。停止亲和温度、阈值、分辨率和逐任务门限扫描。

现有结果未达到论文所报 NVOS 高分。VCAR 的 93.5 使用官方七目标及不同提示／
读出，不能与这里的八任务直接等同。另核对
[NG-GS 的原文 Table 1](https://arxiv.org/html/2604.14706v1)报告 92.6，但其输入、
联合几何优化和阈值也不同；本文不把论文行当作已完成同协议本地复现。

## 实现核验与存储

- 静态图像连续数组八任务与原 N07/N08 父证据逐一哈希一致；静态三维在两种 GT
  下的 tp/fp/fn/tn 与 N08 全部一致。连续三维数组不同，因此 AP 是本轮复跑测量。
- N10 四个父对照的连续数组、混淆计数及 AP 完全一致。
- 独立整数 bincount 核验每组混淆计数；v10 AP 与独立精确分数曲线算法一致。
  原生射线算子对安装版 renderer 的误差低于 1e-4；未观察高斯未被更改。
- signed 授权的三项测试覆盖未知／冲突证据、跨不连通区域传递、支持不足或
  不可分时的中性回退。完整登记测试 167 项通过；整套表格及论文重新生成验证。
- N10 v1 等待任务在任何预测／GT 之前停止，保留调度变更和失败记录；v2
  与 N09 的 CPU 评分重叠计算，没有改方法或根据部分目标分数改变规则。
- 三个运行目录合计 **1,197,630 字节（1.142 MiB）**；没有新增权重或持久密集
  预测。5 个登记的私有预测／父数组目录均已释放。研究目录总量 2,147,188,615
  字节，仍低于原 2 GiB 上限，剩余 295,033 字节；不暗中扩展预算。

本轮打开的八任务是开发队列，不能代替独立最终测试。
