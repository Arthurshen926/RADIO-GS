# 固定几何下的共享元素响应可行性（2026-09-15）

问题：低召回是否主要由同一元素混合正负标签导致，以至于继续训练特征没有意义？新增可重复的解析诊断，分别检查同一 query 的单视角混合与跨视角冲突。未修改几何、模型、教师缓存或训练默认值。

## 方法

在训练视角可见的元素域上，按实际贡献归一化渲染，仅评估支持质量大于 0.5 的已知非冲突像素。对同一 query 汇总各目标视角的正、负像素贡献，得到每个元素的 a_i、b_i。允许该 query 的每个元素具有独立响应 z_i∈[0,1]，绝对误差为 Σ[a_i(1-z_i)+b_i z_i]。解析最小值是 Σmin(a_i,b_i)。减去各视角独立最小值，得到强制共享跨视角响应额外造成的误差。

text 按 text_index 分组，image/prompt 按 query_region 分组；训练与验证完全分离。文本同一目标视角的重复证据先合并。未知与正负冲突标签不生成负样本。记录输入 episode 和 authority 哈希，逐个校验实际贡献文件。

这是固定渲染下独立标量响应的精确 L1 最小值，但只是可学习特征场的松弛问题：没有强制 64 维共享特征、query 线性适配器和余弦响应函数。因此低误差不能证明当前网络具有足够表达能力，也不是 IoU 上限。该诊断不包含 3D hard membership 或提示 seed 损失，不能推断完整训练目标无冲突。报告按标签像素加权，不是任务宏平均；仅针对已有稀疏伪标签，不评价未标注的语义边界或几何质量。

## 结果

|数据/划分|query|最小 MAE|跨视角共享额外 MAE|
|---|---|---:|---:|
|figurines train|text|0.008757|0.007530|
|figurines train|image / prompt|0.0000681|0.00000946|
|ramen 扩展训练 train|text|0.007840|0.006048|
|ramen 扩展训练 train|image / prompt|0.001693|0.000868|
|ramen 扩展验证 validation|text|0.013919|0.012181|
|ramen 扩展验证 validation|image / prompt|0.000359|0.00000990|

扩展验证包含全部 8 个验证视角（31、35、39、42、47、51、55、59），不是此前只取新增 6 视角的指标；不可直接与六视角 IoU 相减。该组含 4 个不同文本 query、41 个不同 image/prompt query，各自聚合多个目标视角。

## 对开发方向的约束

已有标签上的混合冲突很小，暂时没有证据支持为了提升召回重做载体或允许语义梯度修改几何。文本存在更多跨视角伪标签不一致，但是否过滤仍需独立对照，不能直接把伪标签误差当作真值错误。

后续应优先诊断共享低维特征和 query 适配器的表达/优化误差，并继续同时报告覆盖内和全标签质量。不能把本解析标量响应导出为每个 query 的地图，也不能用验证集解析解监督训练。
