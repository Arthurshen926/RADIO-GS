# 系统差距、历史方法迁移与本轮方法控制

本轮针对用户要求核对了实际代码、原始结果、输入权限与输出定义，并完成方法控制。结论是：**最应优先改的是不同范围的教师证据如何写入元素，以及查询如何在这些证据中确定对象范围。当前尚不能声称达到SOTA，也不能把所有问题宣布解决。**

## 当前系统实际怎样工作

1. LERF/NVOS用RGB、已注册相机与MoGe几何构造冻结Gaussian载体，修正尺度、投影和透明度。当前ScanNet保留结果用提供的无标签网格构造载体，是另一输入轨道。后续语义损失不移动几何，载体中“有点”也不保证点、可见性和边界都正确。
2. 合法源RGB上生成query-free SAM区域、原生SigLIP裁剪/文本特征、原生DINO特征以及可选RADIO骨干特征。SAM主要提供范围和边界伪监督。原始区域、后续source-grounded区域及跨视角投影证据构成训练输入；benchmark查询和标注不应参与地图写入。
3. 主场每个元素存一个96D向量：64维原生语义前缀与32维可学习结构部分。前缀通过固定基保留已融合SigLIP特征，结构部分接受教师、关系、范围/提示监督。原生query和场用同一可核验原生空间读出，避免早期随机query适配器与教师解码头各学各的。
4. 文本在原生响应之外使用source-grounded概念范围头、路由与收益准入；概念未被接受时仍可能由原生支持选择proposal并做有界logit修正，最终收益否决才退回纯原生。图像以原生图像空间为基础，也有仅图像使用的有界原生残差；提示依赖注册位置/结构及对应读出。NVOS保留控制还使用参考图SAM支持、查询时优化和空间连通性补全，不能把它与纯文本一次余弦查询说成完全相同计算预算。
5. LERF2D当前开发指标渲染全场概率，在观察贡献上归一化后以0.5判断；选中元素指标先在3D取概率大于0.5的元素，再单独渲染轮廓。这两个输出不能互相替代。当前所谓LERF3D是后一种投影评估，不是独立物理3D真值。

“四教师已接入”不等于四种能力都已成为可直接查询的原生度量。DINO/RADIO辅助重建头不是当前部署图的原生特征出口，32维结构余弦也不自动等于DINO余弦。RADIO可关闭已有路径，但文本能力目前具体由SigLIP提供；功能性替换仍需换成具有文本/图像能力的教师并重建依赖头。

## 核心问题一：区域证据被过早混合，教师认识不等于地图还能分辨

直观地说，教师给“装着面条的碗”整块区域一个描述，给其中“筷子”另一块描述。把两种描述分别涂到覆盖的所有元素，再平均，多次观察后可能形成“碗、面条、筷子都差不多”的方向。后面的范围头看到的是混合后的结果，不能保证把原始区别恢复出来。

这不是仅凭直觉判断。上轮纠正读回权重后，12地图同源文本教师Top1一致率依次为：独立区域64维原生投影78.66%、2D重叠混合56.67%、同视角几何读回54.23%、跨视角地图38.65%。这些是不同受控阶段与原教师的响应一致性，不是GT准确率，各差值不能当作可相加的因果责任。

本轮对figurines同一批22个有支持的小区域进一步分责：

| 阶段 | 文本教师首选一致率 | 图像教师首选一致率 | 图像响应MSE |
|---|---:|---:|---:|
| 原生小区域特征仅投影到相同64维 |59.1%|68.2%|0.0013532|
| 原有地图融合后真实读回 |0%|0%|0.0078789|
| 恢复被过滤小区域后，仍用原融合 |0%|0%|0.0080949|

原地图图像误差是单独投影误差的5.82倍；去掉每区域整体响应偏置后的误差约大89.7倍。**早期学习query适配器破坏原生能力的机制已被当前保护前缀规避，但原生能力完整传到地图的问题仍未解决。** 固定一个已经混合的64维向量，只能防止进一步破坏，不能补回混合之前丢失的区分信息。

22个支持小区域中18个图像MSE严格上升，其中13个与较大保留区域重叠。这13个案例共用94.2%的渲染支持质量，两者原生教师平均余弦约0.71；对应大区域平均面积约34.4倍。这是不同粒度证据混合的具体证据，尚未独立验证其物理整体/部件身份。其余部分没有同视角父区域重叠，跨视角对应、几何读回和教师本身的不可靠性仍在其中，不能把所有损失都算给平均操作。[逐区域诊断](2026-09-26-small-region-fusion-failure-diagnosis.md)

应改的是**证据保留和写入模型**：可信同范围证据可累积，包含关系保留粒度区别，不可靠对应不强行合并；先验证原生查询的相对响应能被写入和读回，再让结构补全范围。区域关系可以约束训练，不必回到“先建完整对象库存、所有查询依赖库存”的早期v4设计。

## 核心问题二：细粒度能力在进入训练前被削弱，几何支持不能保证可分性

检查12地图290个源视角、20,707个原始SAM候选：2,014个（9.73%）因缩到96×128后面积小于0.002被丢弃，尚未生成自己的SigLIP描述符。这个比例是候选比例，不是丢失真实对象的比例。保留掩码原网格→粗网格→原网格平均IoU约87.5–89.8%，细长代理约77.0–81.0%，也不能当成相对人工GT的边界精度。

当前粗网格比历史46×62/60×81更大，元素数量也不少。继续加点或简单扩大维数缺少主因证据。需要分别检查：原始小区域是否进入训练、不同范围在投影后是否仍可区分、跨视角是否落到相同物理表面、何处属于未知而不是负例。

本轮恢复小区域的两个固定先导场景完成：Scan0000小区域文本/图像MSE下降15.72%/7.71%；figurines文本下降4.15%，图像上升2.74%，两个场景未共同通过。恢复候选是必要能力问题，但**把新小区域直接追加进原有平均公式不足以解决它**。[恢复实验](2026-09-26-small-source-region-restoration.md)

几何方面，目前有冻结几何、实际投影责任和观察支持的验证，**没有据此证明所有MoGe边界、多视角身份和尺度都准确**。语义特征可帮助识别不可信对应/边界，但不应该用错误语义损失去移动已较好的几何。ScanNet提供几何与RGB+MoGe轨道必须分别记账。

## 核心问题三：二值范围拟合、查询排序和实际元素选择尚未共同受控

源侧“这个区域要亮”比开放词汇“该query应比易混对象更亮，并且只选完整目标”容易得多。粗概念的范围头可能补全整件对象，却把部件查询扩大成父对象；同名区域也可能属于不同实例或粒度。源二值IoU高不等于开放查询排序、边界或选中元素正确。

本轮将可靠互斥源范围的双向查询排序加入真实渲染训练，两臂同预算、同检查点准入。figurines的排序hinge及实选范围略好，但完整概率IoU/排序准确率略降；Scan0000未得到联合改善检查点。两个场景拒绝扩展。可信互斥对本来已有约98.9%/97.6%的排序准确率，它们未覆盖困难的整体/部件和细身份，单加loss无法补齐监督语义。[排序控制](2026-09-26-source-query-competition-next32.md)

此外发现一个真实优化盲区：现有范围头输出raw概率后硬截断；错到区间外的元素在该路径直接梯度为零。固定源诊断中，相对源伪掩码的漏检像素内，低端截断元素占平均渲染贡献约10.68%/23.58%，这不是总体错误比例。不能据此说所有错误元素永久不可移动，因为共享参数仍可能从其他元素获得梯度。

本轮实现只允许朝合法概率区间恢复的有偏替代梯度，不改前向公式和硬路由规则，冻结原生参数；同参数下梯度替代前后输出完全一致。训练更新范围头后，预测及准入结果仍可能改变。真实训练损失和梯度归属通过独立测试。两场均完成400步配对控制，查询排序改善，但范围联合准入失败：figurines实选24.6577→24.6146%，Scan0000实选46.3763→46.2645%。Scan相同审计范围的错截断贡献减少，说明修复作用于预期机制，**但不是当前范围质量的充分解法**。[梯度机制与控制](2026-09-26-directional-scope-gradient-recovery.md)

## 可以移植哪些方法，哪些不能照搬

| 来源 | 有价值的计算思想 | 当前兼容方式/本轮结论 |
|---|---|---|
| LUDVIG | 按实际alpha×transmittance上拉证据 | 已验证当前归一化会抵消绝对低opacity置信；同几何两源先导直接改raw权重未共同通过，不能盲换 |
| LUDVIG | 语义种子、结构相似度和空间图联合传播 | 已有可运行图控制；须核验32维结构度量而非假定等于原生DINO，防止错误语义沿图传播 |
| LUDVIG | 多次SAM提示的范围稳定性 | 本轮只在允许的参考图做10次正提示SAM；NVOS8 IoU81.1608→81.2840%，AP91.5057→91.2496%，联合拒绝 |
| 历史SurfaceRegionV2 | 物理anchor、core/context、多尺度范围保持分离 | 值得用于来源/范围组织；旧RADIO1280权重不能直接套当前96D，也不必恢复RADIO依赖 |
| 历史identity–extent | 身份证据与范围证据各自可核验，失败回退原生 | 保留当前原生语义保护和准入；禁止范围头仅因同名/包含就覆盖细粒度判断 |
| 后期canonical显式–hash | 元素内先融合local/hash，再做共享仿射解码 | 可烘焙、保持单元素查询与渲染一致；hash是可选容量，当前没有主因证据要求先加它 |
| LangSplatV2 | 高维原生语义码本的稀疏系数、不同SAM粒度保留到读出 | 值得借鉴能力保留与粒度组织；增加两个同一64基内的槽位此前已失败，不能混同此思想 |

LUDVIG恢复的是锁定提交`4461fc515439bb498a75d71738a1e73cf7a452ed`的官方源码，本地旧checkout本身已不在。其图实际由XYZ近邻和PCA-DINO关系构成；文本代码还含依赖同次查询列表的带宽选择，直接复制会破坏当前query A/B/A隔离。NVOS91.26%来自包括目标RGB在内的SAM查询上拉路径，不能拿来证明图传播本身贡献了10点；当前NVOS的参考图限制指查询阶段，不是仅用一张图构图。参考[官方代码](https://github.com/naver/ludvig/tree/4461fc515439bb498a75d71738a1e73cf7a452ed)和[本地审计/参考图实验](2026-09-26-ludvig-local-transfer-and-positive-ensemble.md)。

LangSplatV2联合学习高维语义码本与稀疏系数，并保留多个语义粒度，这不是对每个教师向量做无损缓存；对本项目的启发是“压缩存储不必等于把不同范围平均成一个语义方向”。它并不保证同样技巧直接移植到当前多query合约就有效。[官方论文](https://arxiv.org/html/2507.07136v2)

早期hash在渲染后执行非线性解码，与当前先产生每元素语义再渲染不等价。旧目标RGB GrabCut、目标队列阈值选择和查询词表驱动的源构图也不能混入当前公平对照。移植的是可验证的计算关系，而非把历史高分开关拼起来。

## 本轮最后一项直接写入控制

根据小区域读回诊断，新增固定的细粒度像素证据归属控制：只在恢复的小区域覆盖像素内，抑制面积严格大于2倍、覆盖小区域至少90%的父区域写入；其他源像素的写入权重逐值不变，不符合关系的掩码支持不被删除。受影响像素会重新分配权重，且共享元素的最终其他位置读回也可能变化，不能声称所有其他预测不变。它不把包含当同一身份、不生成额外负例、不增加向量维数。

两场均完成，仍然拒绝：figurines小区域文本MSE下降7.98%，但图像MSE上升4.71%，旧区域/边界图像误差上升1.52%/1.29%；Scan0000小区域文本/图像下降16.54%/8.21%，但旧边界图像误差上升1.203%，超过事前固定的1%保护上限。没有放宽门槛、挑场景或运行目标benchmark试优。

这项控制很关键：它直接干预了早期融合，而非又调一次最终阈值。结果说明局部减少粗粒度写入能改善部分细粒度响应，但“让细区域替换父区域”依然会牺牲另一些能力。**问题需要同时保留可区分的多粒度证据，并验证跨视角身份；单一融合向量里重新分配谁占上风，不足以达到四query共同提升。** 这仍是受两个小型源先导支持的设计判断，不是对所有可能融合算法的否定。记录见 `output/fine_pixel_ownership_next32` 和 `paper/artifacts/fine_pixel_ownership_next32.json`。

## 下一阶段的主任务和投稿验收

优先级应集中在**保留范围身份的跨视角语义写入**，然后才是范围读出。开发顺序是：在同一载体上核对独立区域→重叠像素→元素写入→跨视角读回的文本和图像相对响应；保留整体/部件关系与无法对应状态；通过未参与对应决策的视角检查后，完整重建相关校准/范围头；最后运行全部冻结队列，同时看概率图、实际元素集合、边界、AP和定位。不能只看训练损失或一个平均IoU。

当前保留开发控制仍为LERF2D49.7408%、selected33.5676%、NVOS81.1608%、ScanNet19/15/10为54.5190/55.6667/69.8166%。可选图及源范围控制另列，不能作为一个已经共同验证的默认方法。当前公开队列已反复用于开发，不是未触碰最终test；UQIS按用户要求暂停。四种query在同一地图上的独立、完整评估尚未被这些单项控制取代。

投稿还需要一个共同可冷启动的方法身份、同输入/几何/预算的外部对照、明确独立评估集，以及对单元素输出和不同query能力的消融。以上缺口不能用更多场景阈值、更长训练或不公平的SOTA数字补齐。本轮新实验均保留拒绝结果，不以平均分微升掩盖其他任务退化。

下一阶段待办按依赖顺序限定为以下几项，不继续无目标堆模块：

- [ ] **先保留多粒度证据，再重建场。** 在同一元素的紧凑表示中保留可分别解码的局部/整体信息，区域身份、包含与未知对应分开监督。对照必须使用同一原生教师、同几何、同预算；高维稀疏码本或历史core/context是两种可借鉴机制，不预先宣称某种一定胜出。
- [ ] **共同保护文本与图像的原生相对响应。** 验证发生在真实元素写入和跨视角读回之后；保留小区域及旧区域/边界检查，加入未用于对应决策的视角。不以源伪标签Top1代替实际benchmark，也不复用与新特征不兼容的旧校准/范围头。
- [ ] **用实际选择检验范围改动。** 概率图、实际元素集合、选中轮廓必须同时保存和比较；未知范围不当负例，父子包含不当同一范围，范围证据须经过独立对应检查后才有权改原生判断。
- [ ] **验证结构教师可用性后再扩大图传播。** 从同一场的可解码能力检查DINO式关系是否保留，按实际能力建图；禁止复制query-list依赖、将结构32余弦冒充原生DINO或让错误身份无界传播。
