# 源语义证据、定位排序与成员判定：系统级顺序对照

本轮完成两场景的五种重建/读取对照及一个区域池化诊断。**没有取得整套系统的大幅性能突破。** 可保留的局部进展是：用完整源教师掩码拟合查询相关判定边界，全文本 IoU 从 figurines 33.14% / ramen 4.07% 提高到 33.63% / 8.59%。排序基本不变，图像和注册点结果完全不变。它减少了部分漏召回，没有解决原生语义在地图中定位不准的问题。

## 系统分解与已确认的边界

当前部署流程是冻结几何 → 每 Gaussian 一个 96D 元素向量（64D 语义、32D 结构）→ 原生 query 匹配/注册点结构关系 → 元素后验 → 全场渲染。

上一轮已经验证直接读取结构优于注册点的学习适配器。本轮固定这条结构路径，继续追查文本和图像。源语义前缀原样冻结，只能保护**已经融合进来的语义锚点**；不能保证源教师定位、区域选择、多视角融合及源基底压缩无损。因此不能再把当前全部错误都解释为“训练把 query 空间学坏了”，也不能把参数不变当作原教师全部能力保留。

## 先排查源重建，结果不支持几个简单解释

所有导出对照共用相同冻结几何、64D 语义基底、32D 结构坐标、有效元素、query encoder、校准参数和评估代码。原有模型未覆盖。不同语义锚点的校准参数适配性可能不同，因此同时看 AP，不只看固定门槛的 IoU。

| 全文本方法 | figurines IoU / AP | ramen IoU / AP |
|---|---:|---:|
| 上轮保留模型 | 33.14 / 58.30 | 4.07 / 31.02 |
| 只融合原始 query-free 区域，有空缺处保留原锚点 | 19.91 / 38.49 | 5.90 / 29.83 |
| 每视角内先归一化区域数量，再均衡多视角 | 33.28 / 57.45 | 4.88 / 31.94 |
| 密集局部原生教师裁剪重新融合 | 23.34 / 48.30 | 2.64 / 32.01 |
| 局部已知 3D 标签拟合查询门槛 | 31.92 / 57.42 | 13.93 / 30.83 |
| **完整源 2D 教师掩码拟合查询门槛** | **33.63 / 58.49** | **8.59 / 30.97** |

删除 grounded 增补区域并没有恢复开放语义，反而使 figurines 明显退化。按视角均衡只能带来小幅、混合改变，不能说明区域数量偏置是主因。密集裁剪使用每个源训练视角 8×12 网格、1/8 与 1/4 图像尺度，共每视角 192 个原生 SigLIP 裁剪，经原有贡献权重投到冻结几何。它也没有带来整体改善。该试验仍使用原基底，局部描述符平均投影能量保留约 85.7% / 89.1%；不能据此否定所有密集教师或其他压缩方案。

上述三个锚点替换不进入保留候选。其图像 AP 也未获得一致改善：query-free 为 39.30 / 24.70，密集裁剪为 45.63 / 25.06，均低于原来的 54.52 / 34.21。所有对照的注册点结果保持完全相同。

## 排序能力与阈值潜力分开测

额外诊断采用同一支持域、同一原生 SVD64 基底，并渲染 `(cosine + 1) / 2`，不使用学习 sigmoid。源区域特征直接参与诊断，不是可部署的第二套特征库。两个区域读取分别为概率加权均值，以及 `max(region_probability * region_score)`；它们不是所有非线性融合方法的上界。

| 同合约诊断 | figurines AP | ramen AP |
|---|---:|---:|
| 当前场原生方向 | 57.66 | 30.39 |
| 源区域响应均值 | 56.12 | 27.20 |
| 源区域响应最大值 | 25.88 | 15.89 |

当前场原生响应的**逐观测 GT 最优阈值 IoU**为 48.52% / 26.03%。这是使用目标真值的诊断数值，**不是合法推理成绩，也不是任意新模型的性能上界**。诊断中的最大响应像素位于 GT 内的比例为 76.79% / 26.76%（取排序首个最大值；并列最大值的选择可能影响这一指标）。这些值只用于分解错误，不用于拟合模型。

ramen 存在两类不同情况。例如 frame 24 的 bowl 原生 AP 87.6%、最优阈值 IoU 62.8%，说明有可取出的信息；同帧 wavy noodles AP 7.4%、最优阈值 IoU 9.8%，说明仅改变判定门槛无法解决。不能把所有低 IoU 都归咎于阈值，也不能忽略已排序正确的目标被统一阈值漏掉的问题。

## 已实现的局部修正：源侧学习查询相关边界

新增可选 `native_query_thresholds`，默认不启用。文本输出由固定统一门槛改成：

```
score_i(q) = sigmoid(scale * (native_cosine_i(q) - threshold(q)))
threshold(q) = clamp(w · normalize(q) + b, source_bounds)
```

只增加一个全局 query → scalar 线性头及源范围上下界，不增加每元素特征、类别码本或新教师。全部父模型 tensor 原样保留。它保持每个 query 的原生元素排序；sigmoid 在渲染前应用，因此渲染像素 AP 可以小幅变化，不能声称最终 AP 数学上严格不变。

两种源侧拟合均采用留一源概念验证，从固定 ridge 集合 `[.01,.1,1,10]` 中选择正则，没有 benchmark 查询、目标 RGB 或标签参与拟合。

- 局部已知 3D 标签版本：固定父模型 slope，对每个源概念拟合正负均衡 BCE 的阈值，再回归到 query。14 个概念。ramen 提升更大，但 figurines 退化，保留为权衡对照，不按场景选择它来拼出最优表格。
- 完整源 2D 版本：在原始高置信检测视角，用完整源 SAM3 掩码拟合一个跨源视角阈值，再回归到 query。figurines 28 个概念、ramen 15 个概念。**掩码外部是教师伪负例，不是真实 GT，也不等于已验证不存在。** 没有绕过这个不确定性。源拟合用平均原生余弦，部署仍用渲染前 sigmoid，两者存在非线性混合差异，记录在报告中。

完整源版本在两个场景的全文本与参考子集文本 IoU 均提高，可作为后续开发候选；不升级为跨 benchmark 的共同基线。

同一参考查询子集的最终结果：

| 场景 | 文本 IoU / AP | 图像 IoU / AP | 注册点 IoU / AP |
|---|---:|---:|---:|
| figurines | 32.64 / 56.19 | 33.12 / 54.52 | 40.71 / 57.83 |
| ramen | 8.80 / 30.94 | 13.81 / 34.21 | 24.77 / 51.94 |

全文本是 56/71 个目标观测；参考查询子集是 35/57 个跨视角观测，不能混用分母。图像和点提示采用参考 GT 派生输入；目标 GT 仅用于评分。没有验证物理实例对应、缺席类别或独立最终 test，本轮没有新增 NVOS / ScanNet OVS 成绩。

## 下一步真正需要突破的两个核心问题

1. **源教师的细粒度目标定位能否被可靠地写入地图。** 当前原生锚点就已经把不少真实查询排错。已有证据不支持继续堆步数、简单删除增补区域、调整区域均值或直接加密裁剪。接下来需要在同一源目标上分开原生教师定位、源 masks 的对象/部件覆盖、可见性投影、多视角融合四段，尤其验证细部目标，而不是重新训练一个更大的随机匹配空间。
2. **完整对象范围监督与实际输出合约是否一致。** 已知区域拟合不代表完整对象召回，源 mask 外伪负例也不能假装成 GT。当前查询相关边界释放了部分已有信息，但无法补造面条等目标缺失的区分能力。必须保留 native ranking 的独立检查，再验证对象、部件、同类并集与缺席情形。

## 实现与复核

- 26 项相关测试通过：原生元素排序保持、其他模态不变、上下界、batch/row 独立、冷加载、ridge 外推及旧字段/结构读取兼容。
- 部署候选经冷加载，原生余弦、image/prompt 响应均与父模型逐位相同；参考评估中 image/prompt 每条观测指标完全一致。
- 重建对照保留原有元素支持域和结构坐标；每个实验都记录源资产、模型及源码哈希。
- 不修改旧模型，不根据 benchmark 逐 query 或逐场景选择阈值，不把 GT 最优阈值作为部署分数。
