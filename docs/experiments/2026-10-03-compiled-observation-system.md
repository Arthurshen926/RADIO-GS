## 将区域响应编译成地图

上轮有效方案是先计算原生区域的类别响应，再融合重叠和多视角证据；原实现查询时读取所有区域掩码和相机并重投影。这里把与查询无关的几何关系在建图阶段算完。

定义区域特征字典F，区域到像素的掩码矩阵M，冻结几何的像素到元素alpha贡献A。每个像素重叠区域数为c，每个元素全部有效观察质量为m。跨视图累积得到：

```
W[e,r] = sum_p A[e,p] * M[r,p] / c[p] / m[e]
p(q) = W @ softmax(100 * F @ q.T, over the complete category menu)
```

每个视图拥有独立的区域列，不假设同名区域是同一实例。F保留原生教师坐标，W为查询无关的稀疏非负权重。身份响应先于几何融合；没有提前把不同区域特征平均成一个方向。元素支持域保持不变。

存储为fp16原生区域描述子、float32权重和int32 CSR索引。构建器不读取类别表、查询、评价标签或历史最终答案。推理只读这份观察场和query编码器；源辅助模式再接现有的源证据融合。此类别分支不再读取旧逐元素特征文件、源掩码或相机。

公共构建器：`radio_gs/pipeline/observation_field.py`。公共读出：`radio_gs/querying/native_observation_prior.py`，由现有统一入口调用。研究脚本只负责完整场景调度。

## 完整验证与成本

全10景的先验/完整、19/15/10逐项指标与未编译区域响应方案一致，最大指标差异0。先验48.650799/50.128334/59.544317%，完整58.449245/59.652818/71.027043%。精度收益来自上轮聚合顺序，预编译不产生额外精度收益。

10景语义部署文件从原区域/掩码资产11.029344 GiB变为1.210025 GiB，减少89.03%；相对v2的逐元素特征4.493211 GiB减少约73.07%。这些只统计相应语义文件，不包括几何、模型、源辅助检测缓存或照片。对照资产仍保留在工作区，不能说磁盘已经释放了相应空间。

另以19个新的自然语言表述执行map-only查询，移除源证据、旧特征场、掩码目录及相机配置。与未编译原生观察读出比较，最大概率差7.15e-7，逐元素argmax差0，支持域差0。该实验验证新查询执行与算子等价，不是识别正确率或独立新场景泛化。

结果：`output/compiled_native_observations/summary.json`；新查询：`output/compiled_native_observations/fresh_queries/summary.json`。最终去除旧场依赖后重新执行全部10景公共读出。

v3类别查询总计约20.26–44.45秒/景，包含文本编码器加载、语义读出与既有源缓存融合；为并发观测，非隔离速度基准，不包含建图/源教师生成。编译后响应算子约0.038–0.474秒，**不含调用者加载场文件**，不能将这个算子时间与原实现含文件读取的整段计时直接计算加速比。

这是一种可部署的原生观察场，不是学到的低维四教师学生。互斥类别softmax不适用于直接混合LERF整体/部件的重叠查询。LERF/NVOS未声称获得本轮新增收益；完整四query标注精度、独立3D选取真值、未调参场景泛化及公开SOTA协议仍未完成。CSR预编译本身是线性算子重排与稀疏存储，不单独宣称CVPR算法新颖性。

下一步需要把尚未解决的身份错误和范围错误分开；本轮已排除直接恢复自然背景这一替换。不能因为存储更紧凑就再次进入未经验证的低维蒸馏，也不能把本地开发集收益当作公开SOTA结论。
