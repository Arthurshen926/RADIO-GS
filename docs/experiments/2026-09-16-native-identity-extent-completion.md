# 原生语义与对象范围：补全弃权路径，而非统一替换所有读出

本轮得到一个两个场景文本 IoU 都改善的开发候选 `native_overlap_fallback96`：figurines **36.51→42.28%**，ramen **25.10→26.30%**。figurines AP **58.97→57.75%**，因此不是全面提升，也不是已完成的开放词汇问题修复。原 `source_extent_rendered_residual96` 仍保留作共同基线，不自动替换或按场景混用赢家。两场景仍是反复使用的 LERF 标注开发集，不是独立最终 test。

## 系统层面的断点

现有路径：冻结源 MoGE 几何 → 多教师源证据 → 单个 96D 元素场（64D 原生语义前缀 + 32D 结构后缀）→ 原生 query 和同一个教师解码器匹配 → 源概念门控接受时输出范围头，否则直接输出原生场响应 → 全场几何渲染。

此前优化候选排序仍把不同性质的证据混为一种规则：源概念直接监督可以给出对象范围，但不覆盖所有 query；原生相似性可帮助未覆盖 query，却不保证超过源侧学习阈值的元素就是完整对象。源裁剪描述符的语义正确也不保证它对应的学习范围正确。本轮固定几何、查询编码器、元素场、所有候选范围头，只改变范围选择和原有弃权路径。

## 受控排查及结果

候选集合固定为 301 / 664 个源概念及独立区域范围，不使用目标 RGB、目标 GT、评估词表训练选择器，不新增教师或训练元素场。完整文本有 56 / 71 个观测；宽 480、全场渲染、最终响应阈值 0.5、观察支持判据均沿用原协议。

文本 IoU / AP，单位 %：

| 选择方式 | figurines | ramen |
|---|---:|---:|
| 原共同基线：残差概念范围头 | 36.51 / 58.97 | 25.10 / 37.84 |
| 同一联合候选，源裁剪余弦选择 | 35.50 / 59.50 | 18.72 / 31.62 |
| 候选内部原生均值，保留概念限制 | 34.17 / 59.43 | 15.61 / 27.21 |
| 候选内部原生均值，解除概念限制 | 34.44 / 62.04 | 8.06 / 29.73 |
| 原生正响应与候选的元素 IoU，保留概念限制 | 35.60 / 60.02 | 15.35 / 28.86 |
| 原生正响应与候选的元素 IoU，解除概念限制 | 39.98 / 57.12 | 17.95 / 26.45 |
| **保留原门控已接受的范围，仅补全弃权路径** | **42.28 / 57.75** | **26.30 / 38.15** |

候选内原生均值是归一化元素特征的均值，**不再次归一化均值向量**，因此与 query 的点积等于该范围内元素余弦的均值；与直接逐元素求均值的误差为 4.47e-8 / 1.97e-7。两个场景无空候选。解除概念限制的均值控制要求分数超过原场同一个源侧 query 阈值。它仍失败，说明简单把原生语义均值当范围选择依据不足。均值只表达内部匹配，不惩罚外部漏检；这是评分结构上的缺项，并非据此证明所有失败都只由漏检引起。

第二组控制增加完整覆盖约束：在所有已观察元素上，计算 `候选范围 ∩ 原生正响应 / 候选范围 ∪ 原生正响应`。原生正响应使用原场既有 query 阈值，候选范围使用原有 0.5 阈值。全场分块求交并，查询分批或读取部分元素不改变选择范围；零交集弃权回原场。没有目标标签选阈值。该对照改善 figurines，却破坏 ramen 已有监督支持的查询，否定统一替换。

最终候选只修改原先门控拒绝的路径：门控接受时仍读原来的概念范围；拒绝时用完整原生响应与结构候选的重叠选择范围；无正交集时仍回到原生场。概念头来自原基线，已通过联合头的块对角构造保留。**代码中的 `trusted_concept_start` 仅表示保留原门控接受的概念头，不代表该概念对应已经验证正确。** 本轮没有修复源门控自身的所有错配。

这个分工是同一规则应用于两个场景，没有按评估类别或场景写特殊分支。选择时临时解码候选，不保存第二个逐元素语义图。代价是额外全场候选解码与交并计算；本轮未做部署延迟评估。

## 剩余核心问题，按因果顺序继续处理

1. **门控接受不等于语义对应可靠。** 本轮路由跟踪显示 `bag→table`、`chopsticks→noodles` 被原门控接受。保留已接受路径可防止这一轮回退，但也会保留这些错误。后续应以源侧正负语义对应和独立源视角验证门控，而不能以最高文本余弦超过自相似模板门槛充当充分证据；不能用评估 query 手工修词表。
2. **原生响应的可用程度随概念变化，不能统一归因于阈值或表示。** ramen egg 只有 10 个元素超过既有阈值，corn 为 0；未加范围头时 egg 真实 AP 41.63%、IoU 0，说明有排序能力但范围判定失败；corn AP 0.87%、wavy noodles AP 10.35%，则不是仅调整阈值就能合理解释。原生能力问题必须分别检查范围校准与教师定位/融合后的判别力，不宜又开始全局调阈值。
3. **结构补全还不能稳定保护查询排序。** jake/waldo 的退化和 figurines AP 下降是真实限制。元素 IoU 还受元素采样密度影响；单候选也未保证类别并集中的多实例完整召回。下一步优先对补全前后的正负响应保留做源侧可验证约束，而不是继续扩大候选或增加教师。

本轮新增候选仍未证明超过历史正常路径。历史保留 LERF3D 二值预测在当前 GT 网格重评分为 57.17 / 30.61%，新候选为 42.28 / 26.30%；历史来源、校准和渲染协议未完全统一，不能作严格同条件架构排名。见上一轮历史比较报告。
