# 实际查询范围修正：小幅平均收益没有解决错误接管

本轮延续专家清单 P3/P5。所有训练只读源侧资产；助手审阅的袋子案例只用于诊断，没有作为训练标签。保留历史与 v2 完整模型，不晋升新控制。

## 完整开发评估

指标为完整文本逐观测平均 IoU / AP（百分数），固定查询编码、几何、阈值和评估分母。

| 模型 | figurines | ramen |
|---|---:|---:|
| v2 完整重建 | 43.8119 / 60.0829 | 33.4742 / 50.8735 |
| 实际查询条件修正，600 步 | 44.7199 / 60.1696 | 33.4776 / 50.8748 |
| 平滑修正，所有源范围完整覆盖两轮 | 44.5926 / 60.1559 | 33.4853 / 50.9725 |

两种控制的所有 image/prompt 逐观测指标与 v2 原模型完全一致；全部父模型张量不变。修正仅使用实际文本 query、冻结元素特征及父/原生响应，逐元素学习两者概率的凸组合，不新增对象库存，不改教师或几何。不能恢复两种响应都没有的范围。

第一种控制采用零初始化截断权重。第二种采用独立版本的 sigmoid 权重，排除截断后梯度消失和随机采样漏掉少数查询的解释；完整遍历每个训练视图范围，完全相同像素 mask 的别名平均后计权。四个源视角仅对新增修正训练留出；父模型看过这些源视图，**不是未见范围家族验证**。零步父模型参与选择。

## 核心失败没有消失

助手审阅的同一袋子诊断中，原生文本 IoU 为 70.50%，v2 完整范围输出约 0.029%。两个新增控制仍约 0.029%。平滑修正已经两次训练过源短语 `plastic bag`，所以不能解释为这条查询没有被采样。

更关键的是：原有范围接管训练报告已经包含这条严重负例。在 frame174 对应的源视图上，原生 IoU 为 75.8092%，候选范围 IoU 为 0.0876%，收益为 −75.7216 个百分点，选中范围被记录为 disjoint；该短语不在接管模块的留出集合中。**模块见过严重有害例子，部署仍然错误接管。** 这纠正了“只需补一条范围监督”的解释。

现有接管只依据八项场级一致性统计回归平均收益，不直接表征目标身份；新增共享修正仍按大量源范围的平均损失/平均验证 IoU 选择。已有证据说明这些约束没有防止严重个例退化，但不能据此声称所有错误都来自一个模块。不同源视图的教师 mask 也并非完整真实对象标签，不能把未标区域的负监督自动视为可靠。

进一步复核已封存的验证记录：选出的 v2 接管策略对 figurines 179/179、ramen 74/74 项全部放行（含反事实候选）。其中分别有 38/15 项候选的源平均 IoU 低于原生输出，也全部放行；仅实际路由的验证项分别为 49/19，其中有害项为 6/0。后者不能表述成 ramen “已证明能拒绝错误范围”，因为它没有该类验证负例。该计数是按查询—候选的多视角平均收益定义，不是最终 benchmark 有害率。

实现上，特征先标准化，样本权重再归一化，岭回归采用 0.1/1/10 的惩罚。选中的 penalty=10 将特征系数压到约千分量级，而正截距分别为 0.137/0.257，验证输出退化为全放行。这是已测到的退化行为；调整正则强度是否能泛化仍未证明，不能据此再次盲目扫参。新增审计直接报告策略是否退化、有害接管率、错失收益及 oracle regret；不改变既有模型/选择规则，历史结果仍可复现。机器结果见 `paper/artifacts/scope_admission_degeneracy_20260918.json`。

因此这两项是完成且不满足核心验收的有界控制；不把约 0.8–0.9 个百分点的单场平均收益称为问题已解决。下一项有效修复必须同时检查目标身份、视图级支持/冲突证据，以及有害接管率，不能只再增加一个 query 级开关。

## 其他两场的完整同方法重建

新增 runner `scripts/audits/run_additional_lerf_v2.py` 对 teatime / waldo_kitchen 执行源 SAM、四教师、三类源查询监督、64+32 场、v2 caption、原生像素融合、所有读出与完整开发评估。源图选择只用已有合法源图身份和相机覆盖，训练不读 benchmark 查询/标签。当前正在执行，尚无最终分数，不计为 P5 完成。

waldo 原始两个验证视角没有跨视角对应，episode 编译正确拒绝空验证。保留失败资产后，仅根据同一 18 张源图的冻结几何支持重叠选择 frames60/67，重新编译所有索引相关资产；未改变源 RGB 集合，未跳过验证。此恢复改变训练/验证划分，必须在复现实验时使用新 source_plan，不能复用原失败计划。
