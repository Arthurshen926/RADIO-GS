# 原生语义残差与融合损失：完整有界对照

本轮完成了19张地图的源侧检查、19张独立语义残差地图、ScanNet OVS八场景原生类别评估、LERF四场景208条观测的原生排序评估，以及NVOS八任务原生图像排序评估。**没有获得可称为四个benchmark显著提升的结果，也没有完成全部遗留问题修复。** 新模块保留为实验实现，不替换当前主线。

## 1. 方法改动，而非仅工程调整

针对上一轮0140中1536维教师→64维压缩的损失，先检验在同64维中加入源侧文本方向的共同正交基底。候选使用固定权重0、0.25、1、4；文本与图像都在未参与拟合的源视角检查。所有非零文本权重均未通过双能力约束；少量权重0重算结果改善不足0.02%，不能作为实质进展部署。

随后实现**保持旧64维坐标不变的正交语义残差**：

- 使用源图区域描述子和源侧固定文本银行拟合旧语义空间的正交补；不使用benchmark查询、目标GT或目标图像。
- 在32、64、128额外维度中，选择能够让文本、图像源侧响应MSE都下降至少20%的最小容量。同时要求中心化误差不升、教师Top-1一致率下降不超过1个百分点。
- 原查询与地图共同使用同一个基底。余弦分母使用完整原生query范数，不能单独归一化投影query，否则会改变类别排序。
- 19张地图全部通过区域层面的源侧检查：16张增加32维，3张增加64维。几何、源视角、融合权重、旧64维坐标不变；32维结构支路也不修改。
- LERF/ScanNet沿用逐像素重叠分摊融合；NVOS沿用其原有条件区域概率融合。NVOS额外可见支持上的新增残差置零，不能假称这些元素已有新教师证据。
- 新语义分数不直接接入旧校准和范围头；当前评估是分责所需的原生读出对照。

实现：`radio_gs/training/native_semantic_residual.py`。源侧预注册及所有报告：`output/native_residual_basis_next30_v2/`。拟合规则在目标评估前固定，没有根据各场景目标成绩选择新旧分支。

## 3. 收益消失在哪一段

19张地图中，独立区域的文本和图像响应MSE都至少降低21.10%（各地图较差模态改善范围21.10%–39.25%）。但在12张LERF/ScanNet地图上，用保留源视角的区域概率对实际融合元素做读回后：

- **7/12张地图的文本响应MSE反而略升。**
- figurines区域文本教师Top-1一致率78.77%→82.88%；融合读回后30.56%→30.56%。
- ramen区域83.69%→84.40%；融合读回46.10%→46.10%。
- 0140区域87.50%→93.75%；融合读回35.42%→33.33%。

这些是相对教师响应的诊断，并非真实语义标签准确率。区域独立对照与地图读回也不是完全相同的输入算子，部分无几何支持区域会被单独计数。因此不能把一致率差直接解释为纯融合错误比例，也不能由此排除遮挡和几何对应影响。

可以确定的是：**区域层面的教师保真提升不足以保障实际地图召回提升。** 目前证据将关键损失进一步集中到“区域证据写入元素—跨视角区域读回”这一段，而非再增加训练步数或继续扩容。完整对象、部件、背景重叠、不可见区域对应尚未完成因果拆分，不能宣布某一种混合已经被证明是唯一原因。

## 4. 可靠性检查与已处理问题

- 19张地图旧64维均从相同源证据重建，最大数值误差低于8e−7；导出残差地图时再逐值复制原坐标，确保旧坐标完全一致。
- ScanNet八场景三种类别划分的旧预测逐元素完全复现，差异数为0。
- 目标标签只能在预测保存后读取；冷评估禁止教师训练缓存，NVOS禁止目标RGB和负提示。
- NVOS保持八任务分母，horns_left使用horns_center地图；没有把共享地图误计为独立训练场景。
- 修复本轮预检中遇到的源证据秩不足处理：v1在leaves尝试128残差维度时停止；保留失败现场，v2显式跳过不支持的容量并完整重跑19图，未改选择阈值。
- 18项相关测试通过；冻结1773源文件全部保持原hash。

汇总：`output/native_residual_basis_next30_v2/summary.json`；实现与报告封存：`paper/artifacts/native_residual_next30.json`。

## 5. 收紧下一步验收，而不是再发散

1. **优先拆分源侧融合冲突。** 同一元素的源证据分别统计可见性、视角支持、整体/部件包含与语义不相容；不把范围外、未观测视为负例。先定位哪类证据抹掉细粒度响应，再修改融合规则。
2. **把保留视角的实际地图读回加入候选准入。** 必须同时检查文本与图像的响应排序、完整对象覆盖及所选元素；区域教师MSE只作为辅助，不能单独批准新方法。
3. **先隔离融合改动，再重训依赖头。** 保持几何与源预算不变，比较源侧跨视角收益；通过后重拟合校准、范围头、提示支路，再完整评估四个冻结协议。
4. 本轮残差可用于语义保护和定位压缩损失，但不优先扩大到更高维，也不按已见目标成绩做场景分支开关。新的准入规则同样必须先固定，不能用本轮目标成绩反向调门限。

这份报告完成的是一次有边界的方法检验及责任定位，**不是“全部问题已修复”或“大幅性能提升”的结论**。
