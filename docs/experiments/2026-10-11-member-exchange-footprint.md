# 双向成员交换、解析足迹与原生置信度接入

延续 member-energy 功能参照，本轮实现了真实场可调用的实验接口，未更改默认查询。

## 实现

- 在每遍单成员增删后，检查共享可靠正因子的已选/未选成员交换。每个已选成员
  最多评估 8 个候选，按足迹代价、成员 ID 排序；只接受完整影响因子并集上的
  严格能量下降。总遍数仍为 8。它解决已验证的廉价替代成员局部陷阱，但不保证
  全局最优，截断候选也可能遗漏更好的交换。
- `SupportFootprint` 将每视图、每成员的解析投影积分存入场文件；构建时使用
  相机，推理时仅按原生接受的活跃视图汇总。公式保持源参考的
  `2*pi*opacity/sqrt(det(conic))`，默认 observed 域保持历史一致，可显式扩展至
  observed|semantic-supported。它是无限图像平面的未遮挡 Gaussian 积分，
  **不是**裁剪到图像边界的面积、可见贡献或完整对象范围证书。
- 新实验接口 `query_text_member_energy` 使用强语义初值，复用原生区域接受、
  原生视图置信度及原有场内正负标签函数；置信度实际进入覆盖数据项。输出是
  同一实际二值成员集合，新增成员记为 1、删除成员记为 0，其余保留原分数。
  这些修改后的分数不是校准概率。
- 字段是可选的，旧场仍可加载。缺少足迹时新接口明确拒绝执行，避免以采样命中
  数偷换足迹成本。旧默认解码器和查询接口不变。

## 验证

29 项定向测试通过，覆盖新能量、足迹、原有联合删除、存储以及原生置信度。
测试包括：

- 30 个随机小问题，独立计算最终能量，检查能量不增及全部单翻转/交换邻居；
  此处小图候选预算覆盖所有候选，不代表大型截断图的全邻域最优。
- 原局部陷阱确实被交换解决；会造成负区域泄漏的替换被拒绝。
- 旋转各向异性 Gaussian 的解析积分与独立密集二维数值积分一致。
- CUDA 实际投影在 observed 域与源参考逐元素一致；扩展域保留原成员值并纳入
  有效 semantic-only 行，视锥外成员保持零。
- 场文件往返保存/重载保持旧张量与新足迹函数；实验查询在 Python 文件读取
  被禁止的合成场上可执行。该合成测试不是完整真实场冷启动或操作系统沙箱。

## 尚未解决

覆盖因子仍采样，解析足迹不修复范围遗漏；软能量也不保证保持每个已覆盖正因子。
必须用完整范围诊断验证，不应把这个能力接入直接称为完整性能恢复。
当前坐标/交换实现是 CPU 稀疏功能参照，实际大型场延迟尚未评测。

本轮启动 figurines 构建链路验收，状态以输出目录 compilation.json 为准：
`output/query_field_20261011/compiled_support_footprint_v1/figurines/`。
真实数据构建脚本不使用 benchmark 查询/GT，不重新生成源伪标签。
尚无新 benchmark 预测、默认提升或五任务闭环。四场旧成绩保持固定对照45.1953%、
联合主组44.8761%；不能把测试通过解释为成绩提高。
