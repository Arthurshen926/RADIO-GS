# Gaussian partial-relation functional reference

Fixed before construction or new benchmark predictions. User steering on
2026-10-09 explicitly prioritizes verifiable capability transfer over preserving
intermediate feature layouts or obtaining lower training loss.

## Question and architectural boundary

Does explicitly preserving view-balanced partial support-to-element functions
recover capability lost by the present learned group embedding? v10 retains
joint observation/co-membership and ambiguity before deciding complete-carrier
membership; the current field does not preserve those functions by preserving
its native vectors. This experiment transfers partial positive/exclusion
functions. It does NOT reproduce all six v10 observation features, its labelled
classifier, native patch matching, or a full v10-equivalent capacity bound.

One exported Gaussian field may contain sparse relation coordinates, their
physical scales and dependent-coordinate view groups. No RGB, raster masks,
cameras, source paths used by runtime, source descriptors, old solver or labelled
member model is added. This is an explicitly uncompressed reference with
source-indexed coordinates, not a claim of compactness, novel representation,
or proof that storing observation factors is the final architecture. Keeping
everything in one file alone is not evidence of successful unification.

All inputs, negative supports and category structure use the same member kernel.
Native identity, geometry, grouping, thresholds, shared acceptance parameters,
v2 image correspondence and typed category rules remain unchanged.

## Fixed construction and readout

One arm, `paired_function`, augments the all30 `protected_training` exports.
That prior is chosen before results as the matched rendering control; do not
mix it with per-task winners or retrain the failed conditional residual.
Use exactly its authorized training views and partial SAM regions. No new
teachers, source views, labels, query-conditioned source masks or optimization.

For each valid source region, compile eroded positive and reliable disjoint,
comparable-scale exclusion masks onto Gaussian rows. Normalize each row by its
visible geometric mass. A row must contribute at least10% of a source pixel
to receive evidence, matching the previous partial-element compiler. Keep
positive and negative mass separately; unknown contributes neither. These are
soft geometric observation functions, not verified whole-instance labels.

For a weighted query support, average its positive relation coordinates.
Admit coordinates with support mass>=.5 and physical scale ratio in[.5,2],
matching earlier source associations. Normalize admitted weights within each
view before evaluating the candidate's positive and negative coordinates.
Dependent nested masks therefore share a view's unit of evidence. Sum the
two masses across admitted views as P and N. The fixed member probability is

`(sigmoid(base_logit) + P) / (1 + P + N)`.

The base member is one prior unit. This is a finite-evidence interpolation,
not a calibrated Bayesian posterior. No ratio/weight/threshold search follows.
When P+N=0, preserve the original logit bit-exactly. Inferred identities are
not forced positive; explicitly registered exact 3D constraints retain their
existing semantics. The existing signed exclusion operator remains shared.

## Functional verification and complete evaluation

For every valid source view, use its first region's first and median reliable
support pixels to define one point and one .25/.75 uncertain support. Replay
every Gaussian's P/N against an independent per-view scipy calculation before
export; maximum absolute error must be<=1e-5. This verifies a declared function,
not teacher correctness or held-out benchmark accuracy. Development views are
excluded from compilation and this construction check.

Before scoring, complete all30 exports and all31 prediction jobs. Report all
four LERF scenes, eight NVOS inputs, ten ScanNet rooms and268 UQIS inputs, with
actual selected sets, response/AP, precision/recall and paired scene intervals.
Compare to the protected rendering prior and all previous fixed controls,
including joint training and v10's differently resourced reference.
Repeat exact native outputs across268 UQIS inputs, known-support diagnostics
on all67 point inputs, and copied-export source-denied replay of five cases.
Record source frame/region counts, actual tensor bytes and construction cost.

No model promotion or final-test claim is preauthorized by a source replay.
Interpret failure separately as insufficient source relation evidence versus
the downstream finite-evidence rule; this one arm cannot causally separate them.
Native functional preservation and v10 supervision/input mismatches remain
separate unresolved work. Repeated development cohorts are not independent tests.
