## 实际读取路径与碰撞

全文本21/14个不同query中，最终使用范围输出14/12个，其中原概念路由接受且最终仍使用范围的为8/8个。其余范围输出可来自候选fallback，不等于固定概念接管。

**这批真实文本query没有任意两条最终元素概率逐值完全相同。** 同概念索引对包括miffy/pikachu、chopsticks/kamaboko、egg/nori，但其中一侧概念准入未通过，最终输出不同。因此不能将“有固定概念头”直接推成“当前benchmark主要由query碰撞导致”。

另对合法源图中有合格mask的251/100个短语检查。相同最终二值元素membership且有共同源视角的短语对为22/6；其中至少一张共同视角的源mask IoU<0.5者为9/2。fig其中2对均为空输出，不能算范围头接管。源短语集合经检测筛选，比例不代表开放词汇总体发生率。

确认了可复查的固定头病例，如：

- figurines `plastic bag` / `plastic container`：同视角源范围不重叠，均概念接受、同一个概念头，最终二值范围相同。
- figurines `mountain` / `sky`：同类现象，且范围本身包含远景/天空，几何与语义可用域也需审查。
- ramen `wooden chair` / `wooden table`：同视角源范围不重叠，均进入同一概念头。

这些源掩码不是人工真值，教师本身可能误指。还存在不同概念fallback选择相同范围的病例，必须与固定概念头、空输出分别统计。

自动排错集11组，每组保存源图身份、掩码叠加、短语和实际路径，位于 `output/current_recipe_audit_20260918/scope_casebook.json`。人工审查状态保持pending，物理身份、粒度与可见性判断保持未知，没有把模型看图解释伪装人工标注，也没有用于训练。已人工标注的P1可信集尚未完成。

## 不加新网络的查询条件干预

固定父模型全部参数、原范围选择和准入，仅对“概念接受且最终使用范围”的路径执行：

`新logit(q) = 原范围logit + 原生logit(q) - 原生logit(所选概念原型)`。

原生logit含当前原生query阈值/校准。此干预恢复实际query相对原型的差异，不添加新的gate或拟合参数；query等于原型时修正为零，图像与prompt路径不变。它是**冻结父决策的诊断控制**，不是已完成源家族隔离训练的新架构；没有根据评估GT拟合系数。实现独立放在 `querying/query_relative_scope.py`，保留模型和默认生产模型类不变，评估协议明确标记读出覆盖，不能只凭相同field SHA当成同一方法。

| 全文本开发指标 (%) | figurines IoU/AP | ramen IoU/AP |
|---|---:|---:|
| 保留模型 | 46.20 / 66.80 | 32.97 / 49.75 |
| 实际query差异修正 | 46.33 / 67.18 | 32.17 / 49.51 |

没有共同改善，**拒绝晋升，不按场景拼接结果**。

源碰撞低一致对由9/2降至4/1；剩余包含空预测和非固定概念路径。消除碰撞并不自动变成正确范围：在原先选中的源失败观测上，完整像素分母IoU为fig21.09→20.37、ram49.65→49.64（18/4个query—视角观测）。这是针对已见失败案例的诊断，不是独立验证或全源质量均值。

因此：固定概念接管确实会丢失query差异，但**简单恢复原生query相对差值既不充分，也不是当前共同提分方案**。仍需先确认教师目标范围与对应，再用真实query条件训练范围，不能以碰撞数下降代替召回正确。
