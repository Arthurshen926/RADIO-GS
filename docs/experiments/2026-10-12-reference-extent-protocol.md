# NVOS当前参考输入到共享实际集合引擎：冻结八例协议

在已知旧参考组合八例实际86.9550%、归一化响应83.1015%的条件下设计。
这不是独立最终测试。沿用同七场/八请求、120构建来源、当前正提示派生SAM
参考mask及注册相机；继承原RGB/SAM输入生成成本，不称原始笔画成绩。
所有新预测封存且旧控制选集精确保持后才读目标GT，禁止按中途分数调参。

共享的是单场几何上的A_obs、足迹、R_set及固定四遍离散成员决策。文字输入
没有当前参考相机，须在构建时保留历史观察的函数；参考输入本身包含合法
当前相机，因此从同一场和当前相机实例化这些函数。没有查询时读取历史源
RGB/mask/track、目标相机参与解码、自由连续参数拟合或查询答案入场。
当前几何因子是临时计算状态，审计副本不算部署场，也不得复用于别的查询答案。

固定192×256完整参考栅格，不采样。member_domain为已有field.member_available，
所有遮挡体保留在A_obs构建中，R_set包含可选成员全部潜在足迹。当前完整
参考mask的fractional area值作为target：正值且有效为P，零且有效为N，
其余无效射线未知。这里的背景许可来自明确的完整2D参考mask，不可照搬到
稀疏笔画，也不证明参考不可见的3D部分是背景。c固定为1；无有效P则回退。

四条件，每个请求同一规则，不根据目标或场景路由：

1. `composed`：原有可见区域组合、参考背景成员排除、二值读出，重新执行。
2. `shared_prior`（唯一主候选）：以上实际组合做初值，当前参考范围进入
   共享R_set四遍双向决策，足迹按该初值归一；使用NVOS既有alpha边界0.5。
3. `shared_lift`：其余同主候选，仅先以当前A_obs已知范围重建初值，并按
   该初值归一足迹；未知成员保留原组合先验。初始化及对应成本是联合干预。
4. `shared_literal`：其余同主候选，仅保留LERF原来的10.5/255 alpha边界，
   作为字面复用同一引擎但未迁移任务输出合同的诊断，不按结果挑阈值。

0.5来自已有NVOS消费合同，10.5/255来自既有LERF引擎；不是目标调参候选。
两者都映射为判定概率0.5。数据BCE/overlap、0.1足迹系数、成员遍历顺序及
四遍预算不改；原组合成员可删除/添加，不作硬种子约束。共享代码默认参数
保持LERF原函数，旧reference内核与新linked默认的全决定/trace测试必须相同。

独立审计全部目标mask指标、旧控制选集、三条件同场同输入、实际初末光学
目标、初值和成本、参考范围及valid、未观察/被排除部分变化；真实参考几何
编译至少每例一个独立全renderer对照。源文件禁读探针须区分当前输入与历史
来源；不能把类名或CPU缓存当成功能证明。输出响应和实际投影分别报告，
参考拟合改善不能代替目标泛化。所有失败保留，不自动提升默认或宣称五任务闭环。
