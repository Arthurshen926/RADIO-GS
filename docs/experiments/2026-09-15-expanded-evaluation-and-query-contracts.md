# 扩大验证并修正 query 任务口径

本轮完成六组训练对照、新增六个语义验证视角、冻结模型评估、文本任务去重，以及更保守的提示条件优化。主要进展是获得了更可信的验证结果，并识别原小验证集没有暴露的问题；没有按场景挑选不同最优配置来宣称主线恢复。

## 验证规模与隔离

训练视角保持 `[7,11,15,18,22,27,109,76,131,101,105,90]`。在合法 mapping/native-SAM 交集中，按帧号选择未参与现有语义训练/验证的前六帧 `[39,42,47,51,55,59]`，加入原验证帧 `[31,35]`。选择在新语义特征提取与新视角查询评估前记录；四个被比较模型同时记录了文件哈希。几何仍采用已有冻结阶段，因此这是新增语义验证视角，不是重新构造的几何盲测。

新增 `--validation-frame-ids`，替代只能隐式使用最后两帧的限制。数据包全部八帧验证有文本/图像/提示 38/74/74 条对应记录；本轮主要比较要求 query 与目标视角都在新增六帧内，得到 12/38/38 条记录。

原训练任务、mask、硬元素标签完全一致。重新投影的 fp16 region probability 有 11 个值不同，最大差为 0.00048828125，没有改变任何 `>0.7` 标签。原训练资产和模型没有修改。完整校验见 `paper/artifacts/ramen_extended_holdout_integrity_20260915.json`。

## 文本任务去重

文本 query 不含参考图像身份。同一文本与目标视角不能因为存在多个源对应，就被当成多个独立任务。

新增六帧的 12 条文本记录只有 7 个真实文本—目标视角任务，两个任务的不同记录还带有不同负标签；训练的 50 条记录对应 24 个任务。评估现在默认按文本和目标视角聚合已有正负证据、保留来源记录编号，不把未知区域补成负标签。冲突像素仍由原来的 XOR 规则排除。旧口径可显式使用 `--correspondence-weighted-text`。

训练去重单独通过 `--unique-text-training-tasks` 测试，不改变存储的验证记录。其收益不一致，暂不成为默认训练配置。训练报告记录真实任务覆盖与每个任务的源记录列表；训练过程中的旧参考评估仍使用原对应记录，不能将其条数当成实际优化任务数。

## 冻结模型在新增视角上的表现

下表均使用去重后的 7 个文本、38 个图像、38 个提示任务，全部任务分母，提示为原始 query 响应：

| 模型 | 文本 | 图像 | 提示 |
|---|---:|---:|---:|
| 当前四教师、完整稠密监督覆盖 | 0.6424 | 0.5412 | 0.5797 |
| 加提示标签冲突保护 | 0.6424 | 0.5406 | 0.5793 |
| 教师聚合单位长度 latent | 0.6325 | 0.5471 | 0.5833 |
| 当前配置去 RADIO | 0.6383 | 0.5411 | 0.5940 |

当前四教师按旧重复记录口径的文本 IoU 是 0.7416，按真实查询聚合后为 0.6424；两者权重和已知标签并集不同，不应混报。图像的 38 个任务涉及 27 个 query 区域，仍不是 38 个独立场景。可评估像素平均约为文本 19.92%、图像/提示 13.21%。这些都是教师伪标签诊断，尚无 benchmark GT。

后续训练去重候选在同一开发集为 0.6367/0.5527/0.5395，提示下降；该模型是在新验证集被检查后训练的，只算开发证据。

## 提示条件优化的过度偏移

较大的验证集暴露出旧优化的问题：在已知正负点已经满足之后，它仍继续降低二元交叉熵，推动概率趋向 1/0。满足源视角约束不意味着跨视角结果更好。

新增可选 `stop_when_satisfied` / `--minimal-prompt-refinement`：首次满足正负约束并留有 0.001 概率余量时停止，再沿原 query 到该可行 query 的线段二分回退。它不是全局最小距离求解器。未找到可行解时保留明确的未满足报告；缺少语义支撑时仍保留原 query 进入总分母。地图和几何不更新。

| 新增六帧，提示 IoU | 原始响应 | 原 64 步优化 | 保守优化 |
|---|---:|---:|---:|
| 四教师 | 0.5797 | 0.5230 | 0.5921 |
| 去 RADIO | 0.5940 | 0.5695 | 0.6132 |

35/38 个提示具有全部 seed 支撑，二者均满足这 35 个任务的二值约束；另外 3 个不可用任务保留原始响应，没有被排除。需要调整的四教师 query 平均 2.0 步、去 RADIO 平均 1.75 步完成，而非固定 64 步。

但 figurines 上，四教师保守优化为 0.4074，低于原优化的 0.7908；去 RADIO 为 0.3973，低于原优化的 0.7201。因而保守策略保留为可选实验，不能宣称跨场景全面改善，也不按场景切换默认策略。

## 另外两项有依据的检查

- **提示标签冲突**：ramen 训练提示中 2/136 个任务，在已观测 seed 的多数贡献上，目标伪标签与授权正负点相反（源记录 197、221）；figurines 无此情况。`--guard-signed-targets` 仅屏蔽这些任务的目标伪标签监督，保留源点和教师特征监督，验证标签不变。对照没有明显语义收益，保留为诊断/可选保护。
- **教师与 query 聚合差异**：raw latent 的长度会改变教师端混合方向，但 query 使用逐元素单位向量。ramen 元素 norm 的 1%/99% 分位约为 0.071/1.067；约 2.54% 训练像素的两种混合方向 cosine 低于 0.95。统一单位向量聚合在 figurines 略有改善、ramen 原小验证集退化，新增视角收益也不一致，因此没有改默认。这里改变的是特征混合，不是几何权重。
- **提示输入尺度**：两个 DINO 视觉块平均 norm 约为 0.96–0.99，世界坐标块约为 1.09–1.34，没有发现需要额外模块修复的量级失衡。

## 实现与复现

核心文件：`radio_gs/training/source_view_split.py`、`text_task_aggregation.py`、`signed_label_consistency.py`、`radio_gs/models/signed_query_refinement.py`；训练与评估 CLI 提供独立开关。实际默认行为变化是显式验证视角支持、文本评估去重；新训练损失/聚合/提示优化候选均未设为默认。

证据位于 `paper/artifacts/`：

- `ramen_extended_holdout_protocol_20260915.json`、`ramen_extended_holdout_frozen_fields_20260915.json`：视角与模型冻结协议。
- `ramen_new_views_frozen_models_eval_20260915.json`：原对应记录口径。
- `ramen_new_views_unique_queries_eval_20260915.json`：真实文本任务口径及旧提示优化。
- `ramen_new_views_minimal_prompt_eval_20260915.json`、`figurines_minimal_prompt_eval_20260915.json`：保守优化对照。
- `ramen_text_task_duplication_audit_20260915.json`、`ramen_signed_label_consistency_20260915.json`、`signed_prompt_block_scale_audit_20260915.json`：任务与表示审计。

验证：54 项相关测试通过，覆盖双端验证隔离、去重证据合并、未知标签不参与冲突投票、可行解停止、不可行约束报告及地图梯度隔离。没有覆盖或修改已有训练/评估产物。原始性能基线继续保留；下一阶段应以扩大后的固定任务口径检验监督质量和真实语义边界，避免继续用原来的四个任务选择方法。

补充冷启动验证：在禁止训练特征/标签缓存与 RADIO 文件访问的新进程中，原生文本、图像和提示编码均通过一致性检查。专门选择一个需要修改 query 的执行覆盖样例，保守策略实际运行 2 步，把负点响应从 0.8731 降到 0.4990，同时正点从 0.7905 升到 0.8846；地图没有更新。该样例是分支覆盖测试，不是质量抽样。证据：`paper/artifacts/figurines_minimal_prompt_active_no_radio_cold_20260915.json`。汇总与模型哈希：`paper/artifacts/query_contract_iteration_20260915.json`。
