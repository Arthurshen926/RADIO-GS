# 同一不确定成员函数解释正负射线：完整八例对照

positive_expected_v1四条件完整结果：保留特征模长把实际IoU77.4433→80.5398%，
加入几何方差仅到80.5423%；对原local79.4595%仍四例退化，精确率仍低4.84pp。
这支持特征归一化造成部分虚假确信，不能把空间方差说成主要收益。

原负分支仍将全部负涂鸦平均成一个原型；在正部分覆盖扩大后，检验负射线
是否也应逐条解释。此前移除负分支的对照不是本项对照，也没有证明平均负原型
已经保留多个背景约束。以下为已看前序开发结果后的探索，不是独立最终测试。

同七场/八原始请求/旧120来源，三条件全部24预测封存后统一评分：
- positive_ray_local：原能量混合基线，重新预测。
- positive_ray_expected_union：上轮主方案，正射线期望能量的置信并集，负原型不变。
- 主方案positive_ray_expected_signed：正分支完全相同；负射线保留全部贡献，
  使用完全相同的期望成员能量及注册像素质量，max_r[c_r sigmoid(E[e|ray])]
  得到排除响应，再按原规则使用p_positive*(1-p_negative)。负分支原有区域
  refine也保留。没有修改负权重、阈值、尺度或新增训练/状态。

射线内的贡献不确定性与跨射线的明确约束分开；负像素质量不按射线总数稀释。
未知射线不补最近点，无支持不排除。不强制覆盖正射线，也不把注册深度当准确3D。
新旧负支持打包的差别属于本项功能干预，来源和负提示图像本身完全相同。

可能因过强排除伤害正目标，必须完整报告精确率/召回、原始正负提示覆盖、
响应与实际选集，不按请求取赢家、不晋升默认。单测需验证正负使用同一个
原函数及重复负约束的核心幂等性；该幂等性不扩展到区域refine的支持加权。
一例独立复制场/源拒绝回放；同一方法的五项和UQIS四模态仍需后续验收。
