# Joint observation and member decision transfer: fixed factorial study

This follows completed five-task coverage; it is a UQIS mechanism study on all
nine scenes and all268 inputs, not a new complete five-task architecture result.
No default promotion, final-test claim or benchmark-based parameter selection.

The source-only trials repeatedly omitted two real v10 capabilities: full legal
co-observation and a complete-carrier member decision fitted on independent3D
instance labels. ADR0014 already permits this extra-supervision condition when
declared separately. Do not attribute it to the three source teachers alone.

Freeze a2x2 design before any predictions: small/full legal observation budget
crossed with source conditional co-membership/compiled independent-room forest.
Small uses the exact18 training frame IDs from the previous Gaussian build;
full uses every v10-declared legal mapping frame except the SAME two feature-
development frames. All frames must lie in the package mapping authority and
outside its withheld frames. Both budgets use the same existing query-free SAM
observations, RGB-D visibility and regional SigLIP descriptors. Thus the frame
contrast fixes the teacher/projection recipe; it does not isolate frame count
versus the previous soft-Gaussian projection recipe.

Keep the protected Gaussian geometry, native query channels, group parameters,
candidate program and typed readouts byte-identical. Explicit source_vertex_ids
map observation rows to these Gaussians without nearest-neighbour relation
transfer. Compile binary membership, visibility and within-view association into
the field. Collapse the linear regional native response into per-Gaussian native
moments WITHOUT renormalizing their magnitudes. No source descriptor array,
camera, mask, RGB, old source solver or joblib model is opened at query time.
Export size is measured; this uncompressed reference is not yet paper novelty.

For an exact anchor, preserve all six joint observation statistics, anchor and
element visibility fractions, bounded metric displacement/distance, native
anchor-response and native-support validity: all15 features of DirectAnchorEvidence.
Use the same physical units. Known visible exclusion and missing joint visibility
remain distinct. For uncertain support, mix component view-normalized associations
using input weights; condition the observation fractions on available evidence,
and use the weighted support centre/native moment. This extension is declared,
not claimed equal to v10's dominant-anchor choice. Signed prompts use the existing
common product rule; no signed benchmark is evaluated in this focused study.

The source-only decision is the original visible conditional co-membership, with
.5 acceptance; it consumes the nested vote, not a transferred supervised head.
The extra-supervision decision is the EXISTING64-tree member forest trained on22
independent rooms and calibrated on3 separate rooms. Verify all benchmark scenes
are disjoint. Preserve its double thresholds and leaf values as tensors and apply
it to the exact15-function encoding. No refitting or new label access. The inherited
threshold is.35; recenter odds at that threshold to fit the common.5 interface.
Scores are not newly calibrated probabilities. Every modality calls this same
member function; inferred identity stays uncertain and is never clamped positive.

Both decisions address the COMPLETE frozen Gaussian carrier. Native observation
support and the member output domain are distinct; do not silently erase selected
unobserved members or reject registered points merely for missing native features.
Keep inferred native candidates in the original native domain. The three removed
degenerate mesh vertices in each of two scenes remain declared mapping differences.

Before benchmark inference, test CPU/CUDA forest equivalence on threshold-adjacent
float32 inputs, source observation parity and native-moment algebra, unknown versus
exclusion, mixtures, all-input export/reload and old-field regressions. Each real
scene/budget independently compares16 fixed source-domain anchors against512
uniform carrier rows plus all anchors. Require feature/source-function error<=1e-5,
identical-feature compiled forest error<=1e-7, and zero source-case selected-set
disagreements. Report actual observed differences; do not equate sampled replay
with proof over every possible query and row.

Construct all36 exports before any prediction. Finish all1,072 outputs before
scoring. Retain each prediction/selection/receipt, scene-paired bootstrap intervals,
all modalities and unsupported inputs. Evaluate full known-support diagnostics,
including actual3D precision/recall and the difference between registered point
and uncertain/inferred identity. Copied-export cold replay must deny source paths
and compare raw values/selections; report numerical and bitwise equivalence
separately, preserving failures. Prior confidence-mixture strict failure is not
waived or rewritten. Full five-task generalization and patch-identity transfer
remain required before promotion.
