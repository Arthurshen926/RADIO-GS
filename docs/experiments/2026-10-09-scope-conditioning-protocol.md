# Decouple regional scope from local membership scale

Fixed development study: all eight NVOS raw signed requests, seven frozen fields,
old 120 source views. No training, source addition, query RGB/mask expansion,
new state, target-dependent choice, threshold fitting or default promotion.

Baseline: positive_ray_expected_competitive (existing signed expected energies
and positive/negative/null competition). Keep its local kernel scale, kernels,
ray confidence, per-ray moments, view confidence, thresholds and actual-subset
rendering unchanged. Three declared conditions:

1. Baseline: original [.5,2] regional scale ratio in both signed branches.
2. positive_ray_positive_scope: all region scales eligible for positive lookup;
   negative lookup keeps original scale gate. Directional attribution control.
3. Primary positive_ray_signed_scope: all region scales eligible for both lookups.

Only the compatibility mask changes. Association still requires positive > negative
known mass at support rows, within-view confidence still bounds evidence; unknown
still abstains. More eligible regions can redistribute existing within-view mass,
so all-scale evidence is not a monotone increase in membership or effective evidence.
This is a scope-capacity intervention, NOT complete object composition or a new
object acceptance function. Broad admission can worsen purity and must be measured.

All24 predictions, input/code hashes and eight baseline selection/score replays
must pass before any target labels are opened for scoring. Record both actual-set
IoU and retained normalized response IoU, precision/recall and prompt agreement.
Report all cases and paired development intervals; no per-case winner routing.
A positive outcome would still require common-method full-five validation;
negative results must not be hidden by per-scene choices or weight searching.
Compare v10 only on matching response metric and declare different input contracts.
