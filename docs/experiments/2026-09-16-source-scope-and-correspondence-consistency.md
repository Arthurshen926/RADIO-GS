# 源区域粒度与跨视角对应：固定几何控制及监督修正

本轮完成两场景的原生召回对照、对应图核验和新监督编译。**没有获得可晋升的召回提升，也没有完成新监督下的完整模型训练。** 原完整主线保持不变。结论不是“只要过滤配对就能解决低分”，而是：不能用统一的细/粗粒度替换当前语义融合；源对应还有可观测的范围矛盾，应在保留覆盖的前提下修正并重新验证。

## 1. 固定教师与几何，直接检验嵌套区域混合

新增 `source_region_hierarchy.py`，仅在同一源视角中，以子区域至少 95% 被包含、面积至多为父区域 80% 建立观测包含关系。相同大小的重复区域、普通相交区域和不同视角区域不自动建立整体—部件关系。包含关系本身不证明物理部件身份。

在原 96×128 源掩码上构造两个预先确定的控制：

- **fine**：嵌套重叠像素由小区域承载，父区域在这些像素上退出。
- **coarse**：嵌套重叠像素由大区域承载，小区域仅保留父区域之外的像素。

修改在像素域进行，再通过相同贡献 authority 重新提升。没有在 3D 直接相减归一化概率，也没有按 benchmark 查询挑选粒度。保持源描述符、原 64D 基底、几何、有效元素、查询编码、阈值及完整场渲染协议相同。描述符没有按新残余掩码重新编码，因此这是**固定教师描述的分配因果控制**，不是完整层次特征学习。

figurines / ramen 分别有 169 / 172 条源包含关系，涉及 172 / 180 个区域；约 50.2% / 32.3% 的已观测元素特征发生变化。父子原生描述符余弦中位数为 0.819 / 0.833，说明它们不等价，但该差异不能单独证明其中哪个描述正确。

| 原生路径真实开发指标，IoU / AP，% | figurines | ramen |
|---|---:|---:|
| 保留原融合 | 33.60 / 58.48 | 8.20 / 30.98 |
| 优先细区域 | 32.28 / 55.97 | 7.84 / 29.99 |
| 优先粗区域 | 32.99 / 54.74 | 8.72 / 31.81 |

均为 56 / 71 个文本标注观测，**不是完整范围头路径**，不能与完整方法的 43.52 / 28.42 IoU 混作同一比较。父控制与上一轮原生诊断宏指标误差小于 1e-5；微小差异来自 compact cosine / 稀疏累积的浮点计算。

两个统一替换均不采用。细区域并不自动具有更好的细粒度语义：ramen chopsticks AP 从 40.16 降至 27.24；粗区域使 figurines miffy AP 从 53.19 升至 68.00，却把 pirate hat 从 39.93 降至 12.67。不能按标注类别事后选择粒度作为部署结果。

**可支持的判断**：当前不能靠全局选细、选粗解决问题；整物体和部件需要保留兼容但不同的范围证据。该试验没有排除多视角身份错误、区域教师上下文偏差或表示容量问题，更没有证明混合是唯一主因。

## 2. 核验实际配对图，而不只看局部配对分数

当前编译器以共享可见 Gaussian 区域上的互为最佳 IoU，加 SigLIP/DINO 相似度准入跨视角区域对。局部互为最佳不保证串联后具有一致范围。

在当前保留模型实际训练库存中，把 image 正例配对作为无向图，仅查看连通组内同视角掩码，发现：

| 训练源配对诊断 | figurines | ramen |
|---|---:|---:|
| 原无向跨视角配对 | 73 | 230 |
| 存在同视角多区域的连通组 | 6 | 10 |
| 连通组内同视角掩码对 | 16 | 79 |
| 其中 IoU < 0.9 的非重复范围对 | 12 | 68 |
| 其中完全不相交的范围对 | 0 | 10 |

这说明这些边不能不加区分地解释成同一个实例、同一个范围的等价关系。**它不证明每条边都错误，也不能据此给最终低分分配责任比例**：尺度条件的亲和关系本来可以非传递，而实际匹配监督需要另外明确目标范围。

仓库已有 `reliable_correspondence_tasks`，不是本轮首次发明全局约束。它要求每条轨迹每视角仅一个区域，并加双向覆盖；此前在旧库存上完整训练后，ramen 退化，未进入保留主线。此次核对 `preserved96_protected/report.json`，两场景 `correspondence_admission` 均为空，因此上述冲突并未被它过滤。不能把一个已存在但未采用的选项误报为已修复当前主线。

## 3. 已实现并编译：允许近重复提案的范围一致性准入

新增 `consistent_region_matches` 与编译选项 `--correspondence-policy scope_consistent`：

1. 训练/验证在图合并之前分开，验证观测不能选择训练边。
2. 按原配对置信度稳定排序，合并前检查两个组中的所有同视角区域对。
3. 允许 IoU≥0.9 的近重复提案；低于该阈值的同视角范围不能通过跨视角链路合并。近重复关系也按所有对检查，不假定相似具有传递性。
4. 仅保留原有边，不补造传递正例；被拒绝的边保持未知，不自动变成负例。
5. 基于保留对应重新构造 image/prompt 的负例依据；继续把文本类别并集与实例范围区分。

## 4. 验收、保留结论与下一步

41 项相关测试通过，覆盖深层嵌套、跨视角隔离、部分重叠、近重复、非传递相似、稳定排序、已有对应/可见性和原生解码。新源控制完成冷加载核对；完整保留 checkpoint 的 SHA256 未变化。

本轮落实了 S1/S2/S3 的有限子项，不勾选这些主项完成。还必须明确实际梯度路径：当前受保护模型的原生 text/image 相似度只读取冻结 native64，单纯筛掉对应边并重跑同一个训练流程，不能使这条路径学到新的语义区分能力。image 监督至多影响校准；结构学习对最终原生 image 读出的帮助仍没有建立。不能把本轮对应修正说成已解决原生文本 AP 瓶颈。

下一步应围绕同一个问题推进：**先明确 image/prompt 的跨视角目标范围，核对结构监督的实际梯度；用保留覆盖的新监督训练结构，并与文本/图像可访问的范围读取一起做配对验收。** 将原生排序和结构范围分别报告，避免只改善源任务拟合。原生语义分支保持保护，不同时混入新几何、换教师、hash 或更强适配器来掩盖责任归属。对于仍未接入结构的原生路径，不值得仅为换配对再跑一次完整训练并期待开放词汇能力恢复。

这一步还没有完成。当前完整主线此前测得的 text IoU/AP 仍为 figurines 43.52/62.91、ramen 28.42/42.81%；没有新增完整方法的图像、交互、NVOS 或 ScanNet OVS 成绩。此前几何问题也没有因此关闭。
