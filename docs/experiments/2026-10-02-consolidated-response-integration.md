# 源证据真正进入文本响应：LERF语义70.38%，双输出保持明确

本轮将研究从连续NVOS局部控制扩回完整LERF主线。完成四场景、全部67个标注文本及1个无标注输入探针的三种响应重建路线与一个原生下界对照，共16份完整场景评价；另外完成ramen两次统一推理入口重算和评价。新主线选择简单可见贡献融合：IoU70.3775%、AP87.6429%、实际元素集合投影66.6617%。这是开发集证据，非独立最终test或公开SOTA结论。

## 核心问题与实现

此前identity主线的身份筛选和源范围已进入实际集合求解，但语义响应仍直接保留原生地图的旧概率。于是同一系统拥有更好的范围证据，却没有让它进入语义输出。输入权限和源教师已存在，瓶颈是两个读出分支对证据的使用不一致。此前为了保护原生能力而冻结响应有实验理由，但也成为当前整合主线的明显限制。

新增`fit_consolidated_response.py`消费同一显式Scene/Query、身份筛选后的源掩码和冻结可见贡献矩阵。文本任务允许同视角同类实例取并集；未检测到的视角/查询不作为全图负例，身份拒绝区域保持unknown。原生正响应投影使相应排除证据弃权；这不是保证所有原生正响应都正确。

默认融合为 z = Σ Aᵀ(w·y) / Σ Aᵀw。A为已观察载体的可见贡献归一化矩阵，w为有效像素与检测置信度。无证据元素保留原生概率；几何、原生特征、query编码与实际集合头均不改变。192×256源光栅每视图取四相位之一，与现有集合求解采用的像素阶段一致。没有增加教师调用或源图数量，没有目标图像/标签训练，没有按query名称挑路线。置信度是模型证据权重，不是校准的正确概率。

对照一用NVOS同一`solve_rendered_evidence`继续拟合120步；对照二放开原生正响应对负例的保护；对照三给最终响应施加原生概率下界。最终按完整队列的IoU/AP/开销权衡保留简单融合，而不是把更复杂求解器当作默认。

## 未解决的问题和退化

67个文本按每查询跨帧平均统计：50改善、7下降、10不变。rubber duck with buoy从86.45%降至63.48%，coffee从24.93%降至8.75%；绿色椅子、plate等也有退化。所有完整逐查询记录在`query_deltas.json`，没有按查询回填旧答案。

这再次说明通过身份筛选不等于得到完整范围，区域补集不自动是真负例。新默认是有明显全队列收益的开发版本，不是所有query无退化的保证。无标注新文本仍不能计入准确率。

## 源侧可视化与NVOS结论

新增`visualize_reference_incompatibility.py`，只读合法源照片，展示参考帧和单/共同拟合差距最大的两个源视角。`output/source_incompatibility_gallery/source_conflicts.jpg`显示trex细骨架/楼梯栏杆附近混杂、orchids局部花朵范围弱响应。它支持进一步检查源范围质量，不能作为独立真值或精确错误归因。没有用人工选中的区域训练或修补查询。

NVOS本轮未修改默认，86.4891%为先前完整重算记录，不是新涨分。ScanNet未新增实验；UQIS按要求仍暂停。当前图像/2D/3D点接口的源侧探针结果不能替代统一四query独立验收。

## 统一入口与复现

可执行配方`current_research.json`默认改为`identity_response`：`--native-identity --source-response --response-solver backprojection`。旧`identity`保留为固定对照。`run_consolidated_query.py`在同一次显式推理中完成原生响应、源身份筛选、集合求解和新响应输出；源响应与标量校准互斥，避免组合未经评价的配方。

本轮完整队列复用显式已有原生响应、教师掩码及集合字段，以固定证据隔离响应改动；没有重建几何、重跑VFM或重新训练紧凑特征。ramen入口另行重算身份与集合，然后重建响应：语义张量最大差4.77e-7，IoU59.4019%完全复现，AP仅浮点差异。集合重新优化有1个硬成员变化、软值最大差0.0268，但集合投影IoU保持58.2715%。不要称该重新优化逐元素完全相同。主对照16份评价中的集合张量和observed支持全部逐元素完全不变。

## 能支持的claim与不能支持的claim

可以支持：在相同已声明地图和源证据下，把身份筛选的范围证据用于正确的响应读出，可大幅恢复语义区域精度，同时保持实际集合输出；简单贡献融合已经解释绝大部分收益。

不能支持：新的逆渲染优化本身带来重大贡献、四教师紧凑学生已经成功、同地图四query已全面验证、四benchmark公开SOTA或CVPR贡献已经成立。源证据融合本身是常见操作，本轮首先是架构整合的有效修复。

下一阶段应保持此完整基线，集中研究拒绝不完整范围负证据的可迁移机制，并在未用于调参的场景及独立标注下验证。并行补齐ScanNet统一入口与公开点云/网格口径、四query任务合约及地图/源图/教师/查询总成本；这些是明确待办，不能以本轮LERF涨分代替。
