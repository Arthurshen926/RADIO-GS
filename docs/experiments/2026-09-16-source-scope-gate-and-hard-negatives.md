# 源概念门控缺少困难负样本：定位、修复与真实召回

本轮只处理“query 被错误分配给已有概念范围”这一断点。保留冻结几何、96D 元素场、原生查询编码器、已有范围头及上轮结构补全路径。新增源掩码范围监督的门控否决，两个场景文本 IoU 和 AP 同时改善；这是文本开发候选，不是独立最终 test 或联合 benchmark 晋升。

## 真实结果

完整文本开发协议沿用宽 480、56 / 71 个观测、全场 observed 响应渲染及 0.5 membership 判定；未用目标 RGB 或 GT 训练/调阈值。

| 方法，IoU / AP（%） | figurines | ramen |
|---|---:|---:|
| 原共同基线 source_extent_rendered_residual96 | 36.51 / 58.97 | 25.10 / 37.84 |
| 上轮结构补全 native_overlap_fallback96 | 42.28 / 57.75 | 26.30 / 38.15 |
| 任意共观测配对训练门控（本轮失败对照） | 42.28 / 57.75 | 26.30 / 38.15 |
| **困难负配对门控 hard_source_scope_gate96** | **43.39 / 59.77** | **27.76 / 40.23** |

相对上轮，IoU 增加 **1.11 / 1.46 个百分点**，AP 增加 **2.02 / 2.07 个百分点**。相对原共同基线，IoU 增加 6.88 / 2.65 个百分点；不能把累计收益全部归为本轮。

这次改善不是增加教师、维度、训练元素场或继续搜索评估阈值。新门控只撤销不相容的概念范围，不重写原生语义空间。被撤销的查询进入上轮已经实现的结构补全；无交集仍回原生场。

三类参考查询完整复核（35 / 57 个参考任务，与完整文本集合不同）：figurines 文本 IoU 仍为 41.55%，ramen 从 25.65→27.27%。图像 IoU 33.12 / 13.81%，注册提示 IoU 40.71 / 24.77%，所有图像/提示观测与上轮逐项相等。本轮收益不应描述成三类查询都改善。

## 核心问题定位：现有接受条件不等于语义范围匹配

旧门控选择文本余弦最高的源概念，阈值来自该概念名称与 photo 模板之间的自身相似度。这个条件没有学习“看起来相近的短语为什么不能共享对象范围”，会接受 `bag→table`、`chopsticks→noodles`。

本轮首先以源视角中实际共现的教师掩码监督配对：同一视角两短语的掩码并集 IoU >= 0.5 作为范围相容，未观测到任一短语时未知。原生文本余弦和原生 query 对源区域图像描述符均值的余弦作为两个固定特征，只训练两个非负权重和偏置。

但任意配对中包含大量容易区分的不相关负例，与实际推理中已被最近概念选中的候选不一致。该对照虽有源验证拟合能力，**真实查询结果逐项不变**，没有收益。

进一步只统计实际源路由接受的共观测配对，暴露出反例缺失：

| 场景 | 训练正 / 负 | 按查询短语留出的验证正 / 负 |
|---|---:|---:|
| figurines | 154 / 1 | 32 / 2 |
| ramen | 333 / 1 | 107 / 0 |

figurines 该对照学成全部接受；ramen 因验证缺少负类而停止导出，保存了不足报告，未强行改变拆分或把未知标负。这是本轮新构造的门控训练任务的覆盖审计，不代表其他所有历史监督都只有这些负例。

## 修复：源侧相似但范围不相容的困难配对

对每个有观测的源短语，在同一源视角：

1. 从共观测、掩码 IoU >= 0.5 的概念中选文本最相近的正配对，优先非同名配对，没有才允许自身名称。
2. 从共观测、掩码 IoU <= 0.1 的概念中选文本最相近的负配对；自身名称不作负例。中间范围的模糊配对和缺失观测不充作负例。
3. 构造候选概念图像描述符时，排除当前被监督的源视角；无其他视角证据的配对不参加拟合。
4. 按 query 短语而不是逐配对随机划分留出集，使用固定 seed 42。拟合 1200 步，每 100 步用源留出 BCE 选择 checkpoint；没有 target GT 选择 checkpoint。
5. 推理时保留原来的概念提议，只在新得分小于零时否决；不重新分配给另一个概念，不增加新 query 适配器。

困难配对的训练 / 验证数量为 291 / 100（figurines）、688 / 198（ramen）。留出相容配对召回率为 82.0 / 89.9%，不相容配对误接受率为 14.0 / 40.4%。ramen 的后者仍高，不能声称关系学习已可靠。

这里的范围标签来自源教师伪掩码，不是验证过的物理实例对应。留出仅隔离门控拟合用的 query 短语；基础场、教师和源图像原型此前已使用源图像，所以不是整个系统的独立视角/场景验证。带权 BCE 的 sigmoid 分数也不是校准后的真实查询正确概率；trace 中 `scope_posterior` 仅记录这一模型分数。

## 路由变化与最终范围变化一致

| 场景 / query | 原源概念 | 上轮 IoU | 本轮 IoU |
|---|---|---:|---:|
| figurines / bag | table，撤销 | 0.62 | 31.15 |
| figurines / pumpkin | fruit，撤销 | 28.97 | 60.33 |
| ramen / chopsticks | noodles，撤销 | 0.00 | 17.75 |
| ramen / corn | vegetables，撤销 | 4.17 | 0.00 |

其余逐类 IoU 未变化。`pumpkin→fruit` 和 `corn→vegetables` 是上下位概念，不能称其文字语义毫无关系；问题是范围可能过粗，不能直接替代 query 所要求的范围。

新门控保留了 `napkin→white napkin`、`sake cup→cup`、`old camera→camera` 等有效映射，没有复现此前全局加严门槛同时破坏这些映射的问题。

corn 的退化仍须报告：撤销粗范围后，原生场没有高于原阈值的正元素，因此结构补全没有有效种子。它的原生 AP 仅 0.87%，不足以把问题解释为只有门控或阈值错误。此前 jake/waldo 的结构补全退化本轮也没有解决。

## 取舍与后续核心问题

`hard_source_scope_gate96` 在已测两个场景上同时优于上轮 IoU 和 AP，作为后续**文本开发候选**继续；保留原基线、上轮模型以及本轮失败控制，不按场景挑不同模型。不宣称所有细粒度语义能力恢复，也不宣称历史正常主线已被超越。

接下来主要瓶颈已分成两种，不能混作一个阈值问题：

- corn / wavy noodles 等原生排序本身弱：需要逐概念比较源教师定位、几何融合后的原生特征和 64D 重建，定位剩余信息损失。
- jake / waldo 等原生排序尚有信息、结构补全仍会退化：需要约束补全如何保留正负查询响应，而非再次无条件扩大范围。

本轮没有新增 ScanNet OVS、NVOS 或 SAM 2D 交互评估。所有成绩都是反复使用的 LERF 开发集结果。
