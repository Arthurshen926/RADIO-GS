source-only audit samples 32 evenly indexed training episodes per scene using
fixed median supports and teacher scales. It finds only about 9.5/9.3% of false
additions in newly available disjoint-but-different-scale masks; most lie in
unknown source regions. Do not relabel these unknown regions as negative. The
separate updated readout diagnostic changes no model and cannot promote a
single-anchor or native-only substitute for the requested union contract.

Test a native local directional metric in the same member energy used by text,
image, signed 2D rays and registered 3D elements:

`L = T [cos(group_s(i), prototype_s(S)) - b
        - (1 - cos(native_DINO(i), weighted_native_DINO(S)))]
     - squared_physical_distance(i,S)/(2s²)`.

same support weights. Full-native and affine-codec scoring must agree. The
coefficient is fixed at one inside the existing temperature; no extra trainable
parameters or teacher are introduced. Native coordinates and native query
identity scoring remain protected. This is a test of retaining local evidence
through membership, not a claim of complete object boundaries: unlike-looking
parts of one object may be wrongly excluded.
