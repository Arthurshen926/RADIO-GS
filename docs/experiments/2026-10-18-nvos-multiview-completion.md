# NVOS N15：完整参考响应的多视角融合与停止条件

日期：2026-10-18；工作树 `/root/RADIO-GS-query-field`，分支 `codex/tmm-query-response`。
当前状态：八任务、48 张预测和两种 GT 评分全部完成；停止联合融合分支，保留 N14 作为最高 IoU 候选。补全参考的仅源融合是明确的能力迁移成果。

## 科学问题与固定设计

N14 已恢复参考查询的范围，但 fern/trex 仍有内部误报与细结构损失。
N15 检验同一个完整参考响应能否通过所有原始源视图形成更正确的三维响应。
主方案和停止规则在本轮预测前由 ADR0038 固定。

- 重放 N14 `quality_image` / `quality_native`，校验图像数组哈希和实际三维混淆计数。
- 同一个双帧 SAM3 将原始参考掩码或 N14 质量选择后的完整掩码，分别传播到每个
  原始授权源视图；不按场景挑选视图。参考视图直接使用对应二值种子。
- 源视图证据按既有 512×384 网格进行概率和置信度的面积积分。实例存在分数
  非正时，该视图视为未知，不当作背景。固定原几何、原观察域及初始响应。
- 分别求解原始参考的源融合、完整参考的源融合，以及完整参考的源＋目标融合。
  前两组对目标图像的权重严格为零。主候选为第三组：各有效源视图先按置信度
  总量归一化、再平均，整个源组与原生目标图像具有相同总权重。无权重搜索。
- 三组使用相同算子、独立响应列，120 步 Huber 求解。目标射线和输出均为
  1008×756。每个源／目标算子对照原渲染器，误差须低于 1e-4。

完整八任务共 48 张预测全部封存后，才以原 GT 与 LUDVIG GT 两种口径评分，
固定阈值 0.5，记录 IoU、AP、精确率、召回率与前景修复／损害。
源端原始／补全响应的拟合残差都是教师一致性诊断，不是源 GT 精度。
其他四个 benchmark 的 23 个 job 保留哈希核验的既有参考，不称为新推理。
联合融合对 N14 才是相同目标 RGB 访问条件下的主要增量比较。仅源融合的
匹配机制对照是本轮原始参考对完整参考；与历史 N01 的比较只能说明功能与
性能进展，官方负涂画和 DINOv2 等输入扩展不能被隐藏或计作纯融合收益。

## 停止条件

若此固定方案族不能提高平均 IoU 且保持平均 AP，就停止本融合分支，保留 N14。
不根据本轮目标分数搜索权重、源视图子集或逐任务切换。这里的停止是当前
受控路线的收益判断，不是证明 NVOS 或理想架构已经达到普遍上限。

## 问题归因与机制边界

1. **查询范围补全可以迁移到多视角三维融合。** 匹配仅源对照中，flower、orchids、
   trex 分别增加 8.2234、25.9133、5.8148 pp。增益主要来自修复不完整参考的查询范围，
   不是目标图像输入。按整个场景留一（horns 两查询一并移除），该匹配增益始终为正，
   最低约 +1.7152 pp；这只是已打开开发队列的敏感性描述，不是独立泛化验证。
2. **等权源约束使响应更保守。** 相对 N14，联合融合在全部 8 项上都减少 FP，
   同时也损失 TP。平均精确率增加 0.5054 pp、召回率下降 0.6629 pp；fern 增加
   0.4813 pp，但 orchids、flower 分别下降 0.6088、0.4234 pp。清除背景的收益
   没有抵消完整前景和细结构损失。图示为全任务展示，不能据此挑选部署分支。
3. **源一致性与目标准确率不能等同。** 对补全源教师，按视图再按任务平均的 Huber
   残差由 N14 的 0.00462558 降至联合的 0.00074763；仅源拟合更低，为 0.00061325。
   联合在每个任务上均降低该残差，仍未提高平均 IoU。源教师并非源 GT，不能说已经
   提高所有视角的真实精度。原始源教师残差也下降，但两套教师自身可能有共同误差。
4. **实现检查未发现能解释本次退化的已知数值／评分错误。** 全部 318 个源与 8 个
   目标算子对照原渲染器，最大归一化响应误差 1.1325e-6；观察域外修改为零。
   N14 图像响应逐数组哈希重放一致；三个 v10/N14 对照在两种 GT 下的整数混淆计数
   完全一致。原生连续值 AP 与旧 N14 的差约 0.000004 pp，不称为逐浮点数相同。
   所有 48 张输出先封存，两种 GT 均独立核对计数；这些检查不等于排除所有潜在偏差。

本轮没有分别操纵源证据分辨率、传播误差和源／目标权重，因而不能进一步声称损失
完全由其中某一个环节造成。已确定的是：固定教师条件下，完整参考改变了可迁移的
查询范围，而无差别追加源一致性约束未能突破最强目标条件响应。下一阶段论文可以
使用这个正负对照闭环，不再把优化拟合残差当作目标精度的替代指标。

## 外部对比更新

重新核对原论文后，补齐近期及此前遗漏的公开报告值：

| 方法 | 论文 NVOS mIoU | 可比性边界 |
|---|---:|---|
| [VCAR](https://arxiv.org/html/2608.30870v1#S4.T1) | 93.5 | 官方七目标，提示、几何及读出不同；未完成同协议本地复现 |
| [LEGO](https://arxiv.org/html/2608.10057v1#S4.T1) | 94.2 | 论文描述七场景；具体目标清单及论文运行配置未独立核验 |
| [WildSeg3D](https://openaccess.thecvf.com/content/ICCV2025/papers/Guo_WildSeg3D_Segment_Any_3D_Objects_in_the_Wild_from_2D_ICCV_2025_paper.pdf) | 94.1 | 原论文 Table 1；几何与掩码生成不同，未完成同协议本地复现 |
| [Trace3D](https://arxiv.org/html/2508.03227v1#S4.T4) | 92.5 | 原论文 Table 4；几何／实例追踪路径不同，未完成同协议本地复现 |

LEGO 官方评估器的当前版本识别 horns_center/horns_left，不能从“七场景”直接
推断其仅有七查询。它将 GT 最近邻缩放到渲染网格；提供特征相似度和二值聚类
渲染两种路径。论文分数与发布代码默认路径的对应关系仍需完整复现确认。
因此 93.5 不再被当作充分的 SOTA 达标线；任何跨论文数值差仍不是匹配协议增益。
官方代码 commit 与文件哈希见
`paper/tmm_response/artifacts/nvos_external_comparison_20261018.json`。

需区分两类比较：benchmark 排名不要求各方法使用相同教师或几何实现，
这些可以属于方法本身；它要求目标清单、合法输入／提示预算、GT 与评分口径
可比。固定教师和几何只用于我们内部的机制归因。不能把“实现不同”本身当作
拒绝外部比较的理由，也不能把论文报告值误称为已完成本地匹配复现。

## 实现、核验与资源

方法代码：`radio_gs/querying/multiview_response.py`。
入口：`scripts/research/run_tmm_nvos_multiview_completion.py`；
图示：`scripts/research/plot_tmm_nvos_multiview_completion.py`；
结果由登记入口 `python -m radio_gs.response_study refresh` 校验生成。

首次 v1 在第一张预测前遇到共享 GPU 显存不足，保留失败报告，GT 未打开。
v2 仅更换运行名及 GPU，推理规则不变。184 项登记测试通过，包括独立实验列、
目标证据隔离、重复源视图不增加组权重、未知区域保持原响应。

继续沿用 8 MiB 研究预算、2 MiB 单运行和 1 MiB 单文件限制。源响应每任务在
私有 tmpfs 中最多 256 MiB，封存预测总量最多 256 MiB；不保存新权重或持久密集数组。
配置中的 16 GiB 稀疏算子检查按输入 COO 索引／值的字节数计算，不能表述为整个
进程峰值内存上限；CSR 转换、转置和求解工作区还会增加内存。持久磁盘预算与
临时源数组预算分别核算，不把内存中的算子计作已清理的磁盘实验结果。

最终持久实验新增 **585,403 bytes（0.5583 MiB）**，包含失败记录、完整结果与八任务图示。
继续研究目录共 2,332,647 bytes，剩余 6,055,961 bytes；
旧目录仍为 2,147,475,952 bytes。两个预测内存目录、八个源响应临时目录、
图示链接目录均已释放，新增权重和持久密集预测为零。论文 PDF／构建日志不计入该
实验目录预算，不能把 0.5583 MiB 当作全工作树所有文件的增长量。
审计见 `paper/tmm_response/artifacts/nvos_multiview_completion_storage.json`。
