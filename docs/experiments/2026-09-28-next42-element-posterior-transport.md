## Hypothesis to implement, with same heads/banks and no tuning
Freeze Stage2 B1/B2 checkpoints, evidenceC/F/B, parent next38, geometry/scorers. Replace region-wide clipped logit offset with directional, convex element-posterior assimilation. This is a bounded opinion pool, NOT a claim of exact Bayes independence: parent already shares source observations and pseudo membership may be miscalibrated.

For each region k/query q let r_k be the existing fixed visual member probability. Positive evidence strength c+ = max(2r-1,0). Negative strength c- = max(1-2r,0) multiplied by the maximum c+ of a geometrically disjoint SAME-VIEW competitor. A low score alone is still unknown, and .5 contributes exactly zero. No source text labels/associations enter routing. Do not change the frozen heads to force calibration or use target scores to choose confidence cutoffs.

For each supported element i, each source region supplies directional target change:
  h+_ik = max(r_k - p0_i,0), h-_ik = min(r_k - p0_i,0).
Unlike a region-mean offset, a reliable core cannot suppress evidence for a low-confidence member. Positive evidence cannot reduce a stronger existing positive, negative evidence cannot inflate probability. Only independent source support can override confidently wrong priors; no hard-fixed parent0/.25/.75.

Recover per-view footprint weights BEFORE total-visible-view dilution from existing bank weights and the bank visibility counts (verify builder definition and dimensions, do not guess). Preserve corrected within-view duplicate/mass normalization. Deduplicate identical same-view masks/source identities before pooling; do not count duplicate proposals as fresh observations.

Group source cameras into at most6 deterministic pose-neighbour groups (source-only camera centers and directions, fixed seed/farthest-point centers, no semantic or target-driven grouping). Exact repeated poses must share a group. Grouping discounts correlated source views; do not call all views independent. If registered poses cannot be recovered, use a declared conservative fixed source-sequence grouping, not an undocumented geometry assumption.

Within each group g, sum directional evidence weighted by footprint and c+/c-. Normalize it to a group target displacement and set group mass to the maximum available per-view evidence mass in that group, capped at1. Missing query evidence gives mass0, NOT an extra denominator vote. Then:
  pnew_i = p0_i + [sum_g mass_ig * group_displacement_ig] / [1 + sum_g mass_ig].
The initial1 is one fixed parent opinion; not a tuned strength. This is a convex average of p0 and directional targets in[0,1]; keep it bounded and explicitly prove/test that fact. At most6 group opinions limit confidence inflation. No nominal96D claim: account for the new query-independent camera-group metadata.

The deployment output must represent pnew, not accidentally pass it through old odds a second time. For EXACT zero change return original finite parent logits/scores verbatim. For a genuinely changed probability use its corresponding finite logit, clipping only the changed values; do not erase extreme categorical ranks at zero evidence. Original nontext output exact. Maintain deterministic accumulation, query-alone/A-B-A equivalence, cold serialization. Mixed/unknown/outside-reference regions not treated as background.
