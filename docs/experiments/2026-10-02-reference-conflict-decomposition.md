# 跨视角冲突与单视角覆盖混合：完整掩码改变了诊断结论

本阶段完成八查询两套标签域的冲突分解，以及八次固定证据的负例可靠性控制重建和评价。默认未改变；改动未产生收益。

## 机制诊断

对每个Gaussian、每个视角，按与实际拟合相同的归一化可见贡献累计正/负标签，计算该视角的正例比例p_v及证据质量m_v。将总Bernoulli标签方差严格分解为：

- 单视角覆盖混合：Σm_v p_v(1-p_v)/Σm_v。
- 视角间均值冲突：Σm_v(p_v-p̄)²/Σm_v。

两者之和为p̄(1-p̄)，数值最大误差小于3e-7。通过原始冻结完整场景渲染器把这些连续属性投影到目标，再在固定预测的漏检像素中汇总。标签均来自源教师，目标真值仅在预测和属性图生成后用于划分TP/FN/FP/TN。

这不是错误责任百分比，也不是不可表示性的下界：同一Gaussian有混合标签，不排除多个Gaussian共同渲染能拟合；跨视角差异也可能来自错误几何、遮挡或教师，不能只归因于跟踪错误。

**初看腐蚀后的监督，容易得出“主要是跨视角冲突”的片面结论。** 固定腐蚀已把大量边界混合从观测域删除；恢复完整掩码后，全部八查询都是单视角覆盖混合占多数。两者不是相互矛盾，而是反映了不同标签域。完整原始掩码同样是伪标签，不是真实空间边界。

因此当前有证据支持优先检查空间分辨率与载体覆盖，而不是继续把跨视角负例当作主要优化对象。尚未区分低分辨率光栅混叠、真实Gaussian跨边界以及教师边界错误，不能直接宣称某一种已被证实。

## 唯一机制控制：其他视角正证据保护

实现 `fit_reference_instance.py --negative-policy other-view-positive`。每个源视角的排除权重乘以(1−其他视角正支持)，其他视角按正/已知证据质量聚合，严格去除自身视角。其他视角投影支持覆盖不足一半则不改权重。不添加正标签、不改几何、不换提示、不改变腐蚀或评价阈值。所有八查询使用同一规则和120步。
