# 查询功能恢复阶段总结：联合竞争改善响应，实际范围仍有退化

本轮五项顺序开发实验已全部完成，共八个请求、七个物理场、168份条件预测。
每项均先完成全队列预测，再读取目标标签评分。它们不是168个独立测试样本，
也不是未见标签的最终评测。最后实现冻结于 `a447306`。

固定同一批Gaussian场、旧120个合法来源、教师、几何、尺度及阈值，没有新增
训练、标签、场状态或运行时来源访问。最终方案响应IoU **69.5949→78.0334%**，
实际选集IoU **79.4595→81.4219%**；这些改善来自条件函数与读出，而非特征
重构或训练收敛。但实际选集仍四例改善、四例退化，不能宣称全面稳定恢复。

## 五项研究凝练出的架构结论

| 已检验的环节 | 结果 | 应保留的结论与边界 |
|---|---|---|
| 来源覆盖/尺度/接受/决策 | orchids覆盖98.77→96.38→78.75%，最终召回45.94%；直接区域并集大量误选 | 可覆盖不等于能正确识别实例；不能只归因缺少来源，也不能认定来源已足够 |
| 明确正部分的并集 | 单纯置信max使实际79.46→77.44%，八例精确率均降 | 保留目标不同部分的条件假设有必要，但max不是完整成员决策 |
| 射线内部不确定性 | 保留分组特征模长恢复实际77.44→80.54%；空间方差仅另增0.0025pp | 主要缺陷之一是过度归一化；不能把收益都归给几何方差或泛称不确定性 |
| 多个负背景约束 | 精确率恢复，但fern正提示被误删 | 保留负功能不等于加强独立否决，需处理与正证据的冲突 |
| 正负与未知竞争 | 恢复fern，最终响应78.03%、实际81.42%，仍有四例实际退化 | 同一条件核须配合正确的联合读出；实际实例接受能力仍未完整恢复 |

当前候选的架构可概括为：**注册输入 → 每条射线内保留贡献不确定性的同一成员
能量 → 跨明确正/负部分分别保留假设 → 原场内部分区域证据 → 正/负/未知联合
判定 → 同一Gaussian选集的二维/三维读出**。整个过程使用一份场，无运行时源
RGB、SAM源掩码、track库或旧求解器。图像/文字身份备选不是全部确定正例，
不能不加区分地套用此并集。既有三教师职责与单场原则继续保留。

本轮支持调整中间架构来恢复查询函数，不能证明这些简单算子本身具有论文
新颖性，也不能证明当前部分关系已经等价于v10完整成员判定。

## 仍需完成的能力与验证

1. **可信范围接受与排除。** fortress、horns_left、trex仍有明显实际退化，
   orchid正提示已全覆盖而召回仅62.80%。下一步应检验共同可见、同组/异组与
   粒度分歧如何帮助接受目标的其它部分并拒绝外观相近背景；不继续靠扩大并集、
   调正负倍率或每场换规则救分。保留v10观测统计的数值原语，不等于已迁移其
   决策能力；该缺口继续记账。
2. **完整、匹配的信息条件。** 243合法来源的分辨率/生成契约仍未统一。本轮
   固定120来源便于归因，不意味着额外视图无法减少身份歧义。v10参考RGB/SAM
   提示扩展也仍未转移；需单列当前查询输入的功能与代价，不能长期把它省略后
   只用特征保真替代，更不能偷偷恢复源图像运行时求解。
3. **同一方法的五项验收。** 新增逻辑目前是可选研究接口，没有按任务拼接历史
   最佳成绩。LERF2D/3D、ScanNet OVS、NVOS、UQIS四模态仍需同版本整体验证。

v10响应参考86.5134%，当前主方案仍差8.4800pp；输入与运行时契约存在差异。
不能拿81.4219%的实际选集指标与v10响应直接相减，也不能承诺完整性能已经可达。
