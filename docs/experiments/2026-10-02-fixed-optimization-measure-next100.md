# 固定优化条件后的正证据干预：next100

2026-10-02。三组四场景共12次完整评估完成。不替换 next98，next80 稳定参考与默认参数不变。

## 核心结论

上轮不能简单归因于“不确定正例有害”。固定初始化、视角顺序、置信权重、负标签以及归一化 footprint 代价后，增加 C 正例在四个场景均优于只使用 A 正例。几何筛选与全部恢复的整体表现几乎相同，仍低于现有 next98 的62.430%。本轮没有取得部署性能提升，但分离出了此前混在一起的两类作用。

| 场景 | 仅 A 正例 | A+全部 C | A+几何筛选 C |
|---|---:|---:|---:|
| figurines | 66.541 | 67.149 | 67.205 |
| ramen | 55.703 | 55.912 | 55.911 |
| teatime | 63.552 | 63.851 | 63.851 |
| waldo_kitchen | 61.012 | 61.632 | 61.595 |
| 四场景均值 | 61.702 | 62.136 | 62.141 |

指标为所选 Gaussian 子集的2D投影 IoU，不是独立3D真值指标。

## 实现与实验边界

在 `decode_expanded_extent_next72.py` 添加可选 `--optimization-state-out/in`。先在 A+C 源证据上保存每个查询的初始 membership、活跃视角索引、置信度、最终负例掩码和归一化 support cost。随后两组重新计算各自的正例，使用相同保存状态执行优化。固定步数、相机、交错射线采样、温度退火、损失形式与几何；不使用目标图或真值构造状态。没有新增教师调用。

此前 category-C 变化不仅影响正标签，也影响哪些视角进入负例相互支持、source initialization、视角循环、footprint 相机求和，以及由初始 membership 决定的代价归一化。此次明确将这些因素冻结。没有已接纳正例的固定视角仍可以包含原先固定的已知负例；被撤回的 C 正像素本身没有变成负标签。

**共同状态来自 A+C 分支，而不是一个独立的真值状态。** 因此这是在特定共同优化条件下对正标签接纳的干预，不能声称已独立识别初始化、采样和负监督各自的责任比例；也不能声称 category 控制完全不含 C 的历史影响。正类损失仍按各自接纳像素归一化，干预包括这些正例内部权重变化。

未给出 `optimization-state` 参数时沿用原路径，未改变全局默认。all 基准重跑与 next99 的四场景硬元素选择及最终指标一致；软分数有数值差异，最大约0.0147，不能称为浮点逐位复现。所有12个输出的原生语义分数、未重拟合54类选择与父输出完全一致。

## 如何修正此前判断

按这条具体对照路径：

1. next98（A证据、A派生优化条件）：62.430%。
2. 保留 A 正例，改用 A+C 派生的固定条件：61.702%，下降0.728个百分点。
3. 在同一固定条件下加入 C 正例：62.136%，回升0.434个百分点。

两步净变化为−0.293个百分点。这是一个有明确条件的实验路径分解，不是普适的因果责任比例。它说明不能仅凭第1与第3步结果判断 C 正例整体有害。

几何筛选只比全部恢复高0.004个百分点，不支持继续调见证数。Waldo 在固定条件下68.13→69.17%，spatula却42.12→41.27%，没有稳定补全收益。onion和ladle仍为0，说明这一接纳规则仍不能提供缺失的正确目标证据。

## 后续方法方向

保留 next98。证据质量与优化测度应分开建模：相机/几何代价不随语义核验器是否弃权而改变，正例可靠性只影响对应监督项。此次固定状态是用于验证机制的对照实现，不将依赖 A+C 的状态直接作为最终架构。

后续应优先构建源侧实例对应及局部可见范围，使缺少完整性证据的视角只提供局部正例，不自动提供整个对象的外部排除；用固定相机测度比较这一方法。当前结果不支持再靠几何票数筛 C 获得提升，也不证明几何载体存在不可突破的上限。无需新增教师堆叠或延长训练来解释本轮结果。

本轮没有新的 NVOS、ScanNet OVS、UQIS、四query统一验证或SOTA结果。仍属于源图辅助的查询时范围推理对照，不是可泛化特征场训练的突破。
