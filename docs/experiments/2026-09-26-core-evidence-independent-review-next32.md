# 当前核心证据的独立复核

截至本次复核，已完成的对照没有证明主线达到SOTA，也没有证明某一个小修复能显著改善四个benchmark。下面只讨论已完成、已封存证据；不引用仍在运行的directional-gradient候选结果。

## 优先级1：受保护的是已经混合过的64维坐标，不是完整教师能力

早期“元素教师重建头与query适配器各自学习、彼此不保证一致”的架构缺口，当前已由受保护的原生基底/共享原生解码路径绕开。**因此不能继续把现在的失败全部归给那个旧随机适配器。** 但冻结坐标只保证后续训练不会改坏既有坐标，无法恢复在生成坐标时已经丢失的信息。

当前源区域裁剪描述子仍先被分配给整片mask，重叠区域彼此平均，再通过几何和多个视角融合成元素向量。整体、部件和不同视角上下文因此可以被压成一个折中方向。追加更多区域、冻结该方向或增加一个残差槽，都不保证原生查询关系保留下来。

同输出合约的12图源诊断中，64维文本教师Top-1一致率为独立区域78.66%、2D重叠56.67%、同视角几何往返54.23%、训练地图向保留视角读回38.65%。这些是**教师一致率，不是分类真值准确率**；Top-1非线性，跨视角阶段还改变了观察条件，不能相减后分配“各模块占多少错误”的因果比例。

更新的小区域诊断也支持这一点：figurines相同22个源留出小区域，直接64维投影保留文本/图像教师Top-1 59.1%/68.2%，进入旧或小区域恢复地图后均为0%。它定位的是投影之后的融合/对应/读回缺口，不能据此单独宣布几何正确，或宣布原生教师识别了真实对象。

## 优先级2：当前范围监督没有充分覆盖真实查询中的身份与粒度决策

范围头学到某个源伪mask，不等于判断出“当前query应该返回整个物体、一个部件、多个同类实例还是拒绝”。包含、外观相近和同名都不是同一范围身份的证明。范围外缺少证据，也不自动构成可靠负例。

完整ScanNet8控制中，可见性候选的源完整/实选IoU都提高，而19/15/10类最终IoU略降；LERF选择范围略改善，同时定位下降。二值源拟合、类别之间的区分以及实际元素选择必须分别检查。反过来，next32简单互斥排序监督也没有解决这一问题：可用的可靠互斥对本来就容易，顺序准确率接近98%–99%，它们没有代表困难的整体/部件和同名异范围情况。

真实实现还存在优化局限：概念范围头`logit(clamp(raw))`对错误饱和值的直接梯度为零；非概念查询另有硬范围/回退路线。共享参数仍可通过其他元素梯度移动，不能说这些元素永远不可修复。独立测试确认正在试验的定向梯度近似保持真实前向与冻结参数归属，但本复核不提前给它宣称性能收益。

## 优先级3：载体支持与当前评估不能证明完整任务已经正确实现

几何覆盖、点位置准确、Gaussian轮廓准确和语义可分离是不同条件。12场源审计发现：已有18,644个保留原生mask经96×128固定下/上采样，场景平均IoU87.5%–89.8%，薄结构77.0%–81.0%；另有2,014个原生proposal在裁剪编码前被0.2%面积下限删除。前者是边界信息损失，后者是区域证据缺失，追加grounded区域可能补回一部分；两者都不是独立物体真值结论。

当前网格反而高于所核验历史MPR网格46×62/60×81，元素数也不构成单向劣势。当前语义源视角较少，历史几何、范围组织和读出也不同，所以不能仅凭预算表把历史差距归因于某一项。

当前LERF“3D”是选中元素集合的2D轮廓评估，不是独立物理3D身份真值。四个benchmark目前也不是统一冻结的四query方法，UQIS仍暂停。当前LERF2D的校准概率阈值读出与旧多尺度Occam读出不同；本轮固定4场208观察，将30/7算子应用于单层当前概率图后IoU从49.7408%降为46.8295%，定位从81.2684%降为77.1145%。它说明读出确实影响指标，却没有“换回读出就补回差距”；更不能把该单层敏感性诊断称官方多尺度协议成绩。

## 已被具体对照否定或显著削弱的简单解释

| 简单解释 | 实测限制 |
|---|---|
| 完全重复证据是主要污染源 | 12图没有同mask且同描述子的重复；精确去重基本不改变当前输入 |
| 64维容量不足是唯一问题 | 正交残差改善独立区域，实际跨视角文本Top-1仅38.65→38.93%，7/12图文本MSE仍退化 |
| 只要让区域均值重建更准 | 固定区域均值反演未通过两试点联合文本/图像/边界条件 |
| 再加一个语义方向即可 | 固定双模式源加权读出两试点均失败；不否定所有多模式方法 |
| 透明尾部票放大解释了全局低分 | raw-Tα控制双试点失败；旧alpha<0.1票质量仅占figurines3.05%、Scan0000 0.060% |
| 找回小区域后按原规则平均就够了 | Scan0000改善，figurines图像MSE退化且Top-1仍0%；联合不扩展 |
| 再加一个通用排序loss就够了 | 可信但容易的互斥源对监督未通过配对准入 |
| 当前低分只是评估平滑遗漏 | 固定单层30/7敏感性结果下降；仍应修正协议表述，不能冒称已公平对比SOTA |

这些结论只否定对应固定实现和简单充分性假设，不否定整个方法类别。源伪目标有偏，未通过保守源门槛也不等于已证明真实benchmark必然下降。

## 下一步只做一个有明确机制的写入干预

当前最直接的有界候选是**小区域像素上的局部证据归属**：复用已存在的小区域原生描述子、相同64维基、几何、支持和查询银行，仅在满足固定2D面积比/包含规则的小区域像素上，抑制大parent区域的重复写票；其他源像素的写入权重及原生query解码保持不变。它与“增加loss”“区域均值反演”“两槽max/LSE”不同，直接检验已被观察到的跨粒度写入冲突。该2D规则不证明物理3D对应正确；同一元素还可能覆盖其他像素，因此不能承诺最终渲染的其他位置完全不变。

这是一项局部写入假设，不是假定小区域总是正确，也不能把parent当负对象。必须先证明未受影响像素逐值不变、覆盖/质量归一化正确；再在固定两试点的未参与写入源视角，同时保护小区域和保留区域的文本/图像排序、中心化响应与原有边界。基线应同时包含原地图和刚失败的普通小区域恢复。若任一场不通过，停止这个固定变体，不扫面积比、包含阈值或loss权重。若都通过，才重建全队列及所有依赖头，不能将新向量直接塞进旧范围头。

该候选的登记和实验结论由独立产物负责，本复核不预先宣布有效。跨视角错对应、缺失几何和全局描述子的上下文偏差仍可能独立存在。
