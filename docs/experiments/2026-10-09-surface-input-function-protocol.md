# Fixed geometric input-function probe

Declared while the joint-observation factorial study is still constructing and
before ANY of its benchmark scores. The v10 source code identifies another
untransferred function: a2D point becomes the first intersection with a local
surface, whereas the current Gaussian adapter mixes every ray contributor.
These are different conditioning distributions, not the same member capability.

Test the v10 geometric construction (12-neighbour PCA normal, fourth-neighbour
distance radius, first positive intersection, fixed two-pixel nearest-surface
fallback) computed solely from frozen Gaussian centres. Same current camera and
pixel; no reference RGB/depth, source observations, labels or native identity.
Return an estimated point_2d support to the common member operator. Preserve the
query contract: unlike v10's point reader, do NOT force this estimated3D member
positive. No alternative member head or per-query adapter selection.

Run every67 UQIS2D input on the already-frozen full_supervised joint observation
field. Compare its saved contribution-mixture predictions. Other inputs are not
rerun or claimed evaluated in this probe. Keep this a separate input-function
diagnostic, not a winner bundled with different task models. Its extra22-room
supervision and1089 source-view condition are inherited and explicitly reported.
Finish every prediction before scoring. Source/CPU function parity is checked
against the original geometry routine, including fallback and invalid cameras.
Measure the full fixed cohort, paired scene differences and unsupported inputs;
do not tune radius, normals, thresholds, support choice or model from scores.
