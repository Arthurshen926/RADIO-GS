# 范围重建、局部证据保留与原生语义读出

本轮修改的是范围的表达和读取机制，几何位置、尺度、不透明度、相机、教师描述与原查询编码器保持冻结。没有新增防御性检查、单元测试或审计框架。评估沿用已有输入权限、场景、输出阈值与评分器。

## 解决了什么

原跨视角范围把二维掩码反投影到高斯、二值化，再按可见视角投票。这个过程不是渲染的逆问题：一个高斯可能同时覆盖掩码内外的像素，归一化投票也不能保证重新渲染时得到原掩码。

新实现把每个范围视为高斯上的连续成员权重，直接最小化其**关联源视角**的渲染掩码误差。固定渲染责任矩阵为 A，采用投影梯度：

`m ← clip(m + 0.95 · Σ Aᵀ(y − A m) / Σ Aᵀ1, 0, 1)`

在同一范围的所有关联视角累积梯度后更新，80 次迭代；未关联视角不贡献负例。这里优化的是范围成员权重，不是三维几何。源矩阵来自已有缓存的真实合成权重，目标评估仍使用原高斯渲染器。

另保留未进入任何已匹配范围的源区域，每个区域仅用自己的源视角拟合40次，原生描述不做跨区域平均。它们是局部观测，不声称具有跨视角身份。LERF四场共保留7357个局部区域。这部分只完成范围与语义选择诊断，没有直接装入最终组合，以免把未知对应当成可靠对象。

原有 validation_iou 和图质量权重仍表示**重建前的对应置信度**，没有重新包装成重建后的独立验证成绩。源重建 IoU 是训练量；真实查询上的原生选择及范围容量另列，不能混为一谈。

但加入更多真实局部观测后，oracle 大幅上升，原生第一名却在三场退化。问题不是候选越多越好：完整范围可用性与查询对应可靠性必须分开解决。尤其不能据此把相似范围直接并为同一个对象。

## 三种读出及失败原因

1. 保留先前的混合正负范围否决规则：LERF2D49.7408→49.7432，实际元素选择完全不变。该规则基本阻止新范围发挥作用，不作为主要改进。
2. 取消整范围否决、仍固定高置信原响应：LERF2D49.7408→50.0802，实际选择33.5676→35.2017，四场二者均上升。但 image45.8996→43.3986，不能把同一种范围传播无差别用于所有查询。
3. 原生查询直接匹配范围、取最大成员响应组成多范围：只用源文本掩码拟合温度和阈值，原始语义坐标不变。两个先导失败：figurines49.5920→17.9996，ramen35.3532→21.1822。元素正选择比例分别从0.303%→3.175%、1.102%→3.010%。它扩大了选择，未建立可靠的对象归属。该支路不部署，不扩展成全量配方。

最大组合失败不证明所有多范围方法无效。它具体否定的是“原生相似度经过源侧的全局概率标定，就足以判定每个范围应否加入结果”的这一实现；未覆盖像素仍没有被自动标成负例。

## 最终系统组合

采用此前 next34 的原生多粒度文本证据和源侧标定，接入新的逆渲染范围。固定高置信原响应，范围只作用于文本模态。图像与提示保留其原读出；这是全场景一致的模态选择，不按场景或 benchmark 拼接赢家。

该组合同时评估 LERF4 和 ScanNet8。独立的范围传播对照则完整覆盖19张地图、LERF4文本和图像、ScanNet8、NVOS8任务，含提示后传播对照。所有候选均为开发集实验；UQIS仍暂停。

## 仍未解决的核心问题

- **查询到范围的对应。** 可用正确范围显著增加，但原生语义第一名并不可靠；简单最大组合会扩散误检。有限源概念的标定不能等同于开放词汇范围归属学习。
- **整体、部件、类别并集与引用实例的目标不同。** 图像分支的退化不能靠文本分支的提升抵消。需要目标类型明确的源监督和组合目标，不能再把任意 SAM 区域当成所有查询的统一完整目标。
- **剩余空间误差与语义误差仍需分开。** 本轮修正范围成员，不改几何；没有证明所有几何边界准确。高斯实际选择投影仍低于概率图 IoU。
- **跨任务收益尚未统一。** 不把独立 NVOS 对照的微小提高拼入文本组合，也不宣称达到 SOTA。正确范围的恢复可以保留为方法组件，最终查询选择仍有明显缺口。

后续应以已恢复的范围证据为基础，学习目标类型明确的“原场 / 范围 / 范围组合”选择，在源侧同时监督完整概率输出和实际元素集合；范围之外缺少证据仍须保持未知。优先解决范围归属与可靠排除，避免再用更多平均、更多全局阈值代替这个问题。
