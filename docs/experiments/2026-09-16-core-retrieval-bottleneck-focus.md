# 核心召回瓶颈重新聚焦

结论：教师/query 代数不一致已在可选一致解码路径修复；教师开放词汇能力写入实际元素的质量尚未通过验证。不能将公式等价、测试通过、少量类提升视为核心瓶颈解决。

当前路径：合法源 RGB / 相机 → MoGe 校准及冻结几何 → 源区域与多教师特征 → 单元素 64 维 latent 的场景训练 → 原生 query 编码 → 元素后验 → 完整场渲染或点域输出。SigLIP 文本与图像的新读出为 cos(Dz+b,q)，直接提示仍为 DINO+坐标经过适配器与 latent 比较；并非三类 query 都已完成相同的原生空间一致性修复。

## 本轮只推进第一问题的冻结诊断

复用已封存的真实 GT 裁剪编码，未训练、未修改地图。固定最新解码器 W,b，将原生裁剪方向投影到它可表示方向集合的闭包，再与原生文本查询比较。该集合为 span(W) 加上非负的偏置正交分量；边界可能需要无限 latent 范数才能逼近，因此这是乐观的方向保留诊断，不是实际地图输出，也不是分类最优上界。

| 掩码裁剪 Top-1 | figurines（56） | ramen（71） |
| --- | ---: | ---: |
| 原生描述子 | 83.93% | 88.73% |
| 最新解码器允许的方向投影 | 80.36% | 64.79% |
| 源输入构造 SVD64，原生 query 不投影 | 89.29% | 71.83% |

这次 SVD 对照保留原生 q，和旧的图像、文本同时压缩的 SVD 诊断不同，不直接混用数值。投影可偶然改善某些类别排序，SVD 高于 native 不表示超越教师能力。

固定单位范数的仿射最小二乘会被解码偏置大小影响，给出17.86% /19.72%的低识别结果；这个结果不适合判断余弦读出的方向能力，因此保留记录但不以它归因。诊断也要检查尺度不变性，不能为了证明压缩有问题选择错误控制。

当前证据支持：figurines 的新解码子空间仍允许大部分裁剪类别区分，不能继续把低场召回主要归罪于64维容量；实际元素是否学到这些方向与对象范围，是下一项检查。ramen 在这一乐观方向诊断中仍有明显下降，压缩保留也未过关。两者都没有证明实际元素已经保存这些能力。

证据：`paper/artifacts/{figurines,ramen}_decoder_direction_retention_20260916.json`；脚本 `scripts/audits/diagnose_decoder_subspace_retention.py`。旧固定范数结果也保留在 subspace_retention 文件中，不覆盖。

## 严格执行顺序

1. **先解决教师能力是否写入元素。** 冻结几何、源区域、查询与评估，比较同一源区域的原生教师、实际解码元素、实际元素查询分数。先报告类别排序/间隔和响应保留，再看IoU。当前代码 SigLIP 重建监督作用于区域均值 `D(mean(z))+b`，最终读出却先逐元素余弦和 sigmoid 再渲染；非线性与聚合顺序不同。区域均值重建好不保证各元素响应正确。这是明确约束缺口，其实际损失大小下一步测量后再做单项训练修复。
2. **第一项稳定后，解决对象/部件范围。** 在教师确能辨识的概念上，测已知源正区域覆盖、跨视角可信对应、完整目标漏检和误检。保留未知区域，不硬补伪负样本；扩充细粒度源证据，不从开发标注直接灌入训练。
3. **前两项通过后，再处理提示映射与分数校准。** 三类查询共享元素但不是同一监督/映射；参考点拟合不能代替跨视角验证。AP先行，IoU随后，不能只调阈值掩盖排序问题。

新的大规模 benchmark 扩展、增加教师/维度/训练轮数不作为当前主线；必要几何正确性守卫保留。当前 LERF 为真实标注开发评估，ScanNet/NVOS新语义场目标指标未完成。
