# 当前语义损失主要在哪里：匹配压缩对照与结构补全排序修复

本轮固定几何、源证据、96D 元素场和源概念门控，先定位压缩损失，再修复结构补全覆盖原生排序的问题。新文本开发候选 `native_within_extent96` 将 IoU/AP 从 **43.39/59.77→43.50/62.93%**（figurines）、**27.76/40.23→28.42/42.81%**（ramen）。排序恢复明显，IoU 仅小幅改善；不是全面大幅提升或联合 benchmark 晋升。

## 1. 当前的 64D 压缩并非平均性能损失的主要来源

重建当前模型使用的**同一批源区域**的未压缩原生融合特征，保持区域权重、几何、观察支持、query 和渲染一致。将它投影回当前 64D 基并与实际元素前缀比较，最大绝对误差为 8.94e-7 / 9.54e-7。两者确实来自同一融合，而不是不同裁剪、不同几何或不同训练版本。

两条原生路径使用相同的既有源侧 query 阈值及温度；未压缩分支没有另拟合校准，因此以 AP 为主要诊断。目标 RGB 不参与特征，目标掩码只用于事后计算指标。

| 路径，IoU / AP（%） | figurines | ramen |
|---|---:|---:|
| 当前源证据，未压缩原生融合 | 33.69 / 59.12 | 8.65 / 31.92 |
| 同一融合，当前 64D 原生读出 | 33.63 / 58.49 | 8.59 / 30.97 |
| 上轮完整方法（范围读出后） | 43.39 / 59.77 | 27.76 / 40.23 |

平均 AP 的压缩差距只有 **0.63 / 0.94 个百分点**。这限定于当前基与当前源融合，不能据此说所有低维压缩都无损，也不能否定历史独立适配器造成的大幅语义破坏。

逐类 AP 揭示两种不同问题：

| query | 未压缩原生融合 | 当前 64D 原生 | 上轮最终读出 |
|---|---:|---:|---:|
| jake | 83.21 | 82.69 | 24.62 |
| waldo | 52.17 | 52.61 | 4.04 |
| corn | 1.81 | 0.87 | 0.87 |
| wavy noodles | 10.74 | 10.35 | 7.91 |
| egg | 47.44 | 41.63 | 81.25 |
| chopsticks | 42.75 | 40.16 | 25.77 |

因此，jake/waldo 的主要排序损失发生在**最后的范围读出**。corn/noodles 的弱能力则在压缩之前的融合表示里已经存在；本轮尚未进一步分离原教师、源裁剪范围、证据覆盖和几何融合各自的责任。egg 的压缩 AP 损失约 5.82 点，说明个别概念仍受影响，但不能把整体瓶颈归结为 64D 不够。

## 2. 错误机制：选对部分范围不等于可以替换语义排序

原结构补全路径只要候选范围与原生正响应有非零交集，就返回候选范围头的概率。该头主要拟合源区域范围，其元素分数没有被要求与当前 query 的原生语义排序一致。最终同一张响应同时用于 IoU 和 AP，因而范围头可以在扩大/约束范围的同时抹掉可用排序。

本轮进行了三个固定其他环节的对照：

| 补全读出，IoU / AP（%） | figurines | ramen |
|---|---:|---:|
| 原候选范围概率 | 43.39 / 59.77 | 27.76 / 40.23 |
| 源侧实际收益拟合最小交并门槛 | 41.26 / 60.12 | 27.76 / 40.23 |
| 用范围选择一个全局原生分数阈值 | 40.49 / 60.79 | 27.18 / 41.26 |
| **保留范围内外划分，分别使用原生排序** | **43.50 / 62.93** | **28.42 / 42.81** |

第一项控制用源视角教师 mask 比较原生响应与候选响应的实际渲染 IoU，只对原概念门控拒绝的查询拟合接受阈值，按 query 短语留出验证。fig/ramen 训练仅有 10/7 个观测，验证仅 2/1 个；证据覆盖不足，阈值还受收益并列影响。真实结果未改善两场景，拒绝晋升。不能把这种微小源验证集当作可靠泛化证据。

第二项控制对选中范围拟合原生余弦 cutoff：在全部已观察元素上，找到与候选二值范围 IoU 最大的可实现原生阈值集合，同分元素不能被拆开。最终仍输出原生余弦经正温度缩放的 logits，保持元素排序。该优化只读取地图候选，不读取目标图像或评估掩码，不是 GT oracle。但单个阈值不能同时表达复杂范围，真实 IoU 下降，拒绝替换。

## 3. 保留的修复：结构负责范围优先级，原生语义负责组内排序

只改原概念门控拒绝、且确有交集的结构补全查询。原门控接受的范围头保持，空交集仍回原生响应。对补全查询：

`p = 0.5 × (候选二值元素 membership + 原生 sigmoid 响应)`。

候选内部、外部分别落在响应区间的上半部、下半部，**两个部分内部各自保留原生排序**，避免继续使用范围头任意的置信度顺序。这里没有保证跨范围内外的全局原生排序；范围选择错了仍然会损害召回。它也不是新增逐元素特征、另一个 query encoder 或另存一张语义图。

元素上的内外分类沿用原范围，在当前实测分数范围内保持不变；连续响应改变后经 Gaussian 混合渲染，像素掩码可能改变，因此真实 IoU 仍须重测。所有 IoU/AP 都使用同一个最终响应，不拆开使用两张不同分数图。

实际逐类结果：

| query | 上轮 AP→本轮 AP | 上轮 IoU→本轮 IoU |
|---|---:|---:|
| jake | 24.62→74.52 | 13.58→15.45 |
| waldo | 4.04→39.82 | 6.07→6.41 |
| chopsticks | 25.77→48.32 | 17.75→24.47 |
| wavy noodles | 7.91→8.83 | 5.94→7.32 |

jake/waldo 的结果直接说明：排序恢复很多，但范围仍不正确。不能把 AP 恢复说成完整对象召回已经恢复。

三类参考查询完整复核（35 / 57 个任务，与完整文本集合不同）：新候选文本 IoU/AP 为 41.70/60.36%、27.88/42.39%。图像 IoU 为 33.12/13.81%，注册提示为 40.71/24.77%，所有图像/提示观测与上轮逐项相等。本轮没有改善这两条路径。

## 4. 当前取舍

保留 `native_within_extent96` 为新的文本开发候选，保留上轮 `hard_source_scope_gate96` 和更早共同基线作控制。源收益门槛与全局原生 cutoff 控制均不晋升。

下一步应针对两类已分开的核心问题推进：

- **范围仍错误**：在保持原生排序的前提下，处理候选对原生正负响应的覆盖、同一对象跨视角对应及多实例并集；不能再用候选头任意分数覆盖 query 语义。
- **压缩前原生融合已经弱**：为 corn/noodles 比较源教师定位与融合前后能力，区分源证据缺失、裁剪上下文混合和几何聚合损失。当前对照不支持先增加维度。

本轮没有重新训练几何或元素场，没有证明新几何全面优于历史；没有新增 ScanNet OVS/NVOS/SAM 2D 交互的完整评估。所有实测仍是反复使用的 LERF 开发协议，不能当作独立最终 test。
