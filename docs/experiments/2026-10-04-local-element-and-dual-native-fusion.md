# 局部元素融合与双原生教师：同证据、训练及新房间对照

日期：2026-10-04。原10景、开发6景、预留3景及完整22项全部完成。
无需新增标签拟合的双原生概率平均已合并为 `configs/pipeline/system_v6.json`；
三个学习头均未合并。v5保留为对照。以下阶段性结论不等于SOTA或CVPR贡献成立。

## 问题与实现

上一轮整幅视图/整类权重能减少误检，却会一起取消正确补全。本轮将决策移到实际元素/query，
同时保留两个原生语义教师，检验三个独立问题：局部粒度、第二教师、可学习融合各自是否有效。

冻结几何、SigLIP与公开预训练Mask-Adapter/ConvNeXt CLIP，各自保留原生描述子和文本编码空间。
不学习随机query投影，不把不同教师向量直接相加。两个区域字典共享同一种稀疏元素关联结构，
先分别计算完整类别菜单下的响应，再融合概率。

- `siglip_vote` / `adapter_vote`：两个单教师与相同源投票。
- `average_prior`：原生概率等权平均，进入原有可见性投票；不拟合本场景标签。
  未收到源证据的位置保留原SigLIP回退。本轮map-only输出仍是SigLIP，不把源辅助收益写成离线地图收益。
- `local_single`：每个元素/query的16个统计量，经共享32隐藏单元网络修正原投票logit，577参数。
- `local_dual`：另加第二教师的概率、logit、竞争响应及熵，20输入、705参数。
- `global_dual`：相同20输入与705参数，先按query在全场有源证据的元素间池化，只输出每类全场修正。
  它检验局部粒度；不是上一轮每视图正负质量头的同义实现。

局部输入包括原生/源/基线响应、竞争者及熵，正负证据比例及目标均值、
可见性、已知证据量与源响应方差。全部类别竞争先于query分批计算。
模型没有类别编号或场景编号输入，但这并不等于已证明未见类别泛化。
无源证据的位置保留基线。冻结原生坐标也不等于最终排序不变：残差允许覆盖原判断。

这是一条有额外训练标签的**互斥类别读出研究分支**，不是实例选取器、完整对象质量估计器或紧凑多教师学生。
不将它强行用于LERF整体/部件重叠查询，也不把NVOS旧分支成绩算成新头的贡献。

## 固定训练及评价

训练仅使用九个官方训练房间：0000_00、0062_00、0070_00、0097_00、0140_00、
0200_00、0347_00、0400_00、0590_00。全部932源视图与全部有效GT点。
GT顶点到最近几何元素的映射与现有点评价一致；未知/未观测点仍进入漏检分母。

模型固定seed0、Adam0.003、60轮；0.5类均衡点CE＋0.5 soft IoU＋0.001平均参数L2。
末层零初始化，初始元素类别与旧投票九景全部一致。训练与运行共用局部证据编译器。
零残差回放最大logit差约3.34e-5，来自累积顺序，九景均无元素类别差异。

六个已打开的开发房间：0050_02、0231_01、0412_00、0575_00、0591_02、0599_02。
它们不再称为独立新场景。三个模型在这些分数打开前已冻结，没有按分数改参数。

另预留0606_01、0629_01、0653_01，分别141/134/240张有效姿态的stride20导出RGB，共515张；
无额外源图上限。几何由给定未标注网格构建，分别152050/244962/331565元素。
共36,587个自动区域。全部六个分支先保存预测，再读取这三景语义标签评分。它们是本机制首次使用的官方验证房间，
不是封存的最终test。输入轨道与LERF的RGB＋几何先验分开，不据此宣称公开SOTA协议等价。

### 实际修复的接线错误

训练辅助教师使用信息量加权；原始adapter场景配置部分仍只有旧键
`observation_weighting`。直接读这个配置会漏掉运行时的`native_observation_reliability`，
造成训练/部署第二教师不一致。现在辅助字典继承主场景的同一读出策略，使用自身原生文本编码器。
训练场景回放第二教师最大logit差2.00e-5，元素类别无差异。

修复前的36项开发输出移到 `output/local_element_fusion/development_aux_unweighted/`，
不计有效结果。修复后六分支×六景全部重跑；新三景在修复后才执行预测。
没有重训模型或利用开发分数改参数。这是部署一致性修复，不作为算法贡献。

**双原生平均新三景净增2.347638个百分点19类，三组场景均有平均收益。**
新三景两升一降，0629下降0.463783个百分点，不能称每景都提升。
原10景9升1降，开发6景4升2降；均使用同一规则，没有按GT或场景切换教师。
合并为v6的理由是系统收益、简单性与不新增训练标签，不是新颖性已成立。
v6的22项Scene/Query等执行job与已跑完的候选完全相同，结果仍指向真实候选输出，未复制成假重跑。

**局部学习有局部粒度的正证据，但独立增益仍未充分成立。**
局部双教师新三景比原投票增加2.920371个百分点，三景均升，且比同容量全局高4.432704个百分点；
但比无需新标签的平均仅高0.572733个百分点，15/10反而较差，开发6景19类也落后简单平均0.529128个百分点。
因此不把2.92个百分点全部归因于局部新机制、不纳入默认，也不扩展参数扫描。
这不是“所有局部学习必然无效”的结论；当前统计量、九景监督及固定模型未证明稳定的额外价值。

聚合后的响应、均值和方差仍不足以独立确认原始区域的身份及跨视图对应。源正/负响应只是教师证据，
不是真阳性/真阴性；范围未覆盖的问题仍然存在。下一步应保留每条区域证据到融合决策前，
分别监督其身份正确性和目标覆盖，优先减少错误覆盖与漏补全；不继续仅扩充聚合后置信度头。
需要新的未调场景验证；本轮三景现已打开，不能再当作下一轮未见场景。

新三景双教师查询菜单公共入口耗时29.70/29.58/31.90秒，含模型加载与缓存读取，
不含建图和源教师首次提取；六GPU并发环境下不据此宣称速度优势。
新增辅助字典合计约0.665GiB，源检测/身份/投影缓存约3.712GiB；RGB、几何和模型另计。
完整成本与图见 `output/local_element_fusion/analysis.json`、`transfer_results.png`。
