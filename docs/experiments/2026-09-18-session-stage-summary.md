## 2. 附件建议如何落地

附件指出的主要方向正确：对象数据库不应是唯一出口；重叠候选不能强制互斥/top-2；几何与坐标没有闭合；历史分数、源诊断和最终任务不能混比。

- 恢复历史identity–extent控制，重新加载、重建查询及渲染评分，而不是只引用历史汇总。LERF2D四场恢复39.5842% mIoU；LERF3D公共scorer为43.7394%，原记录约43.7304%，协议差异明确保留。没有恢复出新的五benchmark联合主线。
- 修复像素中心往返，区分resize/stride内参；版本化旧投影。增加自由空间冲突和遮挡未知，体素内RMS不再冒充物理表面一致性。
- 取消新路径强制top-2候选归属，区分重叠假设、实例概率、查询选择；压缩丢失不再混称未知。同图mask外不默认等于不同实例。
- 转向语义场为主体，MoGe几何先建后冻，对象范围提供辅助；不再把整场实例划分或背面补全设为所有查询前提。

证据：[初始修复与历史恢复](2026-09-14-v4-repair-and-control-recovery.md)、ADR0006–0008。

## 3. 当前系统流程

源RGB/COLMAP相机 → MoGe深度/法线 → 源侧尺度校准与可靠性检查 → 冻结表面高斯 → 像素到高斯实际贡献 → 源教师/候选及文本证据 → 特征融合与结构学习 → 查询读出 → 固定几何渲染 → 协议内评分。

持久地图为每元素一个96维向量：64维原生语义坐标与32维结构坐标。SigLIP原生语义经源侧基底/解码器承载；结构训练保护原生前缀。没有用可学习语义损失移动位置、尺度、旋转或opacity。范围头、校准器及图像残差是额外全局模型状态，不能把“单场”说成无其他参数。

文本以原生语义为基础，源概念范围可接管/补充，收益准入器减少错误接管。图像使用原生图像空间及实际召回监督的全局残差。注册点提示使用结构亲和；授权参考图2D点/框/scribble与直接3D点是不同协议。三类查询共享载体与标量渲染接口，但目标不都等于同一个类别或物理实例，当前也没有完全统一的范围推断算法。

## 4. 几何工作与边界

修复了相机合法性、深度采样半像素、MoGe/COLMAP射线不一致时的法线变换，以及后续仿射/局部深度变换的法线传输。隔离错误全局尺度fallback，建立可信邻视角恢复和有界局部校准；区分同体素观测次数与独立深度支持。构建薄、法线对齐高斯并绑定全部几何和相机身份，几何改变后必须重建贡献与教师资产。

实际几何、2D深度渲染及3D可视化、独立稀疏轨迹检查均执行。部分误差明显改善，但不是全场景稠密精度认证：例如ramen局部校准留点/留视角p90从10.91%降至6.15%；fern控制从23.69%降至5.23%，覆盖94.84%→96.18%。figurines独立参考稀疏，薄结构与遮挡融合仍有限。MoGe一致性不等于几何真值。

固定DINO特征辅助几何有独立试验，但没有共同通过；主线没有引入训练中的语义场反向拉动几何。hash或更密载体并未自动解决这些问题。

证据：[几何先行审计](2026-09-14-geometry-first-and-feature-coupling-audit.md)、[局部校准](2026-09-16-local-geometry-calibration-and-native-rebuild.md)、[NVOS重建](2026-09-17-nvos-geometry-rebuild-and-real-retrieval.md)。

## 5. 特征、教师、训练的核心转变

四教师已实际接入：SigLIP提供文本/图像对齐身份，DINOv2和RADIO提供可选特征/关系监督，SAM3提供区域与边界监督。SAM并非被声明为稠密语义向量教师。去RADIO可执行；OpenCLIP在干净输入上完整替换并评估，未获得共同优势。当前SigLIP是实现选择，不是理论必需。

三任务实际元素membership及跨视角渲染BCE/Dice已实现，不再只做教师特征重建。修复SigLIP文本头权重形状、像素提示误当单高斯标签、固定粗词表错标、未知当负例等问题。源文本由少量固定粗概念扩展为源图发现/定位；仍是伪监督。

早期核心诊断：原生SigLIP真实裁剪识别83.9/88.7%，旧64维学习适配器仅23.2/42.3%。随后统一教师解码与原生查询空间，再以64语义+32结构分工保护语义坐标。**独立适配器错位及结构训练改写语义的机制已被约束；原教师能力端到端无损保留并未证明。** 仍有压缩、裁剪上下文、融合和范围读取损失。提高教师重建权重曾使重建显著改善但真实召回下降，已否决。

图像实际像素召回监督的全局残差得到共同收益；把同一修正共享给文本则退化，当前保留image-only路线。冻结语义时文本损失可能只训练校准器，已审计真实梯度，不将辅助损失下降当新增语义能力。

还修复了SAM3复数RoPE被dtype转换丢失虚部的严重实现问题，重建干净源链并重做限定探索。旧污染实验保留历史身份，不与干净模型混报。

证据：[早期定位](2026-09-15-native-space-failure-localization.md)、[能力保留控制](2026-09-16-native-teacher-retention-control.md)、[SAM修复](2026-09-17-sam3-complex-rope-pipeline-fix.md)、[干净重建](2026-09-17-clean-teacher-rebuild-results.md)。

## 6. 融合与范围：实际收益及最近结论

最明确的系统改进是原生融合从条件membership直接平均，改为恢复实际观测贡献，并对每个源像素的重叠候选分票，避免一个像素重复增加总证据。固定输入/几何/结构及基底，重建依赖读出后：

| 指标，IoU% | figurines前→后 | ramen前→后 |
|---|---:|---:|
| 全文本 | 37.92→44.35 | 31.62→32.97 |
| 参考图像 | 38.49→49.95 | 26.23→29.77 |
| 注册prompt | 46.56→46.56 | 32.94→32.94 |

ramen图像AP从58.47降至56.69，不能只报IoU收益。随后用源侧实际范围收益及错误近邻范围训练准入器，figurines全文本进一步44.35→46.20，ramen不变。

最近逐级定位显示：同源候选的高2D一致性不等于跨视角完整性。修复先逐mask投影再max的错误，改为像素并集后投影；解码器会把冲突证据扩展为范围外响应。源误检响应质量中强票冲突占59.32/67.40%，不是误检像素比例，也不是因果责任百分比。

双向支持/包含/不相容/未知已分开，四折12视角决定关系、4视角验证。完整分母融合IoU38.97/51.72%；各分组、选组与局部弃权未共同改善。固定组假设事后oracle仅41.91/53.97%，说明继续修选择器不足以大幅提分。该验证只隔离对应/融合阶段，基础几何和概念库存并非全流程留出。

新增两项确定修复：补回无训练证据目标的8/4项漏检；原生掩码和粗掩码均相同才允许缓存去重。后者重放绑定替换53/8→0，但原替换前后IoU均>98.8%，不夸大为主因。v2完整资产尚未重建。

证据：[像素融合](2026-09-17-pixel-evidence-fusion-and-extent.md)、[范围收益准入](2026-09-17-granularity-and-extent-benefit-admission.md)、[最新隔离验证](2026-09-18-partitioned-scope-supervision-validation.md)。

## 8. 未采用探索与剩余优先级

已执行但未共同胜出的控制包括：额外维度/更长训练、单纯提高重建权重、统一文本图像残差、全局原生阈值替代范围、范围并集/最大组、若干尺度及可见性硬筛、面积分层、显式/MLP/hash结构继续训练、MoGe输出/encoder/refiner蒸馏、固定特征辅助几何、OpenCLIP替换。失败只否定所测配置，不是永久否定方法类别。参考现有工作形成了身份/范围分离、多粒度、跨视角证据和显式隐式控制；没有以论文存在替代本项目验证。

当前优先级收敛为：

1. **可靠身份与范围证据**：将同名、多实例、整体/部件、漏检与不可见分开；提升未参与对应决策视角上的完整性，控制误检。当前假设质量是直接瓶颈。
2. **保持原生能力的范围读取**：原生语义保护已建立，但结构何时改变membership仍缺可靠依据，文本/图像未统一。
3. **独立验收与工程收敛**：几何薄结构/覆盖、v2缓存的完整重建及重复证据处理、统一依赖入口、同一完整方法跨LERF/ScanNet/NVOS及未使用最终集。

项目已经从错误对象唯一出口和不可靠监督拟合，转为可追踪的冻结几何与原生语义保护系统，并获得真实开发集收益；尚未达到“pipeline所有层面已正确、整张清单完成、全面超过历史”的状态。最近范围对照没有新共同收益，应直接面对证据质量与目标定义，不继续用更多gate掩盖。
