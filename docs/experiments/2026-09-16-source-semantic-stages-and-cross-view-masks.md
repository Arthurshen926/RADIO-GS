# 源语义写入与跨视角掩码对应：系统级分段审计

本轮没有获得可采用的性能提升。完成两场景源侧逐级对照、排除语义特征的跨视角掩码对照，以及一个实际渲染算子约束的特征重建控制。**新的重要定位是：即使完全绕开查询编码和特征压缩，同名源掩码跨视角传递仍然严重退化。高几何支持率不能作为对应正确的证据。** 同时，更低的源像素特征重建误差没有转化为真实召回能力，控制模型已拒绝，原主线不变。

## 1. 同一源目标的语义阶段对照

只使用既有源资产。figurines 为 6 个训练视角，ramen 为 12 个。目标来自 source-only caption/SAM 掩码，同视角同短语取并集，置信度至少 0.7、单掩码至少 20 像素，得到 194 / 441 个源短语—视角观测。它们是教师伪标签，不是独立真值；短语别名可能重复同一对象，因此这些平均值也不是独立对象平均。

使用实际语义前缀所依赖的原始区域库存及其原生 SigLIP 描述符，不用新 caption 描述符替换。比较：

1. 源区域描述符按覆盖掩码在 2D 混合，得到投影前响应。
2. 只用当前源视角的 region_probability 提升特征，再投回该视角。
3. 使用全部源训练视角的原生特征融合，再投回当前视角。
4. 排除当前源视角的所有描述符，用其他视角重建后投回。

均使用原生 1536D 描述符与原生文本查询，平均元素余弦响应，不使用 sigmoid 或学习阈值。没有目标 benchmark RGB、查询或标签参与这些步骤。全源融合投到现有 64D 基底后，与部署语义前缀的最大误差分别为约 8.94e-7 / 9.54e-7，确认诊断的是现有库存和融合。

为了避免覆盖范围混淆，以下主表把四条路径限制在**相同像素支持交集**，交集外响应统一为零，完整源教师正掩码仍进入 AP 分母。交集覆盖源正例的比例为 89.66% / 79.54%。

| 源侧 AP，% | figurines | ramen |
|---|---:|---:|
| 投影前 2D 区域混合 | 72.24 | 64.95 |
| 单视角提升及投回 | 68.97 | 63.28 |
| 全源视角融合 | 69.17 | 56.80 |
| 排除当前视角后重建 | 59.34 | 49.47 |

保留各自原有支持时，四行分别是 73.42/66.00、66.26/62.01、64.92/60.08、55.18/52.36。不能把这一组未经支持对齐的差值全部当作语义损失。交集对照仍支持跨视角泛化薄弱，但 figurines 的全视角融合并未比单视角更差，不能一概归罪于所有平均融合。

### 区域覆盖缺口在写入特征之前就存在

在当前视角现有语义区域库存中，用源伪标签事后选最佳区域，平均 IoU 为 72.45% / 65.65%；用原生文本余弦选区域，则为 52.49% / 45.16%。前者是有限库存的 oracle 诊断，不是部署能力或任意组合模型的上界。

ramen 的细部尤其突出：

| 源短语 | 观测数 | 最佳单区域 IoU | 投影前 AP | 全源融合 AP |
|---|---:|---:|---:|---:|
| egg | 9 | 7.2% | 7.6% | 31.2% |
| noodles | 10 | 28.2% | 32.9% | 28.2% |

这里的 AP 保留各自支持，用于描述该短语，不做精确损失归因。egg 反而从其他视角获得信息，说明不能把所有细部失败解释成同一种融合损失。已有 caption 区域中存在细部，不等于这些细部已可靠写入当前冻结语义前缀；简单把新描述符平均进去此前也已失败。

检查了 caption 编码器按源视角拼接描述符的实际顺序：两场景均与 mask/proposal_views 行顺序一致；当前资产不存在这一疑似错位。此结论只针对已检查资产。

## 2. 绕开语义特征，跨视角对应仍然严重退化

直接提升 caption 教师的同名源掩码，去掉所有语义描述符、查询适配器、压缩和范围头。每个目标源视角仅由**其他有该短语检测的源视角**提供掩码；缺失检测的视角保持未知，不当作负例。各源视角内部先取掩码并集，用缓存的冻结几何贡献精确提升，再按可见源视角平均，并投回目标源视角。目标源掩码只用于评分。

只有单视角检测的 9 / 5 个观测不参与跨视角平均；剩余 185 / 436 个成对观测使用相同分母：

| 源掩码诊断，% | figurines | ramen |
|---|---:|---:|
| 原视角提升—投回 IoU | 87.88 | 93.81 |
| 排除目标视角后的跨视角 IoU | **43.20** | **43.81** |
| 跨视角证据覆盖目标正例 | 95.32 | 96.57 |

例如 green apple 同视角 95.22% → 跨视角 60.58%；camera 93.62% → 41.36%；noodles 93.68% → 23.17%；egg 94.25% → 39.58%；white napkin 85.57% → 10.99%。

**这证明当前跨视角源证据传递有显著问题，且不需要语义空间损坏就会出现。** 它尚不能分离几何跨视角投影误差、源教师漏分/过分、同名短语范围变化、多实例并集和可见性处理的各自责任。原视角循环接近自洽也不是独立几何精度证明。尤其不能从正例有载体推出载体对应了正确对象。

## 3. 实施并拒绝：渲染一致的原生特征重建

新增独立控制，用缓存的可见性归一化贡献矩阵 A，反求每元素 64D 原生前缀，而不是直接反向平均区域描述符。监督是源像素处原有区域原生描述符均值，经原生空间归一化后投到不变的基底；没有 benchmark 监督、caption 标签监督或 query 特定更新。

目标为：

`||A z - y_source||² + 0.1 ||sqrt(diag(AᵀA)) (z-z_parent)||²`

采用预条件共轭梯度 80 步，保留没有观测的元素。两场景相对正规方程残差分别约 0.000413 / 0.002031，没有声称达到 1e-5 收敛阈值。保持几何、有效支持、64D 基底、结构后缀和校准参数不变。为避免坐标改变后错误复用旧范围头，从无范围头的 `full_source_query_threshold_control` 导出，与同一个原生参考对比，**不直接替换当前完整主线**。

| 指标 | figurines 参考 → 控制 | ramen 参考 → 控制 |
|---|---:|---:|
| 源像素特征 MSE | 0.001276 → 0.000338 | 0.001083 → 0.000307 |
| 真实开发文本 IoU | 33.63% → 27.66% | 8.59% → 10.25% |
| 真实开发文本 AP | **58.49% → 44.68%** | **30.97% → 22.99%** |

源误差降低约 73.5% / 71.7%，真实排序在两场景都下降。AP 也下降，因此不能只靠“旧校准不适用”解释。控制明确拒绝，不按场景挑选 IoU；也不据此否定所有渲染监督。它说明**拟合当前源混合特征，本身不足以约束跨视角召回泛化**。没有必要再把这个已失败的文本控制接入旧范围头或扩展成整套训练。

## 4. 保留状态与后续唯一优先项

保留 `exact_render_query_threshold96`，本轮未修改其模型或推理路径。全文本开发 IoU/AP 仍为 figurines **43.52/62.91**、ramen **28.42/42.81**。这些是此前测得、本轮校验模型哈希未变的指标，不是新提升；没有新增图像、交互、NVOS 或 ScanNet OVS 成绩。

下一项优先处理**源区域的跨视角对应与范围一致性**：在部件、完整对象及同类并集中分别建立源侧验证，区分几何投影偏移与教师范围变化；验证之前，不把同名掩码或缺失检测自动升级为完整对象正负真值。它应先于再训练更强 query 适配器、扩大维度或继续降低源特征 MSE。当前没有证据允许宣布这些对应问题已修复，也没有获得大幅性能提升。
