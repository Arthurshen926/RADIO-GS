# 区域来源恢复与公共建场运算

日期：2026-10-19；活动工作树 `/root/RADIO-GS-query-field`。
决策：[ADR0044](../adr/0044-preserve-region-provenance-and-independent-visibility.md)。
本轮没有 GPU 训练、教师推理、场景重建或 benchmark 新分数。

## 本轮解决的架构缺口

上轮发现的 20 份 ScanNet 编译场来源缺失已能通过显式元数据补回。
这不是重写特征场：从 10 景 **1,158 份逐帧区域缓存、73,905 个原生区域**恢复
视图顺序、偏移、原始 proposal index，并绑定原始缓存哈希。
主教师描述子逐行严格一致；辅助教师的完整 CSR 索引、权重、支持域、载体和历史
逐视图构建记录核对一致。两套教师各 73,905 个描述子位置对应同一批区域。

恢复文件及配方位于
`output/shared_evidence_20261018/region_provenance_20261019_v1/`。
全部文件共 **3,728,810 字节（约 3.56 MiB）**，最大文件 392,881 字节。
没有复制或修改大型字段、权重、掩码或已有结果。该目录与源缓存应作为配方依赖保留。
可用 `scripts/research/restore_compiled_region_provenance.py --output <新的空目录>` 重建；
任何描述子、区域顺序或贡献关系不一致都会拒绝恢复，不猜测配对。

## 实际代码与消费位置

| 层次 | 本轮实现 | 边界 |
|---|---|---|
| 来源恢复 | `evidence_core/provenance.py` 逐行校验与内容绑定 | 原始 SAM 像素、辅助编码器未重放 |
| 读取 | `compiled_observation_prior` 显式加载来源，再进入公共适配器和原读出 | 保留同一描述子／CSR 张量，不读额外图像 |
| 建场运算 | `evidence_core/gaussian_observations.py` 复用像素区域重叠分摊与贡献累计 | 几何渲染器仍是专用适配器 |
| 几何可见性 | 新建场可选保存未乘区域掩码的渲染贡献质量 | 历史 20 场仍缺此关系；未启动 GPU 重建 |
| 替换教师 | 编译器核对父场描述子、区域顺序并保留来源 | 没有更换当前双教师配方 |
| 队列与追溯 | 全 31 任务配方；主／辅助场景及来源文件进入预检哈希 | 完整推理默认仍为 legacy |

逐区域 provenance 与独立 visibility 是两种信息。恢复前者，不得把后者标为已经完成。
特别是“可见但没有任何区域覆盖”的元素，在新建场可见质量中仍可为正，语义支持质量为零。
这一情况不产生确认负证据；完全遮挡和没有区域证据不能被合并解释。

显式构建开关：`RADIO_GS_EVIDENCE_CORE=shared_v1` 与
`python -m radio_gs.pipeline.observation_field --scene ... --output ... --retain-visibility`。
该开关会增加空区域视图的渲染和额外稀疏数据，尚无真实 GPU 成本或效果结果，默认不启用。
新 Gaussian 运算保持原贡献质量归一化；UQIS 注册地图保持原视图均衡策略。

## 验证

恢复过程对 20 个场使用固定正交查询向量，恢复前后 **59,659,050 个 logit 元素逐个一致**。
这是读出行为检查，不是实际类别编码或新的 ScanNet 精度。
运行时测试还让保留源视图的可靠性读出实际消费附加信息，禁止额外反序列化源数据。

CPU 单测在 `legacy`、`shared_v1` 下均为 **239 passed、1 skipped**。
跳过的是 CUDA/NVCC 渲染器检查。新增覆盖：同数量错序、空视图、篡改字段／来源文件、
重叠区域、空区域、无遮挡但无区域、完全遮挡、真实读出消费与主／辅助配置追溯。
测试不是新的科学消融；两个 profile 的运行也不是两套独立科学证据。

全 31 个任务的组件结果另见
[v6 审计](2026-10-19-shared-core-component-audit-v6.json)。
**31/31 通过，349 项数值比较逐元素一致**；263 个输入与 235 个源码哈希绑定，审计中源码未变化。
它继承 UQIS 全载体成员、LERF/NVOS 源域检查，增加 ScanNet 两帧实际命中下的建场代数对比，
并检查带来源附加层的实际编译场读出。这里的命中网格是已有源证据网格，
不冒充原 256 宽建场的完整重放或独立可见性恢复。

[架构清单 v3](2026-10-19-shared-evidence-architecture-inventory-v3.json)保留 31 条真实命令计划、
15 个模块职责，以及 `shared_build_complete=false`：源帧选择、教师提取、两种几何适配器、
完整 N14 提供器和完整 GPU 验收仍未统一完成。

## 下一步收敛

1. 不再为恢复来源复制大场。新构建立即保留来源；独立可见性按同几何、同相机和同网格补建。
2. 将 N14 完整参考修复／传播接入公共输入权限和运行队列，保留其负涂画与目标 RGB 声明，
   单列同权限对照，避免把额外访问能力算成公共核心收益。
3. GPU 可用时先做已固定的代表样本端到端检查；不以继续堆积新机制替代该验收。
4. 单 SigLIP2、UQIS 查询裁剪 SAM 与后端变化仍分开；最终配方冻结后五项完整重评。

本轮使共同证据底座具备可核验来源，并向公共建场运算推进；没有证明新机制提高精度，
也没有把恢复的元数据作为独立论文创新或完整系统验收。
