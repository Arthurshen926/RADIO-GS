# 系统融合与可见性范围监督：完整对照

本轮保持已冻结的输入权限、几何、查询编码与评估公式。所有结果都是已有公开标注开发集上的方法控制，不是新的独立测试集成绩，也不构成 SOTA 结论。UQIS 按用户要求继续暂停。

## 核心定位

当前链路是：源图教师区域 → 区域语义向像素分配 → 冻结几何写入元素 → 原生查询匹配 → 有条件的范围修正 → 概率渲染或选中元素渲染。

本轮最有解释力的发现发生在语义写入阶段。使用同一批保留源视角、区域及实际渲染有效域，12张地图的文本教师 Top-1 一致率依次为78.66%、56.67%、54.23%、38.65%，分别对应独立区域、2D重叠证据混合、同视角几何往返、跨视角地图读回。**区域教师认识目标，不代表把其全局描述子涂满区域、再和其他区域平均后仍认识同一个目标。** 跨视角阶段还混合了几何对应、教师视角差异和整体/部件变化，不能把阶段差值全部解释为单一原因。

这也是方法问题，不仅是工程错误。训练源视角有31,051对“包含且DINO相似度大于0.8”的区域，其中16,770对的SigLIP文本Top-1不同。外观相似不能证明对象范围相同，传播结构不能自动解决整体与部件的语义冲突。

同时修正了一个真实的诊断错误：上一轮把已经按元素可见质量归一化的区域条件概率当作渲染权重再次池化。新的读回直接按实际像素贡献归一化，再在区域内平均。旧封存结果不改写；其具体幅度由[纠正后的12图对照](2026-09-26-matched-source-fusion-and-region-mean-control.md)替代。

## LERF：实际选择监督与遮挡负例

2D可见掩码不能给被遮挡元素提供可靠的负身份标签。仅渲染选中元素时，遮挡者被移除，原本不可见的目标会显露。如果把这些显露部分全部按原2D背景惩罚，就会诱导模型删除目标元素。

新增可见性约束：正区域保留；选中元素的孤立渲染在完整场中仍有至少一半可见贡献时，才使用该处背景负监督。可见性比值停止梯度，原完整场可见区域损失保留。训练使用连续不透明度近似，验证仍使用原来固定的元素阈值与PNG阈值。

四场都只更新文本范围解码器和残差头，固定400步、种子42、学习率1e−4。设置同预算的原选择损失对照。候选检查点必须在源侧同时满足完整场IoU不降、实际选中元素IoU提高；step zero可以保留。最后四个源视角只对本次头部拟合保留，父模型此前见过它们，因此不称为独立模型验证。

逐查询检查也显示真实退化：teatime的hooves在两帧约下降20.1和16.9个百分点，尽管该场选中元素总IoU提高。这说明范围补全与细部语义的冲突仍在，不能用平均分掩盖。此类目标指标只作事后排错，不用于挑选源侧检查点或逐场拼接赢家。

本轮不替换主线默认值。当前称作LERF3D的固定评估实际上是选中Gaussian集合的2D轮廓评估，不是独立物理3D身份真值。本次遮挡监督修正也没有补出缺失的3D真值。

完整结果及逐张原生掩码重现验证见 `output/selected_visibility_next31_v2/summary.json`。评估器复用导致原始报告继承了“扩大源视角、完整场重建”的旧描述；本次统一汇总明确纠正为**固定几何和特征，仅重拟合文本范围头，源预算不变**。统计及渲染代码与冻结版本一致。

## 其他已经完成的控制

- 精确同掩码、同描述子去重：加入防止重复证据改变权重的实现与测试，但12图训练数据没有这样的重复票，因此它是防护，不是当前瓶颈或性能增益。
- 区域均值一致性：使用固定闭式解修正重叠区域，而非继续逐像素平均。两个预先指定的源侧pilot没有同时通过文本、图像及边界检查；拒绝扩展和部署，不扫参数。
- NVOS参考范围补全：预先固定的高纯度参考证据允许保留额外连通分量。完整8任务IoU从81.1608%降到80.9634%，AP从91.5057%降到91.4251%。trex产生范围外扩张，其他7任务IoU不变，候选拒绝。保留原81.1608%控制，详见[完整报告](2026-09-26-nvos-component-reference-evidence.md)。

## 双组语义证据：方法级探索的边界

固定两个源侧pilot，把同一元素不相容的区域证据存成两个原生语义方向，按真实源贡献量形成先验权重，再按查询做加权log-mean-exp读出。先逐元素评分再按原几何渲染，查询仍在完整原生空间归一化。全局温度只由训练源证据的角残差决定，没有目标指标调参。

该方案增加容量：96维变为160维加1个权重，float32存储从384升至644字节/元素。figurines和ScanNet0000约43.97%/51.34%的观测元素具有两个有一定质量且方向不同的语义分量。但其文本响应MSE分别上升2.56%/0.15%；ScanNet图像MSE下降7.82%的同时，图像Top-1下降2.65个百分点。两场均未通过预先声明的联合源侧准入，未启动benchmark，也未复用旧范围/校准头。

这排除了“仅多存一个方向，再用固定聚合读出即可解决”的具体方案。边界伪目标本身混合了区域描述子，并非像素语义真值，因此不能由此否定所有多模式表征。详见[源加权双模式报告](2026-09-26-source-weighted-native-mixture.md)。

## 投稿前仍需解决的实际问题

1. 在写入和跨视角融合时保留不同粒度的语义身份，而不是指望最后的范围头从平均向量里恢复全部信息。要同时检验文本、图像、边界和过响应，不能只降区域均值损失，也不能只增加特征槽数量。
2. 范围补全需要未参与对应判断的视角验证；参考图上的高纯度、结构相似、相同名字都不足以证明同一完整对象。
3. 范围头的准入必须覆盖查询间区分和最终实际选择。ScanNet二值源掩码变好而类别IoU下降、LERF选择IoU提高而定位准确率下降，都说明仅用两个源IoU选检查点仍不足。只能对可靠互斥关系监督类别竞争，不能把整体与部件强制设为互斥。
4. 目前四个benchmark保留的是各自可复现的开发控制，并非一个已经统一冻结的四query主线。还缺同权限的历史/SOTA完整对照，以及独立数据上的一次冻结验证。参考图/目标图访问权限、几何输入与预算必须共同报告。
