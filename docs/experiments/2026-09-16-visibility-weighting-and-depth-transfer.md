# 跨视角可见证据权重与直接深度传递

本轮实现了贡献加权的源成员融合，并完成两场景匹配训练和真实文本开发评估。**它改善了源掩码传递，也优于同条件的等权训练，但尚未超过保留主线；两种新模型均不采用。** 直接深度传递及源图可视化进一步说明：问题不是只换一个载体或平均方式就能解决，源范围完整性和跨视角对应仍未验证。

## 可复现的设计缺陷：极弱观察获得完整一票

现有提升先把一个 Gaussian 从某视角收到的掩码质量除以该视角的总贡献，得到 membership；随后只要总贡献大于 `1e-6`，跨视角融合就计完整一票。清晰可见的观察与几乎只有尾部贡献的观察具有相同权重。这不是除法算错，而是融合丢弃了可观测证据强度。

本轮使用像素归一化贡献的元素质量作为视角权重。没有新增经验阈值、benchmark 标签或推理时目标图像。权重仅表示渲染证据量，不是教师预测正确率；视角面积、距离和重复观察仍会影响它，因此不能称为已解决全部置信度问题。

在同一批源短语—视角、同一几何和同一输出支持上：

| 跨视角教师掩码 IoU | figurines，185 观测 | ramen，436 观测 |
|---|---:|---:|
| 等权视角 | 43.20% | 43.81% |
| 贡献质量加权 | **46.61%** | **52.73%** |

掩码仍来自源 SAM/caption，是伪标签；改善不是独立 test 分数。缺失检测的视角仍为未知，不补成负例。

实现 `source_membership_consensus` 接收每视角概率及可见贡献质量，保持未知支持，按有效质量归一化。测试覆盖：多个极弱矛盾观察不能压过一个清晰观察、拆分同一观察但保持总质量不改变结果、未知值不污染输出、等质量退化到等权均值。

## 真实模型对照：修正有作用，但不足以替换主线

以 `exact_render_query_threshold96` 为父模型，构造两个同条件训练臂：

- 等权融合。
- 贡献质量加权融合。

两臂先在源像素空间对同概念掩码求并集，再线性提升，避免把 `max(lift(mask))` 当作 `lift(union(mask))`。它们在一般情况下并不相等；本次真实训练对照的两臂都修正这一顺序，因而两臂差值只反映融合权重及其引起的训练采样变化，不将总变化全部归因于权重。

冻结 96D 元素场、原生解码器、所有 query 路径、校准和门控、独立区域范围头及共享隐藏层。仅更新末尾概念范围头的线性输出系数；两臂同种子、同优化器、1200 步，按固定最终步输出，不根据开发标签选 checkpoint。目标不同会改变正负采样池，不宣称逐 minibatch 完全相同。没有改动旧模型文件。

| 真实文本开发 IoU / AP，% | figurines | ramen |
|---|---:|---:|
| 保留主线，重跑 | **43.52 / 62.91** | **28.42 / 42.81** |
| 等权修订训练 | 39.80 / 60.26 | 26.36 / 41.34 |
| 贡献加权修订训练 | 42.02 / 60.94 | 27.88 / 42.82 |

贡献加权相对匹配等权控制的 IoU 增益为 2.22 / 1.51 点，但仍低于主线。因此只保留为可复现控制，不把源侧提升说成整套系统提升。不能据此否定所有证据权重，也不能宣布完整对应已修好。

## 绕开 Gaussian 的几何传递对照

使用当前 source-only MoGe 校准深度与相机：从目标**源视角**的深度像素反投影到世界，再投到其他源视角采样教师掩码。使用已有几何先验容差 `0.08m + 0.02 * source_depth` 检查深度一致性，不用目标掩码选参数。目标源掩码仅用于评分。此控制需要目标源深度，不能作为地图部署成绩。

figurines 的 21、31 帧，ramen 的 18、22、109、76、101、105 帧没有通过既有独立深度校准，均因 scale 超出预设界限而拒绝。本轮不放宽界限、不使用被拒绝的 scale。**校准被拒绝不等于这些视角的 COLMAP 相机错误，也不等于其 RGB 不能参与语义训练。**

为消除输入差异，重做 Gaussian 掩码传递，只保留与直接深度相同的 4 / 6 个源视角和相同的 121 / 224 个短语—视角观测；所有其他源视角也从证据中排除：

| 同源视角集合、同观测的源掩码 IoU | figurines | ramen |
|---|---:|---:|
| Gaussian 等权 | 43.45% | 45.04% |
| Gaussian 贡献加权 | 46.41% | 49.75% |
| 直接校准深度反向采样 | 42.42% | 53.57% |

三者**不是同像素支持**：直接深度的目标正例覆盖为 85.04% / 84.62%，Gaussian 为 95.89% / 93.70%。所有分母保留完整教师目标。不能把差值直接归因于 Gaussian 参数化，或把它解释成某个步骤的责任百分比。直接深度在 ramen 有收益，在 figurines 没有，排除了“只绕开 Gaussian 就能普遍恢复准确对应”的简单解释。

原始直接深度报告的 `matched_gaussian_mask_iou` 仅对齐了目标观测，未对齐其他源证据集合；**正式比较使用** `direct_depth_matched_mask_comparison_20260916.json`，其中检查了两条路径的观测键及每条查询可用其他源视角数完全一致。

## 源可视化：不要把同名检测当作已验证完整对象

[white napkin 源掩码图](/mnt/pool/sqy/results/RADIO-GS/output/source_white_napkin_atlas_20260916.png) 的实际本地路径为 `/mnt/pool/sqy/results/RADIO-GS/output/source_white_napkin_atlas_20260916.png`。

12 个源视角中，掩码覆盖不同位置的小纸片及较大纸面，有些视角包含多个区域。类别并集任务允许多个实例，**多个对象本身不是错误**；可视化也不是独立 GT，不能据此断言每个检测都错。但同名检测尚未验证是否覆盖所有可见同类对象，不能把剩余可见区域无条件解释成可靠负例。

这与数值对照共同限制了后续方向：先验证源教师范围完整性及对应，再确定哪些视角提供正证据、哪些真正能排除目标。仅改变可见性平均能修一部分污染，却无法自动修复漏检、范围变化或几何错位。当前证据尚不能为这三者分配严格责任比例。
