# 提示有效性与 NVOS 几何输入修复

本轮优先解决实际流程错误，没有改写旧训练场或继续增加训练步数。发现并修复了提示优化与渲染有效性不一致、NVOS 相机图像域错配、文件名后缀导致相机身份碰撞三个问题。新增图像提示优化的真实对照没有通过质量门槛，保持可选。

## 提示优化与最终渲染使用同一有效性标准

旧的直接提示优化和新增原生图像 query 优化都会删除未观察元素，再将任意非零剩余贡献归一化。最终输出却要求完整像素 alpha > 1e-8 且 observed/full alpha > 0.5。这会让仅有少量可用特征的像素被优化器当作有效约束。

新增共享 `observed_seed_contributions`，两类优化都先检查全部前向合成贡献，再筛选观察元素。未知支持保留为不可用，直接提示执行保留原 query，任务不从分母移除；图像评估也做同样回退。非法浮点元素索引不再静默截断为整数。调用者必须提供包含未观察元素的完整贡献列表，不能先过滤再调用。

真实参考队列复测使用两场景、各两模型、原有 35 / 57 个任务，旧模态分数复现，说明这批已经选中的参考点未触发新增拒绝条件；不把这项正确性修复解释为当前低分的主要原因。

## 原生图像 query 正负条件优化：真实失败对照

此处输入是原有 GT 参考裁剪，再增加与直接提示相同的一个正像素、一个负像素。它比普通图像 query 多了授权信息，是独立诊断协议；不是官方 NVOS 完整涂鸦任务。目标 RGB 不用于该目标查询编码，目标 GT 仅评分。

| 场景 / 模型 | 原图像 IoU | 条件优化 IoU | 原图像 AP | 条件优化 AP |
| --- | ---: | ---: | ---: | ---: |
| figurines 校准对照 | 28.31% | 28.54% | 45.32% | 45.40% |
| figurines 一致解码 | 32.03% | 27.53% | 50.44% | 41.95% |
| ramen 校准对照 | 20.02% | 17.81% | 29.79% | 34.81% |
| ramen 一致解码 | 18.39% | 16.56% | 28.51% | 29.40% |

满足局部参考点不足以保证跨视角范围正确；优化可能改变原查询方向并损失其他区域的判别。该结果不支持默认启用或扩大优化步数。还不能据此否定完整涂鸦条件化，因为输入证据范围不同；必须在真实 NVOS 场上另行验证。

证据：`paper/artifacts/{figurines,ramen}_signed_support_repair_20260916.json`，包含逐任务指标、参考约束执行结果、场与实现哈希。模型参数和几何保持不变。

## NVOS 几何资产的两个真实接入错误

八场景根目录 `sparse/0` 都是原始畸变相机，尺寸为 4032×3024、模型为 SIMPLE_RADIAL；实际发布 RGB 已去畸变并裁剪。既有 LERF 数据加载器知道 `hwf_cxcy.npy`，新 MoGe 几何构建器原先没有处理它，不能据旧加载器正确就推断新流程正确。

新增 `source_colmap_assets`：存在发布内参 sidecar 时，必须使用匹配的 `dense/sparse` 完整模型，验证无畸变 pinhole 内参和图像尺寸。不能只替换 K 而保留原始畸变域的二维稀疏观测。发布内参加入几何收据哈希；后续 `MogeGeometryPrior` 从收据读取同一套相机。

另一个问题是旧 `_frame_index` 仅取文件名最后一段数字。horns 的 DJI 名称有三组碰撞，trex 有六组，COLMAP 读取字典会覆盖先前相机。现在明确绑定完整文件名到帧编号；MoGe 源选择、COLMAP 融合及后续几何加载共同读取这个映射。无显式映射时遇到重复编号直接报错，不再覆盖。源图像逐文件校验哈希，目标只可提供已发布相机元数据，不能作为源 RGB。

八场景源域检查全部通过，共 318 个任务场景源帧条目（horns 两个交互任务共享同一场景，不能视为 318 张独立图像）。合法源图像尺寸与对应 dense 相机逐一验证。

| --- | ---: | ---: |

## fern 首个真实几何构建与联合尺度拒绝

完成 fern 的 19 张合法源图像 MoGe-3 推理，官方 vitl 固定版本、分辨率级别 9、3 次 refinement、FP32 几何存储。推理读取守卫同时禁止目标 RGB、目标 GT 和交互涂鸦。18 张通过局部尺度校准，1 张拒绝；没有以全局尺度强行接纳被拒绝视角。18 张中 14 张构图、4 张用于源视角几何检查。

| 源保留视角诊断 | 独立尺度 | 联合尺度候选 |
| --- | ---: | ---: |
| 渲染覆盖率 | 89.05% | 90.63% |
| 相对深度误差 | 3.82% | 4.40% |
| 自由空间冲突比例 | 18.74% | 41.13% |
| 深度一致比例 | 71.36% | 51.83% |
| 元素数 | 140,051 | 157,209 |

联合尺度的源对应验证残差均值从 0.01940 降至 0.01535，但完整渲染变差。原构建器仅以对应残差均值和 P90 判断接受，存在方法上的判定不足。新增 `joint_scale_quality_gate`：接受对应优化还必须通过源保留视角覆盖、深度误差、自由空间冲突和深度一致性检查；非有限值拒绝。采用不退化的保守门槛，未按目标标注调参。

本次联合尺度被拒绝，保留独立尺度候选。旧构建报告没有改写，补充哈希绑定的决定记录 `paper/artifacts/nvos_fern_geometry_acceptance_20260916.json`；以后新构建报告同时记录对应验证与完整渲染验证。

这些参考深度同样来自 MoGe，不是独立真值；稀疏尺度校准使用合法源资产，也不能包装成独立最终几何 test。独立尺度仍有明显自由空间冲突和未覆盖区域，目前只是可继续审计的候选。

新场景几何构建不应依赖既有语义或 Gaussian checkpoint。新增显式 `--skip-historical-comparator`，报告注明历史对照未执行，正常执行独立/联合几何构建及源视角验证；默认旧行为保持。

独立尺度候选已完成 14 个构图源视角、46×62 网格的精确前向合成贡献资产，位于 `/mnt/pool/sqy/results/RADIO-GS/output/nvos_frozen_authority_20260916/fern`。这一步未载入特征模型；几何 hash、源 RGB hash 和逐视角贡献 hash 已核验。它不等于语义场已训练，也不等于 NVOS 目标 mask 已生成。
