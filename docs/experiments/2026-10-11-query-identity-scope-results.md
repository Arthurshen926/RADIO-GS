## 更直接的架构上界：只增不删无法恢复目标

评分后的独立诊断读取已冻结预测mask P和GT G，不产生方法预测、不参与训练、
阈值或逐查询路由。对于任何保持P的像素集合P′，最优选择为P∪G，因此

    IoU(P′, G) ≤ |G| / |P ∪ G| = |G| / (|G| + FP(P))

按实际评测的每场案例平均、四场宏平均得到：

|固定基集|当前实际IoU|只增不删的像素oracle上界|只删不增的像素oracle上界|
|---|---:|---:|---:|
|原生初值|42.9498|53.4562|84.1598|
|强固定对照|45.1953|56.9889|83.0460|
|种子补全|46.6535|54.9752|85.4985|

只删不增的像素oracle为P∩G，其IoU等于原预测recall。穷举全部4像素P/G及其
所有单调修改，验证两个解析界和空集边界。所有实际基线IoU重新读取mask核对。

这是允许任意逐像素正确补全的**乐观上界**，没有3D共享、遮挡、候选表达或推理
可辨识性限制；实际Gaussian补全不保证可达。它适用于保持已渲染前景的策略。
当前冻结几何/opacity的选集alpha投影具备单调语义，实测两种seeded组删除像素
均0。若允许修改几何/opacity或撤销原选集，则不属于该界的适用范围。

v10 66.9633%来自同四场实际选集投影的既有参考，但其来源预算、运行时来源
访问等条件不同；不把差额解释为纯架构因果。这里只检验当前受限策略能否达到
这个性能目标。**单Gaussian场、原生教师和共享实际选集没有被此上界否定。**
删除oracle较高也不说明已有删除器有效，或无需补全；它仅说明保持现有FP会
造成硬上限。此前能量组、条件替换组的失败证据依然有效，不能因允许双向修改
就在没有验证的情况下重新提升它们。

## 架构收敛决定

1. 保留一个Gaussian场、三教师职责、类型化查询、2D/3D共享实际集合和无回源
   推理。保留已验证的原生语义、原生区域patch汇聚及区域绑定；它们是函数能力。
2. 原生初值、强固定解和种子改为**可修订的先验／候选**，不再作为最终解的
   不可删除约束。控制组仍须精确复现；新方法有责任修正其中的误选。
3. 不把旧“高纯度种子→完整实例”的森林当成通用文本范围裁判。部件、属性、
   多对象union需要当前查询的范围判断；硬身份筛选没有完成这一功能迁移。
4. 后续联合实际选集读出必须同时验收新增、删除和替换的质量，并对齐Gaussian
   支撑测度与所用判断函数。不能继续只换外观、叠门槛或永久禁止修改基集。
   也不能反过来把未知处一律当背景；应先用相同输入的功能参考检验查询范围、
   有效排除及实际轮廓三项职责，再验收统一五任务。

下一阶段需要实现并验证上述可修订范围函数；本轮没有宣称它已经完成。种子
46.6535%继续保留为开发对照，不作为最终系统定型；没有新的五任务版本或论文闭环。
