# 不完整范围的负监督：next101

2026-10-02。完成3组×4场景共12次评估。未获得足以替换 next98 的提升，不修改默认或稳定参考。

## 问题与方法

源掩码外的区域并不一定是目标外部：跨视角跟踪可能只覆盖可见部件。但直接撤销这些负例也可能放大错误范围。本轮固定 next100 A+C 优化状态（初始化、相机顺序、置信度、负例候选掩码、归一化 footprint 代价），固定 A+C 正例、几何与原生语义，仅改变负例在损失中的含义。

新增可选 `--negative-likelihood`，hard 默认保持原实现。三种对照：

- weighted：负 BCE 与 overlap 中的负像素权重均固定减半。
- contaminated：令负像素 BCE 为 e，使用 `-log(0.5 + 0.5 exp(-e))`；在 overlap 中使用分离梯度的有效权重 `exp(-e)/(1+exp(-e))`。冲突负例惩罚有界，近似把“不完整范围造成的未知”作为无信息分量处理。
- unknown：撤去负像素的 BCE 与 overlap 项，仅保留正监督和原有 footprint 约束。

这三组均维持正 BCE 系数0.5、原有正目标与 overlap 形式。未增加教师调用，未用目标 GT 设定参数，没有按查询选规则。

0.5 是统一假设，不是估计出的教师正确率。contaminated 的有效权重依赖当前模型预测，存在自我确认风险；overlap 的分离权重是鲁棒优化启发式，不是完整的联合概率模型。unknown 仍继承含负例的初始化，也保留紧致性先验，准确说是“移除当前损失中的负监督”，不是从未使用任何负证据。

## 分责结果

后验 precision/recall 分解使用冻结评估输出，不参与训练或挑选参数：

- Waldo：hard IoU68.13%，自适应70.85%，移除负损失73.57%。Recall从69.2%升到72.5%/75.3%，precision从97.7%小降到96.8%/96.9%。这里存在被负监督压制的正确目标范围。
- sake cup：hard IoU69.29%，自适应66.07%，移除负损失59.82%。Precision从80.9%降到76.5%/68.2%，recall仅71.1%升到71.5%/72.2%。放松负损失主要增加误检。
- handle：移除负损失使recall85.5→91.6%，但precision78.8→68.8%，IoU69.98→64.97%。补全与错误扩张同时发生。
- pour-over：移除负损失使recall92.0→98.9%，precision97.3→86.9%。单纯提高覆盖不能替代范围准确性。
- spatula：三种规则几乎无变化，IoU约42%；onion与ladle仍为0。当前负损失强度不是这些失败的充分解释。

这不是“所有负例都错了”，也不是“统一减权即可解决”。本轮证明了当前损失中的负证据对不同目标承担不同作用：既压制部分正确范围，也阻止部分错误范围。它没有识别每个具体负像素的真实性，更没有证明源身份是唯一瓶颈。

## 决策

保持 next98，不拼接 Waldo 等局部收益，不继续用负损失系数扫参。可选实现留作机制对照。

下一步需要的是新的、可检验的排除依据：将局部正证据与对象外部证据分开，依靠源侧独立实例对应及整体/部件关系判定何处可排除，而非让当前模型自己决定哪些冲突标签可信。仍沿用固定优化测度做比较，先验证范围证据质量再比较最终结果。若无法获得这样的证据，应明确记录能力缺口，而不是继续增加标量损失项。

本轮没有其他benchmark的新实验，也没有四query泛化、可学习特征场或SOTA提升结论。
