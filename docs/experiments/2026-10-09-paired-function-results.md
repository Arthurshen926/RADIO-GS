# 关系函数保持与查询失效：两组完整五任务对照

2026-10-09。分支 `codex/query-preserving-gaussian-field`。两组各 30 份场导出、五项评分与全部诊断已完成；没有未结束的实验，没有晋升默认模型。

本轮将研究从“保护特征、拟合部分标签”推进到可独立重放的关系函数参照，但尚未恢复完整性能。最明确的缺陷是当前支持关联在全部 NVOS 提示上完全失活，在部分正确 UQIS 支持上也不接通证据；扩大目标覆盖无法单独修复这个问题。新增证据还同时增加了误选。不能据此否定理想架构，也不能把数值函数保持称为完整 v10 能力迁移。

## 实现与受控条件

Hard 在同一 Gaussian 场中显式保存稀疏正证据、可靠排除、物理尺度与视图组，以受保护的 rendered member 为固定先验。所有输入及正负支持都调用同一成员函数；身份、实例／并集／类别读出保持原有类型语义。运行时只需要导出场、当前合法输入和共享查询编码器，没有源 RGB、掩码、相机库或标注 v10 成员模型。

对于带权支持，Hard 用硬观测正坐标 A 求关联，在物理尺度相容且支持质量至少 .5 的区域内按视图归一化，得到系数 a；候选正／排除质量为 P=B+ a、N=B- a。成员概率使用 `(sigmoid(base_logit)+P)/(1+P+N)`，无证据时保持原 logit。这是固定的有限证据组合，尚不是经过校准的概率推断。

Soft 保留 A 的每个稀疏坐标，唯一改变目标 B+/B-：弱观测按 `min(1, peak_pixel_responsibility/.1)` 提供分数证据。没有额外帧、教师、标签、训练、阈值搜索或任务专用选择。该对照在 Hard 的任何 benchmark 推理之前，由源覆盖检查确定，决定凭据保存在第一组的 `diagnostics/soft_coverage_decision.json`。新增规则没有解决弱／未知查询支持被稀释的问题，特意保持关联函数不变以隔离目标覆盖。

两组均使用同一 534 个有效训练视图、25,451 个部分源区域。**后续清单审计更正：** fern 的原始特征训练清单本来就是 12 个视图，其他29个场各18个；两组关系编译没有额外丢弃训练视图。此前将少六个视图归因于无有效 episode 是错误解释，534 个视图、源区域数和实验结果不变。参见后续 `mixture_functions_v1/diagnostics/reference_budgets.json` 的逐场清单与哈希。每组独立执行 1,068 次源像素组合再投影与场内坐标求值的比较，其中 981 次非空。误差上限分别为 8.5831e-6 和 9.5367e-6，均通过预设 1e-5。

## 实际查询归因

**NVOS：新功能没有接通到合法输入。** 八组提示的正、负支持均未通过关联多数门槛。正支持最大关联为 .1187–.4422，负支持为 .0257–.4100，全部小于 .5；在尺度过滤之前就已没有可用区域。因此增加目标 B 的覆盖也完全不改变这些查询的 P/N。全部八组的成员分数、选集、响应和 retained response 与 Render 逐值相同；用合法当前提示重放预测的最大误差为零。这个失活是已验证机制，不能写成“关系模块起作用但没有学好”。

这里尚不能把所有失活都唯一归咎于 unknown 稀释：硬几何支持门槛、部分区域覆盖、多射线平均及多数接受规则共同决定关联。必须分开未知质量与可靠反对质量，再用同一输入检验源函数与场函数。直接把门槛调低直到八组都非零会引入未验证的证据，不能作为修复验收。

**UQIS：潜在覆盖、实际激活与正确决策并不等价。** 全部 67 个 3D 点查询均审计，其中固定的 59 个支持正确。两组只有 40/59 关联到至少一个视图；包括失活查询在内平均仅 1.339 个视图。Hard→Soft 保持所有实际点查询的关联系数逐值一致；从保存的 Render 概率和新 P/N 重放预测，最大误差约 1e-6。

**范围语义仍有缺口。** Soft 对正确目标约 10.04% 的已观测部分给出占优排除，而另外约 5.20% 的目标部分虽然正证据占优仍被漏选。源 SAM 的部分、同尺度关系不自动等价于完整物理实例；弱质量和固定先验组合也不等价于可用决策。单一 P/N 比例尚未实现 v10 的共同可见、any/all-mask 和粒度分歧功能，更未复现它的完整实例监督。

## 由证据确定的下一步

1. 优先重设共同支持关联函数。显式表达当前支持对每个合法观测的正、排除、未知质量，保留多射线不确定性及观测可信度，避免未知质量在多数规则中被当成反对证据。验收必须同时覆盖实际 NVOS 正负输入、UQIS 正确点、推断支持与源函数独立重放；不能只在源单点／同尺度伪查询上通过。
2. 保留共同可见、any/all-mask 与粒度分歧后再决定范围，将证据是否存在、证据是否可靠、是否同一完整实例分开。当前单次 P/N 组合不能区分这些情形。完整实例能力所需监督与源帧条件须明列，与部分 SAM 关系能力分别对照。
3. 继续补文字与局部图像的原始查询函数参照。保持 native 分数与融合均值向量不够；应验证真实文字排序、局部 patch 双向对应及其与候选范围的交互。现有 v10 的这些功能仍未被完整迁移。
4. 在这些功能可用后，才用 scene-specific 学习表示保持其条件输出，再检验紧凑化。当前高容量参照只覆盖部分关系，不是已经完成的同口径完整基线 B；论文创新与性能恢复都仍须逐项证实。
