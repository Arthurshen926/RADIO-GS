# 同输出合约的源侧融合排查与区域均值一致性控制

本报告只使用训练源图、保留源视角及其教师证据。没有读取benchmark目标图像、目标标注或目标指标，也没有据此替换任何当前主线。

## 先修正上一轮诊断的读回算子

`scripts/audits/audit_native_residual_fusion_next30.py:40` 使用 `episodes.region_probability` 聚合地图。该量在 `compile_three_query_episodes.py:40` 定义为“给定某元素可见时，它属于区域的比例”，已经除去了各元素的可见贡献质量。再次沿元素归一化，并不等于实际像素渲染后在区域内平均：贡献0.99和0.01的两个元素，可能都被当成完整区域票。

新增 `radio_gs/training/source_region_readback.py` 直接构造实际渲染的伴随权重：先逐像素除以已观测元素贡献质量，使用与原生排序评估一致的已观测贡献比例大于0.5的有效域，再在区域内取像素均值。两个单测覆盖逐像素正向等价性、未知域排除及上述错误反例。旧诊断封存文件保留，新结果另存。

12张LERF/ScanNet地图全部完成纠正。旧算子的结果逐项重现到1e−6以内；正确算子下，上一轮新增原生残差仍有7/12张地图文本响应MSE升高，因此原生区域保真不保证地图读回保真的总体结论仍成立。各场景具体幅度不能继续引用错误算子。

12图等权平均文本教师Top-1一致率：

| 对照 | 原64维 | 上轮正交残差 |
|---|---:|---:|
| 旧条件概率池化诊断 | 37.24% | 37.62% |
| 正确逐像素渲染再区域平均 | 38.65% | 38.93% |

这不是最终查询准确率。区域裁剪教师的全局描述子并非逐像素真值，不能将不一致全部解释为代码错误。

## 用相同保留视角、区域和像素域拆分损失

以下四阶段都使用同一保留源视角、同一批文本/图像查询、同一区域及共同可见像素。区域无支持时显式列出并排除，不填造响应。单视角诊断读取保留图自身的教师证据，仅用于责任分离，不能作为可部署地图。

| 12图文本教师Top-1一致率 | 原64维 | 上轮正交残差 |
|---|---:|---:|
| 独立区域原生投影 | 78.66% | 83.56% |
| 仅在2D内平均重叠区域证据 | 56.67% | 58.46% |
| 同视角几何写入再渲染 | 54.23% | 55.84% |
| 训练视角地图向保留视角渲染 | 38.65% | 38.93% |

在这个诊断里，2D重叠混合已经有较大损失，单视角几何往返造成的额外均值损失较小；跨视角读回仍有较大额外损失。后者仍混合了几何对应、不同视角教师响应变化与范围变化，不能直接认定全由语义融合导致，更不能据此宣布几何正确。

完整12图逐场景结果、可见支持数和旧结果重现检查位于 `output/matched_source_fusion_next31/summary.json`。

## 哪些修复方向有实证支持

全部源视角仅出现1对完全相同的低分辨率mask，且描述子并不相同；没有发现同mask、近乎同描述子的重复票。因此，严格重复证据去重可作为防护，但不是当前大幅性能损失的解释，不应为无实际变化的修复跑benchmark并声称方法提升。

训练视角则存在36,169对大范围包含小范围的区域，31,051对的DINO余弦相似度高于0.8。其中5,564对SigLIP余弦低于0.8，16,770对的固定文本银行Top-1不同。例如waldo源帧30的2433像素大区域包含8像素小区域，DINO相似度0.838，但SigLIP相似度0.560，教师文本分别倾向cabinet和fork。这些是教师预测，未经人工确认为真实类别；但足以反驳“结构相似即可视为同一范围”的推断。

相互包含、外观相似与同一对象完整范围是不同关系。把大范围向量写到内部每个小部件，再与小部件向量平均，会混淆它们的语义。面积分层取最大值、重复票清理和单纯DINO图传播都不能自动解决这个问题。

固定规则及反例：`output/matched_source_fusion_next31/contained_compatibility.json`。

## 一个可证伪的方法控制

新增查询无关的“区域均值一致性”源侧校正，先处理2D重叠证据，再使用原来的几何算子融合。它保持单个64维语义向量、原生查询基底和观测支持，没有为查询新建地图，也没有增加面积分层后的最大值读出。

令M为逐区域归一化的像素平均算子，D为原生教师在原64维基底内的描述子，X0为旧的重叠均值像素场。求解：

`mean_region ||M X − D||² + mean_covered_pixel ||X − X0||²`。

两个目标系数均固定为1，闭式解中的正则项因此固定为 `R / Pcovered`，不搜索超参数。它尝试使“区域整体的平均特征”接近区域教师，而不是把每个区域教师都强制涂满其内部每个位置。无重叠区域严格不变；整体与部件之间允许明确的拟合折中，不保证每个区域都改善。像素更新的均方大小受初始区域拟合损失约束，带符号坐标不做静默裁剪，必须报告最大范数和最大变化。

固定pilot为figurines和ScanNet scene0000_00。两者必须各自满足：保留源区域文本和图像响应MSE均降低至少1%，中心化MSE不升、教师Top-1下降不超过1个百分点、观测支持不变。均通过才扩展12图；任一失败就保留step zero，不通过目标benchmark选新旧方法。即使通过，也需要重拟合所有依赖头后才能评价最终召回。

实现和固定计划分别为 `radio_gs/training/region_mean_consistent_evidence.py` 与 `output/region_mean_fusion_next31/registration.json`。无重叠不变、整体/部件折中、旋转及区域顺序等变、近重复稳定性和空区域拒绝五项单测，与读回两项单测全部通过。

本地LUDVIG复现记录说明，其贡献加权融合和几何/外观关系可供借鉴；但其发布NVOS轨道在查询时对多视角RGB调用SAM。这种输入权限不能直接移植后当作当前地图查询轨道的同协议增益。当前方法控制只复用源侧渲染算子，既不是LUDVIG复现，也不借用其在线目标图信息。

## 两场景固定pilot结论：拒绝，保留step zero

两个源侧pilot均已完成，没有启动benchmark评估，也没有扩大到12图或更改正则参数。

| 源侧保留视角指标变化 | figurines | ScanNet 0000 |
|---|---:|---:|
| 区域文本响应MSE | −0.19% | −2.98% |
| 区域图像响应MSE | −1.15% | −3.20% |
| 文本教师Top-1一致率 | 不变 | +3.31pp |
| 图像教师Top-1一致率 | +1.39pp | −2.65pp |
| 准入结果 | 文本MSE改善不足1%，拒绝 | 图像Top-1下降超过1pp，拒绝 |

figurines的像素边界响应误差还增加：文本+3.55%、图像+2.20%。ScanNet 0000边界误差略降，但图像区域身份排序退化。区域均值改善与实际像素定位、身份排序并不等价，不能仅凭均值损失下降继续部署。

两个场景的旧融合重现最大误差均为4.17e−7；观测元素域和基底逐值保持。候选最大元素范数分别为1.206和1.120，最大元素变化为0.671和0.523，没有静默裁剪坐标或挪用旧校准头。`output/region_mean_fusion_next31/{key}/report.json` 保存完整源拟合、区域与像素边界结果及输入hash。

这个负结果收紧了后续方法设计：不能将区域全局描述子的均值一致性直接当作像素语义正确性。需要同时保护不同粒度的查询身份与范围，并在真实渲染域检验实际读出。单纯对均值做更强反演、扫正则权重或放宽源侧门槛都不是本轮允许的后续步骤。当前主线及所有最终benchmark分数不变。
