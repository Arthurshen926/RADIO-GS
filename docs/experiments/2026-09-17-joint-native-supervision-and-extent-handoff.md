# 联合原生召回监督与范围读取衔接

本轮把“仅受图像监督的残差却用于文本”的目标错位分离出来。保持完整场、原生锚、几何、编码器和原范围头不变，只训练同一个全局native残差；固定相对范数上界0.25，随机种子42，240步。文本使用源caption短语对应的SAM掩码并集，图像使用同一源证据的原生crop描述符。损失是元素sigmoid后经精确源贡献渲染的balanced BCE+Dice，不是区域均值特征重建。

文本训练明确监督**原生fallback**，不是概念硬接管头。背景是SAM伪标签，不是独立对象真值。源末视角只从新残差训练中留出，旧场和校准已经见过该视角。按两个模态源IoU都不低于零残差，再最大化两者均值选择检查点，不用此次benchmark标签选步数。figurines选择150步，ramen选择240步。

## 源验证并不代表最终泛化

| 场景 | text源IoU前→后 | image源IoU前→后 |
|---|---:|---:|
| figurines | 26.91→41.36 | 48.70→50.25 |
| ramen | 27.24→47.70 | 30.61→35.29 |

所有原参数逐张量相同；只新增全局残差头。范数约束保护的是原生向量的有限偏转，不保证所有查询排序或所有类别保留。

## 同一全文本队列的分层结果

单位IoU/AP百分比；figurines 56、ramen 71个标注观测，均为反复使用的开发集。

| 路径 | figurines | ramen |
|---|---:|---:|
| 保留完整主线 | 43.52 / 62.91 | 28.42 / 42.81 |
| 原场仅native fallback | 33.60 / 58.48 | 8.20 / 30.97 |
| 联合残差仅native fallback | 35.32 / 58.72 | 22.72 / 41.06 |
| 联合残差 + 原范围读出/校准 | 42.35 / 61.06 | 24.51 / 44.54 |
| 联合残差 + 源侧精确重校准 + 原范围读出 | 41.36 / 60.46 | 28.57 / 45.64 |
| 联合残差 + 重校准 + 统一有界范围强度0 | 35.24 / 58.69 | 21.86 / 41.07 |
| 联合残差 + 重校准 + 统一有界范围强度2 | 37.03 / 59.24 | 22.66 / 45.36 |

强度0/2沿用此前预定控制，不扫描本轮GT最佳强度。重校准仍只用源grounded-text和实际sigmoid-before-raster顺序；这些是14个源概念，不等于所有caption短语都参与校准。

结论：实际文本/图像监督能够改善原生空间的可用性，尤其ramen；但共同源验证进步仍不足以保证完整系统共同进步。重新校准消除了ramen相当一部分衔接损失，却没有解决figurines的回退。统一有界读取也未超过保留完整控制。**不晋升共享残差，也不将取消范围头当作解决方案。**

一个明确失败例：联合残差native路径的ramen chopsticks IoU为17.60%，进入旧完整范围路径后变成0；figurines miffy为20.39%→0。它们用于定位读出损失，不能根据这些GT例子设置逐类特殊规则。反过来，范围头也改善了不少类别，所以不能只保留这些失败例而忽略总体收益。

## 图像与点提示

联合残差的参考image IoU/AP为figurines38.62/57.58、ramen18.43/46.76；不及前一轮独立image监督候选39.41/57.66、19.91/47.68。prompt逐观测保持原值。源侧text重校准仅改text阈值头，不影响这两条路径；有界范围强度2则属于另一个image路径，未在此表混算。

下一项核心约束仍是：源伪标签范围与真实细粒度目标之间的差距，以及原生语义变化后范围选择/校准的有效性。此次把“原生空间不可改善”“只需图像监督即可兼顾文本”“只需重校准”“只需取消接管”四种解释分别做了实测，结果不能支持其中任何一种简单替代。
