# 图像查询接入结构范围：有界读出、校准对照与失败定位

本轮将已有结构范围真正接入图像查询，完成两场景源验证、冷启动和真实参考查询评估。**出现局部收益，但未通过两场景一致改善的验收，保留为显式实验候选。** 同时完成并拒绝一个图像条件阈值回归控制，排除了“压缩后所有查询都不可能达到现有阈值”的解释。没有新增教师、修改几何或重新训练元素特征，原完整主线没有覆盖。

## 1. 完整系统中的实际断点

此前 image 输出只经过固定 native64 和原生解码器，最终做一个全场共享的标量校准；源区域范围头和结构32虽然存在，却没有被这条读取路径使用。只修对应边、重训相同的受保护 native 路径，不会自动让图像召回利用结构。

当前文本已使用范围读取，但它包含文本路由和概念接受条件；不能把这些条件直接套到图像编码向量上。此次复用已学到的**范围候选库**，用查询在原生场中的正支持选择范围，绕开文本特有的模板路由，并限制结构干预幅度。

新增显式配置 `bounded_extent={'image': strength}`，默认关闭，旧 checkpoint 加载行为不变。这个实现只有图像入口；没有声称文本/图像已拥有完全相同的最终算法。

## 2. 已实现的有界结构读出

对图像查询 q，先计算原生 logit L。以已观测元素中 L>0 的集合与各候选范围计算全场 IoU，选择最高重叠候选，得到重叠质量 u 和其逐元素范围概率 p。输出：

`L_new = L + strength * u * (2 * clamp(p, 0, 1) - 1)`

这里 u∈[0,1]，strength∈[0,2]：

- 单元素 logit 改变量最多为 strength*u；差值大于两倍该上界的原生元素对不会逆序。
- **不是全局排序不变保证**。低间隔元素允许由结构调整顺序，必须测最终 AP。
- 原生支持为空或没有重叠时 u=0，准确回退；不会强行召回一个候选。
- 范围选择始终基于完整元素域，不能随输出 rows 或 query batch 改变。
- 全部原参数保持逐位一致，无新 per-element 特征；只复用原全局范围头，加一个部署配置标量。
- 结构路径对范围头和结构后缀的梯度在测试中非零；**本轮没有做结构参数训练**，不能把梯度可达性解释为已学到新增能力。

强度在查看新真实结果之前由源验证选出：候选 0、0.5、1、2，要求两场景源 IoU/AP 均不低于零修正，然后最大化等场景平均源 AP，平分时取较小值。使用上一轮重编译的源对应，其验证图未变化；分别只有 8/4 个跨视角图像任务，是小样本教师伪标签验证。

| 源验证，IoU/AP，% | 原读出 | strength=2 |
|---|---:|---:|
| figurines | 43.64 / 67.39 | 46.17 / 68.73 |
| ramen | 57.35 / 67.94 | 59.56 / 72.43 |

两场景共同选择 strength=2，没有按 benchmark 类别或场景挑选不同强度。

## 3. 真实参考图像召回结果

与父模型在同一进程、同一查询和渲染协议下对照。图像输入仅为授权参考图的 masked crop；目标 RGB 不参与查询，查询执行禁止读取训练缓存。沿用类别并集开发协议，不是官方实例/点提示测试。

| 图像指标，% | 父模型 | 有界结构候选 |
|---|---:|---:|
| figurines IoU（35个观测） | 33.12 | **35.41** |
| figurines AP | 54.52 | **55.63** |
| ramen IoU（57个观测） | **13.81** | 13.56 |
| ramen AP | 34.21 | **34.45** |

这是一次有收益也有代价的改进：figurines IoU +2.29 个百分点；ramen AP 略升但 IoU -0.25 个百分点。不能描述成整体问题已解决，也不按场景拼接最优开关。

逐类可见范围信息确实被使用：figurines rubics cube IoU 27.55→50.47，porcelain hand 39.47→46.19；ramen plate 45.63→54.77，spoon 10.30→21.91。但 ramen wavy noodles 11.78→0，figurines pirate hat 4.22→0。边界干预有界不等于候选范围正确，语义选择错误仍能伤害低间隔目标。

本轮三类参考查询都实际执行。**所有逐观测 text/prompt 记录完全相同**，不只是总体均值相同。父模型原生参数和几何也逐位/哈希一致。这里只评估了参考任务对应的 text 子集，未把它与全文本 56/71 个观测混算。

候选路径：

`preserved_source_inventory_20260916/{scene}/bounded_image_extent96/field.pt`

保留为 opt-in 控制，不替换 `exact_render_query_threshold96`。

## 4. 继续定位：普通 query 条件校准并不足够

ramen 的 nori 参考图像 AP 为 85.64%，IoU 却为 0，说明这一类首先要区分排序失败与判定范围失败。为此做了第二个源侧控制：

- 使用上一轮 scope-consistent 的训练跨视角正对应，不使用 benchmark 目标标签。
- 对每个源 image query 汇集明确匹配的源区域：概率>.7 为正，<.1 且可见为该区域范围外证据；跨视角矛盾行保持未知，未检测视角不贡献负例。这依赖教师区域范围完整性的假设，不是物理 GT。
- 固定原生 cosine 和温度，求正负均衡的每 query 阈值；用归一化原生 image embedding 做 ridge 回归。
- 按 query 来源视角分组验证，选择惩罚系数。这个留出不独立隔离几何和其他任务的目标证据，因此不是独立泛化评估。

figurines / ramen 拟合 96 / 194 个源 query，阈值范围分别为 0.670–0.925 / 0.767–0.936。

| 图像阈值回归控制，IoU/AP，% | 父模型 | 条件阈值 |
|---|---:|---:|
| figurines | 33.12 / 54.52 | **24.10 / 49.13** |
| ramen | 13.81 / 34.21 | **17.96 / 33.37** |

两场景未共同改善，**该控制拒绝**，没有把它与有界结构候选事后拼接。阈值保持逐元素的 query 内排序，但 sigmoid 在混合渲染之前应用，所以最终像素 AP 并不保证不变；此处的 AP 改变不能误报成元素语义向量发生更新。

## 5. 排除投影上界解释，明确剩余缺口

直接编码同一批授权参考 crop，不打开其他目标掩码，检查原生 query 的64维投影范数。零偏置正交解码器 D 下，`||D^T normalize(q)||` 是该 query 可达到的余弦上界。

所有已检查参考查询的上界都高于原固定阈值；因此当前空召回**不能统一归咎于投影上界使阈值不可能达到**。这也不证明压缩完全无损。

ramen 的具体诊断：

| query | 投影上界 | 地图已观测元素最高 cosine | 原阈值 | 超阈值元素数 |
|---|---:|---:|---:|---:|
| nori | 0.9423 | 0.8968 | 0.8672 | **7** |
| corn | 0.9348 | 0.8461 | 0.8672 | **0** |
| kamaboko | 0.9047 | 0.8585 | 0.8672 | **0** |
| wavy noodles | 0.9590 | 0.9079 | 0.8672 | 3,537 |

nori 是高排序但阈值正支持极稀疏；corn/kamaboko 在当前地图上没有超阈值元素，有界结构读取按约定回退。noodles 不是缺少正支持，却被范围修正伤害。这些情况需要分别处理，不能继续统一调温度、扩大结构修正或归咎于几何。

接下来仍应聚焦两项：

1. **图像源监督与真实查询的范围/分数分布一致性**：核验高 AP 低 IoU 的对象范围，建立可泛化的判定证据；普通源 embedding→阈值回归已失败，不继续无依据扫参。
2. **错误范围选择的拒绝与粒度一致性**：接入结构已有可测收益，但不能仅凭原生正支持重叠就信任整个范围。与新对应监督配套验证，而不是扩大残差让结构覆盖原生身份。

新一致性监督下的完整结构重训、全文本范围逻辑修复、几何余项及 ScanNet OVS/NVOS 联合验收仍未完成。此次不增加 hash 或教师。
