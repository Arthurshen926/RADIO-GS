# NVOS N12–N14：完整参考响应与源端采纳

日期：2026-10-18。工作树 `/root/RADIO-GS-query-field`，分支
`codex/tmm-query-response`。目标仍为提高完整 NVOS 性能，当前最佳固定方案为 **93.1730 三维 IoU / 98.9451 AP**；尚不能认定同协议 SOTA。

## 问题与方法决策

N11 的实例约束保留了 flower 的范围收益，但把 orchids 的大量候选区域拒绝；
fern/trex 的正向扩张仍引入误报。固定几何提供的是可见身份证据，不自动证明
未知部件的归属。本轮先测试更直接的查询响应改变：在参考图像上用原始正负
涂画补全响应，再通过同一冻结实例记忆模型传到目标视角。

N12（ADR0035）比较三个参考响应：原始 v10 掩码；冻结 DINOv2 的参考到自身
正负亲和响应，经 SAM3 解码；同一响应再加入每种符号 16 个确定性空间采样
涂画点，并严格满足全部原始涂画像素。采样点均在真实标注上；硬约束不改动
无标注像素。三者使用相同双帧记忆传播和原生射线三维求解。
源端涂画满足率、响应面积和增删像素是诊断，不是完整物体精度。

N13（ADR0036）在 N12 目标评分前固定，检验是否应仅迁移参考干预造成的变化。
令 b 为静态响应，p/q 为原始／补全参考响应下的同模型记忆预测：

- 主要候选：clip(b + q − p, 0, 1)。
- 固定次要候选：sigmoid(logit(b) + logit(q) − logit(p))；数值裁剪 1e-4。
- q == p 的位置在两种方案下均严格保持 b。

它保留了已有响应并允许有正有负的修正；配对变化不等于正确率上的因果收益。
完整替换结果是匹配对照。N11 是前一候选，不是能够叠加其增益的因果对照。

## 协议与实现检查

完整八任务；N12 的 72 张预测、N13 的 56 张预测分别在各自评分前全部封存。
N13 复用哈希一致的 N12 数组，在父实验预测完成后进行推理，在父实验评分完成
后才允许读取自身 GT。两轮公式均在 N12 目标分数可见前固定。

同一几何、原生 1008×756 射线、120 步 Huber 拟合、abs(2p−1) 置信度、原始
高斯观察域和初始化、0.5 读出。独立整数混淆计数，原 GT 与 LUDVIG GT 分别
评分，报告 IoU/AP 及源教师残差。原 v10 为本方法；原始负涂画、DINOv2 和
目标 RGB 是明确披露的扩展输入。其他四个 benchmark 的 23 个 job 仍是
哈希核验的既有结果，本轮不称为重新推理或通用机制闭环。

完整登记测试 180 项通过。新增测试验证真实涂画采样、未知区域不被硬约束
覆盖，以及无参考干预时响应严格不变、双向修正能力。

因此不将残差迁移保留为主方案；无干预严格保持原响应这个数学性质，并不等于

N14（ADR0037）在完整 N12 结果后固定：若语义参考掩码满足全部原始涂画，保留
它，否则使用约束修正；独立质量对照选择 SAM 解码时预测的源图掩码质量较高
者。并列时固定保留语义候选。规则不读取场景名或目标成绩。每个选中结果
重新调用模型，核验其与 N12 对应候选的连续数组哈希，再实际三维拟合并评分。
本轮是已打开开发集上的方法调整，不是独立最终测试。

## 收敛后的方案与剩余问题

当前较强方案是：原始正负查询 → 参考语义范围候选与约束候选 → 源端选择完整
响应 → 冻结双帧记忆传递实例 → 原生射线三维求解与重渲染。保持原教师权重、
特征场与几何，不再叠加已退化的残差模块。质量策略只是当前最佳固定开发配方；
约束主候选及全部负对照保留，未切换全五任务默认方法。

orchids 的主要范围缺失已经恢复到 95.6011；flower 达到 96.7139，horns-left
恢复到 94.8079。剩余重点为 fern／trex 的内部误报、细结构与跨视角一致性：
质量方案的精确率分别约 87.58／91.00，召回率约 94.33／94.63。其图像 IoU
均值 93.4971，实际三维 93.1730，损失 0.3241 点；trex 单任务损失 0.6286 点。
继续扩大所有前景或搜索读出阈值不是当前优先方向。

三个新方案族对原源教师的残差均在全部八任务上升。更完整的新证据可能与旧
源掩码冲突，现有结果不能证明一个查询全局一致的场。下一步应在冻结参考补全
配方后，比较原始／补全参考在所有源视图的完整响应及其三维融合，分别测量
内部背景排除、细结构和源／目标视角一致性，不把更多源拟合本身当作成功。

源图质量对照在 horns-center 仍有少量其他实例误选；其高均值不等于严格满足
所有源涂画约束。原 GT 与 LUDVIG GT 都确认提升，但 VCAR 等论文的任务数、
提示、帧与读出协议不同，不能将接近的数字直接写成同协议 SOTA。

## 完成核验

N12/N13/N14 分别封存 72/56/56 张输出后评分；N14 全部选中图像响应与 N12
对应候选逐位一致，实际三维混淆计数亦一致。两种 GT 均独立整数复核；原生
算子与渲染器最大误差低于 1e-4；未观察元素保持不变。180 项登记测试通过。
其他四 benchmark 的 23 个 job 是哈希核验的未改动参考，不是本轮新推理。

结果和全任务图：`nvos_reference_completion_feedback.json`、
`nvos_reference_delta_feedback.json`，以及各自的 `*_spatial_v1/errors.png`。
N13 反馈检查器曾因新增空间诊断块的位置错误在生成反馈时抛出异常，已修复；
未改变任何推理、指标或实验快照，并新增计划／运行／失败状态回归测试。
