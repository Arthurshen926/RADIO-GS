# 选择输出监督：共同改善，但身份瓶颈尚未解决

本轮完成两场同预算损失对照及两个完整源范围遍历周期，实际改动现有范围头，未新增接管模块。并修复另外两场完整流水线暴露的显存问题。结果允许保留为候选，**尚不替换历史保留模型，也不宣布专家清单完成**。

## 同一输出合约的完整开发结果

全文本为既有 480 宽全场概率协议；选择集合为原尺寸、先选择元素再独立渲染、PNG >10 的本地 polygon 诊断。两列分母/输出合约分别固定，不互相混算；未验证公开 JPEG GT 等价。

| 版本 | figurines 全文本 / 选择集合 IoU% | ramen 全文本 / 选择集合 IoU% |
|---|---:|---:|
| 历史保留 V1 | 46.20 / 25.45 | 32.97 / 17.64 |
| 完整重建 V2 | 43.81 / 25.55 | 33.47 / 18.27 |
| 原损失继续训练，同预算400步 | 44.90 / 26.11 | 33.54 / 18.23 |
| 加入选择集合损失，400步 | 44.60 / 26.62 | 34.70 / 19.67 |
| 加入选择集合损失，两个完整源范围遍历 | **44.32 / 28.14** | **35.42 / 20.35** |

最后一行相对 V2，选择集合 IoU 增加 **2.58/2.07 个百分点**；相对 V1 增加 2.69/2.71 个百分点。全文本 AP 为 61.04/51.65%，V2 为 60.08/50.87%。所有六个训练控制的 image/prompt 逐观测结果均与 V2 完全一致。V1 的 figurines 全文本和参考图像仍优于新候选，因此不作全任务共同晋升声明。

## 如何修复，以及控制了什么

`train_selected_scope_objective.py` 冻结完整元素场（64原生+32结构）、原生解码器、查询编码、相机与高斯几何，仅训练既有范围 decoder/residual。使用源侧自动 caption/SAM mask，不使用助手审阅标签或 benchmark 标签。

匹配控制共用随机种子、任务顺序、优化器与400步预算。新目标平均原全场可见像素损失与选择集合轮廓损失：后者通过连续 opacity gate 形成可微近似；校验和模型选择使用真实的 >0.5 硬元素选择与 PNG 像素阈值，**没有把软代理指标当成最终输出**。场景内四个源视角仅对新增优化留出，父场/旧头已见过，不能冒充 P4 家族隔离。

源验证在400步时仍持续改善，因此继续完成两个完整源范围遍历，预算为 figurines1766、ramen1044步；最终选中1000/900步。模型选择只看源验证的选择集合 IoU，同时要求原全场源 IoU 不下降，零步模型参与比较。每个精确源 mask 作为一个范围任务，别名轮换；这不是每个别名都遍历两次的声明。

## 没有解决的核心问题

- 袋子案例仍失败：原生文本70.50%，两遍历候选完整输出约0.033%。改进输出监督没有修复错误的查询身份/范围接管。
- 源 mask 仍可能混合完整对象、部件和集合；本轮没有建立可靠物理身份和完整范围真值。
- 独立渲染对可见2D标签的误差，既可能来自选错物体，也可能来自正确物体被遮挡部分重新显露。新损失改善的是明确的开发输出合约，**不能证明完整三维对象质量提高**；因此保持有界候选，不依据这些分数直接删除地图的隐藏表面。
- P4父模型监督隔离、P5同方法完整跨benchmark仍未完成。其他两个 LERF 场景继续完整构建。

## 真正的流水线修复：校准分批，保留所有样本

waldo 在完整场训练后，图像校准将全部元素×查询分数一次展开，已占18.8GB时还请求6GB，24GB卡无法完成。`calibrate_frozen_source_images.py` 改为每批32条查询累积相同直方图，源区域概率存CPU；不删查询、不降低地图密度。

在旧 figurines 校准上核对2808项任务和59359049个已知正负样本：任务身份、每项正负数量及总数完全一致。分批矩阵乘法导致少量直方图边界浮点差异，拟合阈值最大变化8.63e-9；实际使用的 balanced 校准模型所有部署张量**完全一致**。记录于 `paper/artifacts/streaming_calibration_validation_20260918.json`。失败日志和代码快照保留，waldo 已从失败阶段恢复，未重跑已完成训练。

## 跨benchmark准备与验证

ScanNet十场景各32张源RGB及注册相机已封存，依据相机覆盖选择，不读语义标签或既有语言特征；相机转换使用[官方 ScanNet→Blender 转换](https://github.com/yanmin-wu/OpenGaussian/blob/main/scripts/scannet2blender.py)的逆变换。验证实际图像尺寸、旋转与源文件hash，且显式记录原train/test相机重合。这里只完成了可靠输入准备，**不是MoGe重建或ScanNet分数**。

33项相关测试通过。训练/模型/完整评价与历史选择集合结果封存于 `paper/artifacts/selected_scope_objective_controls_20260918.json`。可视化及输出合约边界见[选择输出诊断](2026-09-18-selected-object-output-contract.md)。
