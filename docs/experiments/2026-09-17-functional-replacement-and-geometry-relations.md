后续审计确认：本报告复用的源 SAM 自动区域包含[复数 RoPE 转换错误](2026-09-17-sam3-complex-rope-pipeline-fix.md)。以下分数和失败控制保留为旧教师输入条件下的证据，不能作为修复后教师条件下的架构验收。功能性编码分派修复本身仍成立。

本轮补齐此前仅有基础场替换的 T2，并完成 M1/M3 的一项输出关系控制。两类实验均有实际训练、冷加载和真实开发查询评估；都没有构成应替换保留主线的共同收益。它们不是独立最终 test，也不证明其他教师或几何关系永远无效。

## 功能替换：从源编码到完整范围读出

对 figurines/ramen 的 OpenCLIP ViT-B/16 基础场，重新编码原分辨率 SAM caption mask 裁剪和全部源短语，随后重建完整九阶段范围读取：源查询阈值、概念范围、区域范围、渲染范围残差、候选组合、原生支持选择、源范围门控、范围内原生响应和最终源校准。原始图像、SAM masks、几何 lift、按源短语组织的 groups 可复用；旧 SigLIP descriptors、文本 prototypes 和已学范围头均不复用。

查出并修复一个实际替换遗漏：`fit_grounded_semantic_transfer.py` 的文本模板编码直接调用 SigLIP encoder。现在使用已有的功能编码器分派；不修改任何已被旧工件 SHA 绑定的 encoder 实现。

结论：完整功能替换可运行，SigLIP 不是结构上的强制依赖；当前替换没有总体优势，不晋升。两模型规模、原基础场 crop inventory 精度不同，不将差异解释成严格等预算教师排名。完整执行命令与快照位于 `output/openclip_replacement_20260917/{scene}/functional_complete_execution.json` 和 `functional_complete_sources/`；逐类结果见 `paper/artifacts/{scene}_openclip_complete_{text,reference}_20260917.json`。

## MoGe 输出关系：只强调已知负例，不创造语义标签

在相同冻结几何、scope-consistent 源监督、随机种子和两轮预算下，对比：

1. 原显式结构训练；
2. 已有源语义负例按近邻距离与法线夹角加权；
3. 保留负例权重分布、打乱几何归属；
4. 不追加结构训练的直接读取。

权重为 `1 + 2 exp(-distance/(0.1*object_scale)) * (1-|normal dot|)`，只作用于源 mask 已标负的样本。尺度归一化、法线符号不变；未知法线不提供额外证据。没有把同一平面当作同对象，也没有把曲面当作语义边界。原生64坐标、decoder与几何不更新；查询仍只读取单一元素场。

| 控制 | figurines prompt IoU/AP | ramen prompt IoU/AP |
|---|---:|---:|
| 不追加结构训练 | 42.09 / 58.91 | 23.89 / 48.25 |
| 原显式训练 | 28.83 / 52.94 | 20.73 / 40.73 |
| MoGe 几何关系加权 | 28.87 / 52.94 | 20.72 / 40.72 |
| 打乱几何关系 | 28.85 / 52.97 | 20.73 / 40.75 |

四个候选的实际 text/image 响应指标相同，场导出额外检查原生前缀和 decoder 完全不变。几何关系几乎不优于打乱控制，且不能挽救追加结构训练的退化，故拒绝该方案。源验证也没有改善：直接读出最佳 known-element IoU 为 44.00%/44.88%，关系训练后为38.14%/42.53%。不将源训练损失下降解释成泛化提升。

这完成本阶段“直接几何输出关系能否补足结构能力”的限定对照。此前输出法线重建、encoder1024/refiner32 中间特征重建、hash/MLP、固定特征辅助几何均已有结果；本轮没有获得增加 MoGe 辅助特征的采用依据。稠密边界真值不足，不能声称所有几何边界关系已充分验证。逐查询结果见 `paper/artifacts/{scene}_geometry_relation_reference_20260917.json`。
