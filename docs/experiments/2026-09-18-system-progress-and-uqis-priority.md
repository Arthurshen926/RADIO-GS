# 系统进度与UQIS目标恢复

本轮用户明确最终五项为LERF2D、LERF3D、ScanNet OVS、NVOS和自建ScanNet-UQIS，UQIS覆盖text/image/2D prompt/3D prompt，并要求SOTA复现比较。此明确要求优先于此前CONTEXT中以Available-Nine SPIn-NeRF替代UQIS的范围。历史实验、封存协议与分数不重写；SPIn-NeRF作为补充保留，不能替代UQIS验收。

## 方法进度

最近工作不全是工程修补。工程项包括坐标/尺度/法线、几何身份与缓存绑定、冷查询及重放、失败计分和输出合约；方法项包括共享原生解码匹配、语义/结构坐标隔离、多粒度范围保留、实际query冲突监督、源深度分布透明度校准、隐藏概念后的备用路径监督及有限结构修正。它们有明确算法含义，但不等于都已证明跨数据集泛化。

当前保留了“先几何后语义、单一元素特征场、多类query召回、教师能力约束而非对象库存代替场”的主体。偏离风险在于文本路线依赖SigLIP和源概念/范围头、范围修正链较复杂、主要开发证据来自两个LERF场景；同一完整模型尚未证明四类query和五benchmark。原生前缀受保护并非所有特征都端到端按实际召回任务学习，2D prompt和3D prompt也不能合并成一个prompt数字验收。

## 指标身份

最近常报文本45%左右的IoU来自`evaluate_frozen_field_lerf_labels.py`：完整地图的元素分数投影成2D概率图，对本地LERF polygon GT做固定0.5阈值，通常宽480。属于LERF2D投影开发指标，脚本显式声明不是官方协议，不是三维点/体素真值IoU。

`evaluate_current_selected_lerf.py`先选择地图元素，再独立渲染所选集合，与本地polygon比较。它接近公开LERF 3D对象选择输出顺序，但JPEG GT等价性未核实，仍为诊断。OpenGaussian公开`compute_lerf_iou.py`也按渲染mask计IoU，Acc@0.25/0.5是IoU超过阈值的观测比例；不能和定位峰值命中率、像素准确率混称acc。最近AP则是average precision，不是accuracy。

## 五项当前状态

- LERF2D：旧完整V2四场均完成开发评价，宏IoU41.08%；最新几何/范围修复仅figurines、ramen完整验证，不能拼接另外两场旧分数声称新四场方法。
- LERF3D：四场旧V2所选集合诊断完成，新修复两场完成；官方GT/协议等价核验和同版本公共分数未闭合。无体积真值认证。
- ScanNet OVS：十场源数据准备，一场MoGe/融合试跑；留出覆盖22.83%，放宽部分条件仍有覆盖/自由空间冲突，未批准该几何进入完整语义主线。历史成绩不等于当前方法可用。
- NVOS：早期当前体系的七地图/八任务实际跑通，signed分支78.26/81.36%两种读出控制有对应报告，但不同于最近LERF完整范围模型，仍有参考约束问题。不能填入统一最新版结果表。
- UQIS：找到`/mnt/pool/sqy/3d_understanding/ScanNet-UQIS-10`，本会话列目录被系统拒绝。未读取manifest/schema，不能确认数据质量或完成度。仓库PFIR/PFPR提供部分图像/点召回资产，不等同于用户定义的四query完整UQIS。当前未发现该完整协议及最新模型的联合结果。

## 下一阶段顺序与验收

1. **统一任务/输出合约并恢复UQIS入口**：先核验实际UQIS manifest、四类query、2D/3D真值、单位/相机、允许输入、实例/部件范围及划分。数据访问问题需解决后才能完成实物审计；不伪造新数据集替代现有UQIS。固定按物理场景拆分的dev/test，最终集不用于方法/阈值选择。
2. **优先解决ScanNet几何与投影覆盖**：这同时制约ScanNet OVS和UQIS。分离几何先验质量、注册、融合/遮挡和覆盖缺失，保留全部目标分母。若UQIS允许RGB-D，明确统一的RGB-D轨道与RGB+MoGe轨道，不能只给本方法额外深度或网格权限。
3. **建立最小跨任务共同基线**：先在UQIS独立开发场景上同一张冻结地图跑text/image/2D prompt/3D prompt。统一元素响应与选择输出，分别报告每模态IoU/AP/成功率、跨视角和几何支持、失败率及耗时。对应LERF/NVOS接口使用相同方法版本。先完成小规模闭环，再扩全量。
4. **聚焦一个方法瓶颈**：用源侧可见性和可靠跨视角对应区分范围外正/负/未知证据；范围未覆盖不能自动置负，原生正值不能自动认作真阳性。源监督验收必须同时包含投影概率图和所选集合输出。避免继续为两个LERF场景叠加gate。
5. **公平SOTA比较**：先各方法原协议复现，再接统一UQIS输出与允许输入；固定参考图、prompt数量/轮次、注册信息、是否可读目标RGB、GT映射和计算预算。原生不支持某query时标N/A，若添加公共适配器，单列“原方法+适配器”，不能当原论文原生能力。完整冻结方法后才进入UQIS最终集。

已有证据表明系统有真实进展，但阶段仍是“可复现的研究原型和局部修复”，不是“五benchmark统一高性能系统”。最新几何修复、双向有界修正和正向补充分别保留，不按场景/类别拼接最好结果。
