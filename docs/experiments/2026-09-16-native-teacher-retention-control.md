# 第一核心问题：教师能力没有被充分写入实际场

本轮只检查并干预原生教师能力保留，不增加教师、特征维度、区域种类或训练步数。

## 冻结诊断改变了优先级

对同一份真实源区域、同一部署场和同一原生文本查询，比较：

1. 原生 SigLIP 区域描述子与文本的余弦；
2. 当前训练实际监督的区域均值经共享解码器后的余弦；
3. 逐元素余弦按完整渲染贡献聚合的分数；
4. 逐元素 sigmoid 后聚合的后验。

| 源训练区域指标 | figurines（223 区域） | ramen（218 区域） |
| --- | ---: | ---: |
| 区域重建与原生教师余弦 | 0.1654 | 0.1842 |
| 区域均值分数对教师的平均绝对误差 | 0.0986 | 0.1211 |
| 逐元素分数对教师的平均绝对误差 | 0.0910 | 0.1126 |
| 两种聚合顺序的平均分数差异 | 0.00845 | 0.00893 |
| 区域均值的教师 Top-1 一致率 | 28.25% | 41.74% |
| 逐元素平均的教师 Top-1 一致率 | 27.80% | 41.74% |

验证源区域重建余弦进一步降到 0.0419 / 0.0818。这里的 Top-1 是与原教师的一致率，不是标注准确率；教师本身仍可能错误。

**当前最大的已测缺口发生在区域重建阶段，不能继续假定“教师重建已很好，主要在聚合时丢失”。** 聚合顺序的约束缺口存在，但现有测量不支持优先为它加新模块。误差项不能作为独立因果损失相加或计算归责百分比。

训练实际使用 `0.1 × (1 − cosine)` 的 SigLIP 特征损失；成员监督与其他辅助项同时优化。文本校准 scale 已达到 123 / 164，允许放大很小的余弦差别。总损失降低和有限源任务拟合成功不能替代原生能力保留检查。

## 单变量控制

新增 `--siglip-feature-weight`，默认仍为 0.1，检查有限正值并写入报告。本次唯一干预是设为 1.0；两场景仍分别 2,106 / 3,240 步，保持相同几何、源区域、四教师、初始化、成员监督、一致解码和校准方式。旧模型保持原样。

这用于检验权衡导致的教师保留不足，不预设提高权重一定有效。不将教师描述子硬赋给每个元素，也不把教师分数当作对象完整范围真值。

判定顺序：先检查原生重建与查询排序保留是否改善，再看完整真实文本 AP / IoU 及图像、直接提示跨视角指标。如果只改善教师拟合而损害真实召回，不推广。

证据：`paper/artifacts/{figurines,ramen}_teacher_element_response_20260916.json`、`paper/artifacts/native_retention_weight_protocol_20260916.json`。

## 第一项控制结论：重建改善但召回退化，不推广

提高权重后，训练源区域余弦达到 0.8272 / 0.7898，验证源区域达到 0.5666 / 0.5894。但真实全文本 IoU/AP（%）由 figurines 的 28.23/43.73 降为 19.94/33.67，由 ramen 的 15.50/20.17 降为 9.59/18.13。图像参考查询 IoU 分别从 32.03/18.39 降到 21.66/11.77。

源区域教师 Top-1 一致率仅从 27.80/41.74 提高到 40.36/46.79，远小于重建余弦改善的幅度。因而不能用重建余弦替代原生查询关系保留，不能继续只加大特征损失。图像 query 与对应教师描述子的逐区域余弦均值为 1.0，最小约 0.99999976，排除了这一位置明显的索引或原生编码空间错配。

## 第二项控制：约束实际查询响应

保持 weight1 控制的其他配置，只增加源原生查询响应约束。查询集合为既有源文本词表与训练源区域图像编码，不使用真实评估 query 或目标 RGB/标注。监督对象为区域内实际逐元素余弦的加权平均，权重等于既有像素贡献、观察支持归一化和区域平均的组合；不是将教师向量复制到每个元素。

损失为区域原生余弦 MSE 加 temperature² × KL（temperature 0.07），权重 10。它不通过可学习校准，因此不能单靠调整 sigmoid 斜率满足；温度平方避免将 KL 数值尺度与余弦 MSE 混淆。本次固定该配置作机制控制，不按开发标签搜索权重。该约束仍是教师关系保留，不把教师分数当作可靠对象 membership 真值。

`region_element_weights` 与实际像素→区域聚合的等价检查通过；损失对 latent/decoder 的梯度接通且教师/query 停止梯度。两项新测试加已有相关测试共 54 项不同测试通过。

第二项协议初始文件的 baseline 名称由脚本替换误写成 candidate，自变量描述和实际训练 CLI 正确；原文件保留，`native_response_retention_protocol_corrected_20260916.json` 明确纠正为 weight1 基线，不改变训练或评估参数。

## 第二项结果与最终结论

| 场景 / 方案 | 源区域重建余弦 | 全文本文本 IoU / AP | 参考图像 IoU | 直接提示 IoU |
| --- | ---: | ---: | ---: | ---: |
| figurines 原一致解码 | 0.165 | 28.23 / 43.73 | 32.03 | 26.81 |
| figurines 提高重建权重 | 0.827 | 19.94 / 33.67 | 21.66 | 22.56 |
| figurines 再加实际响应约束 | 0.852 | 21.39 / 35.73 | 0.15 | 22.61 |
| ramen 原一致解码 | 0.184 | 15.50 / 20.17 | 18.39 | 19.76 |
| ramen 提高重建权重 | 0.790 | 9.59 / 18.13 | 11.77 | 20.98 |
| ramen 再加实际响应约束 | 0.921 | 10.78 / 23.00 | 7.00 | 22.82 |

IoU/AP 单位 %；全文本与参考队列不同，不能混用分母。本轮四个新训练均完成相同预算和源覆盖检查，两个候选均未通过联合质量门槛，默认参数和旧场不变。

实际响应约束将 ramen 源文本余弦误差从 0.1126 降至 0.0646，且聚合顺序差异降至 0.0012；但源教师文本 Top-1 一致率仍仅 45.87%，真实跨视角图像下降。figurines 的文本教师 Top-1 一致率反而降至 21.97%。该混合原生文本/图像查询 bank 的平均误差不是充分的语义判别指标，候选不能推广。

校准失配也被具体量化：图像元素余弦判为正的门槛 `-bias/scale` 从 0.0983/0.0954 提高到 0.8516/0.8871。源图像 query 与训练教师描述子是相同编码，自视角源任务也包含此类成对输入；真实参考裁剪分布不同。该变化能解释大量阈值漏检，但不能解释全部泛化问题，因为 figurines 图像 AP 也从 50.44% 降到 38.89%。不能将这轮失败简单归咎于阈值或几何。

目前最稳妥的定位：原始场确实缺少原生能力保留；单独补强通用描述子余弦、或不区分模态地匹配源查询平均响应，仍不能保证真实语义判别和查询分布泛化。第一核心问题未解决。下一项应固定其余条件，分开检查文本/图像响应与源自视角/跨视角查询分布，首先检验源自视角同编码监督是否导致图像读出过拟合；不继续盲目增加损失权重，也不扩展几何和 benchmark 工作来替代这一项。

验证：54 项不同的相关测试通过，脚本编译和差异格式检查通过。初版新审计脚本遗漏 mask flatten 导致维度检查失败；修复为与训练一致的 flatten 后重新完成两场景审计，没有生成或使用失败运行的指标。指标来自真实标注开发集，不是独立最终 test。
