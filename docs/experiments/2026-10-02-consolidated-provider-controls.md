# 通用区域证据与源侧校准的收敛结果

2026-10-02。完成两项预先分开的候选、各四场景完整重建/评价。沿用显式Scene/Query入口、冻结几何、完整合法源视图、67文本＋1无标签新文本；没有新增目标真值调参、手工种子或旧查询答案依赖。不是新独立测试集。

## 已落实的接口

- `retrieve_consolidated_seeds.py`：直接检测全源视角为零时，使用本次原生编码，在所有声明源区域内检索top1。不经过历史两视角pair排名，不读取旧查询名单/得分。ramen和kitchen显式包含已存在的小区域补集；其他场景没有该补集，因此小区域覆盖尚未全量统一。
- `track_full_text_sources_next79.py --scene-input --queries --seed-manifest`：从本次自动种子跟踪全部声明源图。旧研究入口保留，新分支不读取next44检测/next54field/历史query编码。
- `run_consolidated_query.py --regional-fallback`：接入上述提供器，全部query重新求解；缺检测这一选择由本次源证据决定，不是按query名称或GT成绩选择。
- `calibrate_consolidated_response.py`与`--source-calibration`：独立拟合每查询一个logit偏置，240步或足够覆盖训练源视角；每五个源视角留一个不参与拟合，只在留出源视角平衡BCE降低时采用。既有集合完全不变。

原生top1是身份假设，原始cosine只是沿用已有种子相对权重，不是校准置信度。一个实例的跟踪不保证同类所有实例齐全。两候选分别评价，没有按query拼赢家，也没有实际评价两候选联用；不能把两列最好数当作已评价联合模型。

## 具体收益与失败

区域补充修改了9个无直接检测查询的证据，但所有查询都重新求解：

- handle39.59→55.55，waldo68.08→67.13。
- kamaboko53.69→83.08，onion0→7.89，sake46.37→11.16。
- dall-e11.86→53.75。
- ketchup23.16→73.78，ottolenghi34.96→70.15，pour-over34.32→0。

源侧种子可视化 `output/research_consolidation/regional_seed_gallery.jpg`：助手观察清酒杯种子落在瓶状容器上，说明至少这个失败在跟踪和几何求解前已经选错对象。pour-over种子主要覆盖金属漏斗/滤器，需要进一步明确身份及整体/部件范围；这不是独立人工真值。观察不用于本轮生成、参数或结果选择。

原生语义仍能发现鱼板、书名、品牌等直接文本检测遗漏的区域；但相似度第一名没有可靠排除同域错误对象。不能简单把更多检索结果或轨迹并进场景。缺检测补充也不处理原先有检测却错误的pikachu/toy cat；它不是完整身份可靠性方案。

偏置校准在元素上单调，但在渲染前作用于元素概率，非线性变换与多元素混合不交换，因此不保证投影像素的AP不变。本轮观测支持内原概率均未触及logit输入截断上下界。不能把这项校准描述为像素排序完全受保护。

## 本阶段收敛决定

代码和结果不再继续接旧答案链。保留同一入口中的明确模式：基础源增强、可选区域/跟踪补充、可选源侧校准；两候选只做一轮全量验证，不开展逐类阈值搜索。历史高分保留作回退和对照。

尚未解决的核心机制已经收窄：**源证据是否认对了对象，以及证据是否足以代表目标完整范围。** 区域检索、跟踪和同教师留出视角一致性都不能独立证明它们。后续先在固定候选和预算下分离身份错误与范围错误，再选择有独立支持的机制；不继续调整相似度权重或把源教师的低损失解释成目标正确。

NVOS/ScanNet本轮未重建，UQIS继续暂停；四query、紧凑化、公开SOTA、未调参新场景都仍未完成。本轮结束的是接口收敛与两候选完整验证，不是全部科学问题解决。
