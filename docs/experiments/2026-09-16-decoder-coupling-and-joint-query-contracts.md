# 原生匹配一致性修复与 LERF / ScanNet OVS / NVOS 联合查询合约

本轮完成六组同预算训练、真实标注开发评估、原生解码数学一致性验证，以及 ScanNet / NVOS 查询输入实现。**一致性修复在 figurines 有效，在 ramen 未通过质量门槛，不能作为全场景默认方案推广。ScanNet / NVOS 尚未完成新几何、场训练与目标评估，不能把输入接口跑通称为 benchmark 跑通。**

证据索引：`paper/artifacts/decoder_joint_iteration_20260916.json`。其中绑定六个部署场的 SHA256、训练报告和各项评估文件；实验从 9 月 15 日开始，原始文件日期与内容保持不变。本轮没有覆盖旧模型，没有更新冻结几何。

## 1. 修复教师重建与实际查询的代数脱节

旧路径为教师头 `D(z)+b` 重建原生特征，但查询使用独立适配器 `A(q)` 与 `z` 比较。即使教师重建成功，也不保证 `cos(z,A(q))` 保留原生语义关系。仅令 `A=Dᵀ` 仍不够：偏置和非正交解码器带来的范数不可忽略。

新实验选项 `--native-decoder-readout` 使用：

```
text/image score(z,q) = cosine(D z + b, q)
```

SigLIP 教师重建与最终文本、图像检索共享同一个 D、b。实际实现通过 Gram 矩阵计算分母，保留原生查询范数和偏置；近零消减时直接解码对应行。仍只存一套逐元素紧凑特征，部署多存一个全局解码器，不存第二套逐元素教师特征。教师头共享参数在优化器中去重，源任务损失到共享解码器的梯度已经验证。直接提示仍使用既有 DINO + 坐标路径。

这是匹配关系正确性的修复，**不等于 D(z) 已完整保存教师语义**。为旧格式兼容保留的文本/图像适配器在该模式下冻结且不参与读出；旧诊断脚本拒绝把它们当作有效查询适配器。旧的归一化 latent query 优化也明确拒绝该模式的文本/图像请求。

两场景全部 274,805 / 362,198 个元素、79 个源查询，在含 RADIO 与无 RADIO 场上均检查：紧凑公式与显式原生解码的最大余弦误差小于 2.99e-7，最大后验误差小于 3.53e-6。该检查证明数值一致，不衡量语义精度。训练报告旧字段 `siglip_adapter_frozen` 仍表示是否传入旧 CLI 冻结选项；新模式的冻结与实际读出应以 `native_decoder_readout` 和模型实现为准，未改写封存报告。

## 2. 六组同预算实验结果

统一使用已修复的 grounded schema v2、独立源区域查询任务、共享 SigLIP 原生编码器、模态标量校准；未启用此前伤害 ramen 的严格对应过滤。figurines 2,106 步，ramen 3,240 步。对照与候选的监督和预算相同。

真实文本开发评估为完整冻结场渲染、宽 480、阈值 0.5、原始查询文本；56 / 71 个标注观测。下表是观测平均 IoU / 宏平均 AP，单位 %。

| 场景 | 独立头与适配器，同预算校准对照 | 一致解码匹配 | 一致解码，去 RADIO |
| --- | ---: | ---: | ---: |
| figurines | 22.02 / 37.06 | **28.23 / 43.73** | 25.92 / 41.44 |
| ramen | **15.94 / 23.09** | 15.50 / 20.17 | 15.12 / 18.72 |

不得把 6.21 点改善误写成相对上一轮最佳模型的改善：上一轮未经校准的 source-query 场 figurines 为 27.97%，ramen 为 16.22%。本轮一致匹配没有形成跨场景优势。

同一参考查询队列的 IoU（文本 / 图像 / 直接提示 / 提示优化，%）：

| 场景 | 校准对照 | 一致解码 | 一致解码，去 RADIO |
| --- | --- | --- | --- |
| figurines | 22.31 / 28.31 / 21.73 / 23.22 | 29.25 / 32.03 / 26.81 / 27.74 | 26.80 / 31.61 / 26.65 / 28.09 |
| ramen | 14.94 / 20.02 / 21.89 / 20.29 | 14.75 / 18.39 / 19.76 / 20.70 | 14.38 / 19.06 / 20.26 / 20.77 |

这批参考任务为 35 / 57 个 GT 派生类别范围任务，图像输入允许参考标注裁剪，提示输入为参考正负像素加估计三维坐标；目标标注仅评分。它们不是 LERF 官方实例、真实三维点击或独立最终 test 协议。

逐类结果：figurines 的 jake 从 17.59% 到 40.27%，waldo 从 4.21% 到 10.79%，但 miffy 仅从 1.76% 到 2.64%。ramen 的 chopsticks / egg 分别从 4.44% / 2.88% 降至 0，wavy noodles 仅从 7.91% 到 8.04%。因此有限源概念、细部定位和对象范围仍是实际问题，不能宣布适配器一致性修复已解决泛化。

无 RADIO 两场均完成训练与禁止训练缓存访问的在线原生三查询冷启动。冷启动编码数值与训练编码有微小差异，后验并非逐位相同；不能将这一检查与上述固定输入下的解码精确等价检查混淆。

## 3. ScanNet OVS：类别点分类输出合约

已审计本地 scannet_og 的 10 个场景、标签点云与图像清单。遵循现有 OpenGaussian OVS 的 19 / 15 / 10 类划分，输出原始 NYU40 ID，不能输出重新编号的连续类别索引。[官方评估说明](https://github.com/yanmin-wu/OpenGaussian#43-scannet-evalution-open-vocabulary-point-cloud-understanding)。

新增 `semantic_point_readout.py`：所有预定类别查询一起评分并 argmax，未知元素输出 0；不读取 GT 决定哪些类别参与查询。未知预测在有效 GT 类别上计漏检，不从分母删除。已编码全部 19 个原生文本查询，15 / 10 类通过规定的 ID 子集选择。

十个场景的 transforms_train/test 图像路径完全重叠，数量依次为 279、37、67、38、215、46、54、61、135、226。全场景三维语义点评估允许使用这些 RGB，但不能声称留出视角评估。当前尚无这十个场景的新冻结几何与学习场，因此三维点对应和正式分数仍待执行。

## 4. NVOS 与二维交互查询

NVOS 应处理参考图像上的正负涂鸦，再评估另一视角；不应把它简化成真实三维点点击。[NVOS 项目](https://jason718.github.io/nvos/)。本地 strict-unseen v1 清单包含 fern、flower、fortress、horns_center、horns_left、leaves、orchids、trex。该本地严格合约禁止场训练及查询阶段读取目标 RGB，目标 GT 只用于最后评分；它不能与允许目标 RGB 的 SAM 视频传播实验混为一谈。

本轮真实执行了全部 8 组官方参考涂鸦：每个符号确定性选 8 点，输入冻结 SAM3，按完整正负涂鸦一致率再按 SAM 质量选择候选，映回原始 RGB 坐标后形成图像查询裁剪。已完成全部 8 个 1536 维原生图像编码；读取守卫禁止打开目标 RGB / GT。所有原始输入、选点、坐标变换、模型与输出哈希均留档。

**8 个 SAM 掩码都没有完全满足全部原始涂鸦。** 因此不把 SAM 输出视为 GT，也不丢弃原始负提示。新增 `condition_native_image_query`：在参考视角已注册、有几何贡献权重时，用完整正负证据优化临时原生图像 query，保持场、解码器和校准参数不变；输出仍通过同一原生读出。未知几何证据拒绝执行，无法满足的约束显式报告。模块已测试，但尚未在新 NVOS 场上完成端到端执行。

二维接口支持像素点及正负标签、单独框、涂鸦转点，检查 XY / XYXY 坐标与冲突。框和点的混合输入需要明确合并策略，不能假定 SAM 内直接拼接可加。真实数据验证本轮覆盖涂鸦转正负点；框接口目前只有单元验证。未注册图像可以形成图像 query，但不能虚构其到地图的像素对应。

初次联合编码时，Python 文件访问审计遇到 bytes 路径而失败；已用 `os.fsdecode` 修复路径规范化并重新完整执行，没有放宽目标输入禁读守卫。

## 5. 验证与剩余工作

98 项相关测试通过，涵盖原生解码值/梯度、模型载入、正负提示、ScanNet 类别 ID、监督冲突与覆盖、可靠对应、度量、无 RADIO 源教师路径。六个部署场哈希与评估记录已核对。

共同能力是从地图元素召回语义或对象，但输出合约不同：LERF 二值语义范围、ScanNet 多类三维点分类、NVOS 交互指定前景，不能共用一个二值阈值替代各自任务。

后续优先级：

1. 在源视角细分原教师能否定位部件、融合后是否保留、D(z) 是否再损失，扩充经过验证的细粒度和完整对象监督；保留未知弃权，不能硬补伪负标签。
2. 构建 ScanNet / NVOS 的冻结几何和可观察性资产，先通过坐标、渲染及点对应检查，再训练同一方法；补齐 NVOS 完整正负证据条件化执行。
3. 以三任务共同结果决定是否推广一致解码候选。当前保留旧控制与失败结果，不扩大训练步数来替代监督、对象范围与跨任务验证。
