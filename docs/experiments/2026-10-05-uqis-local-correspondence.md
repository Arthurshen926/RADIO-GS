# 原生局部对应改善实例身份：完整 UQIS 对照与共同系统收敛

2026-10-05。三组完整实验已完成：27个场景作业、804条独立查询。
UQIS仍是9个已打开开发场景、67个目标；四类查询及18个困难参考均保留。
汇总：`output/local_appearance_study/comparison.json`。
固定条件：`configs/recipes/uqis_local_appearance.json`。

**结论：区域平均确实丢失了本任务可用的局部身份证据。保留原生局部特征，
用双向最近局部相似度选择身份，能够在同教师、同源图、同几何和同范围头下
提高实际实例召回。它没有解决完整对象范围，也还没有独立新场景或紧凑学生证据。**

## 改了什么

原有流程先将一个 SAM 区域内的 DINO patch 平均成一个向量，再与参考裁剪的
平均向量比较。新流程在离线地图中同时保存未平均的原生 patch，以及区域对
patch 的面积权重。图像查询只编码自己的参考裁剪；不读取任何建图 RGB、深度
或 SAM 缓存。点提示的输入权限不变。

几何、39,360个原始区域、区域到3D元素的归属、可见性和范围解码器均保持原样。
全部1,107张合法建图照片参与，保留1,782,270个 patch，无新增候选上限。
重新构建的所有区域平均向量与上阶段逐项一致，最大绝对差为0。

在两个原生空间中分别编码，不压缩或学习投影：

1. SigLIP提供原有原生语义身份与元素场响应。
2. DINO提供原生局部外观；查询与每个源区域之间计算局部匹配。
3. 两个身份分数的支持区域百分位排名等权融合，选一个身份种子。
4. 原有共可见几何对应恢复范围，并独立输出实际元素集合。

局部相似度只改变身份选择，不充当成员概率，不直接裁剪3D元素。文本与两类
点提示的算法、原生场与范围头均未改动。

## 事前固定的三个完整条件

- **区域均值**：重建上一阶段 SigLIP/平均 DINO 等权身份排名，作为同教师控制。
- **双向局部匹配**：查询每个 patch 找区域内最相似 patch，反向也匹配；分别
  按有效查询面积和区域面积平均，再等权平均两方向。所有 patch 都参与。
- **互为最近邻**：仅累计双向互选的 patch 对；每对以两侧归一面积质量的几何
  平均乘以平移到[0,1]的余弦相似度计分。这仍是身份证据，不是概率。

16个区域一组只是显存分块，不是候选截断。没有调阈值、扫融合系数、按场景或
按查询选择方法。两个局部候选都完整跑完后才决定保留哪个统一规则。
三组输入证据和教师相同；局部匹配需要更多存储和查询计算，不能称等部署成本。

## 改善来自哪一步，哪些仍未解决

双向匹配修正9个原来主导身份错误的图像查询，同时破坏1个原来正确的查询，
净增加8个。图像IoU>=0.5从17/67增加到23/67。

但它未解决范围完整性。在v7与双向匹配都选对主导身份的同一36个查询上，
查询宏平均IoU仅从47.96%到49.76%，覆盖55.20%到55.92%。这是固定子集的
后验诊断，不是新的主指标。不能把身份改进解释为完整性已经解决。
互为最近邻也有45个正确主导身份，然而实际IoU更低；两种局部方法共同正确
的42个查询上，双向匹配覆盖53.89%，互选只有51.53%。更严格的局部匹配
没有自动带来更合适的整体/部件粒度。

同目标四类查询均达到IoU>=0.5仅从6/67到7/67，场景宏平均8.995%到10.384%。
文本仅11/67达到0.5，两类点各32/67。当前身份选择与范围恢复仍分别受限：
图像有了实质进展，关系文本和完整实例范围依然是统一高精度的主要障碍。
一项局部实验不能证明四模态核心claim已经成立。

保留的反例是scene0246的lamp（图像query `uq_4849b067349d26399116d81858eab2b6`）：
三种DINO身份条件都选择87个元素的同一种子，范围匹配到6个视角，但目标覆盖
只有10.70%；v7种子397个元素、11个视角，覆盖81.46%。最终IoU56.56%降至9.77%，
两者的主导实例仍都正确。此查询没有路由回旧答案。
这说明多个视角支持同一个部件，仍不等于找全物体。当前一跳范围头要求双边
可见比例与共可见IoU，倾向保持种子的粒度；它不是独立的完整实例补全器。
源区域的整体/部件归属需要额外依据，不能把局部外观对应正确当成整物体监督。

下一阶段保留双向匹配，停止这组匹配规则的继续扫参。优先补充可独立核验的
同实例/整体/部件归属和未见表面的范围证据，保持四类查询共用范围机制；
文本需要真实的目标/参照物身份对应，不能重启上一阶段失败的粗区域几何加权。

## 成本与实现

新高容量地图共2852.810MiB。v7原地图174.038MiB；上一阶段仅增加平均DINO
向量的部署地图231.695MiB。此轮为保持完全相同输入文件，均值对照也挂载了
全量局部数组，但其计算只读取平均向量；纯均值部署不需要这些额外数组。
额外DINO checkpoint330.333MiB，半精度参数165.139MiB；原SigLIP编码器另计。
不能把没有源RGB访问等同于紧凑存储。

编译1,107帧累计186.664秒。三组九景完整查询累计449.161、481.649、474.583秒；
包含教师加载、四类查询和所有读出，且GPU与其他任务共享，不作为隔离延迟基准。

实现：

- `radio_gs/models/native_region_appearance.py`：原生patch及原有面积平均。
- `radio_gs/pipeline/local_appearance_map.py`：同源图离线局部地图。
- `radio_gs/querying/local_appearance_match.py`：两种通用区域局部匹配。
- `radio_gs/querying/registered_observation_query.py`：共同实例读取器中的身份接入。
- `scripts/research/run_local_appearance_cohort.py`、`summarize_local_appearance.py`：完整条件与结果。
