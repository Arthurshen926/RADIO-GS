# 有限证据与原生先验：完成对照，未推广

本轮实现并跑完两种有限证据定义、一个训练/读出消融，共 **24 份完整场景双输出评价**。结论是：**稀疏错误证据可以被抑制，但统一依赖检测置信度来保护原生地图，会损害正确的稀疏目标；本轮没有获得可以替换主线的整体增益。** `identity_response` 默认不变。

## 机制与固定条件

旧语义融合为 `sum(w*y)/sum(w)`。只有一个有效来源时，其标量置信度被约掉；任何非零支持都替换原生响应。集合求解器同时从源均值初始化，在同一组源掩码上重复拟合，缺少保留原生结果的约束。不能把反复优化解释成获得了新的证据，也不能把“不足以否决身份”解释成确认正确。

本轮增加共享函数 `radio_gs/querying/finite_evidence.py`，原生地图参考强度固定为一：

`p = (p_native + C * p_source) / (1 + C)`。

- A：`C = sum_v detector_confidence_v`。
- B：唯一一次强度修订，`C = sum_v max(logit(detector_confidence_v), 0)`；检测准入点0.5附近的强度趋近零。
- 同一源帧只计一次；像素数和优化迭代不增加 `C`。相关视角仍会重复提供相似信息，`C` **不是独立样本数**；置信度与logit也**不是校准过的身份正确率**。
- 语义头对相同回投影提案做上述混合。集合头在实际子集渲染、退火成员判断以及最终读出之前使用同一混合，允许全部已观察元素参与优化，保留遮挡元素修复。
- 消融仅在原求解器输出后混合，不在训练内施加约束；语义头与B完全相同。

四场景67个有标注文本＋ramen一个无标签探针，所有764个合法源视角。两套证据为原始身份筛选证据、上一轮原图＋裁块证据（global）；每套内部几何、原生编码、源掩码、未知/负例权限、240或293步预算完全固定。新教师调用 **0**。没有查询名分支、最低视角数门槛、目标RGB或GT驱动的预测选择。原始和裁块证据的旧完整结果为各自比较对象。

## 两个相反的稀疏案例

源侧可视材料：`output/finite_source_evidence/sparse_proposals.jpg` 与对应JSON，仅用于解释，不作为独立源真值。

|案例|源证据|旧结果：语义/集合|A|B|
|---|---|---:|---:|---:|
|figurines / waldo，裁块证据|1帧，0.50390625；源图可见掩码覆盖海盗帽鸭子|11.37 / 0.00|70.62 / 73.23|79.74 / 69.67|
|teatime / paper napkin，原始证据|1帧，0.55078125；源图位于纸巾范围，实际目标评价支持其有用性|83.04 / 75.80|48.08 / 74.30|0.17 / 32.86|

无裁块时Waldo主线为79.96/68.08。有限更新确实能阻止该错误新提案摧毁原生答案，**但不能据单例做推广**。

纸巾在B中的AP仍为 **99.4172%**，语义IoU仅 **0.1739%**。因此这里不能解释为教师语义排序丢失，而是有限混合把前景响应压低于冻结0.5阈值。若 `C < 1`，即使源提案为1，原生响应低于 `(1-C)/2` 的元素也不能越过0.5。这个限制来自方法参数化，增加优化步数不能消除。成员读出有相似的可达范围限制，但其渲染是子集alpha，不能用响应AP代替集合分析。

这两个例子共同排除了“一帧=不可信”或“低检测分数=错误身份”的简单解释。也说明原生地图并不是天然正确的权威：它可能识别对Waldo，却低估正确纸巾。提高先验权重、降低检测权重，不能区分这两种情况。

## 收敛决定

1. **不推广A或B，不混合每查询最佳结果。** 保留可复现研究选项；原默认生成/评价不变。没有新增全局阈值、参数网格或测试框架。
2. 停止这类单一置信度/视角计数/先验混合的搜索。有限约束处理了更新幅度，却没有获得独立的身份或范围正确性信息。
3. 下一方法必须分别给出：当前提案是否认对对象、范围是否完整、融合响应是否正确校准。不能再用SAM检测分数同时回答三件事，也不能把原生地图高/低响应直接当监督真值。任何新增验证信息应在全部查询上评价，并与保持同一证据的简单融合比较。
4. 需要来源独立的身份/范围监督及未调参场景来验证正反例区分；增加同教师重复票数不满足这个要求。本轮不声称已经完成该机制或贡献证明。

这是一个已完成的、有反例支持的否定结果与故障定位，不是SOTA提升。NVOS、ScanNet OVS没有新结果；UQIS继续暂停，同地图四query独立准确率、紧凑部署、公开协议SOTA与CVPR贡献均未完成。
