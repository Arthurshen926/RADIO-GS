# 二值 Gaussian 区域候选：固定迁移开发对照

此前能量／可见许可失败及新增轮廓归因已知。本轮是适应性开发对照，不是独立
确认性测试；不以跨域特征定义成立来声称模型精度成立。模型有既有额外3D实例
监督（24个ScanNet训练房间），不隐藏该条件。

同四场68文本、原Gaussian几何和原生语义初值、相同72构建视图。构建只读取原
单场张量；association>=0.5定义区域二值归属，scope lift行和>=1-2e-6定义可靠
可见性（已存min(1,peak/.1)，2e-6是浮点容差）。必须验证每区域成员属于该视图
可见域。没有成员归属的可见Gaussian仍进入分母，不能把“至少被某区域接纳”
误作可见性。语义独有／未观察行不强行补成成员。

外观由区域内Gaussian的归一化原生local向量均值后归一化得到。该定义保留
原生局部外观角色，但不同于历史masked-image描述子，Gaussian点密度也不同
于mesh采样；两者为明确分布偏移。原质量森林／阈值完全冻结，不用LERF标签
适配或调参。区域、可见性、描述子和森林都存入同一个field.pt，无外部运行依赖。

查询使用原生region probability>0.5且有二值成员的最高分区域为种子，复用
已迁移的三输出／每视图准入函数，严格多数可见加权投票得到scope。没有种子
或没有获准候选时回退。单种子可能不足以代表多对象union，因此不直接覆盖主
路径已有的多对象强初值。

五组固定：semantic_initial、frozen_visibility（旧强对照，重新执行并验证）、
seed_addition（固定对照并入种子区域）、conditional_addition（主组：固定对照
并入条件多数scope）、conditional_replace（诊断：已知可见处用条件scope，未知处
保留语义初值）。主组允许新增但保留强固定对照，诊断组显示范围判断自身能否
承担删补职责。语义响应不改，各组按实际选集重渲染，不以响应指标代替成员结果。

全部四场五组预测完成且哈希冻结后才评分；报告全部结果和新增／删除数量，
不挑场景／查询提升默认。旧组选集须精确保持，语义连续值容差2e-6。冷启动
公共函数必须在禁止Python open条件下重现选择；这不构成OS沙箱证明。
本轮若无提升，拒绝直接跨域应用原模型，进一步分解候选定义和条件函数的域差异。
不回退逐查询源RGB／掩码／相机拟合，不宣称五任务完成。
