# next52：深度一致性重建、尺度恢复接入与视线分布对照

## 完成本轮工作

固定源图和1500步几何优化，加入标定MoGe期望深度相对L1（权重0.1），保持next51中心移动范围、各向异性尺度和opacity优化。几何冻结后重算贡献算子、以相同120步/查询解码集合。没有目标RGB或标注进入预测构建。

本轮修复了新重建入口遗漏恢复尺度的问题：最初只读取source_report中的初始标定，忽略geometry_report内已接受的recovered_scales。现在仅对原来未接受、后续恢复被接受的视角接入恢复乘法尺度，offset=0，与构建independent_scale载体的约定一致；未接受的恢复不使用，未采用未标定全局fallback。源文件不改写，修正仅在新重建入口生效，不能外推为历史低分已由此解释。

深度训练视角从figurines16/20、ramen8/25、teatime20/23、waldo22/22恢复为20/20、25/25、23/23、22/22。验证帧不参与RGB/深度梯度更新；其参考尺度可能来自已有上游处理，不能称为整个几何流程完全未见过的视角。

## 方法对照

另实现视线分布目标：用可见贡献渲染中心深度的一阶、二阶矩，最小化sqrt((E[z]-d)^2+Var[z])/d，保持权重0.1和相同固定训练预算。它针对“平均深度正确但前后表面分散”的假设。中心深度矩不是完整三维表面距离；结果不支持将这一固定目标提升为默认，也未证明所有分布/失真损失无效。

所有数值为实际选择高斯后的投影IoU，以二维GT评估，不是物理三维GT IoU。

恢复尺度后的深度方案相对next48四场都提高，但仅+0.514个百分点；相对next51 RGB方案也不是四场都提高。它与next50 hard44.059基本持平，并不构成显著突破或统计显著性证明。未按查询/场景拼接赢家。

2D IoU53.914/AP71.211保持不变是原语义分支冻结的结果。当前仍是原语义几何+新集合几何的隔离实验，没有在新几何上重训四教师特征场，不能声称已完成统一地图重建。旧元素初值只用于同索引载体干预，旧投影算子不用于新集合优化。

深度误差是与MoGe先验的一致性，不是真实几何精度；覆盖集合随训练改变，不能仅依据条件AbsRel断言几何变好。RGB before为未拟合灰色，不用PSNR增幅证明几何贡献。

## 科研判断

现有证据支持RGB与尺度一致的MoGe深度共同约束载体，但其增益不足以说明主要缺口已解决。额外视线方差惩罚没有带来稳定收益，不能把理论上合理直接当作有效。

本轮未完成增密/剪枝、跨视角联合尺度重估、完整语义场重建或独立泛化验证。这些仍是下一阶段实质工作；当前代码保留研究候选，不替换全局默认，不宣称CVPR-ready。没有新增ScanNet、NVOS、UQIS结果，也没有新增测试或审计框架。
