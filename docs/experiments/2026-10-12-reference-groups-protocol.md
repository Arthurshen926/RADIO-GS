# 可撤销的部分分组：完整八例固定对照

本轮在新预测/新评分前冻结。上一轮联合观测/选集目标恢复85.7573%，仍低于
组合基线86.9550%；本轮检验保留场内部分关系能否改变这一退化，而不锁死初值。
同八例已经用于开发，结果不是独立泛化或全五任务证明。

固定当前positive-derived SAM完整参考mask/camera、七场/八请求/120构建
观察、原组合初值、A_obs/R_set等权目标、0.1足迹成本及四遍预算。无训练、
额外场持久化状态、目标相机参与解码、历史源回读、连续查询参数拟合。
生成参考mask的RGB/SAM成本继承，不是raw scribble输入。

三组完整条件：

1. free：重新运行上一轮逐Gaussian自由增删，必须与封存coupled选集逐位一致；
   成员和两种投影最大差≤1e-6。作为数值兼容对照。
2. parts，预先指定主候选：相同正区域关联集合的Gaussian形成等价单元，
   再按当前初值位拆分，保证初值一项不变。按组内最小Gaussian编号排序；
   一个提案整体翻转一组，允许增加或删除全部初始正成员。无区域证据者为
   独立单点，不把未知并成对象。区域关系只是部分假设，不是实例真值。
3. shuffled：在“初始位×有区域证据”分层内，固定seed20261012置换组标签。
   每个组槽的大小、初始位、提案顺序与预算完全保持，无区域证据单点不变。
   该对照区分场内关系与任意同规模捆绑；不单独隔离空间局部性与语义身份。

优化仍使用原Gaussian逐命中深度顺序与透射率，不能把组替换为一个虚构
opacity。A_obs组响应、成本为成员精确求和。重复命中的同一组必须整体加入/
删除，一个受影响射线只计算一次；遵守原alpha阈值和提前终止。
小系统测试须逐提案与原Gaussian完整目标枚举一致，覆盖重复组命中、两视图、
不可用成员与撤销整个正组。free内核的旧随机轨迹也须保持。

全部24预测封存和free精确对照通过后评分，报告实际选集及历史定义归一响应
IoU、P/R/AP、八例与七场聚类区间。未知成员、组大小与初值保持独立核验；
实际最终目标与完整渲染端点独立重算。不得按例混合新旧赢家，也不能以
能量降低、参考形状或抑制所有修改宣称身份迁移有效。

构建信息量不变，分组是场内现有部分关系的查询时可执行读出。旧float64
足迹严格门槛两场失败仍单列；本轮继承已绑定的float32操作，不回填为通过。
冷公共主候选首例应拒绝历史数据/输出文件及任意torch.load，允许编译缓存IO。
