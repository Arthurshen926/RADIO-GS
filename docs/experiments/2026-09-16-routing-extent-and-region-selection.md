## 最重要的新定位：源概念不能替代对象对应

旧范围头先把同一短语在每个源视角的掩码合并，再跨可见视角平均，最后让 query 选择一个概念范围。这里缺少“这些区域是否确实描述同一个对象/部件范围”的约束。同名短语并不能保证不同视角的教师掩码具有相同范围粒度。

为区分缺少区域、聚合损失、场表达不足和查询选择错误，本轮固定同一几何、观察支持和渲染合约，让真实标注**仅在诊断阶段**挑选已有候选里最佳的掩码。这些数值均不是可部署分数，不用于训练或门槛拟合：

| GT 辅助选择候选的诊断，IoU % | figurines | ramen |
|---|---:|---:|
| 未压缩、按源概念聚合的 membership | 26.80 | 24.43 |
| 同源证据，保留每个独立区域 | 49.94 | 45.89 |
| 在原 96D 场上学习独立区域范围头 | 54.76 | 44.95 |

这支持“可用的对象范围在独立区域中存在，但聚合后的候选集合未保留它们”。独立区域数量更多，GT 可自由选无关概念；因此这不是纯粹平均算子的无混杂贡献测量，也不是跨视角实例对应已经正确的证明。

进一步，对**同一个已训练的独立区域场**分离选择阶段：

| 选择规则，IoU % | figurines | ramen |
|---|---:|---:|
| GT 可选任意区域或原生回退 | 55.27 | 44.95 |
| 保留实际概念门控，仅让 GT 在允许区域内选；拒绝时原生回退 | 37.05 | 32.88 |
| 实际概念门控 + 原生图文余弦选择区域 | 34.00 | 18.72 |

**fig 的概念门控明显限制了可访问的区域；ramen 在概念内排序也大量选错。** 这些是同一模型上的诊断差距，不应当作不同阶段可相加的因果责任比例。尤其不能把 55.27 / 44.95 报为模型召回成绩。

这比“缺少更多维度/更多训练”更精确：新场已经能表达更多候选范围，但查询还不能可靠地取出它们。独立区域实验的真实成绩下降，明确拒绝替换保留候选。

## 已完成的修复与反面对照

### 1. 路由：不再假定裸文本余弦是语义等价证据

实现了去除源词表共同方向、加入未接纳源概念作为竞争项、以及两者组合。词表仅来自已有固定源词表和源图描述，未加入评估词。竞争项胜出时精确回退旧响应，不把它解释成目标不存在。

源侧诊断中，旧路由把没有已接纳范围头的 146 / 143 个短语中的 61 / 76 个强行分配给现有范围；竞争版本将这个数降到 0。但“没有范围头”不是缺失目标真值；这个统计只测强制分配。

真实评估显示，它能撤销 `bag→table`、`pumpkin→fruit` 等错误，也会拒绝有效的 `napkin→white napkin`、`sake cup→cup`；没有获得联合改善。拒绝用全局加严门槛代替可靠的语义关系学习。

### 2. 监督：反投影标签拟合与最终前向渲染并不等价

反投影是可见性归一化聚合，不是渲染的逆。即使几何与权重正确，掩码反投影后再渲染也会平滑边界、混合相邻区域。因此新增前向监督：固定源视角贡献矩阵，把元素 membership 渲染、按 observed mass 归一化后，与源教师像素掩码计算平衡 BCE + Dice。

配对控制固定同一初始化、视角、概念、800 步、Adam 0.001、seed 42 和每步至多 8 个头，只改变 loss 所在空间。分别对线性头和 96→128→K 的残差概率读出进行比较。残差最后一层零初始化，初始输出精确等于原读出；已有场特征完全不变。

仅加非线性但继续用反投影标签，ramen IoU 降到 19.39%；改为前向像素监督后为 25.10%。所以本轮保留的是监督与读出共同改动，不能把收益全部归于“更大 MLP”。源训练 IoU 不作为跨视角泛化成绩；固定使用最终步，没有按 target 标注挑 checkpoint。

### 3. 分辨率：高分辨率不是当前主要解法

另做了精确 gsplat 前向训练，使用保留的原生 SAM 掩码，在 128 / 480 宽监督。两个版本都以相同原线性头和零残差初始化，400 步、同优化器、同源视角、原生掩码并集后 area resize；只改变监督/渲染分辨率。

480 宽只小幅改善 fig，却降低 ramen。这个对照没有证明高分辨率无用，但不支持它是当前大幅低分的主要解释。不能与 800 步稀疏责任矩阵实验视作纯分辨率对照，只有这两个精确渲染版本彼此匹配。

### 4. 区域：恢复候选范围仍不等于成功召回

新增独立源区域头（260 / 610 个），概念只限定候选；原生 query 与区域原生图像描述符相似度选择具体范围。以源区域拟合初始化，再用前向渲染监督训练 800 步。全部父场和原概念门控参数保留。

部署仍只有一个每元素 96D 场，新增的是全局头和区域描述符/概念关系，无逐元素第二语义图。相对上轮 checkpoint，状态增加约 1.79 / 4.16 MiB；头数量随源区域数增长，未验证大场景扩展性。该版本不是已经建立物理实例对应的对象图，也不保证多个实例的并集召回。

其源区域训练 IoU 为 72.50 / 68.62%，真实文本仅 34.00 / 18.72%；不能用源拟合高分掩盖失败。GT 选择诊断确认候选能力存在，实际概念/区域选择没有可靠传递该能力，因此拒绝晋升。

## 正确性与实验边界

- 39 项相关测试通过：旧 checkpoint 路径、冷状态恢复、原生语义保留、查询/行批不变性、竞争拒绝、零残差初始化、源区域限制、空候选回退，以及前向 loss 的未知像素排除和梯度方向。
- 所有变体逐 tensor 核对：只允许改变明确声明的范围头或路由门槛。几何、原 96D 场和其他父状态保持一致。真实参考评估确认图像/提示逐项不变。
- 所有训练使用源 RGB 已产生的教师证据，不读取 target RGB 或评估标注。独立区域原型来自源裁剪；oracle **例外地读取 target GT 选候选**，仅用于诊断，保存在单独文件。
- 较早控制报告通过继承保留的 `source_fit` / `ridge` 描述上轮初始化；本轮实际优化配置和 source fit 以各报告的 `history`、`objective`、`steps`、`learning_rate` 为准，不能将继承字段当成当前拟合指标。
- 所有源证据、模型及评估与实现均绑定 SHA256；脚本迭代前保留内容寻址快照。评估使用同一观察支持、0.5 membership 判定和完整分母，没有 benchmark 阈值搜索。
- 保留候选通过本轮开发对照选择；不是独立最终 test。未新增 ScanNet OVS、NVOS、缺失目标或 SAM 2D prompt 实验，未证明这些任务改善。

## 下一步只聚焦对应关系与选择监督

证据不支持继续堆头、改维数、调门槛或只提升监督分辨率。接下来需要源侧的**区域—概念—跨视角范围对应**监督，直接约束“真实 query 应选哪些区域/元素”，并对不等价的粗类别、部件、属性和实例范围拒绝错误合并。源区域存在而查询选择失败的部分，应该通过源视角间的可见性一致对应及候选排序监督检验；先验证对应可靠性，再训练选择模块。不能拿 oracle 最佳区域作为训练标签，也不能按本轮评估词编写例外。

目前这条查询选择链尚未修复成功；独立区域实验已明确失败，保留现有较好候选，不把诊断潜力当成已实现的大幅性能提升。
