# 独立场景复核：训练覆盖、监督冲突与评估分母

本轮完成四教师与去 RADIO 的 ramen 实验，并修复训练预算检查、提示无语义支撑时的处理、评估分母透明度。结果尚不足以替换历史性能基线。几何保持冻结。

## 协议与实际结果

预先记录协议见 `paper/artifacts/ramen_three_query_preregistered_20260915.json`。从几何映射帧与已有原生 SAM 帧交集按顺序取前八帧：7、11、15、18、22、27、31、35；前六帧训练，31、35 用于验证 query 与目标视角。没有根据语义分数挑帧。四教师为原生 RADIO、DINOv2-B14、SAM 结构监督、SigLIP；SAM 并非稠密 embedding 教师。

预注册预算为 180 步。审计发现轮转仅遍历图像和提示各 60/84 个任务，因此新增 252 步完整覆盖实验。这是明确的开发修正，不能算成原预注册结果。遍历全部任务只是最低要求，不等于收敛。

下表为固定全部任务分母的已知支撑区域伪标签 IoU；未定义 IoU 按 0 计分，并非给未知像素赋负标签。原始提示结果未使用 query 条件优化。

| 配置 | 步数 | 文本 | 图像 | 原始提示 |
|---|---:|---:|---:|---:|
| 四教师 | 180 | 0.750649 | 0 | 0.003972 |
| 去 RADIO | 180 | 0.707592 | 0 | 0.006121 |
| 四教师，完整遍历 | 252 | 0.553974 | 0.413108 | 0.461137 |
| 去 RADIO，完整遍历 | 252 | 0.568160 | 0.341123 | 0.465109 |

图像和提示改善，但文本下降，不能宣称全面提升。图像的仅有效任务均值分别是 0.550811、0.454831，分母为 3；完整任务分母为 4。以前独立评估丢弃未定义比例，训练报告则计零，造成口径差异。本轮保留数学上未定义值，同时新增逐指标有效任务数、总任务数以及固定分母 IoU。新汇总文件由原逐任务结果生成，无需重复推理，也没有覆盖历史产物。

证据：`paper/artifacts/ramen_three_query_explicit_denominators_20260915.json`，原推理结果 `ramen_three_query_full_coverage_eval_20260915.json`。

## 已落实的修复

1. 训练默认要求三类任务全部至少遍历一次，预算不足在教师/GPU 加载和创建输出目录之前报错。180 步拒绝测试通过且未创建目录。显式短程测试可以使用 `--allow-incomplete-episode-coverage`；报告记录各类访问数及最低步数。
2. 提示 seed 有几何投影但没有已观测语义特征时，返回类型明确的 unavailable，保留原始 query 后验，记录缺失 seed，保持地图冻结；不能换 seed 或假称约束已满足。非法形状/索引等错误仍抛出。
3. 评估记录提示可用性，不能只报可细化子集。本场景 4 个提示仅 1 个具备全部 seed 支撑，另外 3 个保留原始响应进入评估。252 步的可用提示本来已满足约束，条件优化未进一步提高结果。
4. 新增跨视角对应图与同 query 正负标签冲突审计，以及可选的仅训练集冲突标签屏蔽。屏蔽不改变几何、预测、观测集合和评估标签，默认关闭。
5. 教师准备工具支持显式 `--radio-root`，验证原生特征对应的源 RGB 哈希。去 RADIO 原生冷启动验证阻止读取训练教师、episodes、queries 和 RADIO 文件，实际文本/图像/提示编码执行通过；缺失提示支撑被正确报告，而非宣称语义细化成功。

## 尚未解决的主要问题

- **语义覆盖不足**：362198 个几何元素仅 92956 个有观测特征。验证图像和提示只有约 2.36% 像素拥有可评估标签，文本约 2.69%；验证只有两对互反区域。这些是部分源伪标签诊断，不是全图 benchmark IoU。ramen 是相对之前 figurines 调参新增的语义开发场景，不是从未使用过的几何测试场景。
- **区域不能直接当实例**：figurines 的对应图存在同一连通分量包含同视角多个区域；可视化显示部分区域是重叠桌面/背景表面。图冲突可能来自嵌套 SAM 区域，不能据此认定每条对应都错，更不能直接合并为实例。
- **文本硬标签不可靠**：figurines 20 对匹配中 9 对原生文本 top-1 不一致；ramen 44 对中 24 对不一致。视觉审阅只用于诊断，不作为人工 GT。仅从固定词表取 top-1 不能保证正确的物体语义。
- **跨视角监督矛盾**：figurines 同一个文本 query 有 380 个 query-element 对被不同训练任务同时要求正负。可选屏蔽实验文本/图像/提示为 0.392416/0.328493/0.330225，低于原 0.429126/0.342784/0.337224，因此未推广。
- **可学习投影可能扭曲召回关系**：ramen 两个 query 在训练地图没有对应区域；另两个 query 原生空间最邻近训练区域有几何一致性，而学习投影后的第一名变为不一致区域。这是诊断线索，不能单凭最近邻证明它是最终场召回失败的唯一原因。

相关证据：`figurines_identity_conflicts_20260915.json`、`figurines_identity_conflicts_20260915.png`、`figurines_surface_region_review_20260915.json`、`ramen_identity_audit_20260915.json`、`ramen_native_query_alignment_20260915.json`、`ramen_cold_query_availability_20260915.json`，均位于 `paper/artifacts/`。

## 下一步顺序

先补齐训练地图的真实观测特征覆盖，并分开报告几何覆盖、语义观测覆盖和标签覆盖；不能让后续特征训练修几何。其次处理区域身份与文本监督可靠性，避免将重叠表面区域硬定义为物体实例。再对可学习 query 投影与固定原生投影做同预算对照，验证是否需要保留原生空间关系。最后扩大固定验证集、补独立语义标注和历史主线同口径对照。当前不升级任何候选为性能主线。

验证：本轮主测试集 485 项通过；随后增加评估分母回归测试并执行相关专项测试。代码与实验产物尚未提交，保留已有工作区变更。
