# Native feature writing and renderer-residual reconstruction, next75

## Question and controlled interventions

The next74 NVOS gain came from more accurate source-mask fitting. This iteration
asks whether the same issue affects query-independent native feature writing,
and whether correcting a rendered feature residual is more useful than simply
backprojecting teacher observations. These are separate interventions.

All legal source views remain included: figurines293, ramen122, teatime169,
waldo_kitchen180. Frozen next66 RGB+MoGe Gaussian geometry, original-resolution
SAM proposals, native1536D SigLIP region descriptors, query encoder, source
calibration evidence and240 scalar-calibration updates are unchanged. No target
RGB or evaluation annotations enter reconstruction. Source refinement and old
confidence-distribution transport remain unchanged, including their limitations.

1. **Fine writing:** change only native feature fusion raster96x128→192x256.
   Reproject the same native region masks and alpha contributions. Explicitly
   keep calibration at96x128 instead of silently changing its supervision too.
2. **Renderer residual:** retain96x128 and initialize from the previous native
   field. Form the source residual Y−BF, then update each Gaussian with
   0.95 D⁻¹ Bᵀ(Y−BF), where B is the normalized visibility operator and D its
   accumulated column mass. Normalize resulting feature vectors. This is one
   projected correction, not a converged inverse solution or proof of lower
   reconstruction error. No query-conditioned feature adapter is introduced.

First freeze selected membership to isolate semantic effects. For fine writing,
subsequently rerun the SAME next72 extent decoder: original source cohort,
old detection/temporal evidence,240updates, seeded mode, independent semantic
and membership outputs. No scene/query-wise best-result assembly.

## Mechanistic interpretation

Normalized backprojection mixes source observations through the renderer's
footprints; it does not solve the inverse rendering problem. Increasing source
write resolution can avoid some incorrect boundary mixing, while residual
correction tries to undo existing mixing. Neither fixes overlapping teacher
regions that already combine whole-object and part identities in the 2D target.
Therefore an inverse solver can fit a contaminated target more closely without
improving native semantic ranking. This remains a hypothesis about residual
failures, not a measured decomposition of all error.

Fine source masks here are the original SAM masks, not enlargement of a cached
96x128 probability map. Earlier failed LERF query-mask resolution experiments
(next45/67) do not test the same intervention.

## Scope and remaining method gap

This remains a high-capacity native-space research reference. It is not a new
compact four-teacher student or proof of same-map text/image/2D/3D prompt
performance. Current calibration/refinement still depends on historical source
query evidence; arbitrary unseen-query deployment remains incomplete.

The selected metric uses the frozen selected-Gaussian silhouette projected into
annotated views; it is not independent3D-ground-truth evaluation. All results
are development evidence. NVOS and ScanNet are unchanged in this iteration;
UQIS remains paused. No SOTA or CVPR-readiness claim is made.

Implementation: `rebuild_expanded_semantic_next72.py`,
`run_native_write_next75.py`, `decode_native_write_next75.py`.
Machine-readable results: `output/next75/summary.json`, generated by
`summarize_next75.py`. Each result links its full frozen evaluation.

## Conclusion and next research priority

Adopt the complete fine-write/joint-extent recipe as the next high-capacity LERF
research candidate, retaining next74 NVOS unchanged. Do not promote a compact
multimodal deployment or claim that every query improves. Region-level means
still fail on corn/onion segments, plastic ladle/ketchup, while bag, hooves and
coffee remain weak. Query deltas are in `output/next75/query_deltas.json`.
Examples of improvements are pirate hat+13.5pp, miffy+5.4pp and kamaboko+4.1pp;
these diagnostics are not used to choose per-query configurations.

The next major method change should address the observation itself: keep
whole/part region identity distinct before writing it to Gaussian features,
then reconcile those identities with geometric visibility. Another resolution
increase or additional iterations of the same mixed-target inverse fit does
not establish that capability. General query calibration and a rebuilt compact
multi-teacher map remain separate outstanding requirements. The new result
narrows the gap but does not constitute the requested large performance leap.
