# 查询身份与范围：两个机制完成全量验证，均不升级主线

固定当前 `identity_response`，完成四场景、67个标注文本（208个查询视角）及1个无标注输入的三组双输出重建，共12份完整场景评价。包含关系弃权和查询偏好的父范围补全是两个核心候选；未继续调参，没有按查询回填最佳结果。本轮没有得到可合并的大幅提升，默认仍为语义IoU70.3775%、AP87.6429%、实际集合投影66.6617%。

## 固定输入与方法

冻结764张合法源图、几何、原生特征/query编码、条件化身份筛选结果和评价协议。读取已有SAM区域与原生描述符，不新增VFM调用，不使用目标RGB或GT生成预测。实际集合与语义响应都重新求解，不能用其中一个输出的收益替代另一个。

候选一将不明确的包含区域设为unknown：检测区域匹配原生区域IoU至少0.5；父区域覆盖至少90%的检测区域、面积至少为其1.25倍；选最小符合者。结构对照直接弃权；语义对照额外要求父区域的原生query cosine不低于匹配子区域。所有正证据保留，unknown只撤去排除证据，不新增前景。

候选二沿用同一关系与语义判定，但把父区域作为范围补全正证据，与原检测取并集。关系比较在96×128进行；实际父掩码从原SAM掩码采样至192×256，保留已有正证据和身份拒绝unknown。它检验“缺少正范围能否通过原生语义偏好补齐”，不声称cosine是范围真值。

集合拟合维持192×256四相位采样、balanced loss与footprint prior；最少240步，figurines因源帧数实际293步，其余240步。响应使用固定可见贡献融合。没有改变阈值、几何或目标标签。

## 原因定位：正证据本身也需要区分身份与范围

先查看合法源图的首/中/末检测视角，再在预测完成后查看目标标签，仅用于解释错误。coffee源掩码主要覆盖液面，而目标标注覆盖白杯；集合还响应了另一只茶杯。带泳圈鸭子的预测同时覆盖戴帽子鸭子。前者混有范围不足与身份误认，后者有明确的相似对象混淆；不能都解释为错误负例或几何缺失。

随后对全部67查询、两种输出统计源正证据到目标错误区域的传递。该诊断复现原208个视角的语义IoU最大误差2.91e-8、集合IoU误差0。查询内像素汇总与官方逐视角平均分别保存，不混报指标。

- 语义漏检像素中40.93%落在没有任何原始源正见证的投影支持区域；洋葱片、sake cup、kamaboko、书名等很明显。仅改变后端负例无法凭空补入目标身份。
- 语义漏检的44.93%、集合漏检的76.00%在本诊断中仍有正见证：至少存在一个源视角，使相关元素多数可见贡献落在正掩码内，但最终未召回。它们还可能涉及相互矛盾的范围、投影混合、优化和硬选取，不能宣称都由某一环节造成。
- 鸭子、coffee、corn的误检区域也有大量源正见证。因此“多个视角支持”不能作为独立正确身份证明；传播可能稳定传播错误。

以上比例按所有错误像素汇总，不是场景宏平均、不是因果责任百分比。正见证是教师证据，不是真值；Gaussians有空间范围，弱贡献或混合可以产生假支持。实际集合的支持追踪使用全场可见算子，取走非成员后的可见性不同，尤其不能把“无可见支持”直接当作不可重建证明。几何有投影支持也不证明边界或独立三维形状正确。

## 方法结论与下一步边界

本轮直接否定了两个过强假设：仅撤去包含区域的负证据足以解决当前瓶颈；父区域与文本更相似就有权扩大对象范围。原生相似度混合身份、上下文和整体/部件信息，不能同时充当三种判断。

下一阶段需要分别提供：未检测概念的新增身份候选；同类相似实例的独立区分证据；与身份分开的对象/部件范围选择依据。候选发现不再由任意数量上限提前截断，但新候选必须由同样证据下的简单基线共同消费。只有独立部件/边界证据支持的范围推理值得进入下一次机制对照，不继续把区域面积、包含关系或cosine门控串得更长。

先固定这些证据的来源与可证伪判据，再做完整队列与未调参场景评价。当前已挂载LERF标注目录只有反复使用的四场景，源视图留出不能冒称新场景。SOTA/投稿门槛仍未通过：公开协议比较、独立三维评价、同地图四query精度与紧凑化仍待完成。NVOS86.4891%是先前成绩，本轮没有新NVOS/ScanNet收益；UQIS继续暂停。
