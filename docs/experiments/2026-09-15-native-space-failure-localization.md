# 特征场低分分层定位（2026-09-15）

结论：当前最明确的损失发生在原生视觉语言能力进入学习后的紧凑匹配空间时；有限粗类别监督与几何聚合不能自动保护细粒度查询。几何不是已证实的唯一或首要解释。此次仅诊断，没有训练/替换场，也没有把目标图像或GT写进部署地图。

## 1. 排除几何和定位：给定真实目标裁剪的类别识别

固定同一批图像、原生编码和类别候选，仅改变特征投影，统计正确类别Top-1。GT类别并集mask、bbox外扩3像素；masked外部填灰127。此实验使用目标GT裁剪，是有特权的识别诊断，绝不是召回IoU或部署成绩。

|场景|原生1536维|当前学习64维|随机64维（5种子均值）|源输入SVD64|源输入SVD128|
|---|---:|---:|---:|---:|---:|
|figurines|83.9%|23.2%|33.9%|69.6%|78.6%|
|ramen|88.7%|42.3%|25.6%|77.5%|78.9%|

SVD只使用原有训练词表和训练视角图像query，不使用目标特征/标签拟合。等64维SVD显著优于当前适配器，直接排除“64维必然只能达到当前水平”的说法；随机投影维度越大总体保留更多能力，故也不能说维度完全无影响。
未masked、同bbox的控制同样退化：figurines原生87.5%→当前26.8%，ramen原生67.6%→当前26.8%，不是某一种裁剪填充方式单独造成。
这还不能量化“训练相比精确初始化造成多少遗忘”：没有保存该模型精确初始适配器；随机投影是结构对照，不冒充其训练前权重。

## 2. 固定query-free裁剪特征的二维、几何融合与适配器分层

训练和目标均用固定6×8网格、1/4及1/2图像范围的未masked crop，不按GT选位置；同格两尺度描述归一化均值。源特征经冻结高斯贡献加权平均后归一化，不优化任何地图。两种原生融合表示只是临时诊断，不是新增正式持久特征场。
所有方法使用相同目标帧、480宽度、全正标签分母和冻结场有效支持。前两行读取目标RGB，只是二维诊断；源融合与学习场不读取目标RGB构图。比较AP排序，原生余弦未经绝对membership标定，不能把其固定0.5 IoU为0解释为原生模型没有能力。

|场景|目标原生二维 AP|目标经适配器 AP|源原生融合 AP|源融合经适配器 AP|学习场 AP|
|---|---:|---:|---:|---:|---:|
|figurines|0.2333|0.1039|0.3208|0.0950|0.1767|
|ramen|0.1672|0.1767|0.1616|0.1835|0.2581|

figurines原生源融合排序优于当前学习场，适配器在二维和融合后都明显损害该对照。ramen学习场优于粗网格原生特征，适配器在该粗网格上反而略有帮助。因此不能把不同场景所有误差都归于适配器，也不能把粗裁剪参考当作原教师定位能力的上限。
原生二维与原生源融合的差异同时包含视角证据、裁剪上下文、多视角融合及几何，不能把它们的差值纯称作几何误差。这里只能确认冻结几何路径没有必然摧毁所有原生语义。
已有学习场逐任务IoU/AP/AUROC在新脚本中逐项复现，最大误差<1e-6，排除此次分层对照使用了另一个学习场评估口径。

## 4. 已定位的机制与修复优先级

1. 原生教师确实包含大量当前场未保留的细粒度识别能力。关键问题不是“教师完全不认识”，而是压缩/适配、源侧局部特征承载、跨视角监督共同未保持它。
2. 当前老师重建是 D(z) 对齐教师特征，查询是 normalize(Wq) 与 normalize(z)匹配。D和W是独立参数；低重建损失不等价于 q 与 D(z)的原生匹配被保留。默认候选的原生query-region关系约束未启用，普通教师头损失不直接约束query适配器。有限14类硬监督无法替代开放词汇能力约束。
3. 原生crop识别高，但粗网格定位AP低，说明“类别方向正确”和“完整对象、部件边界写到正确元素”是不同问题。ramen的这项空间/粒度问题尤其突出。图像/提示仍主要受旧区域对应伪标签监督。
4. 下一步应先建立原生匹配响应可验证的场重建控制，并对源侧query–区域区分和保留能力设门槛；再逐步允许适配器变化。任何查询变换改变都必须与场重建共同验证，不能把SVD矩阵直接塞进现有场。
5. 源SVD64只证明较好的压缩方向存在，并未证明固定SVD足以修复场。此前固定基场训练已失败过，不能重复当作新解决方案。需要同时检查教师解码、元素特征和query匹配的空间一致性。
6. 在原生能力保留控制通过后，扩充来源可验证的细粒度文本、部件/对象范围及跨视角身份监督；未知区域继续弃权，不能为了提升训练分数把未知都标成负例。

## 5. 验收边界

没有修改既有模型、几何或训练监督。目标RGB/GT裁剪缓存明确标记 privileged_oracle_diagnostic_encodings，不能混入源训练或冷启动推理。仍需独立定位几何边界误差、原教师掩码质量和真实跨视角实例对应；本轮未完成正式历史同合约回归或三维GT评估。
原生源融合是高维诊断控制，不是已满足单紧凑场预算的候选。随机维度对照仅为识别诊断，不对应新的场训练或最终IoU。
