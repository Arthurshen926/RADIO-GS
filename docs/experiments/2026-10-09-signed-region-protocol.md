# 显式正负支持共同条件化：固定八例功能对照

本轮检验“在区域关联阶段处理显式负支持”和“各自解码后相乘”的区别，不把
该假设称作v10 RGB提示扩展的等价迁移。v10的成功经验是按当前提示确定目标
范围；本实现只在场内已有来源区域上表达这一条件作用，禁止源RGB/掩码访问。

固定confidence_mixture_functions_v1的7份NVOS场与全部8组原始正负提示、
原相机、尺度、几何、渲染、阈值。保持旧120来源预算与旧来源分辨率不变，
不把新增123缓存混入本对照。无训练、新监督、参数搜索、场状态或默认修改。

三个固定条件：parent；joint_unsigned；主方案joint_signed。
先用未加来源区域证据的共同成员计算原正负乘积prior。现有confidence mixture
分别产生区域系数a+与a-；joint_unsigned使用a+，joint_signed使用max(a+-a-,0)。
不在排除后重新归一化，不把未知变负例。用同一Gaussian区域矩阵收缩正／排除
质量p,n，再按已有有限证据公式(prior+p)/(1+p+n)读出。两个新条件仅相差区域
系数相减；parent比较同时改变融合顺序，不能单独归于相减或新表示。

无负支持时正式接口保持原查询精确不变。明确正3D元素仍遵守原约束；2D射线
保持不确定关联。范围不再由语义分数限制，但此处尚未新增跨视图身份监督。
这仍是条件函数假设，不承诺恢复性能；v10正提示经源RGB/SAM扩展的参考成绩
86.5134%与当前原始正负输入的契约不同。

全部24预测封存之后才读取任何目标标签。原评分器报告连续响应、实际选集
重渲染IoU与精确率／召回，并记录正负提示覆盖、区域证据激活／被排除质量。
此前标签已被研究使用，不是独立最终测试。保留全部失败、不按场景择优。
新接口至少完成一场复制导出、独立进程、禁止源目录打开的回放；明确覆盖限制。
