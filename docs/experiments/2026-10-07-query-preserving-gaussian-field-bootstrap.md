## 已实现的边界

一个 Gaussian 场持有 SigLIP 原生语义坐标、DINO 局部坐标和可训练 group 坐标。
原生通道作为固定 buffer，分组训练不能改写它们。仿射压缩接口已实现精确配对的原生查询公式，
包括解码偏置和范数，但本轮没有训练或宣称紧凑学生。

文本、图像、2D 射线和注册 3D 点均进入同一个尺度条件成员函数。文本/图像保留多个
空间分离的身份候选，目前返回 MAP 假设；这还不是完成了关系语言绑定或不确定性校准。
图像查询保留局部 patch，不声称已复现 v10 的双向完整 patch 匹配。
真实注册 3D 正负元素可以施加硬约束；估计身份和 2D 射线只提供软证据。

部署包仅包含 Gaussian 几何、场坐标和解码参数。SigLIP/DINO 查询编码器是另外计费的共享
依赖。源图像、SAM 缓存和投影观测只用于建图、训练和外部评估，不进入标准查询路径。
目前 category partition 是完整候选词表上的原生语义对照；结构增强类别竞争仍待实现。

**关键限制：**原生特征写保护只证明分组阶段没有损坏已有坐标，不能证明初始化时的多视图
平均保留了教师的全部检索能力。本轮是高容量 B0 和成员机制实验；真正的查询保持蒸馏、
局部对应保持及后续压缩仍需独立验证。

## 固定数据和评价口径

场景为 figurines，使用当前 v10 的 554,467 个 Gaussian，而非早期 274,805 行缓存。
特征训练视图固定为 11/49/127/174/222/269，开发视图为 69/232；投影分辨率固定 96×128。
建图仅使用原生 SigLIP、DINO、query-free SAM，没有额外 3D 实例标签、benchmark 文本或答案。
242,262 个 Gaussian 获得训练特征观测。几何来自更大的既有映射集合，因而这里只是
**特征视图隔离**，不是几何训练视图隔离，也不是独立最终测试。

评估包含两个开发视图的全部 169 个 SAM 区域。点位置由区域内部最近质心像素确定，
不根据模型成绩挑点。3D 点取该像素的主贡献 Gaussian，属于关联诊断，并非人工标注的
完整实例。14 个 3D 点缺少训练观测支持，仍以零 IoU 保留在分母。区域图像诊断使用
掩码 crop 的 SigLIP 描述和最多 16 个均匀采样的区域 DINO 像素，不等同于真实外部参考图像测试。

两类输出分别统计：

1. 完整场景的归一化 alpha 加权成员概率图，阈值 0.5。
2. 成员分数超过 0.5 的 Gaussian 子集，移除其余 Gaussian 后重新计算透射率，alpha 阈值 0.5。

下表使用训练区域物理尺度的中位数作为默认尺度，没有读取开发目标尺度。
另存的 `teacher_scope` 结果属于已知目标范围的特权诊断，不能当作自动尺度性能。
本地既有 LERF 子集评估使用不同的历史 alpha 阈值（8-bit alpha > 10）；本轮数值不能
与该 benchmark headline 直接比较。

## 三个实验与结果

第一轮 200 步及其帧、分辨率、32D group、优化器和阈值先于新结果固定。
随后发现 489 个可训练区域尚未充分覆盖，固定了一个 2,000 步预算对照。
最后基于历史 next67/68 的已知结论，做同样 2,000 步、只改变训练渲染目标的对照。
后两项是看过首轮开发结果后的实验，不包装为独立预注册测试。

实际选中 Gaussian 子集重渲染 IoU，百分数，全部 169 区域均计入：

| 共享成员模型 | 2D 点 | 注册 3D 点 | 区域图像诊断 |
|---|---:|---:|---:|
| 未训练的 DINO 随机投影 group | 10.88 | 10.92 | 8.75 |
| 完整场景成员图监督，200 步 | 12.17 | 12.21 | 11.23 |
| 完整场景成员图监督，2,000 步 | 11.02 | 10.54 | 10.41 |
| 子集 alpha 监督，2,000 步 | **26.46** | **25.24** | **19.56** |

最后两行保持相同模型、原生坐标、数据、随机种子、训练区域抽样、学习率、训练步数、
默认尺度和评估阈值。两者均抽到 489 个可训练区域中的 485 个。
这是一个训练目标的匹配对照，不是把旧系统的逐查询 source-assisted 求解器搬到推理阶段。

完整场景成员图 IoU 则呈现不同结果：

| 模型 | 2D 点 | 注册 3D 点 | 区域图像诊断 |
|---|---:|---:|---:|
| 未训练 | 19.64 | 18.49 | 12.38 |
| 成员图监督，200 步 | 28.47 | 27.78 | 20.06 |
| 成员图监督，2,000 步 | 26.69 | 25.86 | 20.34 |
| 子集 alpha 监督，2,000 步 | 25.79 | 16.42 | 10.22 |

因此不能宣称所有输出同时提升。子集监督提高了本轮关注的真实集合输出，而归一化成员图
可以退化；受保护的原生 SigLIP/DINO 坐标仍然逐元素不变。这也是语义响应与集合解码必须
区分的原因。

预算对照的固定训练成员图损失从 0.3322 降到 0.0828，但开发子集效果没有改善。
单纯延长该目标的训练不是当前解法。子集目标在不修改几何、基础 opacity 的前提下，
通过当前查询的软选择概率重算 alpha，并允许所有已有观测的 Gaussian 接收梯度，
包括在完整场景中被遮挡的部分。实际部署仍进行硬选择与子集重渲染。
训练中软选择及 gsplat 裁剪是近似梯度，不是离散集合的精确优化器。

这沿用了 [next67](2026-09-30-subset-visibility-support-next67.md) 的可见性修复，
也遵守 [next68](2026-09-30-source-admission-and-dual-observation-next68.md) 的负面结论：
没有未经对照地叠加两个渲染目标。旧实验结果与本轮不能按数值直接横比，但机制可以迁移。

## 投影、部署和验证

开发视图 69/232 的平均已观测射线贡献分别为 94.81%/88.70%；两幅完整场景 alpha 均超过 0.5。
因此 alpha 太低或完全不可见不能单独解释首轮落差。
使用开发掩码做特权单视图回投影，全部几何/仅已观测几何的实际子集 IoU 为 52.10%/51.29%。
该控制既不是可部署方法，也不是严格的最佳可能上界；它只说明该载体能表达显著优于当前
学习结果的部分目标，不能证明错误全由某一个模块造成。

每个高容量导出文件为 2,657,563,621 bytes（约 2.66 GB），语义增量张量
2,626,510,315 bytes，几何张量 31,050,152 bytes。后续四倍压缩目标应针对匹配的语义增量，
另报共享编码器、几何、加载和输入编码成本。
开发评估峰值 CUDA allocated 约 2.86 GB；不含外部并行作业、CUDA allocator 全部保留内存、
查询编码器加载及建图峰值。

17 项定向测试通过，包括实际 gsplat CUDA 回归：移除前方 Gaussian 后，原先隐藏的成员能
重新贡献 alpha 并收到梯度；软渲染在 0/1 选择处与硬子集相符，几何 buffer 不变。
其他测试覆盖仿射查询公式、写保护、未知区域无梯度、带权射线、注册正负约束、完整候选
类别竞争、篡改拒绝和完整评估分母。

真实原生文本、图像及两种注册点输入通过独立进程重载；导出文件复制到临时目录后查询，
禁止打开原 output 和对应场景图像目录，四种输出分数与集合摘要逐位一致。
这是 Python 文件打开审计和实际接口检查，不是 OS 安全沙箱或身份准确率评估。
查询输入编码与 2D 注册耗时不包含在 `results.*.seconds` 的场读出计时中。
SigLIP 1152→1536 投影头恢复沿用已有严格加载器；未使用忽略尺寸错误或随机头替换。
