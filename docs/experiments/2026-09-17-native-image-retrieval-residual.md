# 从区域特征拟合到实际图像召回监督

结论：**将源图像查询通过部署时的元素匹配和渲染路径监督，确实比只拟合区域平均教师特征更有效；但把图像监督的修正无条件共享给文本，会损坏文本召回。** 新开发候选只在 image 读出使用该修正，保留文本和注册点提示路径。它没有增加元素特征表、修改几何或重新学习 query adapter，也不代表统一开放词汇空间已经解决。

## 对照和结果

保留完整控制：`preserved_source_inventory_20260916/{scene}/exact_render_query_threshold96`。
新候选：同根目录 `image_supervised_native_residual`。原控制没有覆盖。

下表均为同一参考查询子集：figurines 35、ramen 57 个目标观测，百分比；不是完整文本 56/71 个观测，也不是独立最终 test。

| 方案 | figurines image IoU/AP | ramen image IoU/AP |
|---|---:|---:|
| 保留完整控制 / 残差强度零控制 | 33.12 / 54.52 | 13.81 / 34.21 |
| 源区域平均特征拟合，原有校准 | 32.27 / 55.01 | 20.88 / 41.39 |

|---|---:|---:|---:|

## 实现和监督合约

每个元素仍只有原来的 96 维向量。固定原生解码器给出 `b = D_native(z[:64])`，新增全局线性头给出 `r = D_residual(z)`；按元素约束 `||r_clipped|| <= 0.25 ||b||`。图像 query 与 `b + r_clipped` 在原生1536维空间计算精确余弦，文本继续读取 `b`。该约束限制偏转幅度，不保证所有 query 的排序；原始向量保留不等于修改后的语义能力不退化。

实现通过扩展紧凑坐标和 Gram 形式计算分母，避免持久化第二张高维元素表；近消去情形分块直接计算。新增全局参数为 1536×97 = 148,992；元素存储不增加。text/image 不再被描述成完全相同的最终度量，而是共享原生基准、各自有明确监督边界的读出。

第一阶段以源区域平均 latent 重建原生源裁剪特征，用固定 ridge/强度候选和最后一个源训练视角选参数。两场景都选到相对界0.25，但图像结果不共同改善。重新校准也没有解决这一点。

第二阶段固定相同架构、相同 bound、全部原控制参数和校准，只训练全局残差头120步；实际前向为：

`源裁剪编码 → 元素原生余弦 → sigmoid → 固定像素贡献聚合 → 正负像素 BCE + Dice`

目标是源 SAM 区域完整掩码，使用原实际 observed/full-alpha 支持门控。每30步在同一残差拟合留出源视角检查 IoU，允许选择第0步。figurines 选择60步，验证 IoU 42.39→48.92%；ramen 选择120步，29.16→36.80%。**这些视角已被原冻结场看到，只是残差拟合留出，不是独立场景验证。** 监督是同视角源裁剪到 mask，不是已验证的物理跨视角实例真值。

## 正确性修复与边界

- 各 native 路径统一使用同一个精确余弦入口，避免普通 image fallback 绕过残差，而结构/text 路径使用残差的实现错位。
- 源直方图校准也必须读取部署时实际 native cosine，不能仍然单独解码旧基底。对不是纯 native cosine 的部署分支明确报错，避免拟合一个未被部署使用的分数。
- 支持显式 modality scope；未指定时历史实验保持 text/image 双模态修正，image-only 候选明确声明其范围。
- 检查显式高维计算等价、梯度、零锚/零初始化、强度零回退、行/query 分批、冷加载和 text/prompt 保留；原几何、原场及原范围/路由参数均逐张量相等。
- 旧 encoder 文件未修改，原 query 身份仍可冷加载。

## 对核心瓶颈的判断

这轮提供了更直接的证据：**源教师特征的重建指标不是实际召回监督的替代品，图像监督也不是文本监督的替代品。** 固定紧凑场仍可通过正确的匹配与渲染监督读取出更多图像区分信息，因此当前图像低分并非只能靠加维度、hash 或继续改善几何解决。

与此同时，文本的可靠粒度/范围监督与开放词汇保护仍未解决。当前候选保留既有文本流程，不能宣称修复了文本范围硬接管。独立 benchmark、同类多实例、2D signed prompt 约束、源视角选择稳定性仍需验收。
