## 发现：原生相似度最高的位置缺少成员训练支持

旧训练器从 SAM 区域内部、当前视图的主贡献 Gaussian 中采样正支持，并要求存在
同尺度、可见且不重叠的可靠排斥区域。推理则在所有有原生观测的 Gaussian 中取
最高 native cosine，两种支持域并不一致。

`support_audit` 使用训练视图的投影贡献和原训练规则重建曝光，不打开 benchmark 标签。
已有观测集合不作删减；像素贡献总量只是曝光诊断，不当作校准置信度。

| 18 视图场 | 已观测 Gaussian | 可采样的内部支持 | 文本第一锚点进入训练支持域 | 第一锚点曾是训练视图主贡献 |
|---|---:|---:|---:|---:|
| figurines | 380,715 | 22,671 | 0/21 | 0/21 |
| ramen | 452,765 | 28,261 | 0/15 | 0/15 |

所有八候选中，符合训练支持条件的比例也只有 2.98%/1.67%。
第一锚点的训练 alpha 贡献总量中位数为 0.000472/0.0000616，训练支持域内则为
2.968/2.413。它们来自同一固定 96×128 光栅，不能当作跨分辨率可比较的物理量。

原生特征归一化之后，极少量贡献仍可能产生很高的 cosine。因此“曾有观测”不能
替代“可作为已训练成员算子的推断入口”。这些是当前两场景的观察，不是所有高分
锚点必然错误的定理。训练可采样也不等于在 2,000 步中被实际抽到。

## 修正及架构边界

支持域严格复用原训练条件：在每个训练视图中，若区域有可信可见排斥像素，就收集
其腐蚀内部、可见、已有原生观测的主贡献 Gaussian，跨训练视图取并集。
开发视图、benchmark 文本和答案均不参与这个掩码的生成。

文字/图像：原生身份响应 → 在训练支持域内寻找原八个空间分离候选 → 原共享成员解码
→ 原 instance/union 规则 → 原阈值与实际子集重渲染。
注册 2D/3D 提示继续使用合法输入指定的支持，通过同一成员算子。

限制的是**推断输入锚点**，不是输出成员。全部已有观测 Gaussian 仍可被选中，
域外注册点不被重新定位到其他物体；推断锚点也没有新增“必为正”的硬约束。
保持原来的 0.05m 候选间距、八候选、0.02 并集 margin、默认物理尺度及 0.5 成员阈值。
本轮没有调半径、loss 权重、阈值或场景专属规则。

`CapabilityField.anchor_eligible` 是可选的保护 buffer。旧包没有该张量时重现旧行为；
新包将它与其他部署状态一起保存、计费和校验，查询不打开训练视图。
训练器与曝光编译器共用 `observations.training_episode`，避免复制后规则漂移。
新拟合可显式指定 `training.inferred_anchor_domain = "training_eligible"`；默认值保留旧对照。

## 双场景结果

在新结果产生前固定局部验收条件：两场景真实文本子集改善；区域图像均值均不下降；
原生文本响应和所有注册点诊断完全保持。它是机制开发的局部条件，不代表接近 v10。
全部新文本预测先于本轮评分保存，调用未修改的原历史 LERF 评测器。

| 场景 | 真实 LERF 实际子集，原→新 | 成员语义图 IoU，原→新 | 区域图像实际子集，原→新 |
|---|---:|---:|---:|
| figurines | 11.60% → 14.68% | 30.31% → 47.45% | 17.05% → 23.07% |
| ramen | 6.74% → 9.66% | 18.64% → 44.23% | 24.14% → 26.33% |

原生语义响应、AP 和语义 IoU 逐项相同；成员语义图改善不等于实际 Gaussian 子集
达到同样水平。新实际子集的像素精度/召回为 figurines 14.74%/97.84%、
ramen 10.20%/86.95%，仍然存在严重外溢。

两个场景全部 1,272 条点诊断行（2D/3D × 默认/特权尺度 × 全区域）对应的状态、
选集数量、成员图 IoU、实际子集 IoU、部分监督损失均精确相同。未支持案例继续保留。
2D/3D 默认尺度实际 IoU 仍为 figurines 31.63%/27.46%、ramen 31.72%/29.57%。

语义图和实际子集分别报告；真实 LERF 使用历史 8-bit alpha > 10，区域诊断使用
alpha > 0.5，二者不是同一指标。区域图像仍是 SAM masked crop 和局部 DINO 的诊断，
不是外部参考图像 benchmark；本地 LERF 子集投影也不是独立 3D GT。

## 第三个场景的固定验证

在前两场景局部检查通过后，选剩余 LERF 场景中按字母排序的第一个 teatime。
没有按结果选场景；它是新主干上首次构建，但整个项目历史上已打开，不能称独立最终集。
训练使用 18 个固定源帧和相同 2,000 步 subset-alpha 拟合，开发帧为 46/134，
训练特征帧排除所有公共目标帧。帧、学习率、尺度规则和两种部署条件先于新结果固定。
支持域在任何 teatime 文本预测之前编译，不使用参考预测作为输入。

载体包含 1,829,615 个 Gaussian，999,142 个有训练原生观测，可采样支持为 32,855 个。
1,115 个可训练区域中，2,000 步实际访问 923 个。训练函数总耗时 237.75 秒，包含加载、
固定诊断和导出，不含教师编译；没有因场景变大改变超参数。几何/原生通道保持不变。

| teatime 配对结果 | 原支持规则 | 训练支持域 |
|---|---:|---:|
| 真实 LERF 实际子集 IoU，14 个文本/59 个 query-view | 16.80% | 21.94% |
| 成员语义图 IoU | 44.84% | 58.94% |
| 区域图像实际子集 IoU，127 个 SAM 区域 | 19.89% | 27.77% |
| 2D 点实际子集 IoU | 30.57% | 30.57% |
| 3D 点实际子集 IoU | 29.41% | 29.41% |

原生语义 IoU/AP 保持 48.69%/83.26%。未支持的 2D/3D 点为 2/9 个，均保留为零，
没有筛掉困难目标。三场景方向一致，支持保留这个局部修正；样本仅三个历史开发场景，
不据此声称独立泛化或完整范围问题已解决。后续仍使用全部任务验收。

## 验证、成本与复现

22 项定向测试通过；提取共同训练条件后，受影响的 14 项回归再次通过。
覆盖源/开发隔离、未知区域、注册正负支持、完整成员域、旧包读取、新包独立重载，
以及实际 gsplat 可见性/梯度。三场景新包与原包的全部旧张量已逐元素核验一致，
三场景合计 1,780 条完整点诊断行也全部保持原指标。
本轮不把重复执行的测试相加描述成更多独立测试。

figurines/ramen 分别新增 554,467/592,709 字节的 Boolean tensor；文件增量略有
序列化元数据开销。场大小仍约 2.66/2.84 GB，没有取得紧凑性成果。
teatime 新增 1,829,615 字节，完整导出 8,771,178,420 bytes；没有省略较大场景的成本。
三个新包的四种真实输入均已从复制目录、独立进程、禁止打开原 source/output 的条件下精确重放；
测试详情见每个 run 的 `runtime_smoke.json`。这仍是 Python 文件打开审计，不是 OS 沙箱。

从 `/root/RADIO-GS-query-field` 使用现有 cybersim_agent 环境与 `PYTHONPATH=.`：

```sh
python -m radio_gs.query_field.support_audit --config configs/query_field/figurines_support_audit.json --output NEW_AUDIT
python -m radio_gs.query_field.support_control package --config configs/query_field/supported_anchor_control.json --job figurines --output NEW_PROBE
python -m radio_gs.query_field.support_control predict --config configs/query_field/supported_anchor_control.json --job figurines --output NEW_PROBE
```

重新执行需复制配置并更新审计目录、导出目录和参考预测路径，既有输出禁止覆盖。
`package` 的导出位置由 job 的 `field` 决定；`--output` 用于后续预测/评分根目录。
对配置内所有 job 先 predict，再逐一 score。teatime 原条件使用 `public_lerf predict`，
新条件使用 `support_control predict` 复用同一当前文本向量，两者都完成后才评分。

## 研究判断

保留这项支持构造修正和共同训练条件，作为可复现的实现进展。它定位了“无论原生峰值
来自什么支持，都直接拿去查询成员算子”的缺陷；仍不能解释全部成员外溢。
原生语义直接选集在前两场景的对照仍为 46.45%/25.42%，明显高于当前共享成员结果。
不以语义图提高或原生旁路对照代替统一集合输出的质量要求。

下一项机制研究应继续区分可靠身份条件下的真实成员外溢、训练软 alpha 与部署硬选集
之间的差异，以及跨视图同组/排斥/unknown 的覆盖。避免把本轮支持域修复扩写成对所有
affinity、压缩或三教师路线的肯定或否定；大规模压缩和五任务替换仍需更强的高容量参照。

原工作区检查发现 `paper/README.md` 及 `paper/journal_study_20261007/` 出现新的并行改动；
原分支、HEAD、暂存 diff 与 index SHA256 仍与初始快照一致。新论文改动原样保留，
本轮只提交独立工作树中的实现和记录，不能再把原工作区描述为所有字节均等于旧快照。
