# 查询身份与种子保持：固定2×2范围对照

本方案在native-region-appearance实验尚未评分时声明。已有证据来自上一轮：
种子补全46.6535%、旧条件扩展44.2876%；351次质量模型准入中108次没有原生
文本正响应。后者不是错误标签，也不能证明硬语义筛选一定有效。

固定采用原生448外观场，不根据第一轮新分数在448/full/旧外观中择优。原质量
森林、阈值、候选、可见性、几何、原生语义和强固定基集均不变。额外3D监督
条件同原森林（24个独立训练房间）。本轮不训练、不校准、不增加语义阈值。

两个因素：

1. 准入是否先要求候选通过已有native probability>0.5，再执行原质量判断和
   每视图竞争。先筛候选再竞争，避免最高质量但语义不匹配者挡住其他候选。
2. 是否保留已验证的完整种子补全集合作为基集，避免跨视图投票／同视图替换
   丢掉已有有效种子补全。实际成员是强固定集合、种子集合、获准scope的并集。

四组：unqualified_addition（00）、unqualified_seeded（01）、native_addition（10）、
native_seeded（11，预声明主组）。另保留frozen_visibility、seed_addition，共六组。
主组与seed_addition比较；完整报告两个因素及交互，不能仅比较较弱条件对照。
四场68文本全部预测、哈希冻结后统一评分实际集合的重渲染。沿用第一轮冻结
的语义响应；公共查询重算已有前三控制并要求集合精确保持。旧448条件输出
仅作为不改因素的冻结对照，不将重用结果伪装成重新预测。

领域限制：原生低响应也可能是同一对象的弱视角，硬筛选可能损失补全；原实例
模型仍存在测度偏移和部件任务不匹配。实验用于检验这些职责的合理组合，不能
凭代码形式宣称解决。查询只使用同一场张量及当前文本，无source RGB/mask/相机，
无逐查询拟合、答案表、GT准入或场景特判。当前实验自适应且开发场景重复，
不自动提升默认，不宣称五任务／独立3D IoU／论文结论闭环。
