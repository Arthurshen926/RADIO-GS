# 独立实例归属学习：必须保留准确的查询条件

状态：训练、确认验证、完整五项评分及固定范围诊断已完成；**候选不升级默认**。
默认仍为 `configs/pipeline/system_v8.json`。本轮引入了额外的
ScanNet 官方训练集三维实例标注，不能与无此监督的 v8 混称同一监督条件。

## 要解决的问题与实际实现

上一轮完整五项结果区分了范围外误检与对象不完整。本轮实际训练两类模型：
区域候选的归属质量，以及最终元素的条件归属。冻结几何与原生教师坐标，
没有重训 query 编码器，也没有用 benchmark 标签选择阈值、场景或查询路线。

第一个模型分别预测候选纯度、当前视角可见目标的完整度，以及候选在种子以外
新增部分的纯度。这样，大量正确重叠不能掩盖错误扩展。第二个模型直接预测最终
元素是否属于目标实例，以区域证据为输入，并增加池化前 DINO 到表面元素的投影。

初始第二个模型有一个方法缺陷：正点仅用于选择最小区域，后续元素模型丢弃了
实际点击位置。同一混合区域中的不同实例会获得近乎相同的输入，只有最后强制
选中点击自身这个元素不同。已修正为保留精确三维锚点、到锚点的相对位置，以及
表面元素与锚点的原生局部 DINO 相似度。区域现在提供上下文，不能替代点的身份。

该修正目前只训练了正点条件。研究模型对文本／图像返回“不适用”，由同一入口
继续计算原生身份与原范围，不把一个点监督模型冒充四种 query 都训练过的模型。
两类点共享同一个模型，2D 点仍只经相机几何转成锚点；查询时无 RGB、深度、SAM。
公开任务继续使用共同架构下原有的类别集合、类别分区和参考实例读出。

## 数据和实验边界

- 完整候选训练索引仍为 1181 扫描；本次明确是小规模方法实验，实际使用
  24 个拟合房间、4 个校准房间、4 个机制开发房间，每房间 12 个合成视角。
  训练／校准／开发房间不重合，排除现有评价房间及其重扫描。
- 合成视图只读取 xyz/RGB；SAM 区域、DINO 特征和几何映射的构建不用实例 ID。
  真正的实例标签只进入学习与独立评分。点云渲染存在孔洞，不能当作真实照片。
- 区域模型有 57,560 个拟合对、13,831 个校准对；新增元素精度目标在校准房间固定。
  最终元素模型有 887,126 个训练样本，每个实例取一个固定正点，以每类最多
  1024 元素的明确训练采样预算拟合，并用权重恢复类质量；推理不截断元素。
- 未标注点是未知，训练不作负例。内部机制评价统计全部已标注实例／元素，
  未标注选集另报，因此此处数字不能直接与 UQIS 主分数横比。
- 最终模型的决策阈值 0.30 来自四个校准房间，实际集合独立于 benchmark
  评分器产生。候选 benchmark 评分之前冻结模型，不做 query 或场景路由。
- 这四个机制开发房间已用于分析多个候选，不能再称为完全未打开的最终测试。
  另外四个按原房间哈希排序选出的确认房间，在最终模型冻结后才构建观测。

## 机制开发结果

四房间、125 个正点实例查询，所有目标保留；表中为房间宏平均，单位 %。

|读出|实际集合 IoU|纯度|覆盖|
|---|---:|---:|---:|
|原锚点共归属|24.569|39.891|43.933|
|最小区域＋原几何对应|25.020|47.280|37.304|
|学习新增区域质量，再投票|24.272|43.056|36.245|
|直接元素监督，区域统计输入|21.197|27.495|57.210|
|再加原生局部表面特征，仍丢弃锚点|21.233|27.307|57.538|
|**保留精确锚点与局部身份证据**|**29.081**|**45.843**|**49.230**|

最后一项相对原锚点增加 4.511 个百分点，四房间都提升；相对丢弃锚点的同局部
特征条件增加 7.848 个百分点。它说明保留查询条件是必要的，不证明紧凑化、
四 query 统一监督或公开 benchmark 的 SOTA 已经完成。

区域对层面，新增元素质量的质量加权纯度由几何规则的 64.95% 升到 77.35%，
但实际集合 IoU 没升。中间量变好不能代替实际元素选集变好。直接元素模型的
早期版本提高覆盖但牺牲纯度，也没有通过。

125 个点中，117 个在合成观测中可见，只有 95 个获得 SAM 区域支持；其中仅
42 个最小种子区域的实例纯度达到 80%，平均种子纯度 62.19%。原区域质量模型
只用较纯种子训练，其部署条件也因此不充分匹配。对不纯种子加更强投票不是解法。
目标表面可见覆盖为 94.17%，而种子一跳候选并集对目标的覆盖只有 63.13%；后者
是带标签的容量诊断，不是自动方法成绩。还有 22 个可见点因没有 SAM 区域而
无法启动当前学习头。这是明确保留的限制，不在本轮用 GT 或逐例规则绕过。

## 原生局部表面资产与代价

`pipeline.element_appearance_map` 用原地图的几何可见性，将池化前 DINO patch
特征累加到表面后归一化，另保留观测一致性和观测比例。构建只使用原来的
1107 张合法建图帧，没有新增源图、候选上限或 query 时图像访问。
九张 UQIS 地图新增 2851.435 MiB 数组，累计构建 150.763 秒；原 v8 数组另计。
这是一条高容量研究路线，不能称为紧凑部署完成。共享编码器、模型及训练数据
成本均不包含在此数组大小里。

## 真实五项任务的完整结果与最终决定

基线 `output/system_v8_membership_closure_20261005/summary.json` 完成 31 项；
候选 `output/learned_instance_additions/element_anchor_system/summary.json`
覆盖同一 31 项任务。40 项必要的新预测为 22 项公开任务共同对照及两组各九景
UQIS；公开预测共享发生在评分之前，规则覆盖所有公开任务，不按 query 或分数
筛选。两组都在各自全部预测完成后评分。

|冻结公开协议，%|本轮重跑|
|---|---:|
|LERF 语义 IoU|70.400676|
|实际 Gaussian 选集二维投影 IoU|66.967651|
|NVOS 正参考 IoU|86.513417|
|ScanNet 19/15/10 mIoU|61.011491 /62.527589 /72.486061|

相对上一完整重跑，LERF 选取投影 +0.004509 个百分点是重跑差异，不计方法收益。
UQIS 基线的四种读出排名和两种实际集合均逐元素完全复现。
LERF 选集投影仍不是独立三维真值；NVOS 仍是保留的正参考协议。

|UQIS，场景宏平均 %|v8 AP|候选 AP|v8 实际 IoU|候选实际 IoU|
|---|---:|---:|---:|---:|
|text|26.596|26.596|16.387|16.387|
|image|44.034|44.034|34.876|34.876|
|point_2d|52.745|**60.557**|**42.090**|38.292|
|point_3d|52.359|**60.457**|**41.524**|38.150|

原生语义、原锚点和原种子控制各自 268 份排名都完全保持，原种子选集也保持。
候选仅改变 130 个受支持点查询的排名与集合；文本／图像以及四个无区域支持的
点查询不变。没有把不同 query 的历史最优结果拼接进来。

2D 点纯度 **80.06→73.70%**，覆盖 **48.52→48.16%**；3D 点纯度
**80.35→74.86%**，覆盖约 **47.73→48.04%**。整体排序更好，却没有带来
更完整、干净的实际集合。四类查询共同 IoU≥0.5 的目标数从 7/67 降为 6/67。
所以不能只用 AP 增加约 8 个百分点宣布方法成功。

最后做了一个固定、无 GT 的定位对照：保留候选全部排名，每个点查询按本次地图
实时计算的原锚点选集数量选取前面的元素；并列按原锚点支持、再按固定顶点顺序。
没有输入／候选截断、阈值拟合或逐 query 规则。该思想在历史 next27 的 LERF
诊断中也用过；这里只对新的点排名测量“相同选择数量下是否更准”。

固定数量后的 2D/3D 点实际 IoU 为 **39.270% /39.188%**，仍低于 v8。
因此退化不只是全局概率尺度或选集大小：决策边界附近的具体成员排序也有问题。
这一控制不能预测完整对象大小，不升级为方法。结果在
`output/learned_instance_additions/fixed_extent_control/result.json`。

**决定：保留 v8，所有新监督头及局部表面资产保留为可复现研究条件。** 不把它们
默认启用，也不靠更多阈值搜索补救。训练和确认房间上的收益是真的，真实 UQIS
选集的退化也是真的；这说明当前条件归属模型尚未可靠迁移到真实观测。
不能仅凭这组实验把原因全部归给合成图像质量：视图密度、区域粒度、查询分布
和原生特征统计都在变化，现有证据尚未逐一分离。

下一阶段集中在一个验收目标：**相同真实观测条件下，直接监督并验证最终完整
选集的成员归属，保持精确 query 身份；同数量控制也必须超过原方法。** 优先补齐
独立训练房间的真实／匹配观测条件与完整范围监督，再学习集合读出。当前已修复
的锚点信息丢失不要回退；未知源区域仍不得自动作负例。可见点没有 SAM 区域时
无法启动、关系文本身份、完整部件监督和紧凑化依旧未完成。
