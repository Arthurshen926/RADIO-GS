# ADR0044：恢复区域来源，单独保存几何可见性

日期：2026-10-19。状态：CPU 实施；GPU 建场和端到端性能待验收。
承接 ADR0042/0043，不改变教师、输入权限、推理默认或各任务读出。

## 问题与决策

旧 ScanNet 编译场保留描述子和区域到元素的 CSR 算子，但没有区域所属源视图。
丢失来源后，公共核心无法可靠地区分同视图重复区域与跨视图独立证据。
区域贡献非零也只能证明区域支持，不能代替独立几何可见性。

1. 用只读、内容绑定的小型元数据文件恢复旧场的区域来源，不复制大型 `.pt`。
   原生场逐帧逐行核对半精度描述子；恢复原始 SAM proposal index，保留空视图偏移。
   辅助教师通过完整 CSR 算子、载体绑定和历史构建记录核对对应顺序。
   这不等于重新执行辅助编码器，也不证明历史原始掩码像素已重放。
2. 查询时显式声明 `native_observation_provenance={path,sha256}`。
   验证元数据、场的描述子／算子内容及场景视图顺序后浅拷贝附加来源；张量不复制。
   运行时不打开源 RGB、SAM 缓存或相机。缺失的可见性仍明确缺失。
3. 抽取 Gaussian 建场的公共区域贡献运算，保留原来的像素重叠分摊、稀疏乘法和累计顺序。
   注册地图继续使用视图均衡归一化，不能与 Gaussian 贡献质量归一化互换。
4. 新 Gaussian 建场可在 `shared_v1` 下显式启用 `--retain-visibility`，保存
   未乘区域掩码的渲染贡献质量，以及相机、分辨率与近远裁剪声明。
   空区域视图也必须渲染。该质量与语义支持质量分别保存；不自动用于负证据或新权重。
   旧场不从其他网格的命中记录补出此关系，新增存储与 GPU 代价待实际测量。
5. 教师替换编译器不再只比较区域总数：必须核对父场描述子和源顺序，并保留来源与
   任何已有独立可见性。替换后的场不得继承父场的旧描述子哈希元数据引用。

## 验证与接入

恢复后的配方保留原 31 个任务，只有 ScanNet 场景增加显式来源文件。
迁移队列使用此配方；历史 `system_v10.json`、大地图和权重保持原样。
预检同时封存主／辅助场景及来源文件；CPU 审计必须绑定实际执行配方。

CPU 检查包括：相同数量却错序、元数据／场内容被替换、空区域、完全遮挡、
可见但无区域支持、嵌套区域分摊、真实稀疏命中下的新旧算式一致。
完整性能仍按代表样本端到端、单模块对照、五项冻结重评的顺序验收。

恢复来源是后续跨视图机制的基础条件，不是新的准确率贡献。
