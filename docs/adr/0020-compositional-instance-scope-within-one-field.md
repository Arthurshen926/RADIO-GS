# 在同一Gaussian场内形成查询条件下的对象组合

状态：2026-10-09已实现并验证当前参考mask条件的初始组合解码器；原始稀疏提示的
完整组合、隐藏部分身份判定及统一五项验证仍未完成。
延续ADR0014/0015/0019，不改变三教师、单场、共享成员后验、标准推理无源访问。

## 证据

[完整结果](../experiments/2026-10-09-scope-and-composition-results.md)：独立取消区域
尺度门，正式实际IoU只81.4219→81.5047%，区间跨零且响应略降，不提升默认。
同一旧场中，GT辅助选择38/26个区域后，flower/orchids的192×256真实选集诊断IoU
可94.3884/90.7613%，远高于最佳单坐标29.4254/22.7552%。这是可行组合，不是
无标签推理成绩、全局最优或模型上界。不能将其宣传成性能已恢复。

## 方法边界与接口责任

保留局部能量用于身份关联和局部连续性；对象范围由独立的组合判定承担。
不再假设一个局部尺度或一个SAM坐标就代表完整对象，也不将全部关联区域无限并集。

共享场的未压缩能力参考可保留Gaussian行上的部分区域坐标、有效观察质量、视图
依赖及跨区域对应证据。它们是场内中间表示，不另起任务专用场，也不在查询时加载
源mask/RGB/tracks。当前Gaussian行的正负部分证据不自动等于完整实例排除证据。

查询适配器保留身份备选及明确正负输入的区别。组合判定应在混合区域之前输出：
哪些部分可共同属于当前对象、对新增部分的可信程度、与负提示的冲突及未知域。
同一组合再作用于共享Gaussian成员后验，2D响应与3D实际选集保持一致。
这些责任可通过显式部分区域和共享条件解码器实现；不预先假定应压缩成多少槽位。

v10的参考扩展/实例对应是功能参考。可在合法构建观察上检验跨视图实例关系和
新增部分判断的迁移，不能拿描述子相似度或训练收敛替代验证。SAM部分mask及其
任意并集不能未经验证当成完整对象真值。源轨迹伪监督需要说明生成条件与质量；
使用22-room标签/旧分类器则继承额外监督，单独报告。查询RGB/SAM扩展属于另列
输入条件，不能混入原始scribble标准轨。

## 验收次序

1. 固定旧来源，检验组合表示是否能容纳好范围，与无目标标签的条件接受分开。
   本轮只完成前者的可行性诊断，不能以此宣称后者有解。
2. 候选接受/新增部分判定采用合法源或独立标注条件，覆盖不完整身份、多部分、
   重叠、负提示冲突和未观察情形。记录输入/监督条件与失败，目标评测标签不得
   进入构建、选择、早停、推理或按场路由。
3. 查询到组合到实际选集完整链路固定后，完整八例对照；再进行统一五benchmark
   与UQIS四模态验证。已有单任务最高值不能替代共同方法验证。
4. fern/trex等组合诊断仍差的例子分别检查提升精度、候选族与来源容量，避免将
   所有问题硬归到同一模块。来源243视图统一是单独干预，不能与解码同时归因。

不部署GT辅助贪心，不以取消尺度门作为主要修复，不回到v10查询时源证据拟合链。
上述职责组织是否构成创新需要后续方法与证据支持，本ADR不宣称已完成论文贡献。

## 实施记录：当前参考条件与可见性

[两轮完整八例研究](../experiments/2026-10-09-reference-visibility-results.md)现已完成。
Runtime.reference_scope以当前mask在同一Gaussian场内组合部分，再输出统一Gaussian
选集；不调用v10源tracks/旧拟合链。两个mask条件明确继承现有参考RGB/SAM生成成本，
本轮仅迁移mask输入后的解码功能，没有重做RGB到mask生成，也不是raw-scribble成绩。

匹配同一mask输入，原局部射线核实际64.1988，组合84.8863；七例升/一例降。
保持整场可见性后响应82.0834→82.9221，但实际84.8863→84.3701，两升六降；
不提升默认，不拼接两个条件各自较好的指标。二值组合AP相对raw-signed八例下降，
必须保留这个限制，不能直接将其推广为全部模态的分级成员后验。

因此下一关键责任是参考不可见扩展部分的同一实例判定及实际边界，而非继续扩大
正集合或只优化参考拟合。可见形状相同不代表隐藏成员相同。当前按区域序号消解
形状等分只是固定复现规则，不是可信身份判断。新的对应功能必须有独立验证，
不能直接复用历史纯种子训练、最终集合失败的24-room区域头并宣称v10迁移成功。

## 2026-10-10：原生区域函数通过绑定，实例接受未通过

[四场五组完整实验](../experiments/2026-10-10-native-region-results.md)将原生区域查询
函数按原始索引编译入同一场，72既有源帧/5137区域，无新增训练/来源。
该函数与条件检测不是同一能力：响应55.3608→61.3865%，实际42.9498→40.8779%，
三场退化；不提升默认。共享P/N的保护单调性已经严格通过，但native保护使四场
Precision下降，说明应先验证被保护部分的身份，而非继续增强保护强度。

源教师一致性诊断显示，匹配源视图上检测辅助单区域/贪心组合可76.48/84.80%，
而原生接受并集44.57%。这是源教师诊断，不是目标真值、全局上界或完整3D可达精度。
下一因果对照应把源教师支持的接受插入相同场成员解码，并单列查询条件来源预算；
不能把该诊断当标准推理、把评测query答案存入场，或跳过功能验收直接增加训练损失。
空检测仍是未知，不能一律作为可靠排除。

同视图并集应与各部分加权竞争明确区分。场内max-positive/min-negative原语与
反例单测已实现，但尚未接入公共API或做benchmark；它和源像素并集并不严格可交换。
弱接受器下源像素并集四场均更差，故暂不优先跑更多下游组合变体。
不冻结一个已经退化的中间实现为最终架构；保留单场、三教师、类型化查询和一致
实际选集的约束，优先验证查询条件下的对象存在、部分归属与可靠负/未知判定。


## 2026-10-10：教师接受插入未恢复，成员解码必须独立验收

[完整四场七组干预](../experiments/2026-10-10-teacher-acceptance-results.md)保持
场、候选和来源不变，引入同视图 RAW v10 查询检测辅助选择。该结果是源辅助诊断，
不是标准部署路径；接受身份和二值置信度同时变化。实际基线42.9498、原生保护
40.8779、教师保护38.5247、教师并集保护37.3503%。主对照相对基线三降一升；
同教师接受下并集相对混合、保护相对不保护，实际均四场下降。不提升默认。

因此修订上一条优先级：仅迁移条件接受不足以让当前边际证据解码恢复性能。
下一阶段必须把组合表示和实际成员集合解码作为独立可替换责任，不继续将当前
逐Gaussian有限P/N更新固定为最终架构。v10具有成员opacity控制下的轮廓目标与
footprint支撑代价；当前更新没有该功能。此代码差异需要独立迁移验收，尚未证明
是唯一因果，不能跳过相同预算的精确并集提升/联合解码对照直接训练更多头。

主组42.56%所选Gaussian无正部分证据（场景内查询平均后宏平均，含12无支持查询）；
这不是错误率。先验、可靠负、未知、正身份必须区别表达，既不将未知当负，也不
将正相似度自动当完整成员资格。标准推理仍只用单场状态与当前查询，不重启源链。
本轮审计、共享证据单调性、全查询支持重放已通过；功能性能未通过，完整五任务
与论文核心贡献闭环仍未完成。该决定调整方法职责，不宣称新联合解码已实现。
