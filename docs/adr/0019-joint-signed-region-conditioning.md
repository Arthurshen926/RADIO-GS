# 在共同条件函数中解释显式正负支持

延续ADR0014/0015；实验性新增Runtime.signed_regions，不提升默认，不改变三教师、
单Gaussian场及无源推理核心。上一轮入选保持只限制不可信排序加分，不能替代
完整范围推断。本轮直接处理明确的正负空间输入，允许现有场内部分区域决定范围。

正、负提示是同一目标的约束，不必分别视作两个完整对象并在结果末端相乘。
新增固定对照将来源区域候选接受质量放到共同正负条件下，未知仍弃权，
排除的候选质量不重新分配给剩余候选。共享原成员先验与相同有限证据读出。
这并非v10源RGB条件分割的完整等价功能，也不宣称六项统计或额外监督已迁移。

见[八例固定协议](../experiments/2026-10-09-signed-region-protocol.md)。先固定旧来源
隔离函数变化；新补建来源的分辨率／生成契约统一为另一个干预。不得把这些
因素混在一个成绩里归因，或按benchmark选择旧求解器。

首轮24预测/8例完整评分否定了主要收益假设：实际IoU69.7200→69.6806%，
区域排除相对无排除对照只改变约0.000005pp。flower/orchids的正提示覆盖仍仅
41.58%/45.63%，与历史“负分支不是主要漏选原因”一致。不得据此添加负约束
权重搜索；该可选实现不提升默认。

下一可选接口Runtime.positive_rays保留正射线各自的条件能量，再按提示质量
汇合，仍使用同一基础成员函数和原负分支。分别固定公共中心和保留射线中心，
避免把多峰亲和与空间位置混为一项因果解释。无新增状态、教师或运行时源访问。
见[探索协议](../experiments/2026-10-09-positive-ray-protocol.md)。这一步仍不能
把正确能量汇合当作原成员函数已经正确或已完成v10提示扩展迁移。

正射线完整对照现已完成：实际IoU69.7200→79.4595%，响应61.8552→69.5949%。
公共中心控制已贡献8.9308pp实际IoU，局部中心另+0.8088pp但区间跨0，
不能把空间中心变化视为主要原因。保留单场和共同成员能量的调整成立为
探索性候选，尚不提升默认。正涂鸦覆盖恢复后orchids召回仍仅45.94%，
下一项责任是提示以外的区域覆盖与条件接受，不是继续强制正支持或追加负权重。
详见[完整结果与边界](../experiments/2026-10-09-positive-ray-results.md)。

随后完整八例阶段归因否定了整体移除区域或负分支的简单修复。orchids的
区域可覆盖98.77%，被当前正支持接受的区域仍可覆盖78.75%，最终召回45.94%；
覆盖并集含背景，不是模型能力上界。fortress尺度门使区域覆盖降到21.06%，
基础成员仍有98.86%召回，区域尺度不能直接当对象尺度。

允许下一显式正支持对照区分两类条件语义：多个身份备选是未确定的假设，
多个明确正涂鸦则共同定义目标的正部分。后者可检验逐射线成员的并集，
仍保留射线内部贡献不确定性和原区域/负分支。主对照保留注册像素的置信
质量，以max(c_r sigmoid(e_r))汇合，不按射线总数稀释，也不把弱射线变成
满置信。该读出未经概率校准，可能放大错误射线，必须完整报告精确率。
这不是把文字/图像身份备选全部视为确定正例的许可。见
[并集协议](../experiments/2026-10-09-positive-union-protocol.md)。

## 完整函数对照后的研究状态

五项顺序开发研究已完成，见[阶段总结](../experiments/2026-10-09-signed-competition-results.md)。
原型置信并集实际79.4595→77.4433%，不能直接采用。保留射线内部特征模长
恢复到80.5398%，空间方差仅另增0.0025pp；主要错误是过度归一化而非几何方差。
正负同核但独立乘法使fern正提示覆盖降到82.89%；相同能量使用既有正/负/未知
竞争恢复100%，最终完整八例实际81.4219%、响应78.0334%。

相对原local，响应八例均升，实际四例升四例降、精确率八例均降，不提升统一
默认。可信实例接受、部分区域的身份关联与实际子集边界仍未完成，不能继续
靠放大正集合或加强负否决解决。图像/文字身份备选的条件语义也不得被改成
全部确定正例。候选保持单场、同条件核、三教师职责和无源推理。

下一阶段应检验区域/嵌套假设本身的对象可辨识性、观测统计到共同成员判定的
功能迁移，并单独补齐来源与输入契约；全区域并集的高覆盖不是实例上界。
所有算子均为研究候选，不能仅凭已有公式组合宣称新颖性或完成五项统一方法。
