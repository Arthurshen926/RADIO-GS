# Verify relation functions before compact relation learning

Status: research implementation under the user's2026-10-09 steering. No
performance promotion. Refines ADR0014 without reverting to the v10 architecture.

The next capacity reference may store uncompressed, source-indexed sparse
positive/exclusion coordinates on the Gaussian rows, with physical scales and
view groups for dependent evidence. Their purpose is to compare the function
computed from legal source observations with the function available from one
exported field. Images, raster masks, cameras and source feature banks remain
absent at standard query time. The initial source-only reference also excludes
the labelled v10 classifier. The later declared decision-transfer condition below
explicitly permits its function as compiled field tensors, with its existing
extra supervision reported; changing the storage format does not remove that
classifier function or turn it into a source-only method. This is expanded scene
state, not compression, and packaging by itself does not establish innovation.

The first reference preserves a specific partial support-to-element function:
weighted support association, scale compatibility, within-view normalization,
and separate positive/negative Gaussian mass. Unknown contributes neither.
Direct source replay combines raster masks before geometry transfer; runtime
contracts precompiled Gaussian codes. Check numerical equivalence before any
benchmark query or optimization. Complete v10 co-visibility/disagreement features
and its supervised membership decision are not claimed equivalent.

The existing protected rendered member is one fixed prior observation; the
same finite-evidence update is used inside the common member function for all
typed inputs and signed supports. Native identity and category competition
remain paired with their existing spaces. Evaluate all five tasks, including
actual selected sets, and retain the full export cost. This reference tests
whether added relation function capacity is useful; one interpolation rule
cannot separate evidence quality from decision quality by itself.

If the reference improves, subsequent learned representation must preserve
its conditional outputs on disjoint source queries, not merely its vectors.
If it fails, compare evidence availability, partial labels, support conditions
and decision calibration before blaming the one-field core. Native text/crop
functions, complete-carrier supervision and source/input budget differences
remain separate capability-transfer requirements. No per-task winner routing
or default change is implied. See the[fixed protocol](../experiments/2026-10-09-paired-function-protocol.md).

## Source-only coverage extension

The first reference is complete at f13f0ec. Its replay succeeds but the full
cohort does not recover performance; LERF selected-set projection regresses in
all four scenes. The second reference was fixed BEFORE first-arm predictions
from source-only availability counts. It retains the hard association matrix A
exactly and changes only target matrices B+/B- to confidence-weighted nonzero
projections. See the [extension protocol](../experiments/2026-10-09-soft-paired-function-protocol.md).

For support weights s, derive region association from A-transpose s, apply the
fixed physical-scale/admission gates, then normalize within each source view
to obtain a. Positive and exclusion masses are B+ a and B- a. The independent
source replay computes each transfer T times (mask matrix M times a), while
the exported field evaluates (T M) times a. Associativity explains the intended
equivalence; deterministic point/weighted source cases test its implementation.
This does not prove that the teacher regions represent complete instances or
that the subsequent finite-evidence decision is calibrated.

Record three separate failures: association does not admit evidence for the
current support; admitted evidence misses/contradicts the target; decision or
typed composition misuses available evidence. Larger B coverage cannot repair
a zero association vector. Uncertain supports also require checking whether
unknown observations dilute admission: averaging support coordinates before a
majority gate need not preserve the decisions of individual supported rays.
Do not quietly substitute a new support operator during the target-only control.

Full v10 jointly visible, any/all-mask and granularity-disagreement functions,
local patch distributions, and complete-instance supervision remain outstanding
capabilities. The reference is allowed to expose those omissions; passing a
partial replay does not discharge them. No model promotion follows solely from
more available rows, more export bytes, or any source numerical check.

Both studies are now complete; see the [full results and attribution](../experiments/2026-10-09-paired-function-results.md).
All eight NVOS signed inputs have zero admitted relation coordinates before
scale gating and exactly unchanged parent outputs. Nineteen of59 correct UQIS
point supports admit no view. Soft target availability rises substantially but
does not repair support admission; extra evidence also increases false selected
vertices. The next support-function design must distinguish unavailable evidence
from reliable opposition and validate the actual uncertain/signed inputs. Do not
interpret the completed source pseudoquery replay as that missing capability,
or silently claim this partial reference has completed the full-capacity B baseline.

## Support-function intervention

The next intervention changes support lookup while retaining the completed soft
reference's entire tensor payload. Positive/exclusion evidence is interpreted
per support component, before a confidence-weighted, within-view association is
mixed over the current query. Unknown components abstain; conditional positive
majority does not turn tiny known mass into a full view. The existing scale gate,
target coordinates, finite-evidence member update and all typed readouts stay
fixed. This is a declared composite association change, not an isolated causal
test of each constituent operation. See the [fixed protocol](../experiments/2026-10-09-mixture-function-protocol.md).

The diagnostic joint-statistic operator now reproduces all six v10 observation
statistics in a tested binary/complementary-visible-exclusion limit. Real partial
soft observations have weighted known mass and are not claimed to reproduce
v10 visibility or its supervised membership decision. The finite-evidence
decision remains a hypothesis. Source replay now includes actual full rays;
real signed inputs and all point queries must still pass separate task audits.

The first mixture intervention was stopped before any scoring after a source
counterexample showed vanishing regional confidence could borrow another
region's view confidence. The [corrected protocol](../experiments/2026-10-09-confidence-mixture-function-protocol.md)
uses p, not p/(p+n), as within-view preference. Its full study is now executed;
see [results](../experiments/2026-10-09-confidence-mixture-results.md). Actual
support activation improved but selected-set performance did not consistently
improve. The original strict cold hash gate also failed; numerical and exact
selection replay are supplemental evidence, not a waiver or model promotion.

The complete-capacity reference is still outstanding. Source manifests expose
534 current training views versus3,286 v10-declared views; supervision and input
conditions differ too. Preserve legal query-independent sources and development
splits when removing the arbitrary20-frame cap. Mean native descriptors,32-D
groups and the finite-evidence update are revisable intermediate choices.
Joint visibility/any/all/granularity statistics must be consumed and tested in
the common member decision; binary primitive parity alone is not that transfer.

## Declared decision-function transfer

The next [factorial study](../experiments/2026-10-09-joint-observation-transfer-protocol.md)
compiles the real binary observation functions into Gaussian coordinates and
separates small/full legal source budgets from source-only/independently labelled
membership decisions. The latter carries the EXISTING22-room extra supervision,
declared under ADR0014; it is not a source-only claim. Forest nodes, thresholds
and leaf values execute as field-owned tensors, not a runtime old solver/model
loader. Native anchor response is collapsed into Gaussian moments with its norm
intact. Full local patch identity is still not transferred.

Native observation support and the member output domain are now distinct.
Complete-carrier decisions and valid registered points must not be silently
masked by the old native training coverage. Inferred native candidates retain
their original domain. All modalities use the same member function; source
assets remain offline. This focused study covers all9 UQIS scenes/all4 inputs,
following prior full five-task coverage. It does not replace the required future
five-task validation or establish novelty through repackaging exact functions.
