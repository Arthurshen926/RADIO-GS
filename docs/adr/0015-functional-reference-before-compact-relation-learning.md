# Verify relation functions before compact relation learning

Status: research implementation under the user's2026-10-09 steering. No
performance promotion. Refines ADR0014 without reverting to the v10 architecture.

The next capacity reference may store uncompressed, source-indexed sparse
positive/exclusion coordinates on the Gaussian rows, with physical scales and
view groups for dependent evidence. Their purpose is to compare the function
computed from legal source observations with the function available from one
exported field. Images, raster masks, cameras, source feature banks and labelled
v10 classifiers remain absent at standard query time. This is expanded scene
state, not compression, and packaging by itself does not establish innovation.

The first reference preserves a specific partial support-to-element function:
weighted support association, scale compatibility, within-view normalization,
and separate positive/negative Gaussian mass. Unknown contributes neither.
Direct source replay combines raster masks before geometry transfer; runtime
contracts precompiled Gaussian codes. Check numerical equivalence before any
benchmark query or optimization. Complete v10 co-visibility/disagreement features
and its supervised membership decision are not claimed equivalent.

The existing protected rendered member is one fixed prior observation; the
same finite-evidence update is used inside the common member function for all
typed inputs and signed supports. Native identity and category competition
remain paired with their existing spaces. Evaluate all five tasks, including
actual selected sets, and retain the full export cost. This reference tests
whether added relation function capacity is useful; one interpolation rule
cannot separate evidence quality from decision quality by itself.

If the reference improves, subsequent learned representation must preserve
its conditional outputs on disjoint source queries, not merely its vectors.
If it fails, compare evidence availability, partial labels, support conditions
and decision calibration before blaming the one-field core. Native text/crop
functions, complete-carrier supervision and source/input budget differences
remain separate capability-transfer requirements. No per-task winner routing
or default change is implied. See the[fixed protocol](../experiments/2026-10-09-paired-function-protocol.md).
