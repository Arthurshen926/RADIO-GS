# ADR0021：统一场内职责，按输入合同选择成员决策

Date: 2026-10-12

Status: Accepted as an architecture constraint; common five-task implementation
and evaluation remain incomplete.

## Context

ADR0020形成的范围、完整观察提升与所选集合光学仍有效，但把同一个自由
二值优化目标当作所有输入的必经路径，缺乏实测支持。允许架构为能力迁移
而调整，意味着需要保留已验证函数，不要求性能迁就某个中间求解器。

完整NVOS开发对照：原组合实际86.9550%，单R_set80.5259%，联合A_obs/R_set
85.7573%，有限改动86.8689%，候选许可86.7514%。最后一项不优于观测分层
匹配随机许可86.7721%或仅初值子集86.9143%，详见
[固定八例四条件](../experiments/2026-10-12-reference-proposals-results.md)。
这些结果不能证明统计等价或单参考方法全都不可行，但不支持继续强推此
自由优化器成为全类型主干。没有新训练或查询源访问可解释这些差异。

## Decision

1. **共同职责保持。** 一份Gaussian场拥有原生语义/局部对应证据及其空间
   支撑；当前合法类型输入在场内生成范围与成员结果。最终相同Gaussian
   集合或类别分区用于2D投影和3D输出。不能把v10源检测、连续拟合或答案库
   重新藏入查询路径，不能把未经确认的推断种子变成硬约束。
2. **优化公式可以不同。** 文字多视图范围保留已验收的A_obs、足迹、R_set
   及有限决策；单参考完整mask保留区域组合和完整场景观测条件化，后续
   自由增删、关联分组和候选许可均为研究对照。类别菜单保留竞争/互斥/void；
   图像保留原生patch对应；明确3D点保留合法提示约束。不得按场景选赢家。
3. **不凭“同一文件”宣称统一。** 当前这些路径仍有不同的成员实现，属于
   功能参照。共用API/存储不是主体空间归属已统一的证明。共同候选必须明确
   共享的空间支撑、原生证据、成员接口，以及各输入特有的选择/排除规则；
   完整输入到最终集合的验证不能由adapter名称替代。若主体仍是互不相干的
   旧任务求解器，就不满足共同方法的验收条件。
4. **恢复已有成功功能，而非重复建模块。** ScanNet完整菜单接口和UQIS全四
   输入已分别验收；复用已有语义测度与原生模式能力。其它场缺文字历史因子
   不代表必须全部重新编译这些因子。当前合法相机可从场几何实例化所需算子。
5. **按实际缺口收敛。** 暂停同八例NVOS的硬分组、候选域和代价扫描；优先
   完成文字条件定位、ScanNet类别条件空间判别及共同五任务版本的验收。
   新范围机制应对比仅检索、相同候选的条件重排序/定位和能力参照，并同时
   检查正范围、获准排除、未知及最终集合，不能以训练损失替代。

## Acceptance and consequences

本决定细化ADR0020中“共享最终成员决策”的含义，撤回将同一自由二值目标
作为全类型必经步骤的解释；不撤销同场、原生函数、合法输入和相同实际集合
约束。已有公共默认不变，负结果及此前严格数值失败保留。

五个本地benchmark按已有合同先跑全，不等待新增真正3D GT。LERF本地选集
投影仍如实标注投影指标；若论文声称真正3D精度，则需另有3D GT证据。
完整SAM mask条件与raw笔画分开；UQIS保留其22房间实例监督及3房间校准
来源账本。不能把这些不同研究的最优数值拼成共同新版。

当前机制贡献仍是三个待闭环命题：保留查询函数的原生证据测度、类型化空间
范围与排除许可、可验证的场内观测/集合函数。单一优化目标不是贡献条件；
接口封装、范围限制、浮点审计或坐标下降本身也不是独立创新。
须补共同版本、独立泛化及相近机制对照；不承诺本轮已经恢复全性能。
