# Separate Universal Field v1 from typed posterior readouts

RADIO-GS treats the D512/L512 factorized RADIO field plus five query-independent reliability scalars as Universal Field v1, while Primitive Readout-v0 remains only a frozen causal baseline. Final benchmark methods may use globally shared typed posterior interfaces, because forcing text extent, categorical rejection, and registered image prompts through one fixed-threshold formula caused large task regressions without reducing persistent scene state.

The promoted typed interfaces are:

- LERF text queries use an identity--extent posterior.  Field/SigLIP evidence
  owns identity and localization; source-view official-SAM instance membership
  owns extent.  Both outputs are rendered independently.
- ScanNet mutually exclusive categories use a bounded SAM-affinity residual
  only on low-margin categorical rows.  SAM never supplies class identity.
- NVOS and SPIn registered prompts may use protocol-authorized transient RGB
  and official SAM.  Box and signed-point hypotheses are decoded independently
  and combined after decoding; a joint box-plus-point SAM call is not the
  method because it failed the frozen promotion gate.

These readouts may create query-transient workspaces, but no second persistent
per-scene semantic field.  A candidate is part of the method only after its
predeclared full-cohort or fixed-transfer gate passes.
