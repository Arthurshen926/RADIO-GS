# Native appearance measures on one Gaussian field

Authorized by the user's instruction to revise intermediate architecture for
verifiable v10 capability transfer. Extends ADR0014's multiple native modes and
ADR0015's uncompressed functional reference; no default promotion or novelty claim.

Each native identity mode binds to the existing Gaussian relation-support column
and a query-independent Gaussian member nearest its coordinate-wise median.
Its semantic direction and weighted local native measure belong to the same
field.pt as geometry and the shared member function. The local measure computes
weighted bidirectional max-cosine; a mean vector is not a sufficient statistic.
All supported modes compete rather than first restricting identity to eight
spatially suppressed mean-feature Gaussians. Selected identity supplies an
estimated anchor to the unchanged shared member, never an exact positive.

The reference exports uncompressed source-derived appearance atoms. This IS
additional scene memory, and its origin and byte cost must be reported plainly.
No source images, masks, camera calibration, per-view patch raster/offset layout,
external feature files or old identity solver is loaded at standard query time.
Unsupported modes/atoms are removed; remaining mode measures share a field atom
table. This clarifies the previous ban on full per-view patch arrays: field-owned
geometrically bound multimode state is permitted; merely renaming an external
patch cache or claiming compression/innovation by serialization is not.

Also preserve the current-input function: v10 uses native crop dimensions and
fractional padding mass, while the intermediate encoder resizes to448 and loses
padding weights. Test this independently from retaining local measures. All
three arms share full legal sources, existing22-room/3-room member supervision,
and the previously validated geometric2D input. Complete all4 UQIS inputs; other
families still require one uniform subsequent study before promotion.
