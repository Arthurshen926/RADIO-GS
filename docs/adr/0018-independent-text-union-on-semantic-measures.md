# Independent text union through scene-owned semantic measures

Extends ADR0014/17. A category menu partitions a scene; a text union may select
multiple disconnected objects and must not compete against other requests.
The old eight Gaussian candidates and relative-to-best admission can omit valid
instances and cannot abstain merely because every candidate is irrelevant.

Use the same SemanticMeasure state for an explicit text_union interface. Compare
each source-derived native atom to current foreground and generic background
directions before spatial integration; no top-k or best-mode-relative semantic
gate. Integrate through its Gaussian association, then optionally corroborate
with the unchanged common member function using the same bounded support rank
as category readout. This latter composition is a hypothesis, not a calibrated
probability or proof that common member support is correct. Its candidate domain
remains the old finite set and is disclosed independently of semantic coverage.

One Gaussian field owns all state; no source RGB, raster mask, camera or old
query-dependent solver at runtime. Background directions are current query
program inputs. Independent text requests are never normalized against each
other. Mean and measure controls preserve every source/atom and differ only in
whether max-background/sigmoid admission precedes spatial integration.

The legal query-free region-to-Gaussian operator is compiled by the v10 rendered
observation primitive with physical camera scale, now for LERF sources. Replay
pixel-side source responses before projection against field-side contraction.
This is NOT migration of v10's text detector, its query-trained two-scalar head,
its online source fitting or complete-instance union decision. Preserve these
missing capabilities, cost and real actual-selection results. No default
promotion, novelty-by-packaging or full-five claim follows from this experiment.
