# ADR0042：共享证据核心与五项任务的能力保留迁移

日期：2026-10-18。状态：实施中；公共核心第一版及组件检查已完成，完整新评估和教师替换待执行。
实施记录见 [第一阶段迁移报告](../experiments/2026-10-18-shared-evidence-migration.md)。
依据：用户本轮明确要求一套实际共用的核心框架、任务适配器、五项重新评估及性能保留。
延续 ADR0024 的 v10 方法归属和分类型读出，扩展 ADR0041 的论文组织。
本文件不更改已封存实验、推理默认值或历史论文数值。

## 一、要统一什么

目标是“共享三维证据底座 + 查询条件的证据编译核心 + 分类型响应后端”。
SAM 提供区域能力，SigLIP2 提供语义对应，DINO 提供局部对应。三个职责不要求
每条查询调用三个模型，也不要求共享特征坐标或完整 DINO 三维场。

统一的科学问题是：局部查询证据怎样在身份与范围均有约束的条件下形成完整响应？
具体机制是：先确定证据的查询适用性、支持／排除权限和作用域，再在保留来源与
几何关系的条件下聚合，最后按实际输出契约恢复响应。统一损失不是目标。

现有实现已拥有部分组件，但还不能声称完成了这次统一：
- typed_evidence.py 有像素到元素算子、可见域、正负域；
- response_reconstruction.py 接收已经准入的证据，负责共识与 Huber 拟合；
  它本身不判断身份、不决定负证据权限；
- native_observation_prior.py 已经在区域内对完整类别菜单 softmax，再投影聚合；
- anchor_observation_evidence.py 保留同视图嵌套掩码的投票、分歧和共同可见性；
- direct_anchor_membership.py 的 15 维证据及学习式成员头必须保留；
- pipeline/cohort.py 已有队列入口，但 ScanNet 默认走十景 mesh，不等于用户要求的八景 Gaussian 主协议；
- UQIS score_selections 已有四路共同成功、两两集合 IoU、共同真覆盖、
  共同误选、并集误召回和身份／范围诊断，无需重新发明评分器。

## 二、四层实现边界

### 1. EvidenceStore：公共观察底座

保存来源视图、区域与成员关系、原生教师描述子、稀疏几何贡献、可见域、
同视图或同来源的分组，以及可追溯的构建配置。公共 schema 不等于将所有旧地图复制一份。
第一步用只读适配器连接现有数据；数据格式迁移与科学机制修改分开。

底座包含两个寿命不同的部分：
- 静态地图：合法建场视图的区域、描述子、贡献、可见性及成员关系；
- 查询临时证据：文本引导掩码、参考修复、跟踪响应、查询局部对应。
  查询临时证据不伪装成查询无关的预计算地图。

不能只保存区域到元素的一个平均权重。对于像素监督的 NVOS 和选集渲染，
必须保留或能从原几何重新构造相应分辨率的像素／射线关系。
几何适配器分别提供线性观察算子与真实选集渲染；选集移除改变透射率，
不能把整场的归一化线性算子直接当成选集渲染器。

Gaussian 和 RGB-D/mesh 几何适配器共享观察接口，不宣称输入条件相同。
SAM 区域生成与几何适配分开，源帧选择和观测分辨率属于显式建场配置。

### 2. QueryEvidenceProvider：按合法输入产生候选证据

建议查询类型为 text、category_menu、reference_image、signed_reference、
point_2d、point_3d。由能力与输入许可选择 provider，不由核心内部按 benchmark 分叉。

每条证据至少包含：
- source/view/group、teacher、原生匹配值及其语义；
- 目标响应、观测域、支持域、排除域、未知域；
- 排除依据：用户负标记、模型区域补集、类别互斥或其他预测依据；
- 几何贡献和实际作用的空间／像素域；
- 是否为显式用户锚点，还是模型推断的身份假设；
- 数值权重的用途、构建／查询阶段成本及资产来源。

“允许读取”和“本次实际使用”都应记录。已标记的 user-negative 与自动预测的负证据
不能共用一个没有来源的字段。对图像裁剪不能读取原始查询帧、完整背景、位姿或隐藏配对信息。

### 3. EvidenceCore：必须真正共用的计算

建议公共核心完成：
1. 校验观测域、权限和贡献坐标；
2. 应用查询条件准入策略，保留被拒绝证据的 unknown 语义；
3. 编译支持／排除／未知，记录负证据依据；
4. 按原视图分组处理嵌套掩码，避免重复掩码充当新增独立观测；
5. 累计正负质量、可见质量、响应矩、覆盖和冲突；
6. 输出与后端对应的 admitted terms、稀疏区域关系和分组统计。

布尔适用域、可见域、权限可以作集合交；这不是“多个置信概率相乘”。
原生匹配、SAM 质量和几何贡献保持各自意义。数值强度按明确的 provider 策略处理，
初期精确保留旧权重；统一校准或新权重必须作为独立方法实验。
支持质量是证据量，不自动解释为准确率或概率。

公共结果不能只有一个平均响应：UQIS 完整成员还需要逐视图嵌套分歧和几何条件；
类别后端需要完整菜单；迭代后端需要未丢失的观测项。允许类型化扩展，避免有损统一。

“真正共用”的验收：五项运行轨迹调用同一个编译／累计实现；相同开关在适用任务中
改变同一种证据操作；核心没有 if benchmark 分支。候选提议和最终损失可以有适配器。
不适用某个控制的任务记 N/A，不把未变化输出写成该机制的成功验证。

### 4. ReadoutBackend：保留实际返回能力

- SemanticResponse：连续语义响应、类别竞争与类别赋值；
- RenderedMembership：独立三维成员及真实选集轮廓优化／重渲染；
- AnchorMembership：保留现有监督、完整载体与学习式成员恢复；
- ViewConditionedResponse：NVOS 声明目标 RGB 权限的参考传播及 native-ray 拟合。

类别竞争发生在区域内、聚合之前；不是换成平均特征后分类。
完整成员头不能改成公共响应阈值而声称等价。
无观测时的行为由显式输出策略声明：保留先验、置零、未知掩码不可混写为同一语义。

## 三、五项接入与报告

| 任务 | 公共核心之前 | 核心之后 | 主报告 |
|---|---|---|---|
| LERF 2D | 保留既有 SAM 区域与 SigLIP2 查询身份处理；DINO 对应为可选新机制 | 连续响应渲染 | 4 场景 208 观测，mIoU、定位准确率；AP 可附报 |
| LERF 3D | 与 2D 使用同一证据包及版本，不另造教师流程 | 既有独立成员优化与实际选集重渲染 | 投影 IoU、Acc@0.25；不是体积真值 3D IoU |
| ScanNet OVS | 区域内完整类别菜单竞争，再向元素聚合 | 类别分配与固定评估器 | 正文八景 Gaussian 的 19/15/10 mIoU、mAcc；十景 mesh 保留为历史回归诊断 |
| NVOS | 合法正负涂画、DINO 局部参考证据、SAM 修复与传播 | 固定 native-ray 响应拟合；直接图像结果另报 | 8 任务 IoU/AP、逐任务变化、两种已有 GT 口径 |
| UQIS | 文本候选；图像全局与局部对应；2D/3D 点的合法锚点 | 保留文本范围读出和图像／点的完整成员头 | 9 房间 67 目标 268 查询，各路 IoU/AP、共同成功、一致性与误召回 |

ScanNet 主配置的“单 SigLIP2”指单一语义教师；SAM 区域能力仍在，DINO 局部对应若启用
也须披露，不能将其表述为全系统只有一个模型。Mask-Adapter 只作为替换教师验证。

## 四、必须分开的两条基准线

H：历史能力回归。冻结原 v10 四类队列及五项输出，另外冻结 NVOS N14 质量策略这一
目标 RGB 扩展的完整八任务结果。v10 与 N14 输入不同，不能用差值归因 DINO。

C：同输入的机制对照。固定地图／几何、教师版本、源视图、用户输入、候选预算、
输出定义和评分方式，只改变声明的核心操作。

新的 ScanNet 单 SigLIP2 主配置与历史双原生配置有实质能力差异。
ADR0024 保留双原生能力作为既有方法事实；用户现在要求单 SigLIP2 作为目标主配置。
两者通过显式 profile 区分，不覆盖历史配方：
- parity profile：双原生教师、原权重与原输出不变，验证迁移；
- proposed main profile：单 SigLIP2 语义教师，重新报告实际性能；
- replacement-teacher profile：Mask-Adapter 替换 SigLIP2，验证教师可迁移性。
先做上述对照，再单独开 DINO。不能把单教师化和 DINO 加入合成一个无法归因的变化。
若单教师下降，恢复机制能力或明确报告取舍；不能继承双教师的成绩，也不能预先保证不降。

## 五、迁移顺序与停止条件

### M0：冻结输入和评价矩阵

保留代码、配置、教师／几何哈希、源视图、原始输出／评分契约及历史结果。
增加正文八景 Gaussian 的独立评分 profile，十景 mesh 不做替换比较。
列出新配置继承了哪些能力、哪些地方改变输入，尤其是 NVOS 负提示／目标 RGB、
UQIS 学习式成员监督和 ScanNet 单教师化。
阶段产物是可运行的冻结队列与差异表，不是再写一份只有框图的说明。

### M1：按原配置做功能等价迁移，再完整重评五项

先实现 EvidenceStore 只读适配器与公共编译核心，并让五项实际调用。
保留原输入、权重、数值精度、操作顺序、阈值和后端。
逐级比较区域响应、贡献／可见质量、正负统计、成员特征、最终连续值与返回集合。
纯迁移优先要求离散输出一致；浮点容差用固定输入的重复运行确定，不能看 GT 后放宽。
先做小规模差分定位，再跑完整队列，不用仅通过单任务来宣布迁移成功。
历史分数是比较基准；统一实现必须产生新的预测，不能复用旧答案冒充重评。

### M2：先做两个有信息量的局部对应／区域修复实验

NVOS：
- 直接 SAM 与 DINO 辅助参考修复使用完全相同的正负涂画、源／目标 RGB 权限、
  点提示预算、候选预算、参考侧选择规则、传播器、后端与读出；
- 第一项只改变 DINO 产生的局部对应／参考先验。
  框生成若随之改变，须显式作为干预的一部分或单列控制，不能称纯 DINO 特征消融；
- 后端优化在同一批封存图像响应上另做对照。
- 原 N14 主／次策略历史身份保持；新实验在运行前声明固定候选选择规则。
- 这项归因实验不重启已经停止的 N15 权重搜索或 N16 crop 参数搜索。

UQIS 图像：
- 首个低成本控制是仅对公开交付的查询裁剪图做 SAM 前景净化，比较现有
  SigLIP2+DINO 路径与净化后局部对应；地图、候选域、成员头、阈值保持一致；
- 若改变 DINO 的局部对应与 SigLIP 区域汇聚两项，先只改变一个，或明确为复合干预；
- SAM 只能用该裁剪中的信息；自动提示不是用户真值，没有额外负标注；
- 净化候选预算、选择规则和失败回退必须事先固定，不按任务 GT 选择；
- 地图侧区域再分割若需要源图像，放在合法建场阶段生成派生区域与描述子，
  将它作为后续独立干预；不在 map-only 查询阶段重新打开源 RGB；
- 全部 67 图像查询统一规则；每个集成候选都重新评估四路 268 查询。
  同目标配对只在 evaluator 使用，不参与推理或跨模态答案投票。

两项若无净收益，停止该配置的扩展，不将同一假设直接铺到 LERF/ScanNet。

### M3：跨任务能力验证

LERF 在相同公共证据包上开 DINO 跨视图对应，2D 与 3D 一起重新评估。
ScanNet 先完成单教师对照，再决定是否测试 DINO 区域对应。
所有模块按查询能力和输入合法性启用；论文不能把只在 NVOS 有效的模块写成全任务必选。

### M4：冻结统一候选后完整重评

一个版本、一个声明的配方、明确的任务适配器，重新执行五项。
输出按任务分组的完整回归表和逐场景／逐查询明细。
方法变化允许查询间有得失，但不能用一个 benchmark 的提升抵消另一个 benchmark 的下降，
也不能用 IoU 上升遮住 AP 下降。任何“性能保留”结论必须基于事先声明的逐项验收标准。
当前队列仍是已用于研发的队列，不能把先预测后评分误称为独立泛化测试。

## 六、核心消融与成本

公共开关按操作定义，不按 benchmark 名字定义：
- 查询候选身份准入；
- 支持／排除／未知的处理；
- 同视图区域分组与重复计数控制；
- 参考或查询区域的范围修复；
- 公共证据与既有完整成员能力的连接。

仅在有定义的路径做该消融；真实点不需要伪造语义候选准入。
固定输入／证据的后端对照单列，不与上游教师变化混合。

统一记录建场总时间和各教师耗时、地图实际字节、派生缓存字节、冷／热查询延迟、
峰值 GPU 显存与 CPU 内存、教师调用次数。成本属于完整配方，不遗漏外部缓存。
静态地图共享引用，临时像素响应／稠密预测在有界空间流式处理；保留配置、源码、
哈希、指标、必要的压缩选集与统一规则选出的案例，不复制完整教师缓存。
原大规模历史实验不因本次设计而删除。

## 七、完成定义

完成不是“所有入口都叫同一个函数”，而是：
1. 五项共享实际执行的证据编译、分组累计和来源语义；
2. 差分回归证明旧能力没有在接口转换中丢失；
3. 适用任务的共同开关有一致含义、可追踪的中间变化及独立评分；
4. 类型后端保留真实成员、原生类别竞争和合法输入；
5. 统一候选的新五项预测、精度、成本与失败归因一起报告。

当前最先应交付 M0/M1；M2 的两个受控实验随后开展。
将本文件作为后续实现边界，尚未实现的内容不得写进论文完成时态。
