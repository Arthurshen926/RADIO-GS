# TMM working paper: query-conditioned partial-evidence fusion

Active branch: `codex/tmm-query-response`. Updated 2026-10-16.

**凝练结论：方法主线与系统职责已经明确；统一准入算法的跨教师、跨 query 增益尚未闭环。**
本篇名称收敛为“查询条件下的部分证据融合”。研究一个问题：已有查询响应有用但不完整时，
**一条观察是否适用于当前目标、在哪些位置有资格修改它？** 教师、特征场、几何、完整成员
提供器及输出语义保持固定。方法只在响应形成环节研究证据准入及其作用范围。

### 一个机制的三个连续决策

1. **身份适用性：这是不是当前 query 所要的证据？** 在同一查询的合法候选内部判断，
   而不是用全场景相似度阈值排除所有弱响应。已有文字路径使用单/双分布证据加权；
   没有足够分组依据不强行拒绝，拒绝区域记录为未知。该具体规则已有文字实证，
   尚不能说同一个分布模型已适用于参考图、类别和点击。
2. **空间权限：它能说明这个目标的哪些部分？** 区分支持、允许排除和未知，同时保留
   可见域及可靠度。识别对了实例不等于掩码范围完整；区域包含一个正确点，也不等于
   区域所有元素都属于目标。原 v10 的负例可靠度、原生正支持保护及完整成员能力要保留。
3. **几何融合：让获准证据进入实际响应。** 在固定对应关系上融合，缺少证据时保持原有
   判断或原协议的弃权行为。简单融合和原稳健求解属于数值后端；不再把所有任务强行
   换成一个逆求解器作为创新目标。最终连续响应、独立实例集合及类别竞争分别按原语义读出。

三步处理同一条证据，不是新增三个网络。“正证据只能增分”只是已测的后置假设，
不作为本方法的定义；共用数据结构也不能替代共用算法的验证。

## 一个机制及其实现边界

```mermaid
flowchart LR
  F[冻结教师与场景] --> P[保留原生匹配、身份与完整成员能力]
  Q[合法文字、图像、点输入] --> P
  P --> R[融合前响应先验]
  P --> A[查询条件的证据适用性]
  A --> B[空间权限：支持、排除、未知]
  B --> C[固定几何上的响应融合]
  R --> C
  C --> O[语义、参考、类别响应]
  P --> M[UQIS 完整成员响应：兼容保留]
  P --> S[独立实际选集：本轮冻结]
```

上图是方法职责抽象，尚不表示全部任务已经接入同一个成功的准入算法。共同输入是响应先验、
观测响应、固定对应矩阵与已准入权重；教师向量不必同维，求解核不接收 benchmark 名称。
UQIS 没有同样的栅格重建阶段，本轮保持完整成员能力并重评分；这只证明兼容性。

1. **查询适用性。** 复用原生文本匹配、图像局部对应或合法点支持，判断观察是否适用于本次目标。
   被拒绝的区域不会因“被拒绝”自动成为目标的负例。
2. **保留证据语义。** 先保留 v10 实际使用的未知域、负证据可靠度、原生正响应保护及双教师先验。
   “前景只能增分”的单向约束属于已测的后置修正假设，并非全部有效旧路径的共同属性。
3. **响应生成。** 在相同准入目标与权重下比较反投影、显式平方误差重建和稳健重建。
   将投影混合、稳健损失与证据准入分开检验，避免把重复使用上游证据当作新能力。

共同代码包含以下已实现路径：

- `AdmittedResponseSystem`：原响应生成位置的三组对照；原稳健求解入口调用兼容包装。
  ScanNet 通过显式捕获接口复用同一套生产证据及两个教师先验。

- `fuse_admitted_evidence`：抽出已有有效可见性融合，LERF 旧入口已调用；保持旧准入策略。
- `refine_response`：共用部分证据原型，按有效残差质量归一化；全队列 v1 已证实会退化。
- `VisibilityNormalizedRefiner`：保留相同许可与残差分子，按可用观察域归一化，弱置信度
  不再自行抵消。未知位置只参与归一化、不给负梯度；无证据保持原响应。
- `SupportAgreementRefiner`：按冻结完整范围与整条观察的一致性分配更新；匹配正负
  总修正量的均匀控制已完成。UQIS 未体现净收益，保留为否定性机制对照。

`response_permissions.py` 与 `response_study_adapters.py` 已完成四种输入协议适配；
共同核不根据 benchmark 选择公式。当前合计 45 项相关测试通过，包括数值核心、实际双教师捕获及暂存恢复。

兼容核心的四场景完整复放已完成：764 个源视角、68 个查询列（67 个有标注文本及
1 个无标注探针）。相对历史响应最大差异 **4.77e-7**，Gaussian 响应的 0.5 阈值位差
为 **0**，原实际选集张量全部相同。只做数值复放，没有新增目标 GT 评分。
记录为 `output/tmm_response_20261016/study/legacy_core_replay_v2/summary.json`。

新原型已完成全部任务的适配与评分，但**共同准入的性能有效性尚未闭环**。
现有身份筛选和范围模块作为固定提供器保留。v2 置信度为 [0,1] 内的证据权重，
影响绝对更新幅度，不声称概率校准或保证精度不下降。

## 集中补齐的实验

完整队列固定为 LERF4、NVOS8、ScanNet10、UQIS9/四种输入；每个候选都报告全体反馈。
不重新扫描教师维度、码本、场景重建或特征训练损失。

| 要验证什么 | 固定输入下的对照 | 主要观察 |
|---|---|---|
| 已有有效行为完整迁移 | 原 v10 路径与抽出的兼容核心 | 响应数值、实际集合、最终任务指标 |
| 部分证据修正有效 | 原响应、原有简单融合、共同修正 | IoU/AP、纠错与破坏、无支持弃权 |
| 查询准入确实有用 | 去身份条件、等数量且匹配观察量的随机过滤 | 相同证据预算下的净收益 |
| 排除权限有用 | 未知当负例、仅正修正、明确正负许可 | 漏检补全和误检排除是否兼顾 |
| 规则可迁移 | 合适的至少两种教师配置；文字、参考图像、点 | 固定更新公式，合法输入保持一致 |
| 可用于新场景 | 设计完成后冻结，在未参与调整的场景评估 | 场景区间、失败案例、额外时间/内存 |

已完成的实验遵循冻结同批预测、统一评分；后续保持同一流程。
如果某任务没有可用额外证据，原样返回是合理行为，但该行不计为新机制的正向证据。
只有输出被新机制实际改变并经过对照的行才能进入新方法消融表。
